# 32장: 에너지 기반 모델

에너지 기반 모델(EBM)은 스칼라 에너지 함수로 확률 분포를 뜻매김하며, 볼츠만 분포를 거쳐 에너지가 낮을수록 확률이 높다. 이 너그러운 틀은 에너지 함수 구조에 사실상 제약을 두지 않아 에너지 기반 모델을 생성 모델 무리를 아우르는 관점으로 만든다. 이 장은 통계 물리학에서 온 이론 기초, 볼츠만 기계와 홉필드 신경망 같은 고전 구조, 다룰 수 없는 나눔 함수를 비켜 가는 학습 방법, 요즘의 신경망 에너지 기반 모델, 그리고 계량 금융에서의 쓰임새를 다룬다.

---

## 1. 에너지 기반 모델의 기초

- 에너지 기반 모델 들어가기 -- 에너지 기반 나타내기의 핵심 원리, 에너지와 확률의 이음, 한가운데 계산 어려움.
- 에너지 기반 모델 살펴보기 -- 에너지 기반 모델 이론, 짜기, 요즘 생성 모델과의 이음을 두루 다루는 학습 꾸러미.
- [볼츠만 분포](ebm_foundations/boltzmann.md) -- 최대 엔트로피 원리에서 유도, 온도의 영향, 지수 무리와의 이음.
- 에너지 함수 -- 에너지 함수의 엄밀한 정의, 바람직한 성질, 신경망 매개변수화.
- [분배 함수](ebm_foundations/partition_function.md) -- 다룰 수 없는 고르게 맞추는 상수, 분포 앎을 담는 몫, 근사 방법.

---

## 2. 고전 에너지 기반 모델

- [볼츠만 기계](classical_ebm/boltzmann_machines.md) -- 확률 이진 단위, 깁스 샘플링, 홉필드 신경망에서 생성 모델로의 넓힘.
- [제한 볼츠만 기계](classical_ebm/rbm.md) -- 다룰 만한 조건 분포를 가진 두 쪽 구조와 Contrastive Divergence 학습.
- 깊은 볼츠만 기계 -- 켜진 나타냄과 평균장 변분 추론을 갖춘 여러 층 방향 없는 모델.
- [홉필드 신경망](classical_ebm/hopfield.md) -- 무늬를 담고 되찾는 데 에너지 최소화를 쓰는 에너지 기반 이어 떠올림 기억.

---

## 3. 에너지 기반 모델 학습

- Contrastive Divergence -- 데이터에서 시작한 짧은 마르코프 사슬 몬테카를로로 다룰 수 없는 최대 우도 기울기를 실제로 어림하기.
- 이어지는 Contrastive Divergence -- 덜 치우친 음의 국면 표본을 얻으려 고침에 걸쳐 마르코프 사슬을 이어 가기.
- 에너지 기반 모델의 스코어 매칭 -- 점수 함수를 맞추어 에너지 함수를 익히며 나눔 함수를 아예 피하기.
- 잡음 맞댐 어림 -- 밀도 어림을 데이터와 잡음 사이의 이진 분류로 줄이고 덤으로 나눔 함수를 학습하기.

---

## 4. 요즘 에너지 기반 모델

- 신경망 에너지 기반 모델 -- 랑주뱅 동역학과 되돌림 곳간으로 익히는 에너지 함수로서의 깊은 신경망.
- 결합 에너지 모델(JEM) -- 분류기의 로짓을 에너지 함수로 다시 읽어 분류와 생성을 하나로 묶기.
- [협력 학습](modern_ebm/cooperative.md) -- 서로 보완하는 힘을 살리려 에너지 기반 모델을 오토인코더, 변분 오토인코더, GAN과 합치기.
- 분류와 그 너머의 에너지 기반 모델 -- 에너지 점수를 쓴 분포 밖 찾기, 얽어 생성, 그림 잡음 없애기.
- 확산 모델과의 이음 -- 스코어 기반 생성로 에너지 기반 모델과 확산 모델을 수학으로 하나로 묶기.
- [에너지 기반 생성](modern_ebm/generation.md) -- 랑주뱅 동역학과 해밀턴 동역학으로 배운 에너지 풍경에서 샘플 생성.

---

## 5. 금융에서의 쓰임새

- 이상 찾기 -- 에너지 기반 이상 점수로 예사롭지 않은 거래 무늬와 드문 시장 사건 찾기.
- 금융의 밀도 어림 -- 두꺼운 꼬리와 정규가 아님을 담는 금융 수익률의 너그러운 비모수 밀도 어림.
- 에너지 기반 꾸러미 최적화 -- 수익 목표와 위험 패널티를 담아 꾸러미 최적화를 에너지 최소화로 적기.
- [신용 네트워크 모델](finance_applications/credit_networks.md) -- 체계 위험을 살피려 볼츠만 기계 구조로 신용 부도 매임을 나타내기.
