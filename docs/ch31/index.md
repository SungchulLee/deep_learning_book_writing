# 32장: 에너지 기반 모델

에너지 기반 모델(EBM)은 스칼라 함수 E(x)와 정규화 상수를 이용해 p(x)∝exp(−E(x))를 정의한다. 낮은 에너지에 높은 밀도를 주는 유연한 표현이지만, 정규화 가능성·모델 기댓값 계산과 샘플링의 혼합이 핵심 과제다. 이 장에서는 분포의 정의에서 고전 이진 모델, 뉴럴 넷트웍 학습과 생성·응용으로 이어 간다.

<div class="storybox" markdown>

**그림으로 보는 AI 1.** 이 장의 말은 거의 다 빌려 온 것이다

에너지, 온도, 자유 에너지, 분배 함수, 평형, 담금질. 이 장의 차례를 훑으면 기계학습 용어보다 **열역학 용어**가 많다. 비유를 들자고 가져온 말이 아니다 — 이 장의 방법들이 실제로 물리에서 걸어 나왔다.

![가로로 뻗은 시간선에 일곱 사건이 찍혀 있다. 왼쪽 파란 둘은 물리로 1925년 이징의 1차원에서는 상전이가 없다는 결과와 1944년 온사거의 2차원에는 있다는 결과다. 오른쪽 호박빛 다섯은 기계학습으로 1982년 홉필드의 에너지 최소점으로서의 기억, 1985년 애클리·힌턴·세즈노스키의 볼츠만 기계, 1986년 스몰렌스키의 하모니움, 2002년 힌턴의 대조 발산, 2005년 휘바리넨의 스코어 매칭이다. 두 무리 사이에 38년이 비어 있다고 적혀 있다. 칸 사이는 고르게 두었고 실제 연도 비례가 아니라고 적혀 있다.](figures/lineage.svg)

연표의 앞 둘은 자석을 설명하려던 계산이다. 뒤 다섯이 이 장의 각 절이고, 그 사이에 **38년**이 비어 있다. 홉필드가 1982년에 한 일은 새 수식을 만든 것이라기보다 **이미 있던 물리의 언어로 기억을 적은 것**에 가까웠다.

빌려 온 것이 말만은 아니다. 어려움도 함께 왔다. 분배 함수 $Z$ 는 물리학자들이 한 세기 동안 씨름한 바로 그 양이고, [분배 함수](ebm_foundations/partition_function.md) 쪽이 보이듯 그 이름부터가 "상태를 모두 더하라"는 뜻이다.

**그런데 여기서 갈린다.** 물리에서 $Z$ 는 **구하고 싶은 것**이다 — 거기서 자유 에너지와 비열 같은 관측량이 나온다. 학습에서 $Z$ 는 **피하고 싶은 것**이다. 그래서 3절의 방법들은 전부 "$Z$ 를 셈하지 않는 서로 다른 방법"으로 읽힌다. [CD](ebm_foundations/05_contrastive_divergence.md)는 표본으로 비껴가고, [스코어 매칭](ebm_foundations/06_score_matching.md)은 입력으로 미분해 지워 버리고, NCE는 아예 모수 하나로 바꿔 세운다. 같은 산을 두고 물리는 오르려 했고 학습은 돌아가려 한다.

**그러니 빌려 온 말을 끝까지 믿으면 안 된다.** 이 장의 쪽들이 거듭 같은 경고를 하는 까닭이 거기에 있다 — 코드의 "온도"가 열역학의 온도와 계수가 다를 수 있고, 격자로 셈한 값이나 짧은 사슬이 돌려준 값을 정확한 $Z$ 나 우도로 읽으면 안 된다고. 말은 물리에서 왔지만 **보증까지 따라오지는 않았다.**

_확인한 곳 — 연표의 일곱 해는 모두 이 장의 해당 쪽에서 원문을 확인한 것이다. Ising 1925 와 Onsager 1944 는 [볼츠만 분포](ebm_foundations/boltzmann.md), Hopfield 1982 는 [홉필드](classical_ebm/hopfield.md), Ackley·Hinton·Sejnowski 1985 는 [볼츠만 기계](classical_ebm/boltzmann_machines.md), Smolensky 1986 은 [RBM](classical_ebm/rbm.md), Hinton 2002 는 [CD](ebm_foundations/05_contrastive_divergence.md), Hyvärinen 2005 는 [스코어 매칭](ebm_foundations/06_score_matching.md) 쪽의 상자에 각각 출처를 적어 두었다. 그림의 칸 사이는 고르게 두었으므로 연도에 비례하지 않는다._

## 1. 분포와 정규화의 기초

[볼츠만 분포](ebm_foundations/boltzmann.md)는 에너지·온도·확률비와 최대 엔트로피 원리를 연결한다. 이산·연속 공간의 온도 극한과 스코어의 부호를 구분한다. [분배 함수](ebm_foundations/partition_function.md)에서는 열역학 관계, 격자 적분, AIS와 변분 자유 에너지를 다룬다.

입력 미분에서 Z가 사라져도 파라미터 미분에서는 일반적으로 남는다. 격자 계산이나 짧은 사슬이 반환한 값을 정확한 정규화 상수·우도로 읽지 않는 것이 다음 학습법을 이해하는 출발점이다.

## 2. 고전 이진 모델

| 모델 | 읽을 내용 |
|---|---|
| [홉필드 뉴럴 넷트웍](classical_ebm/hopfield.md) | 비동기 에너지 감소, 기억 검색과 저장 용량·허위 기억 |
| [볼츠만 기계](classical_ebm/boltzmann_machines.md) | 확률적 단위 갱신, 변수 부호와 온도·조건부 확률의 대응 |
| [제한 볼츠만 기계](classical_ebm/rbm.md) | 이분 그래프, 조건부 독립과 가시 자유 에너지 |
| [MNIST RBM 학습](ebm_foundations/04_restricted_boltzmann_machines.md) | 이진화, CD-1 통계 업데이트와 persistent chain |

0·1 변수와 −1·+1 스핀은 에너지·시그모이드 계수가 다르다. 조건부를 쉽게 계산하는 RBM에서도 전체 분배 함수는 어려울 수 있다. 재구성, 고정점 검색과 평형 생성도 서로 다른 작업이다.

## 3. 뉴럴 넷트웍 모델의 학습

[Contrastive Divergence](ebm_foundations/05_contrastive_divergence.md)는 데이터에서 시작한 짧은 사슬과 모델 기댓값의 차이를 설명한다. PCD는 사슬을 이어 가지만 혼합과 학습 중 파라미터 변화의 문제가 자동으로 사라지는 것은 아니다.

[스코어 매칭](ebm_foundations/06_score_matching.md)은 입력 그래디언트 학습을 다룬다. 에너지의 부호, trace 계수와 활성화의 정규성 조건이 중요하다. [뉴럴 넷트웍 EBM](ebm_foundations/07_neural_ebms.md)에서는 CNN 에너지와 짧은 랑주뱅 사슬을 연결하고 실제 업데이트 예산·온도 계수와 평가 범위를 확인한다.

## 4. 생성기와의 결합 및 생성 방법

[협력 업데이트 예제](ebm_foundations/08_cooperative_training.md)는 생성기 초기화, 에너지 기반 수정과 수정 결과 모방을 연결한다. [다른 뉴럴 넷트웍과의 결합](modern_ebm/cooperative.md)은 오토인코더·VAE·분류기와 결합할 때의 분포·로스·그래디언트 조건을 다룬다.

[에너지 기반 생성](modern_ebm/generation.md)은 ULA·MALA·HMC·병렬 템퍼링과 조건부·제약 생성을 비교한다. 초기값의 범위, 유한 벌점과 정확한 지지집합을 구분하며 스텝 바이어스·혼합·실효 표본 수를 함께 살핀다.

## 5. 응용과 모델 간 연결

[응용 예제](ebm_foundations/09_ebm_applications.md)는 OOD 점수, MAP 복원·인페인팅과 에너지 조합을 다룬다. 낮은 에너지가 항상 정상 입력을 의미하거나 에너지 합이 정확한 의미론적 교집합을 만든다고 가정하지 않는다.

[확산·흐름·잠재변수 연결](ebm_foundations/10_advanced_ebm_topics.md)은 스코어의 적분 가능성과 새로운 정규화 상수, 결합 우도와 주변 우도의 차이를 설명한다. [신용 네트워크](finance_applications/credit_networks.md)는 이진 의존성의 교육용 예이며 통계적 조건화와 인과 전염, 부도 개수와 금액 로스를 구분한다.

## 정리하며

에너지 모델의 장점은 같은 스칼라 표현으로 분포·학습·최적화·생성을 연결할 수 있다는 것이다. 각 연결에는 정규화, 변수·온도 관례와 올바른 전이 조건이 필요하다. 페이지별 코드가 구현한 범위와 설명된 제한을 확인하고, 로스 값·재구성 오차·평형 표본·테스트 우도를 구분해 평가한다.
