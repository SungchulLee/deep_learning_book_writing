# 45장: 모델 배포

이 장은 딥러닝 모델을 서비스에 내놓는 온 삶을 다룬다. 갈무리와 다듬기에서 서비스 기초, 흩어 계산, MLOps 결에 이른다. 늦음, 나름, 미더움이 거래 성능과 위험 다루기에 곧바로 걸리는 계량 금융에서는 잘 드는 내놓기가 중요하다. 이 장은 연구 공책의 모델을 서비스 구조로 옮기는 손에 잡히는 길잡이를 준다.

---

## 1. 갈무리하기

학습된 모델을 여러 자리에 내놓으려고 담고, 부르고, 내보내기.

- 모델 담기 -- PyTorch에 든 담기 구조와 서비스에 내놓을 때의 자리를 넘나드는 옮김
- 상태 사전 -- 모델 담기, 옮겨 학습하기, 디버깅에 쓰는 PyTorch의 여느 매개변수 갈무리
- TorchScript -- C++, 손전화, 박아 넣는 데에 내놓을 파이썬 없는 갈무리할 수 있는 모델 만들기
- ONNX 내보내기 -- 틀과 쇠 붙임새를 넘나들며 모델을 내놓는 열린 신경망 주고받기 꼴
- 되살림 자리 만들기 -- 오래 도는 일에서 되살리기, 살피기, 모델 고르기에 쓸 온전한 학습 상태 담기

---

## 2. 다듬기

잘 드는 추론을 위해 모델을 누르고 빠르게 하기.

- [양자화](optimization/quantization.md) -- FP32에서 INT8/INT4으로 수의 촘촘함을 줄여 자리를 아끼고 추론을 빠르게 하기
- 모델 쳐내기 -- 군더더기 매개변수를 없애 기억과 계산이 적은 성긴 모델 만들기
- [지식 증류](optimization/distillation.md) -- 큰 스승 모델의 앎을 작고 내놓기 좋은 제자 모델로 옮기기
- [신경망 아키텍처 탐색](optimization/nas.md) -- 맞음, 늦음, 모델 크기를 다듬는 저절로 하는 구조 꾸미기

---

## 3. 추론 다듬기

모델이 미루어 볼 때 나름을 가장 크게 하고 늦음을 최소화.

- CPU 다듬기 -- CPU만 쓰는 자리를 위한 실 차림, 연산 녹이기, 그 밖의 다듬기
- TensorRT으로 하는 GPU 다듬기 -- 낟알 저절로 맞추기, 촘촘함 다듬기, 켜 녹이기를 하는 NVIDIA TensorRT
- 배치 추론 -- 입력 여럿을 한꺼번에 다루어 쇠 붙임새를 가장 많이 쓰기
- 기억 다루기 -- 기억 모자람 어긋남을 막고 늦음을 줄이는 GPU·CPU 기억 다듬기
- 흐르는 추론 -- 살아 있는 시장 데이터와 거래 신호를 위한 끊임없는 데이터 흐름의 제때 다루기

---

## 4. 서비스에 올리기

크기 늘리기, 판 매기기, 지켜보기를 갖춘 서비스로 모델 배포.

- REST API 서비스 -- 요청 묶기, 판 매기기, 옆으로 크기 늘리기를 갖춘 모델 서비스 틀
- gRPC 서비스 -- Protocol Buffers과 HTTP/2으로 하는 빠르고 늦음이 적은 모델 서비스
- TorchServe -- 움직이는 묶기와 여러 모델 다루기를 갖춘 PyTorch의 정식 서비스 틀
- NVIDIA Triton 추론 서비스개 -- GPU 차례 잡기와 모델 앙상블을 갖춘 기업 품질의 여러 틀 서비스
- BentoML -- 컨테이너 받침을 갖추고 서비스 품질의 AI 서비스를 짓는 파이썬 앞세운 틀

---

## 5. 흩어 계산

여러 GPU과 마디에 걸쳐 학습과 추론을 크게 늘리기.

- 데이터 나란히 -- PyTorch DataParallel으로 하는 한 흐름 여러 GPU 학습
- 분산 데이터 병렬 학습(DDP) -- AllReduce 알림으로 GPU 수백 개까지 크게 늘리는 여러 흐름 학습
- 모델 나란히 -- 큰 모델이 GPU 하나의 기억을 넘을 때 장치에 걸쳐 쪼개기
- 관 나란히 -- 잔 배치의 계산을 GPU에 걸쳐 겹쳐 여러 장치 학습을 잘 들게 하기
- 온통 쪼갠 데이터 나란히(FSDP) -- 매개변수, 기울기, 가장 좋게 하는 개의 상태를 쪼개 기억을 아끼는 흩은 학습
- DeepSpeed -- 매개변수가 수십억에서 수조인 모델을 익히는 마이크로소프트의 ZeRO 가장 좋게 하는 개

---

## 6. MLOps

서비스에서 머신러닝의 삶을 다루는 일의 결.

- 해 봄 좇기 -- 다시 해 볼 수 있게 하이퍼파라미터, 자, 산물을 짜임새 있게 적기
- 모델 등록소(MLflow) -- 모델 판, 자리 옮김, 내놓기 자리로의 올림을 다루기
- 머신러닝을 위한 CI/CD -- 모델 고침을 시험하고 익히고 따지고 내놓는 저절로 도는 흐름
- 서비스 지켜보기 -- 참 자리에 내놓은 모델의 성능, 몸 상태, 데이터 옮겨감 좇기
- 모델 A/B 시험 -- 서비스에서 모델 판을 견주며 활성화 자를 통계로 살피기

---

## 7. 금융 응용

계량 금융 구조에 남다른 내놓기 결.

- 서비스 흐름 -- 저자 달력, 회사 처분, 규정 요건을 다루는 끝에서 끝까지의 머신러닝 흐름
- 제때 구조 -- 거래 구조에서 늦음이 한결같은 모델 추론을 위한 구조 결
- 늦음 요건 -- 금융 쓰임의 늦음 예산, 재는 길, 다듬는 꾀
- 백테스팅 기초 -- 앞을 미리 보는 것과 살아남은 것만 보는 편향을 제대로 다루며 지난 데이터로 모델 성능 따지기

---
