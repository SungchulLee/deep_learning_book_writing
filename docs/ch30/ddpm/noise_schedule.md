# 노이즈 스케줄

노이즈 스케줄은 정방향 과정에서 원본 신호가 줄고 노이즈가 늘어나는 속도를 정한다. 같은 시간 인덱스라도 스케줄이 다르면 모델이 보는 신호·노이즈 비율이 달라진다. 데이터 스케일, 학습의 시간 선택과 로스 웨이트, 생성에 사용할 시간 목록을 함께 고려해야 한다.

## 1. β, 누적 신호와 SNR

정방향 가우시안 전이에서 βt는 한 단계의 노이즈 분산이며 보통 0<βt<1을 사용한다. αt=1−βt, ᾱ₀=1과 다음 누적곱을 정의한다.

$$\bar\alpha_t=\prod_{s=1}^t\alpha_s,\qquad
x_t=\sqrt{\bar\alpha_t}x_0+\sqrt{1-\bar\alpha_t}\epsilon$$

스케줄 계수의 SNR은 다음과 같다.

$$\mathrm{SNR}(t)=\frac{\bar\alpha_t}{1-\bar\alpha_t}$$

이는 원본의 좌표별 분산을 1로 보는 기준이다. 실제 신호의 분산·채널 스케일이 다르면 관측에서의 신호 대 잡음비도 달라진다. β는 한 단계, 1−ᾱ는 누적 조건부 노이즈 분산이므로 서로 같은 값이 아니다.

## 2. 선형 β 스케줄

T≥2에서 선형 스케줄은 다음과 같다.

$$\beta_t=\beta_{start}+\frac{t-1}{T-1}(\beta_{end}-\beta_{start})$$

[DDPM 논문](https://arxiv.org/abs/2006.11239)에서 사용한 대표 설정은 T=1000, 시작 10⁻⁴, 끝 0.02다. β가 작을 때 log ᾱt≈−Σs≤tβs이므로 **log 누적 신호의 감소는 누적 β**로 결정된다. 선형 β라면 그 합은 시간에 대해 대략 이차식이다. 누적 신호가 일정 비율로 감소하는 단순 지수식과는 구분한다.

후반 β가 커져도 데이터 신호가 이미 작으면 추가로 잃는 정보가 작을 수 있다. 이를 후반 단계가 실제로 노이즈를 거의 더하지 않는다고 표현하면 안 된다. 단계의 유용성과 품질은 모델·목적·시간 선택에서 평가해야 한다.

## 3. 코사인 누적 스케줄

[Improved DDPM](https://arxiv.org/abs/2102.09672)은 누적 신호를 코사인으로 설계하는 방법을 다룬다.

$$f(t)=\cos^2\!\left(\frac{t/T+s}{1+s}\frac\pi2\right),\qquad
\bar\alpha_t=\frac{f(t)}{f(0)}$$

$$\beta_t=1-\frac{\bar\alpha_t}{\bar\alpha_{t-1}}$$

대표적인 오프셋 s=0.008은 초기 노이즈가 지나치게 작아지는 것을 피하려는 선택이다. 모든 데이터 표현에 최적인 상수는 아니다. 마지막 β가 1에 가까워지는 것을 막으려고 상한 0.999를 두면 실제 β의 누적곱은 잘라내기 전 이상적인 코사인 곡선과 마지막 부근에서 다르다.

코사인 스케줄은 초기 신호 감소를 완만하게 설계할 수 있지만 모든 과제에서 선형보다 좋은 품질을 보장하지 않는다. 두 스케줄의 시간별 신호 곡선을 실제 설정으로 계산해야 하며, 조건 없이 고정된 누적 신호 표를 사용할 수 없다.

## 4. 이차·시그모이드 β 스케줄

이 페이지의 이차 스케줄은 **시간 비율의 제곱으로 β를 보간**한다.

$$\beta_t=\beta_{start}+\left(\frac{t-1}{T-1}\right)^2(\beta_{end}-\beta_{start})$$

β의 제곱근을 선형 보간한 뒤 제곱하는 다른 구현과 같지 않다. 같은 양 끝값에서 초반 β가 선형보다 작지만 누적 신호·품질이 선형과 코사인의 중간에 놓인다는 일반 법칙은 없다.

시그모이드 방식은 u를 −6에서 6까지 선형으로 놓고 β=βstart+(βend−βstart)sigmoid(u)로 만든다. sigmoid(−6)>0, sigmoid(6)<1이므로 **양 끝 β가 지정값에 정확히 닿지는 않는다**. 이름만으로 다른 패키지의 시그모이드 누적 스케줄과 동일하다고 볼 수도 없다.

## 5. 학습 가능한 시간 파라메터화

로그 SNR을 학습하는 접근에서는 시간이 증가할수록 신호가 감소하도록 단조성을 정한다. 양의 웨이트·단조 증가 활성화만으로 만든 MLP는 보통 증가 함수이므로 그것을 그대로 감소하는 log SNR이라고 부르면 부호가 맞지 않는다. 음의 log SNR을 증가시키거나 출력에 음수를 붙이는 등 정의를 명확히 해야 한다.

학습 가능한 스케줄과 적은 단계로 생성하도록 모델을 증류하는 것은 다른 설계다. 아래 코드는 고정 스케줄 함수만 제공하며 단조 뉴럴 넷트웍·증류·품질 비교를 구현하지 않는다.

## 6. 연속시간 VP와의 대응

연속시간 VP SDE에서는 다음과 같다.

$$dX_t=-\frac12\beta(t)X_tdt+\sqrt{\beta(t)}dW_t,\qquad
\bar\alpha(t)=\exp\!\left[-\int_0^t\beta(u)du\right]$$

작은 Δt의 이산 βk는 β(tk)Δt와 근사적으로 연결된다. 이산 β를 스텝 폭 없이 연속 β(t)에 그대로 대입하지 않는다. log SNR을 γ(t)라 두면 β(t)=−γ′(t)/(1+exp(γ(t)))다.

VE는 일반적으로 원래 신호를 수축시키지 않고 증가하는 분산의 노이즈를 더하는 다른 SDE다. sub-VP도 VP와 확산 계수를 다르게 정하는 방식이며 단지 β가 더 빨리 감소하는 스케줄이라고 분류할 수 없다. 드리프트·확산 계수와 초기 조건을 함께 정해야 한다.

## 7. 구현과 유효 범위

```python
import torch
import numpy as np
import matplotlib.pyplot as plt

def linear_schedule(T, beta_start=1e-4, beta_end=0.02):
    return torch.linspace(beta_start, beta_end, T)

def cosine_schedule(T, s=0.008):
    t = torch.arange(T + 1)
    f = torch.cos((t / T + s) / (1 + s) * np.pi / 2) ** 2
    alpha_bar = f / f[0]
    betas = 1 - alpha_bar[1:] / alpha_bar[:-1]
    return torch.clamp(betas, 0, 0.999)

def quadratic_schedule(T, beta_start=1e-4, beta_end=0.02):
    t = torch.arange(T)
    return beta_start + (t / (T - 1)) ** 2 * (beta_end - beta_start)

def sigmoid_schedule(T, beta_start=1e-4, beta_end=0.02):
    t = torch.linspace(-6, 6, T)
    betas = torch.sigmoid(t) * (beta_end - beta_start) + beta_start
    return betas

# 차례표마다 alpha_bar을 셈한다
def compute_alpha_bar(betas):
    alphas = 1 - betas
    return torch.cumprod(alphas, dim=0)
```

함수들은 β 목록을 만들고 compute_alpha_bar가 누적곱을 계산한다. 스케줄 선택에 따른 모델 학습·샘플링이나 그래프 출력은 없다. T와 β 범위, 유한성을 검사하지 않으며 특히 quadratic_schedule은 T=1이면 T−1로 나누어 유효하지 않다. 코사인의 clamp 하한 0은 β=0도 허용하므로 후속 코드가 1−ᾱ로 나누는 경우를 확인해야 한다.

반환 텐서는 기본 CPU 정밀도다. 학습·생성 장치로 옮기고 같은 β·누적곱을 사용해야 한다. 시간 목록을 줄여 생성하려면 선택한 이전 시간에 맞는 DDIM·다른 솔버의 전이식이 필요하며, β 목록을 단순히 띄엄띄엄 고르는 것만으로 충분하지 않다.

## 8. 로스 웨이트와 비교 조건

시간별 노이즈 MSE에 명시적 w(t)를 둘 수 있다.

$$L=\mathbb E_{t,x_0,\epsilon}
[w(t)\|\epsilon-\epsilon_\theta(x_t,t)\|^2]$$

w(t)=1로 정의했다면 스케줄을 바꿔도 **명시적 웨이트가 저절로 바뀌지는 않는다**. 다만 같은 균등 시간 선택이 서로 다른 SNR 영역을 얼마나 자주 보는지와 관측 난이도는 바뀐다. 정확한 변분 목적에서는 β·분산·누적곱에 따른 시간별 웨이트가 등장하므로 별도로 구분한다.

비교에는 데이터 표현·스케일, T·β 정의, 시간 추출과 로스 웨이트, 모델·학습량, 생성 솔버·시간 목록·평가 조건을 맞춘다. 코사인이 언제나 최선이거나 특정 단계 수가 모든 이미지·소리·영상에 적합하다는 규칙은 없다. 이 페이지에는 성능 수치나 시간 비교 실험이 없다.

## 정리하며

노이즈 스케줄은 β, 누적 신호와 SNR의 시간별 관계를 정한다. 이산·연속 계수, 스케줄의 실제 끝값과 clipping, 시간 선택·로스 웨이트를 구분한다. 특정 곡선의 이름이나 고정 단계 수만으로 품질·가속의 우열을 보장하지 않는다.
