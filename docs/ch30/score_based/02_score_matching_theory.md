# 스코어 매칭 이론

밀도 식을 모르는 데이터에서도 스코어를 학습할 수 있을까? 스코어 매칭은 데이터 분포와 모델의 로그 밀도 기울기 차이를 최소화하는 접근이다. 부분적분으로 알 수 없는 데이터 스코어를 목적함수에서 제거하거나, 노이즈를 추가해 계산 가능한 조건부 스코어를 회귀 목표로 사용할 수 있다.

## 1. 가우시안과 나선형 데이터의 학습 예제

아래 코드는 상관된 2차원 가우시안에 선형 스코어를 맞추고, 2차원 나선형 데이터에 고정된 노이즈 수준의 MLP 스코어를 맞춘다. 확산 모델의 시간별 노이즈 스케줄이나 이미지 생성 성능을 비교하는 실험은 아니다. 코드와 기존 출력은 보존한다.

??? note "코드 (502줄)"

    ```python
    """
    점수 맞추기 이론
    ================================

    어려움: 처음~중간
    시간: 3~4시간
    미리 알아 둘 것: 1단원(점수 함수 기초)

    학습 목표:
    -------------------
    1. 왜 자료에서 곧바로 점수를 셈할 수 없는지 이해한다
    2. 드러난 점수 맞추기(ESM)의 목표를 배운다
    3. 잡음 없애는 점수 맞추기(DSM)를 이해한다 - 핵심 생각이다!
    4. 잡음 없애는 점수 맞추기를 베이즈 잡음 없애기와 잇는다
    5. 장난감 자료의 기본 점수 맞추기를 짠다

    수학 바탕:
    -----------------------
    문제:
    자료 묶음 {x_i}_{i=1}^N ~ p_data(x)가 주어질 때 s(x) = ∇_x log p_data(x)를 배운다

    어려움: p_data(x)를 모른다! 표본만 있다!

    어수룩한 길(되지 않는다):
    p_θ(x)를 자료에 맞춘 뒤 s_θ(x) = ∇_x log p_θ(x)를 셈한다
    문제: p_θ(x)을 고르게 맞추어야 하는데 이는 다룰 수 없다!

    점수 맞추기 풀이:
    p_data(x) 없이 점수 s_θ(x)을 참 점수에 곧바로 맞춘다!

    핵심 통찰: 어느 분포도 몰라도 점수를 맞출 수 있다!

    지은이: 이성철 @ 연세대학교
    날짜: 2025년 11월
    """

    import numpy as np
    import matplotlib.pyplot as plt
    import torch
    import torch.nn as nn
    import os
    from scipy.stats import multivariate_normal

    plt.style.use('seaborn-v0_8-darkgrid')
    torch.manual_seed(42)
    np.random.seed(42)

    print("=" * 80)
    print("MODULE 02: SCORE MATCHING THEORY")
    print("=" * 80)

    # ============================================================================
    # 마디 1: 바탕이 되는 문제
    # ============================================================================
    print("\n" + "="  * 80)
    print("SECTION 1: Why Direct Score Computation Fails")
    print("=" * 80)

    print("""
    SCENARIO:
    --------
    주어진 것: 알 수 없는 p_data(x)에서 뽑은 자료 묶음 {x₁, x₂, ..., x_N}
    목표: 점수 함수 s(x) = ∇_x log p_data(x)를 배운다

    왜 점수를 곧바로 셈할 수 없는가:
    -----------------------------------
    1. p_data(x)의 식이 없다
    2. 모델 p_θ(x)을 자료에 맞출 수 있다
    3. 그런데 p_θ(x)를 고르게 하려면 다음을 셈해야 한다.
       Z_θ = ∫ p̃_θ(x) dx  (intractable!)

    4. 그래서 log p_θ(x) = log p̃_θ(x) - log Z_θ를 셈할 수 없다
    5. 따라서 ∇_x log p_θ(x)도 셈할 수 없다

    EXAMPLE:
    -------
    p̃_θ(x) = exp(E_θ(x))로 매긴다고 하자
    여기서 E_θ은 신경망(에너지 함수)이다.

    Then: p_θ(x) = exp(E_θ(x)) / Z_θ
    여기서 Z_θ = ∫ exp(E_θ(x)) dx  ← 셈할 수 없다!

    그런데 우리가 바라는 것은 s_θ(x) = ∇_x log p_θ(x) = ∇_x E_θ(x)다

    반가운 소식: 점수는 Z_θ가 필요 없다!
    안 좋은 소식: p_data(x)를 모르면 여전히 익힐 수 없다!

    풀이: 점수 맞추기!
    """)

    # ============================================================================
    # 마디 2: 드러난 점수 맞추기(ESM)
    # ============================================================================
    print("\n" + "=" * 80)
    print("SECTION 2: Explicit Score Matching (ESM)")
    print("=" * 80)

    print("""
    피셔 갈림:
    -----------------
    점수 함수 사이의 거리를 뜻매김한다.

    D_Fisher(p||q) = (1/2) 𝔼_{x~p} ||∇_x log p(x) - ∇_x log q(x)||²

    Minimize w.r.t. θ:
    J_ESM(θ) = (1/2) 𝔼_{x~p_data} ||∇_x log p_data(x) - s_θ(x)||²

    문제: 우리가 갖고 있지 않은 ∇_x log p_data(x)가 여전히 필요하다!

    휘바리넨의 재주(2005):
    ------------------------
    부분 적분(스타인 항등식)을 쓰면:

    J_ESM(θ) = 𝔼_{x~p_data} [ tr(∇_x s_θ(x)) + (1/2)||s_θ(x)||² ] + const

    핵심 눈썰미:
    - 목표에서 ∇_x log p_data(x)을 없앴다!
    - 필요한 것은 p_data의 표본과 s_θ의 미분뿐이다
    - tr(∇_x s_θ(x)) = 야코비 행렬의 대각 원소의 합

    DRAWBACK:
    - tr(∇_x s_θ(x))을 셈하려면 헤세를 셈해야 한다
    - 차원이 높으면 아주 비싸다!
    - 그림 같은 데는 쓸 수 없다

    더 나은 방식이 필요하다 → 잡음 없애는 점수 맞추기!
    """)

    # 장난감 자료에서 드러난 점수 맞추기를 보여 준다
    print("\nDemonstration: ESM on 2D Gaussian")
    print("-" * 80)

    # 참 분포: 2차원 정규 분포
    mu_true = np.array([0, 0])
    Sigma_true = np.array([[1.0, 0.5], [0.5, 1.0]])

    # 표본 만들기
    n_samples = 1000
    samples = np.random.multivariate_normal(mu_true, Sigma_true, n_samples)

    # 참 점수 함수(견주기용)
    Sigma_inv = np.linalg.inv(Sigma_true)
    def true_score(x):
        return -Sigma_inv @ (x - mu_true)

    # 단순한 선형 점수 모델: s_θ(x) = A(x - b)
    # 정규 분포에서는 A = -Σ^(-1), b = μ이 가장 좋다
    class LinearScoreModel(nn.Module):
        def __init__(self):
            super().__init__()
            self.A = nn.Parameter(torch.randn(2, 2) * 0.1)
            self.b = nn.Parameter(torch.zeros(2))

        def forward(self, x):
            # s_θ(x) = A(x - b)
            return (self.A @ (x - self.b).T).T

    # 드러난 점수 맞추기 목표: 𝔼[tr(∇s_θ) + 0.5||s_θ||²]
    def esm_loss(model, x_batch):
        """드러난 점수 맞추기 손실"""
        x_batch.requires_grad_(True)

        # 점수 셈하기
        score = model(x_batch)

        # 항 1: 0.5 * ||s_θ(x)||²
        score_norm = 0.5 * torch.sum(score ** 2, dim=-1).mean()

        # 항 2: tr(∇_x s_θ(x)) - 야코비의 대각합
        # 점수의 성분마다 x에 대해 미분한다
        trace_term = 0
        for i in range(2):
            grad_outputs = torch.zeros_like(score)
            grad_outputs[:, i] = 1
            grads = torch.autograd.grad(score, x_batch, grad_outputs, 
                                         create_graph=True)[0]
            trace_term += grads[:, i].mean()

        return score_norm + trace_term

    # 드러난 점수 맞추기로 익힌다
    model_esm = LinearScoreModel()
    optimizer = torch.optim.Adam(model_esm.parameters(), lr=0.01)

    x_tensor = torch.FloatTensor(samples)
    print("Training with Explicit Score Matching...")
    for epoch in range(500):
        optimizer.zero_grad()
        loss = esm_loss(model_esm, x_tensor)
        loss.backward()
        optimizer.step()

        if epoch % 100 == 0:
            print(f"  Epoch {epoch}: Loss = {loss.item():.4f}")

    print("\n✓ ESM training complete!")
    print(f"  Learned A ≈ -Σ^(-1):")
    print(f"    {model_esm.A.detach().numpy()}")
    print(f"  True -Σ^(-1):")
    print(f"    {-Sigma_inv}")

    # ============================================================================
    # 마디 3: 잡음 없애는 점수 맞추기(DSM)
    # ============================================================================
    print("\n" + "=" * 80)
    print("SECTION 3: Denoising Score Matching (DSM) - The Key Idea!")
    print("=" * 80)

    print("""
    ESM의 문제:
    -------------------
    tr(∇_x s_θ(x))을 셈하는 것은 비싸다(헤세가 필요하다).
    차원이 높으면(그림 등) 키울 수 없다.

    잡음 지우기 점수 맞추기(뱅상 2011):
    ---------------------------------------
    핵심 통찰: 대신 잡음 없애는 법을 배운다!

    PROCEDURE:
    1. 깨끗한 자료 x ~ p_data(x)를 가져온다
    2. 가우스 잡음을 더한다: x̃ = x + σ * ε, 여기서 ε ~ N(0, I)
    3. 잡음을 헤아리는 법을 배운다: s_θ(x̃) ≈ -(x̃ - x)/σ²

    OBJECTIVE:
    J_DSM(θ) = 𝔼_{x~p_data} 𝔼_{ε~N(0,I)} ||s_θ(x + σε) + ε/σ||²

    왜 이것이 되는가:
    --------------
    잡음 분포 q_σ(x̃|x) = N(x̃; x, σ²I)의 점수는 다음과 같다.

    ∇_{x̃} log q_σ(x̃|x) = -(x̃ - x)/σ²

    그리고 가장자리 잡음 분포는 q_σ(x̃) = ∫ q_σ(x̃|x)p_data(x)dx이다
    이것으로 어림할 수 있는 점수를 가진다!

    베이즈 미룸과의 이음:
    --------------------------------
    잡음 없애기가 곧 베이즈 사후 추론이다!

    잡음 섞인 관측 x̃ = x + noise가 주어질 때,
    뒷분포 p(x|x̃)로 깨끗한 x를 미룬다

    점수 ∇_x log p(x|x̃)가 잡음을 어떻게 지울지 알려 준다!

    확산 모델이 하는 일이 바로 이것이다.
    - 앞으로: 잡음을 더한다(이미 안다)
    - 거꾸로: 배운 점수로 잡음을 지운다(배운다)

    DSM의 좋은 점:
    -----------------
    ✓ 헤세를 셈할 필요가 없다
    ✓ 기울기 셈하기가 단순하다
    ✓ 차원이 높아도 키울 수 있다
    ✓ 잡음 없애는 오토인코더와 이어진다
    ✓ 확산 모델의 바탕이다
    """)

    # 잡음 없애는 점수 맞추기를 보여 준다
    print("\nDemonstration: DSM on 2D Swiss Roll")
    print("-" * 80)

    # 스위스 롤 자료를 만든다
    def generate_swiss_roll(n_samples=1000, noise=0.1):
        t = 1.5 * np.pi * (1 + 2 * np.random.rand(n_samples))
        x1 = t * np.cos(t)
        x2 = t * np.sin(t)
        data = np.stack([x1, x2], axis=1)
        data += noise * np.random.randn(n_samples, 2)
        return data

    swiss_roll = generate_swiss_roll(1000, noise=0.1)

    # 여러 층 신경망 점수 신경망
    class MLPScoreNet(nn.Module):
        def __init__(self, hidden_dim=128):
            super().__init__()
            self.net = nn.Sequential(
                nn.Linear(2, hidden_dim),
                nn.Tanh(),
                nn.Linear(hidden_dim, hidden_dim),
                nn.Tanh(),
                nn.Linear(hidden_dim, 2)
            )

        def forward(self, x):
            return self.net(x)

    # 잡음 없애는 점수 맞추기 손실
    def dsm_loss(model, x_batch, sigma=0.1):
        """잡음 없애는 점수 맞추기 손실"""
        # 잡음 더하기
        noise = torch.randn_like(x_batch)
        x_noisy = x_batch + sigma * noise

        # 점수 미리보기
        predicted_score = model(x_noisy)

        # 목표 점수: -(x_noisy - x)/sigma^2 = -noise/sigma
        target_score = -noise / sigma

        # 평균 제곱 어긋남 손실
        loss = torch.mean((predicted_score - target_score) ** 2)
        return loss

    # 잡음 없애는 점수 맞추기로 익힌다
    model_dsm = MLPScoreNet()
    optimizer_dsm = torch.optim.Adam(model_dsm.parameters(), lr=1e-3)

    x_swiss = torch.FloatTensor(swiss_roll)
    sigma_noise = 0.1

    print("Training with Denoising Score Matching...")
    for epoch in range(2000):
        optimizer_dsm.zero_grad()
        loss = dsm_loss(model_dsm, x_swiss, sigma=sigma_noise)
        loss.backward()
        optimizer_dsm.step()

        if epoch % 400 == 0:
            print(f"  Epoch {epoch}: Loss = {loss.item():.6f}")

    print("\n✓ DSM training complete!")

    # 배운 점수 마당을 그려 본다
    x1_grid = np.linspace(-15, 15, 20)
    x2_grid = np.linspace(-15, 15, 20)
    X1, X2 = np.meshgrid(x1_grid, x2_grid)
    grid_points = np.stack([X1.ravel(), X2.ravel()], axis=1)

    with torch.no_grad():
        scores = model_dsm(torch.FloatTensor(grid_points)).numpy()

    scores = scores.reshape(X1.shape + (2,))

    fig, axes = plt.subplots(1, 2, figsize=(16, 6))

    # 그림 1: 자료
    axes[0].scatter(swiss_roll[:, 0], swiss_roll[:, 1], s=1, alpha=0.5, c='blue')
    axes[0].set_title('Swiss Roll Data', fontsize=14, fontweight='bold')
    axes[0].set_xlabel(r'$x_1$')
    axes[0].set_ylabel(r'$x_2$')
    axes[0].set_aspect('equal')
    axes[0].grid(True, alpha=0.3)

    # 그림 2: 배운 점수 마당
    axes[1].scatter(swiss_roll[:, 0], swiss_roll[:, 1], s=1, alpha=0.3, c='blue')
    axes[1].quiver(X1, X2, scores[:, :, 0], scores[:, :, 1], 
                   color='red', alpha=0.6, scale=50, width=0.003)
    axes[1].set_title('Learned Score Field via DSM\n(Points toward data manifold)', 
                      fontsize=14, fontweight='bold')
    axes[1].set_xlabel(r'$x_1$')
    axes[1].set_ylabel(r'$x_2$')
    axes[1].set_aspect('equal')
    axes[1].grid(True, alpha=0.3)

    plt.tight_layout()
    plt.savefig('02_dsm_swiss_roll.png', dpi=150, bbox_inches='tight')
    print("✓ Saved: 02_dsm_swiss_roll.png")
    plt.close()

    # ============================================================================
    # 마디 4: 드러난 점수 맞추기와 잡음 없애는 점수 맞추기 견주기
    # ============================================================================
    print("\n" + "=" * 80)
    print("SECTION 4: ESM vs DSM Comparison")
    print("=" * 80)

    comparison_table = """
    |  갈래                  | 드러난 점수 맞추기(ESM)           | 잡음 지우기 점수 맞추기(DSM)    |
    |-----------------------|-----------------------------------|----------------------------------|
    | Objective             | 𝔼[tr(∇s_θ) + 0.5||s_θ||²]        | 𝔼||s_θ(x̃) + ε/σ||²             |
    | 필요한 미분           | 이계(헤세)                        | 일계만                           |
    | 셈 비용               | 표본마다 O(d²)                    | 표본마다 O(d)                    |
    | 크기 늘리기           | 나쁨(높은 차원)                   | 아주 좋음                        |
    | 이음                  | 피셔 갈림                         | 베이즈 잡음 지우기               |
    | 실제 쓰임             | 드묾(너무 비쌈)                   | 표준(요즘 모델 모두)             |
    | 잡음 매개변수         | 필요 없음                         | σ를 골라야 함                    |
    """

    print(comparison_table)

    print("""
    핵심 얻음:
    -------------
    1. 드러난 점수 맞추기는 이론으로 아름답지만 셈이 비싸다
    2. 잡음 없애는 점수 맞추기는 쓸모 있고 키울 수 있어 요즘 모든 모델이 쓴다
    3. 잡음 없애는 점수 맞추기는 베이즈 잡음 없애기와 이어져 확산의 바탕이 된다
    4. 둘 다 고르게 맞추는 상수를 셈하지 않는다
    5. 잡음 없애는 점수 맞추기는 자료만으로 점수를 배울 수 있게 한다

    다음 걸음: 여러 잣수의 잡음 없애는 점수 맞추기
    --------------------------
    문제: 잡음 수준 σ 하나로는 어디서나 잘 듣지 않을 수 있다
    풀이: 여러 잡음 수준에서 점수를 배운다
    이것이 잡음 조건 점수 신경망(NCSN)으로 이어진다!
    """)

    # ============================================================================
    # 간추리기와 익힘
    # ============================================================================
    print("\n" + "=" * 80)
    print("MODULE SUMMARY")
    print("=" * 80)

    print("""
    배운 것:
    ---------------
    1. 자료에서 곧바로 점수를 셈하는 것은 다룰 수 없다
    2. 드러난 점수 맞추기는 고르게 맞추기를 피하지만 헤세가 필요하다
    3. 잡음 없애는 점수 맞추기는 쓸모 있고 키울 수 있다
    4. DSM은 잡음 지우기를 배우는 것이고 곧 베이즈 미룸이다!
    5. 잡음 없애는 점수 맞추기는 확산 모델의 바탕이다

    핵심 식:
    ------------
    1. ESM 목표:
       J_ESM = 𝔼[tr(∇_x s_θ(x)) + 0.5||s_θ(x)||²]

    2. DSM 목표:
       J_DSM = 𝔼_{x,ε} ||s_θ(x + σε) + ε/σ||²

    3. 잡음 지우기 점수:
       ∇_x log q_σ(x̃|x) = -(x̃ - x)/σ²

    만들어진 파일:
    ---------------
    1. 02_dsm_swiss_roll.png - 스위스 롤 자료의 잡음 없애는 점수 맞추기

    """)

    print("=" * 80)
    print("EXERCISES")
    ```

## 2. 데이터 스코어와 정규화 상수

유한한 데이터 표본만으로 미지의 밀도 p와 그 기울기를 정확히 알 수는 없다. 그러나 모델의 미분 가능한 비정규화 밀도 $\widetilde p_\theta$가 주어져 있다면, $p_\theta(x)=\widetilde p_\theta(x)/Z_\theta$에서 Zθ가 x와 무관하므로 모델 스코어는 직접 계산할 수 있다.

$$s_\theta(x)=\nabla_x\log\widetilde p_\theta(x)$$

따라서 출력의 '정규화 상수를 몰라 모델 스코어도 계산할 수 없다'는 문장은 잘못된 문제 제기다. 어려운 것은 **알 수 없는 데이터 스코어를 목표로 학습하는 방법**이다. 코드에서 exp(Eθ)를 쓰는 것은 로그 비정규화 밀도의 부호 관례이며, 보통 에너지 모형의 exp(−Eθ)와 반대다. 적분 가능한 분포를 정의하는지도 별도로 확인해야 한다.

## 3. 피셔 발산에서 암시적 목적함수로

모델 스코어와 데이터 스코어의 차이를 다음처럼 측정한다.

$$J_F(\theta)=\frac12\mathbb E_{x\sim p}\|s_\theta(x)-\nabla_x\log p(x)\|^2$$

제곱을 전개하면 모델의 제곱 노름, 교차항과 θ에 무관한 항이 나온다. 경계항이 사라지고 미분·적분이 정당화되는 조건에서 부분적분은 다음 관계를 준다.

$$\mathbb E_p[s_\theta(x)^T\nabla_x\log p(x)]
=-\mathbb E_p[\nabla_x\cdot s_\theta(x)]$$

따라서 θ에 무관한 상수를 제외하면 다음을 최소화할 수 있다.

$$J_{SM}(\theta)=\mathbb E_p\left[\frac12\|s_\theta(x)\|^2+
\operatorname{Tr}(\nabla_xs_\theta(x))\right]$$

[Hyvärinen의 스코어 매칭 논문](https://www.jmlr.org/papers/v6/hyvarinen05a.html)은 이런 변환으로 비정규화 모형의 추정을 다룬다. 코드에서는 이 trace 목적함수를 `esm_loss`라고 부르지만, 데이터의 참 스코어를 직접 회귀하는 explicit 목적과 구분하기 위해 위 식을 암시적 형태라고 이해하면 된다. 경계가 있는 분포나 특이한 데이터에서는 같은 부분적분을 조건 없이 적용할 수 없다.

이 목적값은 상수를 뺀 값이므로 음수여도 된다. 원래 피셔 발산이 음수가 되었다는 뜻이 아니다. 서로 다른 목적함수인 trace 손실과 DSM 손실의 절대 크기를 직접 비교해 어느 학습이 더 좋은지 판단할 수도 없다.

## 4. 선형 스코어와 입력 미분

`LinearScoreModel`은 $s_\theta(x)=A(x-b)$로, A의 네 원소와 b의 두 원소를 학습한다. 목표 가우시안의 스코어는 $-\Sigma^{-1}(x-\mu)$다. 유한 표본에서는 참 Σ가 아니라 표본 모멘트에 맞춰질 수 있으며 수치 최적화의 오차도 남는다.

A를 대칭·음의 정부호로 제한하지 않으므로 학습 중의 벡터장이 항상 정규화 가능한 밀도의 기울기인 것은 아니다. 임의의 벡터 신경망도 일반적으로 보존적 벡터장이나 확률 밀도의 스코어를 자동으로 정의하지 않는다.

trace는 벡터 스코어의 **야코비안 대각합**이다. 스코어 자체를 에너지의 입력 기울기로 정의했다면 에너지에 대한 이계 미분이 되지만, 직접 벡터를 출력하는 네트워크에서 항상 전체 헤시안을 만들어야 하는 것은 아니다. 코드의 루프는 차원별 미분으로 대각합을 구하며 차원 2에 고정되어 있다. `create_graph=True`는 그 입력 미분 항을 다시 파라미터에 대해 미분하기 위해 필요하다. 비용은 차원과 네트워크에 따라 달라져 모든 경우 O(d²) 대 O(d)로 정해지지 않는다.

## 5. 디노이징 스코어 매칭

깨끗한 데이터 $x_0\sim p$에 대해 $\widetilde x=x_0+\sigma\epsilon$, $\epsilon\sim N(0,I)$, σ>0으로 노이즈를 더한다. 조건부 가우시안의 관측 좌표 스코어는 계산할 수 있다.

$$\nabla_{\widetilde x}\log q_\sigma(\widetilde x\mid x_0)
=-\frac{\widetilde x-x_0}{\sigma^2}=-\frac\epsilon\sigma$$

이 값을 제곱오차 회귀 목표로 사용한다.

$$J_{DSM}(\theta)=\mathbb E_{x_0,\epsilon}
\left\|s_\theta(x_0+\sigma\epsilon)+\frac\epsilon\sigma\right\|^2$$

조건부 평균이 제곱오차의 모집단 최적 예측이므로, 적절한 미분·적분 조건에서 다음을 얻는다.

$$s^*(\widetilde x)=\mathbb E\left[-\frac\epsilon\sigma\mid\widetilde x\right]
=\nabla_{\widetilde x}\log p_\sigma(\widetilde x)$$

pσ는 **노이즈가 추가된 주변 분포**다. 목표에 깨끗한 x₀가 사용되더라도 출력의 '깨끗한 데이터에 대한 사후 스코어를 학습한다'는 설명과는 다르다. 연결되는 것은 사후평균 디노이저 $D^*(\widetilde x)=\mathbb E[x_0\mid\widetilde x]$다.

$$D^*(\widetilde x)=\widetilde x+\sigma^2\nabla_{\widetilde x}\log p_\sigma(\widetilde x)$$

## 6. 구현의 범위와 그림 읽기

`MLPScoreNet`은 2→128→128→2의 tanh MLP이며 파라미터는 17,154개다. 데이터와 예측·목표 스코어의 모양은 모두 N×2다. `dsm_loss`는 표본과 두 좌표를 모두 평균 내므로 표시한 제곱 노름 합의 평균보다 1/2배다. 상수 배율은 모집단 최적점을 바꾸지 않지만 기울기 크기에는 영향을 준다.

나선 데이터 자체에도 표준편차 0.1의 노이즈가 들어 있고, 학습에서 다시 σ=0.1 노이즈를 추가한다. 따라서 학습 목표는 선택한 데이터 분포를 추가로 평활화한 주변 스코어다. σ를 모델의 입력으로 주지 않으므로 학습 후 σ만 바꾼다고 다른 노이즈 수준에 맞는 스코어가 되는 것은 아니다.

그림의 화살표는 학습된 벡터장이다. 데이터에서 먼 영역의 정확한 스코어나 모든 모드의 샘플링을 검증한 결과는 아니다. 작은 σ에서는 회귀 목표의 크기와 분산이 커질 수 있고, 큰 σ는 데이터 구조를 더 평활화한다. 여러 노이즈 수준을 함께 모델링하는 접근은 [노이즈 조건 스코어 모델](https://arxiv.org/abs/1907.05600)로 이어지지만, 이 코드에는 그 학습이나 노이즈 스케줄 비교가 없다.

## 정리하며

스코어 매칭은 경계 조건 아래 부분적분으로 참 스코어를 제거한 목적함수를 사용한다. DSM은 가우시안 조건부 스코어를 회귀해 노이즈 주변 분포의 스코어를 학습한다. 데이터 스코어와 모델 스코어, 조건부 회귀 목표와 주변 스코어를 구분한다.
