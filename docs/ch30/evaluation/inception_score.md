# 확산 모델의 인셉션 점수(IS)

인셉션 점수는 생성 이미지에 대한 분류기의 예측을 요약한다. 확산 모델에서도 생성 단계 수나 가이던스를 바꾸었을 때 분류 예측이 어떻게 달라지는지 볼 수 있다. 하지만 실제 이미지 분포와 직접 비교하거나 프롬프트 일치도를 측정하는 지표는 아니다. 기본 구현은 [IS 설명](../../ch29/gan_evaluation/inception_score.md)을 참고한다.

## 1. 정의와 정보 이론적 의미

분류 확률 p(y|x)를 생성 분포에서 평균한 값을 p(y)라 하면 다음과 같다.

$$\operatorname{IS}=\exp\left(\mathbb E_x
 D_{\mathrm{KL}}(p(y\mid x)\|p(y))\right)
=\exp\left(H(Y)-\mathbb E_x H(Y\mid x)\right)$$

예측이 각 이미지에서 확신 있고 전체 이미지에서 여러 클래스를 고르게 사용할 때 커진다. C개 클래스에서 1≤IS≤C다. 여기서 Y는 예측 확률에서 뽑는 클래스 변수이며 argmax 레이블만을 뜻하지 않는다. 낮은 조건부 엔트로피가 실제 이미지 품질이나 예측의 정확성을 자동으로 보장하지는 않는다.

분류기의 출력 확률이 모든 이미지에서 같으면 IS=1이다. 반대로 클래스마다 한 이미지만 외워 반복해도 예측이 확신 있고 클래스 비율이 균등하면 높은 IS를 얻을 수 있다. 클래스 내부 다양성과 학습 데이터 재생을 구분하는 능력은 제한적이다.

## 2. 가이던스에 따른 변화

CFG를 키우면 분류기 예측이 더 확신 있어질 수 있다. 그러나 동시에 클래스 분포가 편중되면 H(Y)가 줄어들 수 있으므로 **IS가 가이던스 강도에 따라 항상 증가하지는 않는다**. 이미지가 과도하게 왜곡되어 분류기에만 잘 인식되는 경우도 구분해야 한다.

실제 데이터의 IS는 생성 모델이 넘을 수 없는 상한이 아니다. 실제 데이터에 모호한 예제가 있으면 더 전형적이거나 반복적인 생성 표본이 높은 값을 받을 수도 있다. 그렇다고 클래스 수를 줄이는 모드 붕괴가 항상 IS를 높이는 것은 아니다. 한 클래스만 확신 있게 반복하면 IS=1이다.

## 3. 보고 조건과 보존된 예시

```
따진 결과:
  FID-50K:          3.17  (으뜸 자)
  IS (50K, 조각 10개): 9.46 ± 0.11  (곁들이 자)
  CLIP Score:       28.5  (글월에서 그림을 만들 때만)
```


위 블록의 수치는 기존 문서에 들어 있던 **보고 형식 예시**로 보존한다. 동일한 모델·데이터·평가 실행에서 함께 측정되었다는 근거로 사용하지 않는다. 특히 ±가 표본 간 표준편차인지, 분할별 표준편차인지, 반복 실행의 변동인지 명시되어야 한다.

IS에는 분류기 가중치와 클래스 수, 이미지 전처리, 생성 표본 수, 분할 수와 분할 방법을 기록한다. 분할별 점수를 평균하면 모든 표본을 한 번에 계산한 값과 일반적으로 다르다. 분할 간 표준편차는 그 자체로 평균의 표준오차나 신뢰구간이 아니다.

사전학습된 분류기의 범주가 데이터와 맞는지도 확인한다. ImageNet 분류기의 클래스 엔트로피가 의료 이미지나 숫자 이미지, 텍스트 조건의 의미를 적절히 반영한다고 가정할 수 없다. 생성 비용과 특징 추출 비용은 따로 측정하며 IS가 모든 상황에서 FID보다 훨씬 저렴하다고 단정하지 않는다.

## 4. 보완 평가

[FID](fid.md)는 실제·생성 특징의 모멘트를 비교하고 IS는 생성 예측의 엔트로피를 요약한다. 둘 다 이미지 분포 전체나 사람의 품질 판단을 완전히 표현하지 않는다. 조건부 생성에는 조건별 정확도나 텍스트 일치도를, 다양성에는 [정밀도·재현율](../../ch29/gan_evaluation/precision_recall.md) 등 추가 자료를 사용한다.

고해상도 이미지도 분류기 입력 크기로 변환하는 과정에서 세부 차이를 잃을 수 있다. 이미지 원본을 함께 검토하고 동일 프롬프트의 여러 결과와 최근접 학습 예제도 살펴야 한다. 측정 근거가 다른 모델들의 점수를 섞어 현재 순위를 만들지 않는다.

## 연습문제

<div class="drillbox" markdown>

**연습문제 1.**

모든 이미지에 같은 확률 벡터를 출력하는 분류기의 IS는 얼마인가?

</div>

??? success "연습문제 1 풀이"
    p(y|x)=p(y)이므로 모든 KL 항이 0이고 IS=1이다. 공통 확률 벡터가 균등할 필요는 없다.

---

<div class="drillbox" markdown>

**연습문제 2.**

가이던스를 높이면 IS도 항상 높아지는가?

</div>

??? success "연습문제 2 풀이"
    아니다. 조건부 예측 엔트로피가 낮아져도 클래스 주변 엔트로피가 함께 줄면 점수는 낮아질 수 있다. 한 클래스에 집중한 확신 있는 예측은 IS=1이다.

---

<div class="drillbox" markdown>

**연습문제 3.**

클래스마다 대표 이미지 하나를 균등하게 반복한 경우 높은 IS를 얻을 수 있는가?

</div>

??? success "연습문제 3 풀이"
    분류기가 각 이미지를 해당 클래스로 확신 있게 분류하면 높은 점수를 얻을 수 있다. 클래스 내부 다양성이나 새로운 이미지 생성은 보장되지 않으므로 반복·재생 여부를 따로 확인해야 한다.

---

<div class="drillbox" markdown>

**연습문제 4.**

분할별 IS 평균±표준편차를 신뢰구간으로 읽을 수 있는가?

</div>

??? success "연습문제 4 풀이"
    그대로는 읽을 수 없다. 분할 점수의 변동은 평균 추정의 표준오차나 정해진 포함 확률의 신뢰구간과 다르다. 표본 수·분할 방법과 통계량의 의미를 명시해야 한다.

## 정리하며

IS는 분류 예측의 확신도와 클래스 분포의 엔트로피를 함께 요약한다. 가이던스와의 관계를 단조 증가로 보지 않으며, 실제 데이터 점수를 상한으로 사용하지 않는다. 분할 통계의 의미와 전처리를 명시하고 조건 충실도·내부 다양성·재생 여부를 보완 평가한다.
