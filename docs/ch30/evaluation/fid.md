# 확산 모델의 FID 평가

확산 모델의 생성 품질은 모델 가중치뿐 아니라 시간 목록, 샘플러와 가이던스 설정에도 영향을 받는다. FID를 보고할 때는 이 전체 생성 절차를 평가 대상으로 삼아야 한다. 기본 유도와 구현은 [FID 설명](../../ch29/gan_evaluation/fid.md)을 참고하고, 여기서는 확산 실험의 비교 조건을 정리한다.

## 1. 특징의 첫 두 모멘트 비교

실제 이미지와 생성 이미지에서 같은 특징 추출기로 벡터를 얻고 평균 μ와 공분산 Σ를 추정한다. 대칭 양의 준정부호 행렬 표현을 사용하면 다음과 같다.

$$\operatorname{FID}=\|\mu_r-\mu_g\|^2+
\operatorname{tr}\left(\Sigma_r+\Sigma_g-
2(\Sigma_r^{1/2}\Sigma_g\Sigma_r^{1/2})^{1/2}\right)$$

이는 특징 분포를 가우스로 근사했을 때의 제곱 2-Wasserstein 거리다. FID=0도 두 특징 분포 전체나 원본 이미지 분포의 동일성을 보장하지 않는다. 평균·공분산이 같은 다른 분포가 있기 때문이다. 표본 FID에는 유한 표본 편향과 변동도 존재한다.

## 2. 무엇을 고정하고 무엇을 바꾸는가

같은 가중치에서 샘플러를 비교하려면 평가용 실제 데이터, 생성 수량, 특징 추출기와 전처리를 고정한다. 바꾸는 항목은 샘플러, 실제 시간 목록, 단계 수, 가이던스 계수나 분산 설정으로 명확히 표시한다. 초기 노이즈를 공유하는지와 EMA 가중치 사용 여부도 기록한다.

| 비교 항목 | 함께 보고할 조건 |
|---|---|
| 단계 수 | 실제 모델 평가 횟수, 시작·끝 시간, 벽시계 시간 |
| CFG 강도 | 결합식의 계수 관례, null 조건, 조건 분포 |
| 노이즈 스케줄 | 학습 때의 스케줄, 시간 입력과 샘플러의 대응 |
| 모델 구조 | 가중치, 학습 데이터·예산, 해상도와 전처리 |

한 번에 여러 조건을 바꾼 결과를 샘플러 하나의 효과로 해석하지 않는다. 특히 노이즈 스케줄을 바꿔 새로 학습한 모델과 기존 가중치의 샘플링 단계만 바꾼 모델은 다른 비교다.

## 3. 단계 수와 가이던스의 곡선

단계를 줄이면 호출 수를 줄일 수 있지만 FID가 항상 단조롭게 나빠지는 것은 아니다. 수치 적분 오차, 예측 오차와 샘플러 설계가 함께 작용한다. CFG도 조건 일치도를 강화하면서 다양성을 줄일 수 있으나 모든 모델에서 같은 계수가 최적이거나 같은 모양의 FID 곡선을 보장하지 않는다.

따라서 특정 논문의 서로 다른 모델·학습 예산·해상도에서 얻은 FID를 한 표에 모아 샘플러 순위로 단정하지 않는다. 이 페이지는 검증되지 않은 최신 순위나 고정 성능값 대신, 같은 설정에서 시간·모델 호출 수·FID를 함께 비교하는 절차를 사용한다.

## 4. 전처리와 표본 수

FID-50K라는 이름은 일반적으로 생성 이미지 50,000개를 사용했음을 뜻한다. 실제 데이터의 수량·분할과 통계 파일은 별도로 명시해야 한다. 같은 수량이라도 특징 가중치, resize 필터, 양자화와 정규화가 다르면 값이 달라질 수 있다.

특히 모든 FID 구현이 torchvision 분류기와 같은 ImageNet 정규화를 쓰는 것은 아니다. [전처리 연구](https://arxiv.org/abs/2104.11222)가 보여 주듯 비교할 기준의 실제 파이프라인을 맞추어야 한다. 서로 다른 구현 이름만으로 결과의 직접 비교 가능성을 보장하지 않는다.

표본을 늘린다고 개별 실행의 값이 항상 내려가는 것도 아니다. 반복 생성과 조건을 명시한 불확실성 평가를 사용할 수 있지만, 부트스트랩 구간이 편향을 자동 제거하거나 임의의 작은 차이를 유의하게 만드는 것은 아니다. 특징 차원이 2048이면 적은 표본에서 공분산 추정이 특히 불안정할 수 있다.

## 5. FID가 답하지 않는 질문

전체 FID는 프롬프트별 조건 일치도나 클래스 내부 다양성을 직접 측정하지 않는다. 조건을 무시해도 전체 특징 통계가 비슷할 수 있다. 텍스트·이미지 유사도와 조건별 평가를 보완하되, 그 지표 하나를 사람 판단과 동일시하지 않는다.

학습 데이터 재생, 드문 실패와 세부 왜곡도 평균·공분산에서 충분히 드러나지 않을 수 있다. [정밀도·재현율](../../ch29/gan_evaluation/precision_recall.md), 최근접 학습 예제 점검과 표본 검토 등 목적에 맞는 자료를 함께 사용한다. 확산의 [우도 평가](likelihood.md)는 또 다른 질문이며 FID로 대체되지 않는다.

## 연습문제

<div class="drillbox" markdown>

**연습문제 1.** <span class="diff med" title="중간"></span>
FID가 0이면 원본 이미지 분포가 같다고 할 수 있는가?

</div>

??? success "연습문제 1 풀이"

    아니다. 같은 특징 평균과 공분산을 가진 서로 다른 분포가 존재한다. 특징 추출 자체도 원본 정보를 모두 보존하지 않는다. FID는 가우스 근사의 첫 두 모멘트를 비교하는 값이다.



---

<div class="drillbox" markdown>

**연습문제 2.** <span class="diff med" title="중간"></span>
같은 확산 가중치에서 1,000단계와 50단계 샘플러를 비교할 때 기록할 조건을 설명하라.

</div>

??? success "연습문제 2 풀이"

    실제 시간 목록과 모델 평가 횟수, 가이던스·분산·끝점 처리, 초기 노이즈 공유 여부와 EMA 사용을 기록한다. 실제 데이터 통계, 생성 수량과 특징 전처리를 고정하고 벽시계 시간도 함께 측정한다. 호출 수 비율을 곧 실제 속도 비율로 단정하지 않는다.



---

<div class="drillbox" markdown>

**연습문제 3.** <span class="diff easy" title="쉬움"></span>
FID-50K라는 표기만으로 두 결과를 직접 비교할 수 없는 이유는 무엇인가?

</div>

??? success "연습문제 3 풀이"

    생성 수량만 같아도 실제 데이터 분할, 통계 파일, 특징 가중치와 resize·정규화·양자화가 다를 수 있다. 이 조건들과 생성 파이프라인을 확인해야 한다. 고정된 수량이 유한 표본 편향까지 제거하지도 않는다.



---

<div class="drillbox" markdown>

**연습문제 4.** <span class="diff med" title="중간"></span>
FID를 최소화한 CFG 계수가 실제 서비스에서도 최적이라고 말할 수 있는가?

</div>

??? success "연습문제 4 풀이"

    그 계수는 특정 표본·특징 통계에서 얻은 선택이다. 조건 충실도, 프롬프트별 다양성, 세부 오류와 사용자의 목적은 다른 평가가 필요하다. FID 최적값이 모든 품질 기준의 최적값은 아니다.



## 정리하며

확산 모델의 FID는 생성 절차 전체의 평가다. 가중치·시간 목록·가이던스와 실제 데이터 통계·전처리·표본 수를 기록한다. 낮은 FID의 의미를 특징 모멘트 수준으로 한정하고 조건 충실도와 다양성·재생 여부를 별도로 살핀다.
