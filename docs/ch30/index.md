# 31장: 확산 모델
확산 모델은 차츰 잡음을 더하는 과정을 거꾸로 돌려 데이터 만드는 법을 배우는 생성 모델이며 그림 만들기, 소리 만들기 등에서 최고 수준의 결과를 이룬다. 어려운 생성 문제를 작은 잡음 없애기 걸음 여럿으로 나누어 봉우리를 잘 덮는 품질 높은 표본을 낸다. 이 장은 수학의 기초, 스코어 기반 방법, DDPM, DDIM, 확률 미분 방정식 적기, 조건 생성, 구조, 따지기 잣대, 돈살림 쓰임새를 다룬다.

---

## 1. 기초

- 확산 모델 들어가기 -- 확산 모델의 수학 틀: 앞 잡음 더하기, 뒤 잡음 없애기, 세 가지 매개변수화.
- 앞 확산 과정 -- 데이터를 차츰 정규 분포 잡음으로 망가뜨리는, 붙박이고 매개변수 없는 마르코프 사슬.
- [역방향 과정](foundations/reverse_process.md) -- 앞 확산을 거꾸로 돌려 잡음을 구조 있는 데이터로 바꾸는, 배운 생성 커널.
- 학습 목표 -- 변분 아래 한계에서 단순하게 만든 잡음 헤아리기 손실과 스코어 매칭와의 이음까지.

---

## 2. 스코어 기반 방법

- 점수 함수 -- 스코어 기반 생성 모델의 수학 기반으로서의 로그 밀도의 기울기.
- 스코어 매칭 -- 나눔 함수를 셈하지 않고 점수 함수를 맞추어 고르게 맞추지 않은 모델을 학습된이다.
- [Denoising Score Matching](score_based/denoising_score_matching.md) -- 비싼 헤세 계산을 아는 잡음 목표에 대한 단순한 되돌아 기대기로 바꾼다.
- [Sliced Score Matching](score_based/sliced_score_matching.md) -- 아무 쏘기와 허친슨 대각합 어림개를 쓴, 키울 수 있는 대안.
- 스코어 기반 모델 살펴보기 -- 이론과 짜기를 아우른 스코어 기반 생성 모델의 두루 갖춘 길잡이.
- 확산으로 이어지는 스코어 기반 방법 -- 베이즈 추론과 마르코프 사슬 몬테카를로 샘플링에서 요즘 확산 모델로 잇는 다리.
- 빠른 시작 길잡이 -- 스코어 기반 방법 길잡이 꾸러미의 빠른 시작 길잡이.

---

## 3. DDPM

- DDPM 기초 -- 잡음 없애는 확산 확률 모델: 앞 과정, 뒤 과정, 단순하게 만든 손실을 갖춘 온전한 틀.
- [노이즈 스케줄](ddpm/noise_schedule.md) -- 분산 차례표가 앎의 흐름, 학습 움직임, 생성 품질을 어떻게 다스리는가.
- DDPM 학습 -- 지수 이동 평균, 기울기 자르기, 섞인 정밀도, 실제로 쓸 만한 짜기를 담은 온전한 학습 물길.
- [DDPM 샘플링](ddpm/sampling.md) -- 이끌기 고르기를 갖춘, 배운 뒤 과정으로 순수 잡음에서 거듭 잡음을 없애기.
- 확산 모델 길잡이 살펴보기 -- 기초에서 앞선 재주까지 확산 모델을 배우는 가르치기 꾸러미 살펴보기.
- 확산 모델 모음 -- 장난감 수준에서 전문가 수준까지의 온전한 DDPM 짜기와 도구 모음.
- 빠른 시작 길잡이 -- 확산 모델 길잡이의 깔기와 빠른 시작.
- 이론 길잡이 -- 처음 배우는 이를 위해 앞 확산과 뒤 확산 과정을 다룬 직관 이론 길잡이.
- 시작하기 -- 확산 모델 꾸러미에서 처음 배우는 이와 익숙한 이의 입문.
- 빠른 참고 -- 복잡함과 할 수 있는 일로 확산 모델 짜기를 한눈에 비교.
- 꾸러미 간추리기 -- 확산 모델 가르치기 꾸러미의 온전한 파일 목록과 설명.

---

## 4. DDIM

- [DDIM 기초](ddim/fundamentals.md) -- 디노이징 확산 암시 모델: 다시 익히지 않고 마르코프가 아닌 과정으로 더 빠르게 샘플링.
- 정해진 샘플링 -- 같은 잡음이 늘 같은 것을 내놓는 온전히 정해진 생성.
- 빠르게 샘플링 -- 품질을 지키면서 샘플링 걸음을 1000에서 50 이하로 줄이는 방법.

---

## 5. 확률 미분 방정식 틀

- 확률 미분 방정식 기초 -- 확률 미분 방정식으로 확산 모델을 이어진 때의 눈으로 하나로 보기.
- 분산 지키기 확률 미분 방정식(VP-SDE) -- 퍼지는 내내 분산을 거의 1으로 지키는 DDPM의 이어진 때 넓힘.
- 분산 터짐 확률 미분 방정식(VE-SDE) -- 잡음이 커지고 신호가 줄지 않는 NCSN의 이어진 때 넓힘.
- 확률 흐름 상미분 방정식 -- 사후확률 미분 방정식과 가장자리 분포가 같은 정해진 상미분 방정식으로 정확한 우도와 사이 메우기를 가능하게 한다.

---

## 6. 조건 생성

- 분류기 이끌기 -- 바깥 분류기 기울기로 확산 샘플링을 바라는 갈래 쪽으로 이끈다.
- [Classifier-Free Guidance](conditional/classifier_free.md) -- 조건 있는 모델과 없는 모델을 함께 익혀 따로 분류기 없이 조건 생성 품질을 높인다.
- 글에서 그림으로 생성 -- 확산 모델과 CLIP 글 인코더를 아울러 자연어 설명에서 그림을 만든다.

---

## 7. 구조

- U-Net 잡음 없애개 -- 건너뛰기 이음과 때 걸음 조건 주기를 갖춘 확산 모델의 여느 인코더-디코더 구조.
- 확산 트랜스포머(DiT) -- U-Net을 보기 트랜스포머 등뼈로 바꾸어 확산에서 트랜스포머의 키우기 법칙을 보인다.
- 잠재 확산 모델 -- 계산을 크게 아끼려 누른 잠재공간에서 확산을 하며 Stable Diffusion의 기초가 된다.

---

## 8. 평가

- [확산 모델의 FID](evaluation/fid.md) -- 샘플링 걸음과 이끌기 잣수를 비롯한 확산에 딸린 살핌을 담은 프레셰 인셉션 거리.
- [확산 모델의 인셉션 점수](evaluation/inception_score.md) -- 실제 쓰기 길잡이와 함께 확산 모델의 둘째 잣대로서의 인셉션 점수.
- [우도에 바탕한 따지기](evaluation/likelihood.md) -- 원칙 있는 앎 이론의 따지기를 위한 음의 로그 우도, 차원마다 비트, 헷갈림도.
- CLIP 점수 -- 글에서 그림으로 가는 확산 모델의 으뜸 잣대로서 글과 그림의 맞음을 잰다.
- 사람이 따지기 -- 생성 모델 따지기의 으뜸 기준으로서 잘 듣는 사람 따지기 연구를 짠다.

---

## 9. 금융

- 인공 돈살림 데이터 생성 -- 실제 돈살림 데이터의 통계 성질을 지키면서 사생활을 지키는 인공 데이터셋을 만든다.
- 시나리오 생성 -- 위험 다루기, 버팀 시험, 꾸러미 최적화를 위해 그럴듯한 앞날 저자 상태를 낸다.
- 시계열 생성 -- 두꺼운 꼬리, 출렁임 뭉침, 자산 사이 서로 이어짐을 지키는 그럴듯한 돈살림 시계열을 만든다.
