# 에드먼즈-카프 알고리즘

포드-풀커슨 방법은 늘림 경로를 어떻게 고를지 정하지 않아서 느려지거나 담이가 무리수일 때는 끝나지 않을 수도 있다. 에드먼즈-카프 알고리즘은 늘 너비 우선 돌아보기로 **최단 늘림 경로**(변이 가장 적은 길)을 골라 이를 다룬다. 이 단순한 규칙 덕에 늘림이 $O(VE)$ 번 안에 끝남이 보장되고 온 시간 복잡도가 $O(VE^2)$이 된다.

---

## 1. 포드-풀커슨에서 에드먼즈-카프로

포드-풀커슨은 남은 그래프에서 늘림 경로를 거듭 찾아 그 길로 흐름을 흘려 보낸다. 이 방법은 어떤 경로 고르기 전략에도 옳지만, 늘림 횟수는 어떤 경로를 고르느냐에 달렸다.

에드먼즈-카프는 늘림 경로를 찾을 때 근원 $s$에서 **너비 우선 돌아보기**를 쓰도록 포드-풀커슨을 좁힌 것이다. 너비 우선 돌아보기는 거리가 늘어나는 차례로 꼭짓점을 살펴보므로, 찾은 경로는 늘 남은 그래프의 모든 $s$-$t$ 경로 가운데 변의 수가 가장 적다.

---

## 2. 알고리즘

```
EDMONDS-KARP(G, s, t):
    Initialize flow f(u,v) = 0 for all (u,v)
    while BFS finds a path P from s to t in G_f:
        c_f(P) = min { c_f(u,v) : (u,v) in P }
        for each edge (u,v) in P:
            f(u,v) = f(u,v) + c_f(P)
            f(v,u) = f(v,u) - c_f(P)
    return f
```

너비 우선 돌아보기마다 $O(V + E)$ 시간이 든다. 핵심 물음은 이것이다. 늘림이 몇 번이나 일어날 수 있는가?

---

## 3. 최단 경로 거리의 단조성

$O(VE^2)$ 테두리를 받치는 종요로운 결은 남은 그래프에서 최단 경로의 거리가 결코 줄지 않는다는 것이다.

**보조정리.** $\delta_f(s, v)$을 남은 그래프 $G_f$에서 $s$부터 $v$까지 최단 경로의 거리라 하자. 최단 경로를 따라 늘린 뒤 모든 꼭짓점 $v \in V$에 대해 다음이 이루어진다.

$$
\delta_{f'}(s, v) \geq \delta_f(s, v)
$$

여기서 $f'$은 늘린 뒤의 흐름이다.

*증명 얼개.* 어긋남을 보이려고 어떤 꼭짓점 $v$에 대해 $\delta_{f'}(s, v) < \delta_f(s, v)$이라 하자. 그런 꼭짓점 가운데 $\delta_{f'}(s, v)$이 가장 작은 $v$을 고른다. $G_{f'}$에서 $s$부터 $v$까지 최단 경로에서 $v$의 바로 앞 꼭짓점을 $u$이라 하자. 그러면 $\delta_{f'}(s, v) = \delta_{f'}(s, u) + 1$이다.

$v$을 그렇게 골랐으므로 $\delta_{f'}(s, u) \geq \delta_f(s, u)$이다. 변 $(u, v)$은 $G_{f'}$에 반드시 있다. $(u, v)$이 $G_f$에도 있다면 $\delta_f(s, v) \leq \delta_f(s, u) + 1 \leq \delta_{f'}(s, u) + 1 = \delta_{f'}(s, v)$이 되어 가정과 어긋난다.

$(u, v)$이 $G_f$에 없다면 $(v, u)$을 따라 늘리면서 생긴 것이다. 늘릴 때는 최단 경로를 쓰므로 $(v, u)$은 $G_f$의 최단 $s$-$t$ 길 위에 있고 따라서 $\delta_f(s, u) = \delta_f(s, v) + 1$이다. 그러면 $\delta_{f'}(s, v) = \delta_{f'}(s, u) + 1 \geq \delta_f(s, u) + 1 = \delta_f(s, v) + 2$이 되어 다시 $\delta_{f'}(s, v) < \delta_f(s, v)$과 어긋난다. $\square$

---

## 4. 늘림 횟수의 한계

**정리.** 에드먼즈-카프 알고리즘은 많아야 $O(VE)$번 늘린다.

*증명 얼개.* 남은 그래프의 변 $(u, v)$이 늘림 경로에서 남은 담이가 가장 작으면(곧 꽉 차게 되면) 그 변을 그 경로 위의 **결정적인** 변이라 하자. 늘림마다 적어도 변 하나가 꽉 찬다.

변 $(u, v)$이 고비 변일 때 $\delta_f(s, v) = \delta_f(s, u) + 1$이다. $(u, v)$이 남은 그래프에 다시 나타나려면 나중에 늘릴 때 $(v, u)$을 따라 흐름을 밀어 넣어야 한다. 그때 $\delta_{f'}(s, u) = \delta_{f'}(s, v) + 1$이다. 한 방향으로만 바뀜 보조정리에 따라

$$
\delta_{f'}(s, u) = \delta_{f'}(s, v) + 1 \geq \delta_f(s, v) + 1 = \delta_f(s, u) + 2
$$

그러므로 $(u, v)$이 잇달아 고비 변이 되는 사이에 $\delta_{f'}(s, u)$이 적어도 2 는다. 거리는 $|V| - 1$으로 마디 지어지므로 변마다 많아야 $O(V)$ 번 고비 변이 된다. 변이 $O(E)$개이므로 늘림은 모두 많아야 $O(VE)$ 번이다. $\square$

---

## 5. 전체 복잡도

**정리.** 에드먼즈-카프 알고리즘은 $O(VE^2)$ 시간에 돈다.

*증명.* 늘릴 때마다 $O(E)$ 때가 드는 너비 우선 돌아보기가 든다(이어진 그래프에서는 $E \geq V - 1$이기 때문이다). 늘림이 $O(VE)$ 번이므로 모두 $O(VE) \cdot O(E) = O(VE^2)$이다. $\square$

---

## 6. 풀이 예제

꼭짓점이 $\{s, a, b, t\}$인 그물을 보자.

| 변 | 담이 |
|------|----------|
| $(s, a)$ | 4 |
| $(s, b)$ | 3 |
| $(a, b)$ | 2 |
| $(a, t)$ | 3 |
| $(b, t)$ | 5 |

**되순환 1.** $s$부터 너비 우선 돌아보기를 돌리면 최단 경로 $s \to a \to t$(변 2개)을 찾는다. 병목 담이는 $\min(4, 3) = 3$이다. 흐름 3을 밀어 넣는다.

남은 그래프 고침: $(s, a)$의 남은 담이는 1, $(a, t)$은 꽉 참, 거꿀 변 $(a, s)$과 $(t, a)$이 담이 3으로 생긴다.

**되순환 2.** 너비 우선 돌아보기가 $s \to b \to t$(변 2개)을 찾는다. 병목은 $\min(3, 5) = 3$이다. 흐름 3을 밀어 넣는다.

**되순환 3.** 너비 우선 돌아보기가 $s \to a \to b \to t$(변 3개)을 찾는다. 병목은 $\min(1, 2, 2) = 1$이다. 흐름 1을 밀어 넣는다.

**4번째 바퀴.** 너비 우선 돌아보기가 $s$에서 $t$에 닿지 못한다. 알고리즘이 최대 흐름 = 7로 끝난다.

$s$에서 $t$까지의 최단 경로 거리가 1번째와 2번째 바퀴에서 2였다가 3번째 바퀴에서 3으로 늘어난 것을 보라. 단조성을 확인해 준다.

## 7. 파이썬 구현

```python
"""
최대 흐름을 위한 에드먼즈-카프 알고리즘.

너비 우선 돌아보기로 최단 늘림 경로를 찾아
시간 복잡도 O(VE^2).
"""

from collections import deque

# === 늘림 경로를 찾는 너비 우선 돌아보기 ===

def bfs(capacity: list, source: int, sink: int, parent: list) -> int:
    """
    너비 우선 돌아보기로 최단 늘림 경로를 찾는다.

    경로의 병목 담이를 돌려준다. 경로가 없으면 0.
    """
    n = len(capacity)
    visited = [False] * n
    visited[source] = True
    queue = deque([(source, float('inf'))])

    while queue:
        u, flow = queue.popleft()
        for v in range(n):
            if not visited[v] and capacity[u][v] > 0:
                visited[v] = True
                parent[v] = u
                new_flow = min(flow, capacity[u][v])
                if v == sink:
                    return new_flow
                queue.append((v, new_flow))
    return 0

# === 주된 알고리즘 ===

def edmonds_karp(n: int, edges: list, source: int, sink: int) -> int:
    """
    에드먼즈-카프로 최대 흐름을 셈한다.

    매개변수
    ----------
    n : int
        꼭짓점의 개수(0부터 n-1까지 이름 붙임).
    edges : (u, v, cap) 튜플의 목록
        담이를 갖는 방향 변.
    source : int
        근원 꼭짓점.
    sink : int
        바닥 꼭짓점.

    반환값
    -------
    int
        최대 흐름 값.
    """
    capacity = [[0] * n for _ in range(n)]
    for u, v, cap in edges:
        capacity[u][v] += cap

    parent = [-1] * n
    max_flow = 0

    while True:
        augment = bfs(capacity, source, sink, parent)
        if augment == 0:
            break
        max_flow += augment
        v = sink
        while v != source:
            u = parent[v]
            capacity[u][v] -= augment
            capacity[v][u] += augment
            v = u

    return max_flow

# === 보기 ===

if __name__ == "__main__":
    # s=0, a=1, b=2, t=3
    edges = [
        (0, 1, 4),  # s -> a
        (0, 2, 3),  # s -> b
        (1, 2, 2),  # a -> b
        (1, 3, 3),  # a -> t
        (2, 3, 5),  # b -> t
    ]
    result = edmonds_karp(4, edges, 0, 3)
    print(f"Maximum flow: {result}")  # 기대값: 7
```

!!! tip "에드먼즈-카프를 쓸 때"
    최대 흐름을 간단히 짜야 할 때는 에드먼즈-카프가 좋은 기본 고름이다. $O(VE^2)$ 테두리가 다항식이고 코드도 단순하다(너비 우선 돌아보기만 있으면 된다). 빽빽한 그래프에서 더 빠르게 하려면 $O(V^2E)$ 테두리를 지닌 디닉 알고리즘을 살펴보아라.

## 연습문제

**연습문제 1.**
에드먼즈-카프는 포드-풀커슨을 어떻게 낫게 하는가? 어떤 찾기 전략을 쓰는가?

??? success "연습문제 1 풀이"
    에드먼즈-카프는 아무 길이나 찾는 대신 너비 우선 돌아보기로 남은 그래프의 최단 늘림 경로를 찾는다. 그래서 최단 경로의 길이가 되순환 사이에 결코 줄지 않고, 같은 거리에서 많아야 $O(E)$ 번 늘린 뒤에는 늘어남이 보장된다. 늘림은 모두 $O(VE)$ 번이다. 너비 우선 돌아보기마다 $O(E)$이 든다. 모두 $O(VE^2)$이며 다항식이다. 흐름 값에 매인 포드-풀커슨의 $O(Ef^*)$과는 다르다. $\square$

---

**연습문제 2.**
에드먼즈-카프에서 최단 늘림 경로의 길이가 결코 줄지 않음을 증명하여라.

??? success "연습문제 2 풀이"
    최단 $s$-$t$ 길 $P$을 따라 늘린 뒤에는 $P$의 어떤 변이 가득 차고(나머지에서 지워지고) 그 뒤집은 변이 더해진다. 뒤집은 변은 더 긴 길에만 나타날 수 있다(거꾸로 가기 때문이다). 남은 그래프의 새 $s$-$t$ 길은 본디 남은 변만 쓰거나(같거나 더 길다) 뒤집은 변을 쓴다(적어도 2만큼 더 길다). 그러므로 최단 경로의 길이는 줄지 않는다. $\square$

---

**연습문제 3.**
에드먼즈-카프에서 늘림 경로 바퀴는 많아야 몇 번인가? 까닭을 대어라.

??? success "연습문제 3 풀이"
    많아야 $O(VE)$ 번이다. 거리 켜 $d$(최단 경로의 길이)마다 거리가 늘기 앞에 늘림이 많아야 $O(E)$ 번 일어난다(늘릴 때마다 거리 $d$의 변을 적어도 하나 가득 채우고, 변 하나는 이 거리에서 많아야 $O(V)$ 번 가득 찬다). $d$이 1부터 많아야 $V - 1$까지이므로 늘림은 모두 $\leq O(V \cdot E) = O(VE)$ 번이다. 늘릴 때마다 $O(E)$의 너비 우선 돌아보기를 쓰므로 모두 $O(VE^2)$이다. $\square$

---

**연습문제 4.**
에드먼즈-카프를 짜고, 근원 $s = 0$, 바닥 $t = 3$, 담이가 $(0,1,10), (0,2,8), (1,2,5), (1,3,5), (2,3,10)$인 변을 갖는 그래프에서 최대 흐름을 찾아라.

??? success "연습문제 4 풀이"
    너비 우선 돌아보기가 길 $0 \to 1 \to 3$을 찾아 5을 밀어 넣는다. 다음으로 $0 \to 2 \to 3$에 8을 밀어 넣는다. 그다음 $0 \to 1 \to 2 \to 3$에 2을 밀어 넣는다(나머지 $1 \to 2$의 담이는 5이지만 $2 \to 3$의 나머지 $10 - 8 = 2$에 매인다). 더는 늘림 경로가 없다. 최대 흐름은 $= 5 + 8 + 2 = 15$이다. $\square$
