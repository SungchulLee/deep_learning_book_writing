# 계층 베이즈 모델

계층 베이즈 모델은 그룹별 파라메터가 공통 모집단 분포를 따르도록 하여 그룹 사이에 정보를 공유한다. 비풀링·완전 풀링·부분 풀링을 비교하고, 알려진 하이퍼파라미터 아래의 조건부 수축 공식을 유도한다. 단순 대입 추정과 하이퍼파라미터까지 적분하는 추론은 구분한다.

## 1. 계층 모델의 구조

### 1.1 여러 레이어의 틀

계층 모델은 여러 레이어에서 분포를 정한다.

**레이어 1(데이터):** 그룹 안의 관찰

$$
y_{ij} | \theta_i \sim \mathcal{N}(\theta_i, \sigma^2)
$$

**레이어 2(그룹):** 그룹 수준의 파라메터

$$
\theta_i | \mu, \tau \sim \mathcal{N}(\mu, \tau^2)
$$

**레이어 3(하이퍼파라미터):** 모집단 수준의 파라메터

$$
\mu \sim \mathcal{N}(\mu_0, \sigma_0^2), \quad \tau \sim \text{Half-Cauchy}(\text{scale})
$$

### 1.2 기호

| 기호 | 뜻 |
|--------|---------|
| $y_{ij}$ | 그룹 $i$의 $j$번째 관찰 |
| $\theta_i$ | 그룹마다의 파라메터 |
| $\mu$ | 모집단의 평균(하이퍼파라미터) |
| $\tau$ | 그룹 사이의 표준편차 |
| $\sigma$ | 그룹 안의 표준편차 |
| $n_i$ | 그룹 $i$의 표본 크기 |

### 1.3 쓰임새

| 분야 | 그룹 | 관찰 |
|--------|--------|--------------|
| 교육 | 학교 | 학생의 시험 점수 |
| 의료 | 병원 | 환자의 결과 |
| 마케팅 | 상품 | 고객의 평점 |
| 심리학 | 피험자 | 되풀이한 측정 |
| 스포츠 | 팀 | 경기 성적 |

---

## 2. 세 가지 풀링 전략

### 2.1 비풀링(온전히 따로 두기)

그룹의 구조를 아랑곳하지 않고 $\theta_i$마다 따로 추정한다.

$$
\hat{\theta}_i^{\text{no pool}} = \bar{y}_i = \frac{1}{n_i} \sum_{j=1}^{n_i} y_{ij}
$$

**성질:**

- 그룹 사이의 차이에 가장 자유롭다
- 작은 그룹에서 분산이 크다
- 다른 그룹의 정보를 아랑곳하지 않는다

### 2.2 완전 풀링(그룹 효과 없음)

모든 그룹이 같은 파라메터를 나누어 쓴다고 놓는다.

$$
\hat{\theta}_i^{\text{complete}} = \bar{y}_{\cdot\cdot} = \frac{1}{N} \sum_{i,j} y_{ij}
$$

**성질:**

- 분산이 가장 작다
- 그룹이 정말 다르면 바이어스가 가장 크다
- 그룹의 구조를 아예 아랑곳하지 않는다

### 2.3 부분 풀링(계층)

그룹의 추정값을 모집단의 평균 쪽으로 오그라뜨린다.

$$
\boxed{\hat{\theta}_i^{\text{partial}} = w_i \bar{y}_i + (1 - w_i) \mu}
$$

여기서 w_i는 **데이터 웨이트**이며 수축 비율은 1−w_i다. 다음 식은 μ·τ·σ를 고정한 정규 모형의 조건부 사후평균에 해당한다.

$$
w_i = \frac{n_i}{n_i + \sigma^2/\tau^2}
$$

**성질:**

- 그룹별 데이터와 공통 모집단 정보를 결합한다.
- 알려진 분산 아래 표본 수가 작을수록 데이터 웨이트가 낮다.
- 조건부 사후평균은 해당 모형의 사후 제곱 로스를 최소화하지만 모든 참값의 빈도주의 MSE를 최소화한다는 뜻은 아니다.

---

## 3. 수축 현상

### 3.1 수축 무게 이해하기

무게 $w_i$은 그룹 $i$의 추정값이 제 데이터와 모집단 가운데 어느 쪽에 얼마나 기대는지를 정한다.

$$
w_i = \frac{n_i}{n_i + \sigma^2/\tau^2} = \frac{\text{group precision}}{\text{group precision} + \text{prior precision}}
$$

| 상황 | $w_i$ | 거동 |
|----------|-------|----------|
| $n_i$이 큼 | $\approx 1$ | 그룹의 데이터를 믿는다 |
| $n_i$이 작음 | $\approx 0$ | 모집단의 평균을 믿는다 |
| $\tau$이 큼(그룹이 서로 다름) | 더 높음 | 덜 수축 |
| $\tau$이 작음(그룹이 서로 비슷함) | 더 낮음 | 더 수축 |

### 3.2 정규화로서의 수축

부분 풀링은 극단적인 표본평균을 모집단 중심으로 수축시키는 정규화로 해석할 수 있다. 모형이 적절하면 분산을 줄이는 데 도움이 되지만 잘못된 공통 분포 가정은 바이어스를 만들 수 있다.

- 잡음 많은 그룹 추정값에 지나치게 맞추어지는 것을 막는다
- 작은 그룹에 특히 이롭다
- 데이터에 맞추어 수축을 저절로 조절한다

### 3.3 눈으로 보는 직관

고정된 분산에서 수축 비율은 표본 수로 결정된다. 관측 평균이 μ에서 멀면 같은 비율이라도 절대 이동량이 크다. 극단적 값이라는 이유만으로 수축 비율 자체가 자동으로 커지는 것은 아니다.

---

## 4. 그룹 평균의 수축 예제

교육 효과의 그룹 추정으로 부분 풀링을 설명할 수 있다. 고전적인 여덟 학교 모형은 학교별 효과 추정값과 표준오차를 관측하는 모형이다. 원시 학생 수와 공통 분산에서 출발하는 아래 함수는 그와 다른 단순 예제이며 실측 여덟 학교 자료를 재현하지 않는다.

### 4.2 구현

함수는 모집단 평균을 관측 그룹평균의 단순 평균, 그룹 간 표준편차를 그 표준편차로 대입한다. 그룹 표본 수가 다르면 단순 평균은 모든 원시 관측을 합친 완전 풀링 평균과 다르다. 관측 평균의 잡음을 그룹 분산에서 분리하지 않으며 μ·τ의 사후분포도 추론하지 않는다. 표준편차 0·비양수 표본 수·빈 입력을 별도로 처리해야 한다.

```python
import numpy as np

def hierarchical_estimates(observed_means, sample_sizes, sigma=15.0):
    """
    어울림 없음, 온전한 어울림, 얼마쯤 어울림 어림값을 셈한다.
    
    파라메터
    ----------
    observed_means : array
        무리 표본 평균
    sample_sizes : array
        무리마다의 표본 크기
    sigma : float
        아는 무리 안 표준편차
    
    반환값
    -------
    어울림 전략마다의 어림값을 담은 dict
    """
    n_groups = len(observed_means)
    
    # 어울림 없음: 관측 평균을 그대로 쓴다
    no_pool = observed_means.copy()
    
    # 온전한 어울림: 큰 평균
    complete_pool = np.full(n_groups, np.mean(observed_means))
    
    # 얼마쯤 어울림: 큰 평균 쪽으로 오그라뜨리기
    tau_est = np.std(observed_means)  # 경험 어림값
    grand_mean = np.mean(observed_means)
    
    weights = sample_sizes / (sample_sizes + sigma**2 / tau_est**2)
    partial_pool = weights * observed_means + (1 - weights) * grand_mean
    
    return {
        'no_pooling': no_pool,
        'complete_pooling': complete_pool,
        'partial_pooling': partial_pool,
        'weights': weights
    }
```

### 4.3 결과 해석

각 그룹의 관측 평균과 대입한 모집단 평균 사이에서 w_i에 따라 추정값이 이동한다. 실제 수치 비교에는 함수에 전달한 평균·표본 수·분산을 명시해야 한다. 조건이 없는 수축 결과 표를 표준 실측 자료의 결과처럼 제시하지 않는다.

## 5. 수학적 끌어내기

### 5.1 그룹 파라메터의 사후확률

계층 모델에서 데이터와 하이퍼파라미터가 주어졌을 때 $\theta_i$의 사후확률은 다음과 같다.

$$
\theta_i | y, \mu, \tau, \sigma \sim \mathcal{N}\left(\hat{\theta}_i, V_i\right)
$$

여기서 각 기호는 다음과 같다.

$$
\hat{\theta}_i = \frac{\frac{n_i}{\sigma^2} \bar{y}_i + \frac{1}{\tau^2} \mu}{\frac{n_i}{\sigma^2} + \frac{1}{\tau^2}}
$$

$$
V_i = \frac{1}{\frac{n_i}{\sigma^2} + \frac{1}{\tau^2}}
$$

### 5.2 정밀도로 무게 준 평균

사후확률의 평균은 **정밀도로 무게 준 평균**이다.

$$
\hat{\theta}_i = \frac{\tau_{\text{data}} \cdot \bar{y}_i + \tau_{\text{prior}} \cdot \mu}{\tau_{\text{data}} + \tau_{\text{prior}}}
$$

여기서 각 기호는 다음과 같다.

- $\tau_{\text{data}} = n_i/\sigma^2$은 데이터의 정밀도이다
- $\tau_{\text{prior}} = 1/\tau^2$은 사전확률의 정밀도이다

### 5.3 극한의 경우

**$\tau \to \infty$일 때**(그룹이 아주 다름):

- 사전확률이 흐릿하다 → $w_i \to 1$
- 부분 풀링 → 비풀링

**$\tau \to 0$일 때**(그룹이 똑같음):

- 사전확률이 빡빡하다 → $w_i \to 0$
- 부분 풀링 → 완전 풀링

---

## 6. 계층 모델의 이점

관련된 그룹의 정보를 공유해 작은 그룹의 불안정한 추정을 완화할 수 있다. 효과는 그룹 교환가능성과 선택한 분포가 적절한지에 달려 있다. 부분 풀링이 모든 그룹에서 언제나 더 정확하다는 뜻은 아니다.

완전한 계층 베이즈 추론은 그룹 파라메터뿐 아니라 모집단 하이퍼파라미터의 불확실성도 포함한다. 조건부 정규 공식에 추정 하이퍼파라미터를 대입하는 계산은 그 불확실성을 생략한다.

## 7. 실전에서 살필 것

그룹 정의와 관측 잡음, 모집단 분산의 사전분포를 명시한다. 표본이 많은 그룹과 적은 그룹의 적합도 및 새로운 그룹에 대한 예측을 나누어 점검한다.

MCMC나 변분 추론을 사용한다면 계산 진단과 사후예측 점검이 필요하다. 데이터가 적은 그룹 간 분산의 추론에는 하이퍼사전과 파라메터화가 영향을 줄 수 있다. 소프트웨어를 사용한다는 사실만으로 식별성이나 계산 안정성이 해결되지는 않는다.

## 정리하며

계층 모델은 공통 분포를 통해 그룹 정보를 공유한다. 조건부 데이터 웨이트·수축 비율과 하이퍼파라미터 불확실성을 구분하고, 단순 대입 예제를 실측 여덟 학교 분석이나 완전한 계층 사후추론으로 해석하지 않는다.
