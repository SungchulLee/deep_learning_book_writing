# 학습 기반 옵티마이저: 최적화를 위한 메타 학습

학습 기반 옵티마이저는 그래디언트와 이전 상태를 입력받아 파라메터 갱신량을 출력하는 함수를 학습한다. SGD나 Adam의 갱신 규칙을 설계하는 대신 여러 최적화 문제에서 좋은 규칙을 찾는 메타 학습이다. 반복해서 푸는 문제의 구조를 활용할 수 있지만, 메타 학습 비용과 새로운 문제에서의 일반화 성능을 함께 평가해야 한다.

## 1. 핵심 개념

- **최적화 대상 모델**: 로스를 줄일 파라메터 θ를 가진 모델
- **학습 기반 옵티마이저**: 갱신 규칙을 정하는 파라메터 Φ를 가진 함수
- **상태**: 그래디언트와 모멘텀, 이전 갱신 등 최적화 이력
- **메타 목표**: 여러 문제의 최적화 경로에서 측정한 로스
- **일반화**: 학습에 없던 모델·로스·최적화 길이에서 갱신 규칙이 유효한지 평가

## 2. 수학적 틀

### 경사 하강법을 기준으로 보기

가장 단순한 경사 하강법의 갱신은 다음과 같다. Adam과 모멘텀 SGD는 추가 상태를 사용하므로 이 식만으로 모두 표현되지는 않는다.

$$\theta_{t+1} = \theta_t - \alpha_t \mathbf{g}_t$$

여기서 $\mathbf{g}_t$은 그래디언트이고 $\alpha_t$은 러닝레이트다.

### 학습 기반 옵티마이저 틀

고정된 갱신 규칙을 학습한 함수로 대체한다.

$$\theta_{t+1} = \theta_t + f_{\Phi}(\mathbf{g}_t, \mathbf{m}_t, \mathbf{s}_t)$$

여기서 각 기호는 다음과 같다.

- $f_{\Phi}$은 배운 갱신 함수이다
- $\mathbf{m}_t$은 이동평균 등 이전 그래디언트를 요약한 상태이다
- $\mathbf{s}_t$은 문제의 구조를 담는다

### 최적화 로스

메타 학습은 학습 자취 위의 로스를 가장 작게 한다.

$$\mathcal{L}_{\text{meta}}(\Phi) = \mathbb{E}_{\ell\sim\mathcal D}\left[\sum_{t=1}^{T}w_t\ell(\theta_t(\Phi))\right]$$

각 최적화 문제의 파라메터 θ는 학습된 갱신 규칙을 반복 적용한 결과이므로 Φ에 의존한다. 웨이트 w_t는 최종 성능이나 초기 수렴 등 목표에 맞춰 정한다. 외부 옵티마이저가 이 메타 로스로 Φ를 갱신하며, 학습 기반 옵티마이저 자신이 반드시 외부 최적화까지 수행하는 것은 아니다.

## 3. 학습 기반 옵티마이저의 구조

### 순환 뉴럴 넷트웍 옵티마이저

LSTM은 그래디언트와 은닉 상태·셀 상태를 받아 새 상태와 갱신량을 계산한다. 아래 식의 h는 두 상태를 포괄하는 간단한 표기다. 좌표마다 같은 LSTM 웨이트를 공유하고 상태만 따로 둘 수도 있다.

$$\mathbf{h}_t = \text{LSTM}(\mathbf{g}_t, \mathbf{h}_{t-1})$$

$$\Delta \theta_t = \text{Linear}(\mathbf{h}_t)$$

LSTM이 그래디언트 이력에 따라 갱신 크기와 방향을 조절하도록 학습한다. 모멘텀이나 러닝레이트 조절과 유사한 액션을 배울 수 있지만, 안정적인 하강 방향이나 수렴을 자동 보장하지는 않는다.

### 컨볼루션 옵티마이저

컨볼루션 레이어의 그래디언트는 입력 채널·출력 채널·공간 커널 축을 가진다. 이 구조에 컨볼루션을 적용하는 갱신 규칙을 설계할 수 있지만 모든 파라메터의 그래디언트가 이미지 형태인 것은 아니다.

$$\Delta \theta_t = \text{Conv}(\mathbf{g}_t, \text{컨볼루션 내력})$$

그래디언트의 공간 구조를 잡아내어 레이어의 종류마다 어떻게 갱신해야 하는지를 배운다.

### 트랜스포머 기반 옵티마이저

그래디언트 이력과 문제 구조를 어텐션으로 처리한다.

$$\Delta \theta_t = \text{Attention}(\mathbf{g}_t, \text{지난 그래디언트})$$

여러 갱신 단계 사이의 의존성을 표현할 수 있다.

## 4. 상태 표현

학습 기반 옵티마이저에 어떤 피처를 넣어야 하는가?

### 그래디언트 정보

**원시 그래디언트**: $\mathbf{g}_t$을 그대로 쓴다(원래 크기와 방향을 유지한다)

**정규화한 그래디언트**: $\mathbf{g}_t / (\|\mathbf{g}_t\| + \epsilon)$(크기를 없애고 방향에 집중한다)

**로그 절댓값 그래디언트**: $\log(|\mathbf{g}_t| + \epsilon)$(넓은 크기 범위를 다룬다)

### 모멘텀 정보

$$\mathbf{m}_t = \beta \mathbf{m}_{t-1} + (1-\beta) \mathbf{g}_t$$

최근 갱신 이력과 모멘텀 상태를 담는다.

### 2차 정보

**그래디언트 분산**: 최근 창에 대한 $\text{Var}(\mathbf{g}_{t-k:t})$

**로스 곡률 근사**: 헤시안 대각 성분의 근사에서 얻는다

### 문제에 맞춘 피처

!!! tip "도메인 지식 활용"
    더 잘 맞추어 가도록 영역에 맞춘 피처를 넣는다.
    
    - 자산 종류(주식, 채권, 파생)
    - 시장 유동성 국면
    - 지난 변동성
    - 마지막 갱신 뒤로 흐른 시간

## 5. 학습 절차

### 메타 학습

서로 다른 최적화 과제(다른 로스, 데이터셋, 구조)를 모은다.

```
for each meta-iteration:
    Sample task T ~ P(tasks)
    Initialize θ from N(0, I)
    for t = 1 to T_steps:
        g ← compute gradients
        Δθ ← optimizer(g, history)
        θ ← θ + Δθ
        Accumulate meta-loss L(θ)
    Compute meta-gradient: ∂L_meta/∂Φ
    Update optimizer: Φ ← Φ - α∇Φ L_meta
```

### 메타 학습의 어려움

**비정상성**: 내부 최적화가 진행되면서 그래디언트와 상태의 분포가 바뀐다. 짧은 경로로 학습한 옵티마이저를 더 긴 경로에 적용했을 때도 안정적인지 확인한다.

**일반화 격차**: 특정 문제 분포로 학습된 옵티마이저가 다른 종류의 문제로 옮겨 가지 못할 수 있다.

**계산 비용**: 외부 학습에서 내부 최적화 경로를 미분하면 높은 메모리와 계산 비용이 든다. 경로를 잘라 역전파하면 비용을 줄일 수 있지만 메타 경사가 바이어스될 수 있다.

---

## 6. 일반화 다루기

### 과제 분포 설계

여러 문제 분포로 메타 학습한다.

- 서로 다른 로스 함수(분류, 회귀, 순위 매기기)
- 서로 다른 구조(CNN, RNN, 트랜스포머)
- 서로 다른 데이터셋 크기
- 서로 다른 조건수(쉬운 최적화 지형과 어려운 최적화 지형)

### 학습 기반 옵티마이저의 정규화

특정 문제에 지나치게 맞추어지지 않도록 정규화를 더한다.

$$\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{meta}} + \lambda \Omega(\Phi)$$

여기서 Ω(Φ)는 웨이트 크기나 갱신 크기 등 선택한 성질을 제어하는 정규화 항이다. 정규화 항을 추가하는 것만으로 갱신 규칙의 해석 가능성이나 수렴이 보장되는 것은 아니다.

### 섞은 접근법

배운 부품과 고정 부품을 섞는다.

$$\Delta\theta_t=-\alpha_\Phi(\mathbf g_t)\mathbf g_t-\beta_\Phi\mathbf m_t$$

그래디언트와 모멘텀 방향에 음의 부호를 두고 양의 스텝 크기를 학습하는 한 가지 혼합 설계다. 다른 부호 규약을 쓰면 갱신 함수가 부호까지 출력해야 한다. 양의 스텝 크기만으로 임의의 로스에서 안정성이 보장되지는 않는다.

## 7. 효율에 대한 고려

갱신마다 뉴럴 넷트웍을 계산하고 좌표별 상태를 저장하므로 일반 옵티마이저보다 단계당 비용이 늘 수 있다. 필요한 갱신 수가 줄더라도 전체 시간이 줄었는지는 별도로 측정한다.

비슷한 문제를 반복해서 풀면 메타 학습 비용을 여러 실행에 나누어 부담할 수 있다. 비교에는 메타 학습 시간, 대상 모델 학습 시간, 메모리, 검증 성능과 실패율을 포함한다. 특정한 실험 조건 없이 Adam보다 일정 비율 빠르다고 단정할 수 없다.

## 8. 고정 옵티마이저와의 비교

| 항목 | SGD·Adam 등 | 학습 기반 옵티마이저 |
|---|---|---|
| 갱신 규칙 | 사람이 정한 수식과 상태 갱신 | 학습한 함수와 상태 갱신 |
| 사전 준비 | 러닝레이트 등 하이퍼파라미터 선택 | 과제 분포 설계와 메타 학습도 필요 |
| 실행 비용 | 상태 수와 연산이 비교적 명확 | 구조·상태 크기에 따라 달라짐 |
| 일반화 평가 | 문제별 조율 후 비교 | 새로운 문제와 최적화 길이도 점검 |

어느 쪽이 빠르고 정확한지는 같은 종료 기준과 조율 예산에서 비교한다. SGD가 일반화하는 문제 범위가 본질적으로 좁다고 분류할 근거는 없다.

## 9. 계량 금융에서의 쓰임

새 데이터로 모델을 반복 재학습하는 과정에 학습 기반 옵티마이저를 적용해 볼 수 있다. 이때 외부 학습에 쓰는 과제와 최종 평가 기간을 분리하고, 각 시점에 관측 가능한 정보만 갱신 함수에 제공한다.

일반 옵티마이저 대비 재학습 시간과 예측 오차를 평가한다. 예측 모델의 최적화가 빨라지는 것과 거래 수익이나 포트폴리오 성과가 개선되는 것은 별개의 결과다.

## 10. 연구의 방향

- 다른 모델 구조와 로스로의 일반화
- 학습 때보다 긴 최적화 경로에서의 안정성
- 메타 학습의 메모리·계산 비용 절감
- 갱신 규칙의 수렴 조건과 해석 가능성

??? success "연습문제 1 풀이"

<div class="drillbox" markdown>

**연습문제 2.** <span class="diff easy" title="쉬움"></span>

---

<div class="drillbox" markdown>

**연습문제 3.** <span class="diff med" title="중간"></span>
Andrychowicz 등의 좌표별 LSTM 옵티마이저에서 공유되는 것과 분리되는 것을 설명하라.

</div>

??? success "연습문제 3 풀이"
    LSTM의 웨이트는 좌표 사이에 공유하지만 은닉·셀 상태는 좌표마다 따로 둔다. 각 좌표의 그래디언트를 전처리해 갱신량을 계산한다. 0 근처 그래디언트의 로그가 발산하지 않도록 크기에 따른 분기와 스케일 처리가 필요하며 단순 log|g|만으로 전처리가 완성되지는 않는다.

---

**연습문제 4.** <span class="diff med" title="중간"></span>
학습 기반 옵티마이저와 Adam을 공정하게 비교할 조건을 제시하라.

</div>

??? success "연습문제 4 풀이"
    대상 문제의 학습·검증·테스트를 분리하고 같은 목표 성능과 종료 기준을 사용한다. Adam의 러닝레이트도 검증셋에서 선택한다. 학습 기반 옵티마이저의 사전 비용, 단계당 비용과 분포 밖 실패를 포함하며 평가 과제를 메타 학습에 사용하지 않는다.

## 정리하며

학습 기반 옵티마이저는 최적화 경로에서 얻은 로스로 갱신 규칙을 학습한다. 반복 문제에서의 이점을 평가하려면 사전 비용과 단계당 비용, 새 과제 및 긴 경로에서의 안정성을 함께 측정해야 한다.

**참고**: [Andrychowicz 등, Learning to learn by gradient descent by gradient descent](https://arxiv.org/abs/1606.04474).
