# T5

T5는 2020년 논문 "Exploring the Limits of Transfer Learning with a Unified Text-to-Text Transformer"에서 나왔다. 모든 과제를 텍스트를 텍스트로 옮기는 문제로 다루며(입력도 출력도 텍스트다), 구조는 인코더-디코더 트랜스포머이고, 사전 학습 때 *스팬 손상*(span corruption, 연속한 토큰 구간을 센티넬 토큰으로 가리고 그 구간을 맞히게 하는 것)을 쓴다.

이 쪽의 구현은 T5의 핵심만 남긴 교육용 예시다. 코드는 핵심 구조와 순전파(forward pass, 입력에서 출력까지의 계산)에 집중하므로, 주요 구성 요소를 살펴보고 여러 가지로 바꾸어 보기 쉽다.

## 1. 코드

```python
#!/usr/bin/env python3
"""
T5 - 텍스트를 텍스트로 옮기는 트랜스포머
논문: "Exploring the Limits of Transfer Learning with a Unified Text-to-Text Transformer" (2020)
저자: 콜린 라펠 외
핵심 아이디어:
  - 모든 과제를 텍스트를 텍스트로 옮기는 문제로 다룬다(입력도 출력도 텍스트다)
  - 인코더-디코더 트랜스포머
  - 사전 학습 때 *스팬 손상(span corruption)*(센티넬 토큰)을 쓴다

파일: appendix/transformers/t5.py
참고: 교육용 단순 구현이다(구조 + 순전파의 형태).
"""

import torch
import torch.nn as nn
import torch.nn.functional as F

# ========================================================================
# 메인
# ========================================================================


class T5Encoder(nn.Module):
    """트랜스포머 인코더: 토큰 임베딩 -> 인코더 은닉 상태."""
    def __init__(self, vocab_size=32128, d_model=512, nhead=8, num_layers=6):
        super().__init__()
        self.embed = nn.Embedding(vocab_size, d_model)

        # PyTorch 인코더 레이어는 셀프 어텐션 + 피드포워드를 쓴다
        enc_layer = nn.TransformerEncoderLayer(d_model=d_model, nhead=nhead, batch_first=True)
        self.encoder = nn.TransformerEncoder(enc_layer, num_layers=num_layers)

    def forward(self, input_ids, attention_mask=None):
        # input_ids: (B, S)
        x = self.embed(input_ids)  # (B, S, D)

        # attention_mask(선택): 남길 토큰이면 True/1, 패딩이면 False/0
        # PyTorch는 src_key_padding_mask를 쓰며 True이면 "계산에서 제외한다"는 뜻이다
        src_key_padding_mask = None
        if attention_mask is not None:
            src_key_padding_mask = ~attention_mask.bool()  # (B, S)

        h = self.encoder(x, src_key_padding_mask=src_key_padding_mask)  # (B, S, D)
        return h


class T5Decoder(nn.Module):
    """트랜스포머 디코더: 자기회귀 셀프 어텐션 + 인코더로 가는 교차 어텐션."""
    def __init__(self, vocab_size=32128, d_model=512, nhead=8, num_layers=6):
        super().__init__()
        self.embed = nn.Embedding(vocab_size, d_model)

        dec_layer = nn.TransformerDecoderLayer(d_model=d_model, nhead=nhead, batch_first=True)
        self.decoder = nn.TransformerDecoder(dec_layer, num_layers=num_layers)

        # 언어 모델 헤드: 디코더 상태를 어휘 로짓으로 옮긴다
        self.lm_head = nn.Linear(d_model, vocab_size)

    def forward(self, decoder_input_ids, encoder_hidden_states, encoder_attention_mask=None):
        # decoder_input_ids: (B, T)
        y = self.embed(decoder_input_ids)  # (B, T, D)

        # 인과 마스크가 디코더가 뒤 토큰을 미리 보지 못하게 한다
        T = decoder_input_ids.size(1)
        causal_mask = torch.triu(torch.ones(T, T, device=y.device), diagonal=1).bool()  # (T, T)

        # 인코더 패딩 마스크: True이면 계산에서 제외한다
        mem_key_padding_mask = None
        if encoder_attention_mask is not None:
            mem_key_padding_mask = ~encoder_attention_mask.bool()  # (B, S)

        # encoder_hidden_states로 가는 교차 어텐션을 쓰며 디코딩한다
        dec_h = self.decoder(
            tgt=y,
            memory=encoder_hidden_states,
            tgt_mask=causal_mask,
            memory_key_padding_mask=mem_key_padding_mask,
        )  # (B, T, D)

        logits = self.lm_head(dec_h)  # (B, T, vocab)
        return logits


class T5(nn.Module):
    """T5 인코더-디코더 래퍼(텍스트를 텍스트로)."""
    def __init__(self, vocab_size=32128, d_model=512, nhead=8, num_layers=6):
        super().__init__()
        self.encoder = T5Encoder(vocab_size, d_model, nhead, num_layers)
        self.decoder = T5Decoder(vocab_size, d_model, nhead, num_layers)

    def forward(self, input_ids, decoder_input_ids, attention_mask=None):
        enc = self.encoder(input_ids, attention_mask=attention_mask)
        logits = self.decoder(decoder_input_ids, enc, encoder_attention_mask=attention_mask)
        return logits


if __name__ == "__main__":
    model = T5(vocab_size=1000, d_model=256, nhead=8, num_layers=2)
    input_ids = torch.randint(0, 1000, (2, 7))
    dec_in = torch.randint(0, 1000, (2, 5))
    attn = torch.ones(2, 7, dtype=torch.long)
    logits = model(input_ids, dec_in, attention_mask=attn)
    print("logits:", logits.shape)  # (2, 5, 1000)
```

**출력:**

```
logits: torch.Size([2, 5, 1000])
```

## 2. 논의

이 구현은 클래스 3개(`T5Encoder`, `T5Decoder`, `T5`)를 정의하고, 이들이 함께 완전한 트랜스포머 구조를 이룬다. 클래스마다 고유한 역할을 맡아 코드가 모듈로 나뉘고 확장하기 쉽다. `forward` 메서드가 PyTorch의 자동 미분이 쓰는 계산 그래프를 정의한다.

이 코드는 구조를 이해하기 위한 교육용 구현이다. 실제 학습에서는 데이터와 하드웨어에 맞춰 혼합 정밀도, 분산 학습, 데이터 어그멘테이션 등을 검토할 수 있다. 다만 이런 기법의 적용 조건과 효과는 모델별로 확인해야 한다.

## 연습문제

<div class="drillbox" markdown>

**연습문제 1.** <span class="diff easy" title="쉬움"></span>
기본 설정으로 만든 `T5Encoder`의 학습 가능한 파라메터를 모두 세어라. 웨이트와 바이어스를 포함해 레이어마다 나누어 적어라.

</div>

??? success "풀이"
    `nn.Linear(in_features, out_features)`마다 웨이트 파라메터가 `in_features * out_features`개이고 바이어스가 `out_features`개다(`bias=False`가 아니면). `nn.Conv2d(in_c, out_c, k)`마다 웨이트가 `in_c * out_c * k * k`개, 바이어스가 `out_c`개다. `nn.Embedding(num, dim)`은 파라메터가 `num * dim`개다. 모든 레이어의 값을 더한다. `sum(p.numel() for p in model.parameters())`로 확인할 수 있다.

---

<div class="drillbox" markdown>

**연습문제 2.** <span class="diff hard" title="어려움"></span>
어텐션 웨이트 뒤(값과 곱하기 앞)에 드롭아웃 레이어를 추가하여라. 학습하는 동안 드롭아웃 비율 0.1을 써라. 어텐션 드롭아웃이 정칙화에 왜 도움이 되는지 설명하여라.

</div>

??? success "풀이"
    `__init__`에 `self.attn_dropout = nn.Dropout(0.1)`을 추가하고 소프트맥스 뒤에 적용한다. `attn_weights = self.attn_dropout(F.softmax(scores, dim=-1))`. 어텐션 드롭아웃은 학습하는 동안 어텐션 웨이트 일부를 무작위로 0으로 만들어, 모델이 토큰 사이의 특정 관계에만 의존하는 것을 막는다. 그래서 모델이 어텐션을 더 고르게 분산하고 더 강건한 표현을 학습하게 되는데, 이는 일반 드롭아웃이 뉴런끼리의 공적응(co-adaptation, 서로에게 지나치게 의존하게 되는 것)을 막는 것과 같다.

---

<div class="drillbox" markdown>

**연습문제 3.** <span class="diff med" title="중간"></span>
셀프 어텐션의 계산 복잡도를 시퀀스 길이 $n$과 모델 차원 $d$의 함수로 나타내어라. 이것이 긴 시퀀스를 위해 Longformer나 Linformer 같은 구조가 나온 동기가 되는 까닭은 무엇인가?

</div>

??? success "풀이"
    표준 셀프 어텐션은 $n \times n$ 어텐션 행렬을 계산하므로 시간 복잡도는 $O(n^2 d)$, 어텐션 웨이트의 메모리는 $O(n^2)$이다. 시퀀스가 길면($n = 4096$ 따위) 감당할 수 없다. Longformer는 슬라이딩 윈도 국소 어텐션($O(n \cdot w \cdot d)$, $w$는 윈도 크기)과 선택한 토큰에 대한 희소한 전역 어텐션을 함께 쓴다. Linformer는 키와 값을 더 낮은 차원 $k \ll n$으로 투영하여 복잡도를 $O(n \cdot k \cdot d)$로 줄인다. 둘 다 표현력을 얼마쯤 내주고 긴 입력에서 효율을 얻는다.

---

<div class="drillbox" markdown>

**연습문제 4.** <span class="diff hard" title="어려움"></span>
`T5Encoder`를 레이어나 블록의 수를 설정할 수 있게 확장하여라. `__init__`에 `num_layers` 인자를 추가하고 `nn.ModuleList`로 깊이를 바꿀 수 있는 구조를 구현하여라. 레이어 2개, 4개, 8개로 시험하여라.

</div>

??? success "풀이"
    하드코딩한 레이어를 다음으로 대체한다.
    ```python
    self.layers = nn.ModuleList()
    for i in range(num_layers):
        self.layers.append(YourBlock(dim, ...))
    ```
    `forward` 메서드에서 `for layer in self.layers: x = layer(x)`로 순회한다. 일반 파이썬 리스트가 아니라 `nn.ModuleList`를 써야 PyTorch가 그 안의 파라메터를 모델에 등록하고, 옵티마이저가 그것들을 갱신할 수 있다. `for n in [2, 4, 8]: model = T5Encoder(num_layers=n); print(f'Layers={n}, params={sum(p.numel() for p in model.parameters()):,}')`로 시험한다.
