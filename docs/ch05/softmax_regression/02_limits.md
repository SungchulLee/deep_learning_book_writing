# 소프트맥스 회귀의 한계

---

## 1. 학습 목표

이 절을 마치면 다음을 할 수 있게 된다.

- 소프트맥스 회귀의 결정 경계가 왜 초평면인지 유도하기
- 결정 영역이 볼록하다는 사실과 그 결과를 설명하기
- 선형으로 가를 수 있는 자료와 없는 자료에서 성능 차이를 재기
- 은닉층이 무엇을 더해 주는지, 그리고 언제 더해 주지 않는지 말하기

---

## 2. 결정 경계는 왜 직선인가

소프트맥스 회귀는 로짓을 아핀 변환 하나로 만든다.

$$\mathbf{z} = \mathbf{x}A + \mathbf{b}, \qquad z_k = \mathbf{x}\mathbf{a}_k + b_k$$

예측은 로짓이 가장 큰 클래스이다. 소프트맥스는 순서를 바꾸지 않으므로 확률로 바꾸어도 결과가 같다.

$$\hat{y} = \arg\max_k z_k$$

클래스 $i$와 $j$의 경계는 두 로짓이 같아지는 자리이다.

$$z_i = z_j \iff \mathbf{x}\mathbf{a}_i + b_i = \mathbf{x}\mathbf{a}_j + b_j \iff \mathbf{x}(\mathbf{a}_i - \mathbf{a}_j) + (b_i - b_j) = 0$$

이 식은 $\mathbf{x}$에 대해 **일차식**이다. 즉 두 클래스의 경계는 언제나 초평면이며, 2차원 자료에서는 직선이다. 가중치를 아무리 학습해도 이 사실은 달라지지 않는다. 학습이 바꿀 수 있는 것은 직선의 기울기와 위치뿐이다.

### 결정 영역은 볼록하다

한 걸음 더 나아가면 더 강한 성질이 나온다. 클래스 $k$로 분류되는 영역은 다음과 같다.

$$R_k = \{\mathbf{x} : z_k \geq z_j \ \ \forall j\}$$

각 조건 $z_k \geq z_j$는 반평면 하나를 뜻하고, $R_k$는 그 반평면들의 **교집합**이다. 볼록집합끼리의 교집합은 볼록이므로 $R_k$도 볼록이다.

!!! tip "이것이 뜻하는 바"
    소프트맥스 회귀는 각 클래스의 영역을 **볼록한 덩어리**로만 그릴 수 있다.
    영역이 휘어야 하거나, 둘로 나뉘어야 하거나, 다른 영역을 감싸야 한다면 이 모델로는 표현할 수 없다.

이 성질은 추상적인 말로 그치지 않고, 아래에서 숫자로 확인된다.

## 3. 세 가지 자료로 확인하기

성질을 확인하려면 성질이 드러나는 자료가 필요하다. 2차원 자료를 쓰는 까닭은 결정 경계를 눈으로 그릴 수 있기 때문이다. MNIST에서는 784차원이라 이런 확인이 불가능하다.

| 자료 | 생김새 | 볼록한 영역으로 가를 수 있는가 |
|---|---|---|
| `make_blobs` | 흩어진 세 덩이 | 가능하다 |
| `make_moons` | 서로 맞물린 두 초승달 | 어렵다 |
| `make_circles` | 겹겹의 두 동심원 | 불가능하다 |

동심원이 특히 결정적이다. 안쪽 원이 한 클래스이고 바깥 고리가 다른 클래스라면, 바깥 클래스의 영역은 안쪽을 감싸는 **고리 모양**이어야 한다. 고리는 볼록하지 않다. 따라서 소프트맥스 회귀로는 원리상 풀 수 없다.

```python
import numpy as np
import torch
import torch.nn as nn
from sklearn.datasets import make_blobs, make_moons, make_circles
from sklearn.model_selection import train_test_split


def make_data(name, n=2000, seed=0):
    """세 가지 2차원 자료를 같은 방식으로 만들어 나눈다."""
    if name == "blobs":
        X, y = make_blobs(n_samples=n, centers=3, n_features=2,
                          cluster_std=1.2, random_state=seed)
    elif name == "moons":
        X, y = make_moons(n_samples=n, noise=0.20, random_state=seed)
    else:
        X, y = make_circles(n_samples=n, noise=0.10, factor=0.5, random_state=seed)
    # 특징마다 평균 0, 표준편차 1로 맞춘다. 두 모델에 같은 조건을 준다.
    X = (X - X.mean(0)) / X.std(0)
    return train_test_split(X.astype(np.float32), y.astype(np.int64),
                            test_size=0.3, random_state=seed)


def train(model, Xtr, ytr, Xte, yte, epochs=400):
    """전체 묶음 경사 하강법으로 학습시키고 시험 정확도를 돌려준다."""
    opt = torch.optim.Adam(model.parameters(), lr=0.05)
    criterion = nn.CrossEntropyLoss()
    Xtr, ytr = torch.from_numpy(Xtr), torch.from_numpy(ytr)
    Xte, yte = torch.from_numpy(Xte), torch.from_numpy(yte)
    for _ in range(epochs):
        opt.zero_grad()
        criterion(model(Xtr), ytr).backward()
        opt.step()
    with torch.no_grad():
        return 100 * (model(Xte).argmax(1) == yte).float().mean().item()


print(f"{'자료':<10} {'클래스':>5} | {'소프트맥스 회귀':>16} | {'은닉층 있는 MLP':>16}")
print("-" * 60)

for name in ("blobs", "moons", "circles"):
    Xtr, Xte, ytr, yte = make_data(name)
    k = len(np.unique(ytr))

    # 소프트맥스 회귀: 아핀 변환 하나뿐. 은닉층도 활성화 함수도 없다.
    torch.manual_seed(0)
    linear = nn.Linear(2, k)
    acc_linear = train(linear, Xtr, ytr, Xte, yte)

    # 견주기 위한 다층 퍼셉트론. 은닉층과 ReLU가 경계를 휘게 해 준다.
    torch.manual_seed(0)
    mlp = nn.Sequential(
        nn.Linear(2, 32), nn.ReLU(),
        nn.Linear(32, 32), nn.ReLU(),
        nn.Linear(32, k),
    )
    acc_mlp = train(mlp, Xtr, ytr, Xte, yte)

    print(f"{name:<10} {k:>5} | {acc_linear:>15.2f}% | {acc_mlp:>15.2f}%")
```

**출력:**

```
자료           클래스 |         소프트맥스 회귀 |       은닉층 있는 MLP
------------------------------------------------------------
blobs          3 |           88.83% |           87.50%
moons          2 |           86.50% |           97.00%
circles        2 |           52.17% |           99.00%
```

## 4. 표를 읽는 법

세 줄이 저마다 다른 이야기를 한다.

**흩어진 덩이(blobs)** — 두 모델이 거의 같다. 오히려 소프트맥스 회귀가 조금 낫다. 자료가 이미 선형으로 갈리므로 은닉층이 보탤 것이 없고, 매개변수만 많아져 손해를 볼 수도 있다. **모델을 키우는 일이 언제나 이득은 아니다.**

**초승달(moons)** — 격차가 벌어진다. 두 초승달이 맞물린 자리를 직선 하나로는 깨끗이 가를 수 없어, 경계 언저리의 점들을 놓친다.

**동심원(circles)** — 소프트맥스 회귀가 52% 언저리에 머문다. 클래스가 둘이므로 아무렇게나 찍어도 50%이다. 즉 **거의 아무것도 배우지 못했다.** 학습이 실패한 것이 아니라, 배울 수 있는 것이 없었던 것이다. 어떤 직선을 그어도 안쪽 원과 바깥 고리를 가를 수 없기 때문이다.

세 번째 줄이 2절의 볼록성 논증을 숫자로 확인해 준다. 이론이 "불가능하다"고 말한 자리에서 실제로 우연 수준의 정확도가 나온다.

## 5. 벽을 넘는 두 가지 길

동심원을 풀려면 결정 경계가 휘어야 한다. 방법은 크게 둘이다.

**특징을 손수 더한다.** $x_1^2 + x_2^2$이라는 특징 하나를 더하면 동심원 문제가 곧바로 선형으로 갈린다. 반지름이 곧 그 값이므로, 새 좌표에서는 두 클래스가 문턱 하나로 나뉜다. 다만 이 방법은 **자료의 생김새를 미리 알아야** 쓸 수 있다.

**특징을 학습하게 한다.** 은닉층과 비선형 활성화 함수를 두면 모델이 쓸모 있는 좌표계를 스스로 찾는다. 어떤 특징이 필요한지 몰라도 된다는 점이 결정적이며, 이것이 딥러닝이 하는 일이다.

위 표의 마지막 열이 두 번째 길의 결과이다. 왜 활성화 함수가 있어야 하는지는 [6.1 활성화 함수](../../ch06/index.md)에서, MNIST에서 같은 도약이 일어나는 모습은 [3.3 다층 퍼셉트론](../../ch03/mnist/03_mlp.md)에서 볼 수 있다.

!!! note "소프트맥스 회귀가 쓸모없다는 말이 아니다"
    고차원 자료는 낮은 차원보다 선형으로 갈리기 쉬운 경향이 있다. MNIST에서 소프트맥스 회귀가 92.51%를 얻는 것이 그 예이다([3.2절](../../ch03/mnist/02_linear_softmax.md)).
    이 절의 요점은 모델이 나쁘다는 것이 아니라, **모델마다 표현할 수 있는 모양이 정해져 있다**는 것이다. 자료가 그 안에 들어오면 단순한 모델로 충분하다.

## 연습문제

**연습문제 1.**
동심원 자료에 특징 $x_1^2 + x_2^2$을 하나 더해 입력을 3차원으로 만든 뒤 소프트맥스 회귀를 학습시켜라. 정확도가 얼마나 오르는가?

??? success "연습문제 1 풀이"
**52.17%에서 99.50%로** 오른다. 같은 모델, 같은 학습 설정인데 특징 하나를 더했을 뿐이다. 새 특징이 곧 반지름의 제곱이므로, 세 번째 좌표축에서 두 클래스가 문턱 하나로 갈린다. 원래 공간에서는 원이던 경계가 새 공간에서는 평면이 된다.

    ```python
    X3 = np.concatenate([X, (X ** 2).sum(1, keepdims=True)], axis=1)
    ```

    이것이 커널 기법의 직관이기도 하다. 자료를 더 높은 차원으로 올려 선형으로 갈리게 만드는 것이다.

**연습문제 2.**
흩어진 덩이에서 MLP가 소프트맥스 회귀보다 조금 나빴다. 어떻게 설명하겠는가?

??? success "연습문제 2 풀이"
    자료가 이미 선형으로 갈리므로 은닉층이 더할 것이 없는데, 매개변수는 수십 배로 늘어난다. 늘어난 자유도가 학습 자료의 잡음까지 따라가면 시험 자료에서 조금 손해를 본다.

    또한 같은 에포크 수에서 더 큰 모델이 아직 덜 수렴했을 수도 있다. 어느 쪽이든 요점은 같다. **문제에 견주어 모델이 지나치게 크면 값을 치른다.**

---

**연습문제 3.**
클래스가 셋인 자료에서 소프트맥스 회귀의 결정 영역은 어떤 모양이 되는가?

??? success "연습문제 3 풀이"
    반평면들의 교집합, 곧 **볼록 다각형**(2차원에서는 다각형 모양의 영역)이 된다. 세 클래스라면 평면이 세 개의 볼록 영역으로 나뉘며, 경계는 직선 조각들로 이루어진다.

    따라서 어떤 클래스의 영역이 둘로 떨어져 있어야 하는 문제라면 클래스 수와 무관하게 소프트맥스 회귀로는 풀 수 없다.

## 정리하며

**다룬 것** — 소프트맥스 회귀가 표현할 수 있는 모양

소프트맥스 회귀의 결정 경계는 언제나 초평면이다. 두 로짓이 같아지는 조건이 $\mathbf{x}$에 대한 일차식이기 때문이다. 나아가 각 클래스의 결정 영역은 반평면들의 교집합이므로 **볼록**하다.

이 성질은 자료로 확인된다. 선형으로 갈리는 덩이 자료에서는 은닉층이 보탤 것이 없고, 맞물린 초승달에서는 격차가 벌어지며, 동심원에서는 우연 수준까지 떨어진다. 마지막 경우는 학습의 실패가 아니라 **표현력의 한계**이다.

벽을 넘는 길은 특징을 손수 더하거나, 은닉층을 두어 스스로 찾게 하는 것이다. 후자가 딥러닝이며, 그 첫걸음이 다음 장의 활성화 함수이다.

앞의 연습문제 3개로 직접 확인할 수 있다.
