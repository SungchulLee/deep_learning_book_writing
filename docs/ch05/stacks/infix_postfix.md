# 중위에서 후위로

사람은 산술을 **중위 표기**로 쓴다. `3 + 4 * 2`처럼 연산자가 피연산자 사이에 놓인다. 읽기는 편하지만 연산자 우선순위를 알아야 하고 괄호도 다루어야 하므로 프로그램으로 계산하기는 어렵다. **후위 표기**(역폴란드 표기, RPN)는 연산자를 피연산자 뒤에 놓는다. `3 4 2 * +`처럼 쓴다. 이 표현은 뜻이 하나로 정해지고 괄호가 전혀 필요 없으며, 스택을 써서 왼쪽에서 오른쪽으로 한 번만 훑으면 계산할 수 있다. 에츠허르 데이크스트라가 고안한 **조차장 알고리즘**은 연산자를 잠시 담아 두는 스택을 써서 중위 표기식을 후위 표기로 바꾼다. 이 쪽은 이 알고리즘을 자세히 설명하고 몇 가지 예를 따라간다.

## 세 가지 표기 체계

같은 산술식을 세 가지 표기로 쓸 수 있다.

| 표기 | 형태 | 예 ($3 + 4 \times 2$의 경우) |
|----------|--------|-------------------------------|
| **중위** | 연산자가 피연산자 사이에 | `3 + 4 * 2` |
| **후위** (RPN) | 연산자가 피연산자 뒤에 | `3 4 2 * +` |
| **전위** (폴란드) | 연산자가 피연산자 앞에 | `+ 3 * 4 2` |

후위 표기와 전위 표기에는 괄호가 없다. 연산자의 순서가 우선순위를 뜻이 하나로 정해지게 담고 있기 때문이다. 컴파일러는 보통 기계 명령을 만들기 전에 중위 표기 소스 코드를 후위 표기(또는 나무 표현)로 바꾼다.

## 조차장 알고리즘

이 알고리즘은 **출력 큐**와 **연산자 스택**을 쓴다. 토큰을 왼쪽에서 오른쪽으로 처리한다.

1. **수** — 곧바로 출력 큐로 보낸다
2. **연산자** $o_1$ — 스택 꼭대기에 (왼쪽 결합 연산자의 경우) 우선순위가 같거나 높은 연산자 $o_2$이 있는 동안 $o_2$을 빼서 출력 큐로 보낸다. 그런 다음 $o_1$을 스택에 넣는다.
3. **여는 괄호** `(` — 스택에 넣는다
4. **닫는 괄호** `)` — 여는 괄호를 만날 때까지 스택에서 연산자를 빼어 출력 큐로 보낸 뒤, 여는 괄호는 버린다

모든 토큰을 처리한 뒤 스택에 남은 연산자를 모두 빼서 출력 큐로 보낸다.

토큰의 수를 $n$이라 할 때 이 알고리즘은 $O(n)$ 시간과 $O(n)$ 공간에 돌아간다. 각 토큰은 많아야 한 번 들어가고 한 번 나온다.

??? example "풀이 예: `3 + 4 * 2`"
    | 단계 | 토큰 | 동작 | 출력 큐 | 연산자 스택 |
    |------|-------|--------|--------------|----------------|
    | 1 | `3` | 출력 | `3` | |
    | 2 | `+` | 넣기 (스택이 비어 있다) | `3` | `+` |
    | 3 | `4` | 출력 | `3 4` | `+` |
    | 4 | `*` | 넣기 (`*` > `+`) | `3 4` | `+ *` |
    | 5 | `2` | 출력 | `3 4 2` | `+ *` |
    | 6 | 끝 | 모두 빼기 | `3 4 2 * +` | |

    결과: `3 4 2 * +`

??? example "풀이 예: `(3 + 4) * 2`"
    | 단계 | 토큰 | 동작 | 출력 큐 | 연산자 스택 |
    |------|-------|--------|--------------|----------------|
    | 1 | `(` | 넣기 | | `(` |
    | 2 | `3` | 출력 | `3` | `(` |
    | 3 | `+` | 넣기 | `3` | `( +` |
    | 4 | `4` | 출력 | `3 4` | `( +` |
    | 5 | `)` | `(`을 만날 때까지 빼기 | `3 4 +` | |
    | 6 | `*` | 넣기 | `3 4 +` | `*` |
    | 7 | `2` | 출력 | `3 4 + 2` | `*` |
    | 8 | 끝 | 모두 빼기 | `3 4 + 2 *` | |

    결과: `3 4 + 2 *`

## 구현

```python
"""
중위에서 후위로의 변환 — 데이크스트라의 조차장 알고리즘.

스택으로 연산자 우선순위와 괄호를 관리하여 중위 산술식을 후위 표기(RPN)로
바꾼다.
"""


# === 조차장 알고리즘 ==================================================

PRECEDENCE = {"+": 1, "-": 1, "*": 2, "/": 2}


def tokenize(expression):
    """식 문자열을 토큰의 목록으로 나눈다."""
    tokens = []
    i = 0
    while i < len(expression):
        if expression[i].isspace():
            i += 1
        elif expression[i] in "()+-*/":
            tokens.append(expression[i])
            i += 1
        else:
            j = i
            while j < len(expression) and (expression[j].isdigit() or expression[j] == "."):
                j += 1
            tokens.append(expression[i:j])
            i = j
    return tokens


def infix_to_postfix(expression):
    """Convert an infix expression to postfix (RPN) notation.

    데이크스트라의 조차장 알고리즘을 쓴다.
    모든 연산자가 왼쪽에서 오른쪽으로 결합한다고 가정한다.

    시간:  O(n), 여기서 n은 토큰의 수이다.
    공간: 연산자 스택과 출력 큐를 위해 O(n).
    """
    tokens = tokenize(expression)
    output = []
    operator_stack = []

    for token in tokens:
        if token in PRECEDENCE:
            # 우선순위가 같거나 높은 연산자 빼기 (왼쪽 결합)
            while (operator_stack and
                   operator_stack[-1] != "(" and
                   operator_stack[-1] in PRECEDENCE and
                   PRECEDENCE[operator_stack[-1]] >= PRECEDENCE[token]):
                output.append(operator_stack.pop())
            operator_stack.append(token)
        elif token == "(":
            operator_stack.append(token)
        elif token == ")":
            while operator_stack[-1] != "(":
                output.append(operator_stack.pop())
            operator_stack.pop()  # "("을 버린다
        else:
            output.append(token)  # 피연산자

    # 남은 연산자 빼기
    while operator_stack:
        output.append(operator_stack.pop())

    return " ".join(output)


# === 후위 표기 계산기 (검증용) =====================================

def evaluate_postfix(postfix_str):
    """변환이 올바른지 확인하려고 후위 표기식을 계산한다."""
    operators = {
        "+": lambda a, b: a + b, "-": lambda a, b: a - b,
        "*": lambda a, b: a * b, "/": lambda a, b: a / b,
    }
    stack = []
    for token in postfix_str.split():
        if token in operators:
            b, a = stack.pop(), stack.pop()
            stack.append(operators[token](a, b))
        else:
            stack.append(float(token))
    return stack[0]


# === 시연 ============================================================

if __name__ == "__main__":
    test_cases = [
        "3 + 4 * 2",
        "(3 + 4) * 2",
        "5 + (1 + 2) * 4 - 3",
        "2 * 3 + 4",
        "2 + 3 * 4 + 5",
        "(2 + 3) * (4 + 5)",
    ]

    print(f"{'Infix':<30s} {'Postfix':<25s} {'Value':>8s}")
    print("-" * 65)
    for expr in test_cases:
        postfix = infix_to_postfix(expr)
        value = evaluate_postfix(postfix)
        print(f"{expr:<30s} {postfix:<25s} {value:>8.1f}")
```

**출력:**
```
Infix                          Postfix                     Value
-----------------------------------------------------------------
3 + 4 * 2                      3 4 2 * +                     11.0
(3 + 4) * 2                    3 4 + 2 *                     14.0
5 + (1 + 2) * 4 - 3            5 1 2 + 4 * + 3 -            14.0
2 * 3 + 4                      2 3 * 4 +                     10.0
2 + 3 * 4 + 5                  2 3 4 * + 5 +                 19.0
(2 + 3) * (4 + 5)              2 3 + 4 5 + *                 45.0
```

중위 표기식이 저마다 올바른 후위 표기로 바뀐다. 후위 계산기는 바뀐 식이 원래 식과 같은 값을 냄을 확인해 준다.

## 오른쪽 결합 연산자 다루기

위 알고리즘은 왼쪽에서 오른쪽으로의 결합을 전제한다. 우선순위가 같은 연산자는 왼쪽에서 오른쪽으로 계산된다. 거듭제곱(`^`)처럼 오른쪽 결합인 연산자에서는 비교가 "같거나 크다"에서 "엄격히 크다"로 바뀐다.

- **왼쪽 결합**: 스택 꼭대기의 우선순위가 현재 연산자보다 $\geq$인 동안 뺀다
- **오른쪽 결합**: 스택 꼭대기의 우선순위가 현재 연산자보다 $>$인 동안 뺀다

그래야 `2 ^ 3 ^ 4`이 `2 3 ^ 4 ^`($(2^3)^4$이 된다)이 아니라 `2 3 4 ^ ^`($2^{(3^4)}$으로 계산된다)으로 바뀐다.

## 복잡도 분석

$$
T(n) = O(n) \quad \text{and} \quad S(n) = O(n)
$$

$n$개의 토큰이 저마다 정확히 한 번 처리된다. 각 토큰은 연산자 스택에 많아야 한 번 들어가고 한 번 나오므로 스택 연산은 모두 합해 많아야 $2n$번이다. 출력 큐는 많아야 항목 $n$개까지 커진다.

**연습문제 2.**
중위에서 후위로을(를) 서로 다른 두 자료 구조로 구현하라. 각각의 절충을 비교하라.

??? success "연습문제 2 풀이"

**연습문제 3.**
중위에서 후위로을(를) 쓰는 딥러닝 응용을 하나 설명하라(예: 그래프 신경망의 너비 우선 탐색, 기호 미분에서의 식 계산, 데이터 적재의 스케줄링).

??? success "연습문제 3 풀이"
    구체적인 응용은 그 추상 자료형의 순서 성질에 달렸다. 선입선출(큐)은 GNN의 너비 우선 그래프 순회에 쓰이고, 후입선출(스택)은 자동 미분 테이프 처리에 쓰이며, 우선순위 순서는 빔 탐색과 예정 표집에 쓰인다.

---

**연습문제 4.**
중위에서 후위로을(를) 원형 배열로 구현하면 모든 연산이 상각 $O(1)$ 시간임을 증명하라.

??? success "연습문제 4 풀이"
    원형 배열은 머리와 꼬리 인덱스를 용량으로 나눈 나머지로 관리한다. 넣기와 빼기는 인덱스를 $O(1)$에 조정한다. 배열이 가득 차면 용량을 두 배로 늘리는 데 $O(n)$이 들지만, 이는 값싼 연산 $O(n)$번 뒤에 한 번 일어나므로 동적 배열과 같은 논법으로 상각 $O(1)$이 된다. $\square$
