# 본새 꾸러미

겨루기 짜기를 하는 이들은 흔한 자료 얼개와 알고리즘을 미리 적고 미리 시험한 개인 꾸러미를 지닌다. 겨루기 동안 믿을 만한 본새를 베끼면 짜는 때가 사라지고 잘 아는 조각에서 벌레가 날 위험이 준다. 이 마디는 본새 꾸러미에 무엇을 담을지, 어떻게 갈래를 지을지, 겨루기의 압박 아래에서 본새를 믿을 만하게 만드는 설계 원칙을 다룬다.

## 본새가 중요한 까닭

여느 5시간 겨루기에서 알고리즘 통찰이 뻔한 문제는 짜는 때가 대부분이다. 토막 나무를 맨바닥부터 적으면 15~20분이 걸리고 압박 아래에서 틀리기 쉽다. 시험한 본새를 쓰면 붙여 넣고 맞추는 30초로 준다.

본새는 다음에 값지다:

- **복잡한 자료 얼개**: 토막 나무, 펜윅 나무, 서로소 모임 합치기, 볼록 껍질 재주.
- **여느 알고리즘**: 데이크스트라, KMP, 빠른 푸리에 변환, 최대 흐름.
- **틀에 박힌 코드**: 빠른 들고남 짜임, 법 셈, 그래프 들임 뜯기.

## 본새 설계 원칙

### 올바름이 먼저

미묘한 벌레가 있는 본새는 아예 없느니만 못하다. 짜는 이가 그것을 믿고 엉뚱한 데서 벌레를 찾느라 때를 낭비하기 때문이다. 본새마다 다음을 갖춰야 한다:

- 서로 다른 문제 3~5개에서 **확인함**.
- 힘으로 미는 잣대와 맞대어 **마구 시험함**.
- 빈 들임, 원소 하나, 최대 크기에서 **가장자리 경우를 시험함**.

### 가장 작고 읽기 쉽게

겨루기 본새는 읽을 수 있는 한 되도록 짧아야 한다. 다음을 피한다:

- 쓸데없는 두루 쓰임(보기로 합과 최대만 쓰면서 연산 10가지를 받쳐 주는 토막 나무).
- 한 줄을 아끼지만 급할 때 이해하는 데 1분이 걸리는 영리한 재주.
- 물려받기, 가상 함수, 복잡한 대상 지향 짜기. 납작한 갈래나 홀로 선 함수가 낫다.

### 맞추기 쉽게

좋은 본새에는 쓰는 이가 문제마다의 논리를 끼워 넣을 자리가 또렷이 표시되어 있다.

```python
"""
겨루기 짜기를 위한 틀 서고.

대회에서 빨리 고쳐 쓸 수 있게 만든 흔한 자료 얼개와 알고리즘의
다시 쓸 수 있는 짜기를 내놓는다.
"""

import sys
from collections import defaultdict, deque
from heapq import heappush, heappop

# ===================================================================
# 빠른 들고남 틀
# ===================================================================

input = sys.stdin.readline

def read_int():
    """정수 하나를 읽는다."""
    return int(input())

def read_ints():
    """빈칸으로 나뉜 정수 한 줄을 읽는다."""
    return list(map(int, input().split()))

# ===================================================================
# 법 셈 틀
# ===================================================================

MOD = 10**9 + 7

def mod_pow(base, exp, mod=MOD):
    """빠른 법 거듭제곱."""
    result = 1
    base %= mod
    while exp > 0:
        if exp & 1:
            result = result * base % mod
        exp >>= 1
        base = base * base % mod
    return result

def mod_inv(a, mod=MOD):
    """Modular inverse using Fermat's little theorem (mod must be prime)."""
    return mod_pow(a, mod - 2, mod)

# ===================================================================
# 서로소 집합 합치기(합치기-찾기) 틀
# ===================================================================

class DSU:
    """길 옥죄기와 등수 합치기를 하는 서로소 집합 합치기."""

    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n

    def find(self, x):
        """길 누르기로 뿌리를 찾는다."""
        while self.parent[x] != x:
            self.parent[x] = self.parent[self.parent[x]]
            x = self.parent[x]
        return x

    def union(self, x, y):
        """등수 합치기. 새로 이어지면 참을 돌려준다."""
        rx, ry = self.find(x), self.find(y)
        if rx == ry:
            return False
        if self.rank[rx] < self.rank[ry]:
            rx, ry = ry, rx
        self.parent[ry] = rx
        if self.rank[rx] == self.rank[ry]:
            self.rank[rx] += 1
        return True

# ===================================================================
# 토막 나무 틀
# ===================================================================

class SegTree:
    """범위 물음과 점 고침을 위한 토막 나무.

    물음 갈래(합, 최소, 최대, 최대공약수 등)에 맞게 합치기 함수와
    항등원을 고쳐 쓴다.
    """

    def __init__(self, data):
        self.n = len(data)
        self.tree = [0] * (2 * self.n)
        # 짓기
        for i in range(self.n):
            self.tree[self.n + i] = data[i]
        for i in range(self.n - 1, 0, -1):
            self.tree[i] = self.tree[2 * i] + self.tree[2 * i + 1]

    def update(self, pos, value):
        """자리 pos를 value로 둔다(0부터 셈)."""
        pos += self.n
        self.tree[pos] = value
        while pos > 1:
            pos >>= 1
            self.tree[pos] = self.tree[2 * pos] + self.tree[2 * pos + 1]

    def query(self, l, r):
        """Query the range [l, r) (0-indexed, exclusive end)."""
        res = 0
        l += self.n
        r += self.n
        while l < r:
            if l & 1:
                res += self.tree[l]
                l += 1
            if r & 1:
                r -= 1
                res += self.tree[r]
            l >>= 1
            r >>= 1
        return res

# ===================================================================
# 그래프 틀
# ===================================================================

def dijkstra(adj, src, n):
    """Dijkstra's algorithm with binary heap.

    인수:
        adj: adjacency list as dict of {node: [(neighbor, weight), ...]}
        src: 시작 마디
        n: 마디 개수

    반환값:
        src에서의 최단 거리 목록.
    """
    dist = [float('inf')] * n
    dist[src] = 0
    heap = [(0, src)]
    while heap:
        d, u = heappop(heap)
        if d > dist[u]:
            continue
        for v, w in adj[u]:
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                heappush(heap, (dist[v], v))
    return dist

# ===================================================================
# 메인
# ===================================================================

if __name__ == "__main__":
    # 서로소 집합 합치기 보기
    dsu = DSU(5)
    dsu.union(0, 1)
    dsu.union(2, 3)
    dsu.union(1, 3)
    print(f"0 and 3 connected: {dsu.find(0) == dsu.find(3)}")

    # 토막 나무 보기
    data = [1, 3, 5, 7, 9]
    st = SegTree(data)
    print(f"Sum [0,3): {st.query(0, 3)}")
    print(f"Sum [1,5): {st.query(1, 5)}")

    # 법 셈 보기
    print(f"2^10 mod (10^9+7): {mod_pow(2, 10)}")
    print(f"Inverse of 3 mod (10^9+7): {mod_inv(3)}")
```

**출력:**
```
0과 3이 이어짐: True
Sum [0,3): 9
Sum [1,5): 24
2^10 mod (10^9+7): 1024
3의 법 (10^9+7) 역원: 333333336
```

## 연습문제

**연습문제 1.**
아무 결합 두 자리 셈에 대해 점 고침과 범위 물음을 받치는 가장 작은 토막 나무 틀을 설계하여라. 쓰는 이가 셈과 항등원을 끼워 넣을 자리를 또렷이 표시하여라.

??? success "연습문제 1 풀이"
    ```python
    class SegTree:
        # 쓰는 이: op와 항등원을 정하시오
        op = lambda self, a, b: a + b  # 결합 셈
        identity = 0                    # op(항등원, x) = x
    
        def __init__(self, n):
            self.n = n
            self.tree = [self.identity] * (2 * n)
    
        def update(self, i, val):
            i += self.n
            self.tree[i] = val
            while i > 1:
                i >>= 1
                self.tree[i] = self.op(self.tree[2*i], self.tree[2*i+1])
    
        def query(self, l, r):  # [l, r)
            res = self.identity
            l += self.n; r += self.n
            while l < r:
                if l & 1: res = self.op(res, self.tree[l]); l += 1
                if r & 1: r -= 1; res = self.op(res, self.tree[r])
                l >>= 1; r >>= 1
            return res
    ```
    쓰는 이는 `op`를 아무 결합 셈(보기로 `min`, `max`, `gcd`)으로, `identity`를 그에 맞는 항등원(min은 $\infty$, max는 $-\infty$, gcd는 0)으로 바꾼다. 틀은 20줄이고 $n$이 $10^6$까지 되며 마구 시험하기도 쉽다. $\square$

**연습문제 2.**
대회 중에 데이크스트라 틀이 무게 0인 변이 있는 그래프에서 틀린 답을 냄을 알아차렸다. 그럴 만한 벌레를 짚고 틀 설계에서 이를 막는 길을 밝혀라.

??? success "연습문제 2 풀이"
    그럴 만한 벌레는 우선 줄에서 이미 꺼낸 마디를 건너뛰는 들른 집합 살피기와 거리 동점을 옳게 다루지 못한 것이 겹친 것이다. 틀이 `if dist[u] < d: continue`(흔한 게으른 지우기 무늬)를 쓰면 무게 0인 변 때문에 어떤 마디가 옳은 거리로 닿았지만 더 나쁜 길을 거쳐 온 상황이 생기고 무게 0인 변을 거친 뒤의 바로잡기가 건너뛰어질 수 있다. 고침은 `if d > dist[u]: continue`(엄격히 큰 경우)를 써서 가장 좋은 거리로 닿은 모든 경우를 다루는 것이다. 틀에서 이런 벌레를 막으려면 늘 변 무게가 $\{0, 1\}$인 경우와 무게 0인 변이 많은 그래프(보기로 데이크스트라로 나타낸 무게 없는 너비 먼저 훑기)로 마구 시험한다. $\square$

**연습문제 3.**
서로소 집합 합치기(DSU) 틀의 두 설계 철학을 견주어라. 하나는 길 옥죄기만 쓰고 다른 하나는 길 옥죄기와 등수 합치기를 함께 쓴다. 고르게 나눈 복잡도 차이를 살피고 대회 틀로는 어느 쪽이 나은지 따져라.

??? success "연습문제 3 풀이"
    길 옥죄기만 쓰면 셈마다 고르게 나눈 $O(\log n)$이다(등수 합치기까지 쓰면 역 애커만이지만 없으면 $O(\log n)$이다). 등수 합치기만 써도 $O(\log n)$이다. 둘을 함께 쓰면 $O(\alpha(n))$을 이루는데 $\alpha$는 역 애커만 함수로 사실상 상수다. 대회에서는 두 다듬기가 코드 2~3줄만 늘린다. 길 옥죄기는 `find` 함수에서 `parent[x] = find(parent[x])`이다. 등수 합치기는 `rank` 배열을 지녀 낮은 나무를 높은 나무 아래에 붙인다. 함께 쓰는 쪽이 낫다. (1) 코드가 늘어나는 값이 거의 없고, (2) 셈 $10^6$번에 때 한도가 빡빡한 문제는 거의 상수인 고르게 나눈 값이 필요하며, (3) 외우거나 벌레 잡기가 더 어렵지도 않다. $\square$

**연습문제 4.**
동료의 법 셈 틀이 곳곳에서 `(a * b) % MOD`를 쓴다. C++에서 64비트 정수에 이것이 언제 틀리는지 밝히고 넘침을 다루는 튼튼한 틀을 내놓아라.

??? success "연습문제 4 풀이"
    C++에서 `a`와 `b`가 모두 $10^{18}$까지라면(`long long`에 든다) `a * b`가 64비트 범위($2^{63} - 1 \approx 9.2 \times 10^{18}$)를 넘칠 수 있다. 부호 있는 셈에서 이는 뜻이 정해지지 않은 움직임이다. 튼튼한 틀은 이를 받치는 번역기에서 `__int128`을 쓴다: `(__int128)a * b % MOD`. 그렇지 않으면 거듭 두 배로 만드는 법 곱하기(두 갈래 방법)를 짠다. $b$를 비트로 가르고 더하기와 두 배만으로 $a \cdot 2^i \bmod M$을 쌓으며 그때마다 법으로 줄인다. 이는 $O(\log b)$에 돌고 줄이기 전에도 $2M$을 넘지 않는다. 틀에서는 이를 `mul_mod(a, b, m)` 함수로 싸서 한결같이 쓴다. $\square$

**연습 5.**
새 틀을 내 서고에 넣기 전에 검증하는 시험 규약을 내놓아라. 그 규약은 옳음 벌레, 빠르기 문제, 어울림 문제를 잡아야 한다.

??? success "연습 5의 풀이"
    네 단계 규약이다. (1) **낱 시험** — 손으로 만든 들임에서 모든 셈과 가장자리 경우(빈 얼개, 원소 하나, 최대 크기)를 확인한다. (2) **마구 시험** — 작은 크기($n \le 100$)의 아무 들임 $10^4$개 넘게로 힘으로 미는 잣대와 견준다. (3) **빠르기 시험** — 최대 크기 들임($n = 10^6$)에서 돌려 벽시계 때가 바라는 가둠의 50% 안에 드는지 확인하고, 숨은 상수 인수 문제를 살핀다. (4) **어울림 시험** — 함께 쓰일 만한 다른 틀(보기로 무거움-가벼움 쪼개기 속 토막 나무, 크러스컬 속 DSU)과 엮어 그 엮음을 마구 시험한다. 네 단계를 모두 지나야 틀이 서고에 든다. 검증에 쓴 문제를 틀과 함께 적어 두어 나중에 참고한다. $\square$
