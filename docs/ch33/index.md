# 34장: 그래프 신경망

이 장은 **그래프 신경망**을 다룬다.

그래프 신경망은 딥러닝을 유클리드가 아닌 자료 구조, 곧 그래프로 넓혀 관계 데이터 위에서 힘센 나타냄 학습을 할 수 있게 한다. 소셜 네트워크와 분자 구조에서 금융 거래 네트워크와 앎 기초에 이르기까지 그래프는 실제 쓰임새 어디에나 있다. 이 장은 그래프 신경망의 이론, 구조, 쓰임새를 두루 다룬다.

---

## 1. 차례

### 29.1 그래프 기초

- [그래프 기초](foundations/graph_basics.md) -- 그래프의 엄밀한 정의, 방향 있는 판과 없는 판, 기초가 되는 그래프 말
- [그래프 표현](foundations/representations.md) -- 인접 리스트, 행렬, 엣지 목록을 비롯한 그래프 나타내기 자료 구조와 계산의 트레이드오프
- [인접 행렬](foundations/adjacency_matrix.md) -- 인접 행렬과 거기서 얻는 행렬, 스펙트럼 그래프 이론과 그래프 신경망 적기에서의 구실을 깊이 살핌
- 노드와 엣지의 특징 -- 노드 속성과 엣지 성질을 그래프 신경망 들임용 특징 행렬로 담기
- [그래프의 성질](foundations/graph_properties.md) -- 연결성, 거리 잣대, 뭉침을 비롯한 핵심 위상과 구조 성질
- PyTorch Geometric 기초 -- PyG의 Data 대상, 데이터 불러오기, 그래프 다루기 연장 소개

### 29.2 메시지 패싱

- 메시지 패싱 틀 -- 하나로 아우른 MPNN 틀: 메시지 계산, 집계, 고치기 걸음
- 집계 함수 -- 자리바꿈에 안 바뀌는 집계 연산자(합, 평균, 최대)와 그 나타냄 힘
- [업데이트 함수](message_passing/update.md) -- 스스로의 앎과 모은 이웃 메시지를 합쳐 새 노드 임베딩을 만들기
- [MPNN](message_passing/mpnn.md) -- 그래프 신경망 구조를 하나로 아우른 Gilmer 등의 메시지 패싱 신경망 적기

### 29.3 그래프 합성곱

- [스펙트럼 그래프 이론](convolutions/spectral_theory.md) -- 그래프 라플라스 고유 분해, 그래프 신호, 스펙트럼 합성곱의 수학 기초
- 그래프 푸리에 변환 -- 라플라스 고유 벡터로 푸리에 변환을 그래프 구조 데이터로 넓히기
- ChebNet -- 그래프 라플라스 거르개의 체비쇼프 다항식 어림으로 효율 좋게 스펙트럼 거르기
- 그래프 합성곱 신경망(GCN) -- 대칭으로 고르게 맞춘 Kipf와 Welling의 1차 스펙트럼 합성곱
- [GraphSAGE](convolutions/graphsage.md) -- 이웃 샘플링과 여러 모으개 변형으로 하는 귀납 그래프 학습
- 그래프 어텐션 신경망(GAT) -- 데이터에 따라 달라지는 이웃 중요도 가중치를 배우는 어텐션 기초 그래프 신경망
- [그래프 동형 신경망(GIN)](convolutions/gin.md) -- 1차 바이스파일러-레만 같은 꼴 시험만큼 힘셈이 밝혀진, 나타냄 힘이 가장 센 메시지 패싱 그래프 신경망

### 29.4 나아간 그래프 신경망 방법

- 깊은 그래프 신경망 -- 지나친 매끄러워짐에 맞서려는 나머지 이음과 고르게 맞추기를 비롯해 더 깊은 그래프 신경망을 세우는 재주
- 지나친 매끄러워짐 -- 깊은 그래프 신경망에서 노드 나타냄이 한곳으로 모이는 것을 살피고 누그러뜨리는 셈속
- Jumping Knowledge 신경망 -- 노드마다 가장 알맞은 받는 자리 깊이를 고르게 하는 맞춤형 여러 층 집계
- [그래프 트랜스포머](advanced/graph_transformers.md) -- 온 자리 앎을 주고받으려 트랜스포머의 셀프 어텐션을 그래프에 쓰기(Graphormer, GPS)
- [이종 그래프](advanced/heterogeneous.md) -- RGCN과 HAN 구조로 노드와 엣지의 갈래가 여럿인 그래프를 다루는 그래프 신경망
- [시간 그래프](advanced/temporal.md) -- 띄엄띄엄한 때와 이어진 때의 경로로 바뀌는 구조를 다루는 그래프 신경망
- [하이퍼그래프](advanced/hypergraphs.md) -- 넘 엣지가 아무 개수의 노드를 한꺼번에 잇는 하이퍼그래프 위의 신경망

### 29.5 그래프 켜의 일

- 그래프 분류 -- 그래프 신경망 층, 읽어내기 함수, 여러 층 신경망 분류기로 그래프 전체에 레이블 매기기
- 그래프 회귀 -- 양자 화학과 분자 녹음성에 쓰이는, 그래프 전체의 이어진 값 헤아리기
- [그래프 풀링](graph_tasks/pooling.md) -- 노드 임베딩을 그래프 나타냄으로 누르는 납작한 집계 방법(합, 평균, 최대, 어텐션 가중치)
- 계층적 풀링 -- 여러 눈금의 나타냄을 얻으려 DiffPool, TopKPool, SAGPool으로 그래프를 차츰 성글게 하기
- Set2Set -- 단순한 집계보다 나타냄 힘이 센, 차례에 안 바뀌는 그래프 나타냄을 내놓는 어텐션 기초 장단기 기억망 읽어내기

### 29.6 노드와 이음의 일

- 노드 분류 -- 옮김과 귀납 자리에서 그래프 구조와 특징으로 하는 반쯤 스승 있는 노드 레이블 매기기
- [링크 예측](node_link/link_prediction.md) -- 스코어 기반 방법과 음의 샘플링로 빠진 엣지이나 앞으로의 엣지를 헤아리기
- 노드 임베딩 -- DeepWalk, Node2Vec, LINE, 비교 그래프 신경망 방법으로 하는 스승 없는 노드 나타냄 학습
- 커뮤니티 탐지 -- 그래프 신경망 기초 뭉치기와 무리도 최적화로 빽빽하게 이어진 노드 무리 찾아내기

### 29.7 그래프 신경망의 쓰임새

- 분자 특성 예측 -- 원자와 결합 특징이 담긴 분자 그래프에서 화학 성질 헤아리기
- 약 찾기 -- 가상 걸러내기, 약과 약의 서로 작용 헤아리기, ADMET 성질 어림에 쓰는 그래프 신경망
- 소셜 네트워크 분석 -- 사회 그래프에서 커뮤니티 탐지, 영향 헤아리기, 번짐 나타내기, 로봇 계정 찾기
- 추천 시스템 -- LightGCN과 PinSage로 쓰는 이-물건 이분 그래프 그래프 위의 그래프 신경망 기초 함께 거르기
- 지식 그래프 -- 링크 예측을 위한 R-GCN, CompGCN, 점수 함수로 하는 낱것과 관계 임베딩
- 금융 네트워크 -- 금융 그래프 위의 꾸러미 최적화, 체계 위험 퍼짐, 옮아감 나타내기, 속임수 찾기
