# 앙상블 — 새 생각 없이 남은 정확도

[4.1절](01_two_ladders.md)은 씨앗을 바꾸면 같은 모델이 70.68%에서 71.79%까지 흔들린다고 재었다. 거기서 그 흔들림은 **재는 것을 방해하는 잡음**이었다. 걸음 사이의 이득이 그 흔들림보다 큰지를 따져야 했으니까.

이 절은 같은 흔들림을 **자원으로 쓴다.**

하는 일은 이것뿐이다. 씨앗만 다른 모델 다섯 개를 따로 학습시키고, 시험할 때 다섯의 확률을 평균 낸다. 새 구조도, 새 자료도, 새 생각도 없다.

---

## 1. 코드

```python
"""4.5절: 같은 모델을 씨앗만 바꾸어 다섯 번 학습하고 확률을 평균한다.

seeds.py가 하던 것과 딱 한 군데가 다르다. 정확도만 적고 모델을 버리는
대신, 시험 집합의 확률을 남겨 둔다.
"""

import torch
import torch.nn as nn
import torch.nn.functional as F
import torch.optim as optim
from torch.utils.data import DataLoader, TensorDataset
import torchvision
import torchvision.transforms as transforms

BATCH, LR, EPOCHS = 100, 1e-3, 5
device = torch.device("mps" if torch.backends.mps.is_available() else "cpu")

tf = transforms.Compose([
    transforms.ToTensor(),
    transforms.Normalize((0.4914, 0.4822, 0.4465), (0.2470, 0.2435, 0.2616))])
tr_ds = torchvision.datasets.CIFAR10("./data", train=True, download=True, transform=tf)
te_ds = torchvision.datasets.CIFAR10("./data", train=False, download=True, transform=tf)


def materialize(ds):
    xs, ys = [], []
    for x, y in DataLoader(ds, batch_size=2000, shuffle=False):
        xs.append(x); ys.append(y)
    return torch.cat(xs), torch.cat(ys)


Xtr, ytr = materialize(tr_ds)                  # (50000, 3, 32, 32)
Xte, yte = materialize(te_ds)


class CNN(nn.Module):
    """4.1절 4걸음 그대로."""

    def __init__(self):
        super().__init__()
        self.conv1 = nn.Conv2d(3, 32, 3, padding=1)
        self.conv2 = nn.Conv2d(32, 64, 3, padding=1)
        self.pool = nn.MaxPool2d(2, 2)
        self.dropout = nn.Dropout(0.25)
        self.fc1 = nn.Linear(64 * 8 * 8, 128)
        self.fc2 = nn.Linear(128, 10)

    def forward(self, x):
        x = self.pool(torch.relu(self.conv1(x)))
        x = self.pool(torch.relu(self.conv2(x)))
        return self.fc2(self.dropout(torch.relu(self.fc1(x.flatten(1)))))


def train(seed, epochs=EPOCHS):
    torch.manual_seed(seed)                     # 달라지는 것은 이것뿐이다
    model = CNN().to(device)
    opt = optim.Adam(model.parameters(), lr=LR)
    crit = nn.CrossEntropyLoss()
    g = torch.Generator().manual_seed(seed)
    loader = DataLoader(TensorDataset(Xtr, ytr), batch_size=BATCH,
                        shuffle=True, generator=g)
    for _ in range(epochs):
        model.train()
        for x, y in loader:
            x, y = x.to(device), y.to(device)
            opt.zero_grad()
            crit(model(x), y).backward()
            opt.step()
    return model.eval()


@torch.no_grad()
def test_probs(model):
    """시험 집합의 클래스 확률 (10000, 10).

    로짓이 아니라 softmax를 평균한다. 모델마다 로짓의 크기가 제멋대로라,
    로짓을 평균하면 확신이 센 모델이 과도한 발언권을 갖는다.
    """
    return torch.cat([torch.softmax(model(Xte[i:i + 1000].to(device)), 1).cpu()
                      for i in range(0, len(Xte), 1000)])


def acc(pred):
    return 100.0 * (pred == yte).float().mean().item()


probs = []
for seed in range(5):
    m = train(seed)
    probs.append(test_probs(m))
    print(f"  씨앗 {seed}  {acc(probs[-1].argmax(1)):.2f}%", flush=True)

singles = [acc(p.argmax(1)) for p in probs]
print(f"\n홑모델 평균 {sum(singles) / 5:.2f}%  가장 좋은 것 {max(singles):.2f}%")

# 몇 개를 모을 때까지 이득이 이어지는가
print()
for k in range(1, 6):
    ens = torch.stack(probs[:k]).mean(0)
    print(f"앙상블 {k}개  {acc(ens.argmax(1)):.2f}%")

# 다양성 — 두 모델이 서로 다르게 답한 비율의 평균
preds = torch.stack([p.argmax(1) for p in probs])
dis = [100.0 * (preds[i] != preds[j]).float().mean().item()
       for i in range(5) for j in range(i + 1, 5)]
print(f"\n서로 다르게 답한 비율 {sum(dis) / len(dis):.2f}%")

# 천장 — 다섯 가운데 하나라도 맞힌 비율
print(f"신탁 (하나라도 맞힌 비율) {100.0 * (preds == yte).any(0).float().mean():.2f}%")
```

**출력:**

```
  씨앗 0  71.49%
  씨앗 1  71.42%
  씨앗 2  71.29%
  씨앗 3  71.79%
  씨앗 4  70.68%

홑모델 평균 71.33%  가장 좋은 것 71.79%

앙상블 1개  71.49%
앙상블 2개  73.32%
앙상블 3개  74.06%
앙상블 4개  74.41%
앙상블 5개  74.73%

서로 다르게 답한 비율 22.78%
신탁 (하나라도 맞힌 비율) 86.79%
```

## 2. 결과

| | 정확도 |
|---|---|
| 홑모델 다섯 개 | 71.49, 71.42, 71.29, 71.79, 70.68 |
| 홑모델 평균 | 71.33% |
| 홑모델 최고 | 71.79% |
| **다섯 개 앙상블** | **74.73%** |

평균 홑모델보다 **3.40%포인트**, 가장 좋았던 홑모델보다 **2.94%포인트** 높다. 그 자리의 씨앗 퍼짐이 1.11이니, 이득이 흔들림의 세 배에 가깝다. 재고 있다고 말해도 된다.

몇 개부터 이득이 붙는지 보면 이렇다.

| 모델 수 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| 정확도 | 71.49 | 73.32 | 74.06 | 74.41 | 74.73 |
| 더해진 몫 | — | **+1.83** | +0.74 | +0.35 | +0.32 |

**두 번째 모델이 이득의 절반을 가져간다.** 그 뒤로는 빠르게 줄어든다. 다섯 개를 쓸 형편이 안 되면 두 개만 써도 대부분을 얻는다.

## 3. 같은 셈을 어디에 쓸 것인가

이 절이 진짜로 묻는 것은 이것이다. 셈할 여력이 정해져 있을 때, **한 모델을 오래 돌릴 것인가 여러 모델을 짧게 돌릴 것인가.**

[4.3절](03_augmentation.md)이 이미 한쪽을 재어 두었다.

| 쓰는 곳 | 에포크 총합 | 정확도 |
|---|---|---|
| 1개 모델을 30 에포크 | 30 | 71.75% |
| **5개 모델을 5 에포크씩** | **25** | **74.73%** |

**에포크를 더 적게 쓰고 2.98%포인트를 더 얻는다.**

4.3절에서 보았듯 한 모델에 25 에포크를 더 주면 그 시간을 전부 **외우는 데** 쓴다. 학습 정확도가 81.40%에서 99.05%로 오르는 동안 시험 정확도는 71.86%에서 71.75%로 제자리였다. 같은 셈을 다섯 갈래로 나누면 각자 덜 외우는 대신 **서로 다른 실수를 하고**, 평균이 그 실수를 지운다.

이것이 앙상블의 요점이다. 이득은 모델이 더 똑똑해져서 나오는 것이 아니라 **실수가 서로 어긋나서** 나온다.

---

## 4. 다양성이 이득을 정한다

실수가 어긋나야 이득이 난다면, **더 많이 어긋나는 모델끼리는 더 많이 얻어야** 한다. 잴 수 있는 주장이다.

다섯 모델이 시험 그림 한 장에 서로 다른 답을 내는 비율을 재고, 같은 실험을 3걸음 MLP로도 해 보았다.

| | 씨앗 퍼짐 ([4.1절](01_two_ladders.md)) | 서로 다르게 답하는 비율 | 앙상블이 버는 몫 |
|---|---|---|---|
| 4걸음 CNN | 1.11 | 22.78% | +3.40%p |
| 3걸음 MLP | 2.74 | **38.22%** | **+4.29%p** |

MLP끼리는 시험 그림의 38%에서 서로 다르게 답하고, 그만큼 평균이 벌어들이는 것도 많다.

여기서 [4.1절](01_two_ladders.md)의 표를 다시 읽게 된다. 그 절에서 퍼짐이 큰 것은 나쁜 소식이었다. 재기 어렵다는 뜻이었으니까. 같은 수가 이 절에서는 좋은 소식이다. **모델들이 서로 다르다는 뜻이기 때문이다.** 하나의 측정값이 무엇을 재려느냐에 따라 잡음도 되고 자원도 된다.

---

## 5. 천장은 어디인가

평균이 최선인가? 다섯 가운데 **하나라도** 맞힌 비율을 세어 보면 알 수 있다. 매번 맞힌 모델을 골라낼 수 있다면 얻을 정확도이며, 어떤 결합 방식도 이 값을 넘지 못한다.

| | 홑모델 평균 | 앙상블 (평균) | 오라클 (하나라도 맞힘) |
|---|---|---|---|
| 4걸음 CNN | 71.33% | 74.73% | **86.79%** |
| 3걸음 MLP | 50.35% | 54.64% | 73.47% |

**71%짜리 모델 다섯이 모이면, 그 가운데 정답을 아는 놈이 있는 경우가 86.79%다.** [4.2절](02_vgg16_transfer.md)의 VGG16 전이(84.93%)보다도 높다.

그런데 단순 평균은 그중 74.73%만 건져 낸다. **12%포인트가 "누군가는 알고 있다"와 "평균이 찾아낸다" 사이에 놓여 있다.**

평균이 놓치는 까닭은 간단하다. 한 모델만 정답을 알고 넷이 틀린 쪽으로 몰려 있으면, 평균은 다수를 따른다. 다수결이나 단순 평균보다 나은 결합을 찾는 일이 여기서부터 시작되며, 어느 모델을 언제 믿을지 가리는 것이 그 핵심이다.

## 6. 공짜가 아니다

"새 생각 없이" 얻었다고 해서 값이 없는 것은 아니다.

| | 홑모델 | 5개 앙상블 |
|---|---|---|
| 학습 셈 | 1배 | 5배 |
| 추론 셈 | 1배 | **5배** |
| 저장할 매개변수 | 545,098 | **2,725,490** |
| 정확도 | 71.33% | 74.73% |

학습이 다섯 배 드는 것은 앞의 "같은 셈을 어디에 쓸 것인가"에서 보았듯 오히려 남는 장사였다. 같은 에포크로 더 얻었으니 학습 쪽은 손해가 아니다. 문제는 **추론**이다. 그림 한 장을 판정할 때마다 다섯 번 순전파해야 한다.

그래서 견줄 자리를 옳게 잡아야 한다. 매개변수 272만 개로 74.73%를 얻는 것과, [4.2절](02_vgg16_transfer.md)의 전이 학습이 **한 번의 순전파로 84.93%**를 얻는 것 가운데 어느 쪽이 나은가. 정확도로도 추론 비용으로도 전이 쪽이다.

**앙상블이 값진 자리는 따로 있다.** 이미 최선을 다한 모델이 있고, 새 생각은 떨어졌고, 정확도 2~3%포인트가 더 필요하며, 추론 비용은 감당할 수 있을 때다. 대회에서 앙상블이 흔하고 실시간 서비스에서 드문 까닭이 그것이다.

## 연습문제

<div class="drillbox" markdown>

**연습문제 1.** <span class="diff easy" title="쉬움"></span>
본문의 코드는 로짓이 아니라 softmax를 평균한다. 로짓을 평균하면 무엇이 달라지는가?

</div>

??? success "연습문제 1 풀이"
    로짓은 크기가 정해져 있지 않다. 어떤 모델은 $[-2, 8]$ 범위를, 어떤 모델은 $[-20, 30]$ 범위를 낼 수 있고, 같은 확신을 나타내더라도 그렇다.

    로짓을 평균하면 **크기가 큰 모델이 결과를 좌우한다.** 다섯 표를 걷는 것이 아니라 목소리 큰 하나를 따르는 셈이 된다.

    softmax를 지나면 모두 합이 1인 확률이 되므로 발언권이 같아진다. 그래서 평균할 것은 확률이다.

    다만 softmax 평균이 유일한 답은 아니다. 기하평균(로그 확률의 평균)을 쓰기도 하며, 이쪽은 **한 모델이라도 강하게 반대하면 그 후보를 죽이는** 성질이 있다. 산술평균은 관대하고 기하평균은 엄격하다.

---

<div class="drillbox" markdown>

**연습문제 2.** <span class="diff normal" title="중간"></span>
본문은 씨앗만 바꾸어 다양성을 얻었다. 씨앗 말고 무엇을 바꾸면 더 다양해지겠는가? 세 가지를 들고, 각각이 [4.1절](01_two_ladders.md)의 규약을 깨는지 따져라.

</div>

??? success "연습문제 2 풀이"
    **하나, 구조를 섞는다.** CNN 셋과 MLP 둘을 함께 평균한다. 서로 다른 가정 위에 서 있으므로 실수도 크게 어긋난다. 다만 약한 모델(MLP 50%)이 강한 모델(CNN 71%)을 끌어내릴 수 있어, 가중치를 두어야 할 수 있다.

    **둘, 자료를 나눠 준다.** 학습 집합에서 매번 다시 뽑아(부트스트랩) 모델마다 조금씩 다른 자료를 보게 한다. 이것이 배깅이며 무작위 숲이 쓰는 방법이다. 각 모델이 보는 자료가 줄어 홑모델 성능은 떨어지지만 다양성은 커진다.

    **셋, 증강을 다르게 건다.** [4.3절](03_augmentation.md)의 수법을 모델마다 다르게 준다. 자르기만, 뒤집기만, 둘 다.

    규약으로 보면 셋 다 "모델만 바꾼다"는 이 장의 전제를 넘어선다. 첫째는 구조를, 둘째와 셋째는 자료를 건드린다. 그래서 이 절은 **씨앗만** 바꾸었다. 가장 약한 형태의 다양성으로도 3.40%포인트가 나온다는 것이 오히려 요점이다.

---

<div class="drillbox" markdown>

**연습문제 3.** <span class="diff hard" title="어려움"></span>
오라클이 86.79%인데 평균은 74.73%만 건진다. 이 12.06%포인트를 줄이려면 무엇을 알아야 하는가? 그리고 오라클 자체를 실제로 달성할 수 없는 까닭은 무엇인가?

</div>

??? success "연습문제 3 풀이"
    **줄이려면 "어느 모델을 언제 믿을지"를 알아야 한다.** 평균은 다섯을 언제나 똑같이 대접한다. 그림마다 누가 더 미더운지 알 수 있다면 소수의 정답을 살릴 수 있다.

    실마리로 쓸 만한 것들이 있다. 확신도(softmax 최댓값)가 높은 모델에 가중치를 더 주거나, 검증 집합에서 클래스별로 잘하는 모델을 가려 두거나, 결합하는 방법 자체를 학습시키는 것(스태킹)이다.

    **오라클을 달성할 수 없는 까닭**은 그 값을 계산할 때 **정답을 이미 썼기** 때문이다. "하나라도 맞혔는가"를 세려면 맞았는지 알아야 하고, 그것은 시험 라벨을 본다는 뜻이다. 실제로는 볼 수 없다.

    그러므로 오라클은 달성할 목표가 아니라 **천장**이다. 이 다섯 모델을 아무리 영리하게 결합해도 86.79%를 넘지 못한다는 것, 그리고 아직 12%포인트가 남아 있다는 것을 알려 주는 값이다.

    한 가지 더. 오라클이 [4.2절](02_vgg16_transfer.md)의 전이 학습(84.93%)보다 높다는 사실은 이 다섯 모델이 **집단으로는** 그만한 정보를 쥐고 있음을 뜻한다. 부족한 것은 정보가 아니라 그것을 꺼내는 방법이다.
