# 지식 증류의 기초: 교사·학생 구조

지식 증류는 교사의 출력·피처·표본 관계를 학생의 학습 목표로 사용하는 방법이다. 학생이 반드시 더 작을 필요는 없으며, 이미 학습한 교사를 쓰는 압축과 함께 학습하는 자기 증류를 구분한다. 교사 모방이 품질·일반화·해석 가능성을 자동으로 높이는 것은 아니다.

## 1. 핵심 개념

- **교사·학생**: 학습 목표를 제공하는 모델과 그 목표에 맞추는 모델이다.
- **소프트 타깃**: 정답 하나 외에 교사가 부여한 클래스별 확률을 사용한다. 이 정보에는 교사의 오류도 포함될 수 있다.
- **온도**: 로짓의 스케일을 바꾸어 확률 분포의 집중도를 조절한다.
- **응답·피처·관계 증류**: 출력 분포, 중간 피처 또는 표본 간 관계 중 무엇을 맞추는지에 따라 나눈다.

## 2. 로스와 온도

### 증류 로스

아래는 레이블을 쓰는 분류 증류의 한 구성이다. CE는 온도 1의 학생 로짓으로 계산하고 KL은 온도 T로 만든 교사·학생 분포를 비교한다. 레이블이 없는 자기 증류는 다른 목표·붕괴 방지 설계가 필요하다.

$$\mathcal{L}_{\text{KD}} = \alpha \mathcal{L}_{\text{CE}}(\mathbf{y}_s, \mathbf{y}) + (1-\alpha)T^2\mathcal{L}_{\text{KL}}(\mathbf{p}_t \,\|\, \mathbf{p}_s)$$

여기서 각 기호는 다음과 같다.

- $\mathcal{L}_{\text{CE}}$은 정답 레이블 $\mathbf{y}$에 대한 교차 엔트로피 로스다
- $\mathcal{L}_{\text{KL}}$은 교사의 출력에서 학생의 출력으로 잰 쿨백-라이블러 발산이다. KL은 비대칭이라 자리가 뜻을 바꾼다 — 교사가 앞에 선다
- $\mathbf{p}_s, \mathbf{p}_t$은 온도로 변환한 확률 분포이다
- $\alpha$은 지도의 원천을 다스리는 웨이트 파라메터이다

### 온도에 따른 분포

온도로 변환한 확률 분포는 온도 파라메터 $T$을 쓴다.

$$\mathbf{p}_i = \frac{\exp(z_i / T)}{\sum_j \exp(z_j / T)}$$

여기서 $z_i$은 로짓 값을 나타낸다.

온도로 변환한 분포 사이의 KL 발산은 다음과 같다.

$$D_{\text{KL}}(\mathbf{p}_t \| \mathbf{p}_s) = \sum_i \mathbf{p}_t^{(i)}(T) \log \frac{\mathbf{p}_t^{(i)}(T)}{\mathbf{p}_s^{(i)}(T)}$$

**온도의 효과**:

- **T=1**: 원래 로짓의 소프트맥스다. 그 분포가 반드시 뾰족한 것은 아니다.
- **T>1**: 고정된 로짓에서 분포가 더 평평해진다. 클래스 관계를 살펴볼 수 있지만 그 관계가 항상 올바른 것은 아니다.
- **T→∞**: 유한 로짓의 소프트맥스는 균등 분포로 간다.

## 3. 증류의 클래스

### 응답 기반 지식 증류

마지막 출력 분포를 맞춘다.

\mathcal{L}_{\text{response}}=T^2D_{\mathrm{KL}}(\operatorname{softmax}(z_t/T)\|\operatorname{softmax}(z_s/T))

**조건**: 교사·학생의 출력 클래스 의미와 순서가 같아야 한다. 서로 다른 어휘·클래스 체계라면 별도 대응이 필요하다.

**나쁜 점**: 중간 표현의 정보를 잃는다

### 피처 기반 지식 증류

중간 레이어의 표현을 맞춘다.

$$\mathcal{L}_{\text{feature}} = \|F_s(\mathbf{x}) - F_t(\mathbf{x})\|_2^2$$

여기서 $F_s, F_t$은 학생과 교사의 중간 피처가다.

**좋은 점**: 지도가 더 넉넉하고 피처가 더 잘 옮겨 간다

**조건**: 피처 축·해상도·대응 레이어를 맞추는 투영이나 어댑터가 필요할 수 있다. 두 구조가 완전히 같아야 하는 것은 아니며 추가 비용을 확인한다.

### 관계 기반 지식 증류

표본 사이의 쌍별 관계를 맞춘다.

$$\mathcal{L}_{\text{relation}} = \|R_s(\mathbf{x}_i, \mathbf{x}_j) - R_t(\mathbf{x}_i, \mathbf{x}_j)\|_2^2$$

여기서 $R$은 표본 사이의 유사도이나 관계를 잰다.

## 4. 학습 동작

### 학생 로짓의 그래디언트

교사 확률을 경사에서 분리하고 표본 하나의 로스를 쓴다고 하자. 온도 1 학생 확률을 s, 온도 T의 학생·교사 확률을 p_s·p_t라고 하면 다음과 같다.

$$
\frac{\partial\mathcal L_{\mathrm{KD}}}{\partial z_i^s}
=\alpha(s_i-\mathbf1_{i=y})+(1-\alpha)T\bigl(p_s^{(i)}(T)-p_t^{(i)}(T)\bigr)
$$

KL 자체의 미분에는 1/T가 있고 로스의 T²와 결합해 T가 남는다. 분포 차이도 T에 따라 달라지므로 온도를 높이면 경사가 무조건 커진다는 뜻은 아니다. 배치 평균이면 추가로 배치 크기로 나눈다. [원래 증류 논문](https://arxiv.org/abs/1503.02531)의 온도 보정과 함께 읽는다.

## 5. 구현할 때 살필 점

온도 T>0과 혼합 계수 0≤alpha≤1을 정하고 검증셋에서 비교한다. 클래스 수를 임의의 “증류 중요도”로 나누는 식으로 alpha를 계산하는 일반 법칙은 없다. 두 로스의 reduction·정답·스케일을 기록한다.

교사는 보통 eval 모드로 두고 no_grad 또는 detach로 목표를 계산한다. 하지만 동시 학습·EMA 교사 등은 목적이 다르므로 해당 갱신 규칙을 따른다. 학생의 수렴이 반드시 더 빠르거나 로스 분산이 더 작아야 한다는 기준은 없다. 교사·학생의 독립 평가와 잘못된 지식 전달도 확인한다.

## 6. 계량 금융에서의 쓰임

복잡한 예측 모델을 작은 학생으로 옮겨 지연·메모리를 줄이는 실험을 설계할 수 있다. 입력·정답과 시점별 사용 가능한 데이터를 맞추고 교사와 학생의 오차·캘리브레이션·비용을 함께 평가한다.

압축 자체가 해석 가능성, 규제 충족이나 수익성을 높인다는 보장은 없다. 다른 시장으로 옮길 때도 분포 변화와 독립 검증이 필요하며 이 페이지에는 금융 실험 결과가 없다.

## 7. 이론적 성질

응답 증류의 대표 목표는 교사 분포와 학생 분포의 기대 KL을 줄이는 것이다.

$$
\theta_s^*=\arg\min_{\theta_s}\mathbb E_x[D_{\mathrm{KL}}(p_t(\cdot\mid x)\|p_s(\cdot\mid x;\theta_s))]
$$

교사·학생 출력의 상호 정보를 최소화하는 것과는 다르다. 실제 품질은 교사의 오차, 학생 용량과 학습 데이터 범위에도 의존한다. 구조가 다르면 피처 정렬이나 표현의 동일성도 자동으로 성립하지 않는다.

## 8. 더 깊은 주제

**여러 교사 증류**: 여러 교사의 지식을 아우른다.

$$\mathcal{L} = \sum_t w_t \mathcal{L}_{\text{KD}}(\text{Student}, \text{Teacher}_t)$$

**서로 학습하기**: 바깥의 교사 없이 학생들이 서로를 동시에 가르친다.

**자기 증류**: 같은 구조의 이전 모델·더 깊은 레이어·EMA 목표 등에서 지도 신호를 구성하는 여러 방식이 있다. 반드시 과거 계수의 사본 하나만 쓰는 정의는 아니다.

<div class="drillbox" markdown>

**연습문제 3.** <span class="diff hard" title="어려움"></span>
아래 로스 함수의 확률 방향·reduction과 교사 경사·가져오기 조건을 설명하라.

</div>

??? success "풀이"
    F는 torch.nn.functional로 별도 가져와야 한다. kl_div의 입력은 학생 log 확률, target은 교사 확률이라 KL(교사||학생)이다. 함수가 교사 로짓을 detach하거나 eval로 만들지는 않으므로 호출자가 목표 경사를 분리해야 한다. batchmean은 (B,C) 분류를 가정하며 시퀀스 입력이라면 유효 토큰·패딩별 평균을 다시 정해야 한다.

    ```python
    def distillation_loss(student_logits, teacher_logits, labels, T=4, alpha=0.1):
        soft_loss = F.kl_div(
            F.log_softmax(student_logits / T, dim=-1),
            F.softmax(teacher_logits / T, dim=-1),
            reduction='batchmean') * T * T
        hard_loss = F.cross_entropy(student_logits, labels)
        return alpha * hard_loss + (1 - alpha) * soft_loss
    ```

## 정리하며

증류는 교사의 출력·피처·관계를 학습 목표로 쓰는 설계다. 온도·KL 방향·로스 웨이트와 교사 경사·모드를 맞추고, 출력 모방과 학생의 실제 품질·비용·해석 가능성을 구분한다.
