# 행동 인식의 과제·입력·평가 설계

행동 인식은 비디오나 클립에서 어떤 행동이 일어나는지 예측하는 과제다. 전체 클립에 하나의 클래스를 주는 분류, 여러 행동의 동시 예측, 행동의 시작·끝 또는 사람의 위치까지 찾는 탐지는 서로 다른 목표다. 이 페이지의 기존 코드는 안내 문구만 출력하며 행동 인식 시스템이나 평가기를 구현하지 않는다.

## 2. 레이블의 단위부터 정하기

잘라 놓은 클립 하나가 한 행동에 해당하면 단일 레이블 분류로 구성할 수 있다. 긴 원본 비디오에 짧은 행동이 들어 있을 때 임의의 crop 모두에 전체 비디오 레이블을 부여하면 행동이 없는 구간에도 같은 정답을 줄 수 있다. 시간 범위 주석과 표본 선택의 관계를 확인해야 한다.

동시에 여러 행동을 허용하면 K개 독립 목표와 sigmoid 기반 손실 등을 검토한다. 상호 배타적인 단일 클래스의 softmax·교차 엔트로피와 다르다. temporal localization은 시작·끝을, 시공간 행동 탐지는 프레임의 사람 상자·행동을 함께 다루므로 단순 클립 정확도만으로 평가하지 않는다.

## 3. 입력과 비교할 기준 모델

RGB 프레임별 CNN 평균은 외형·배경만으로도 강한 기준이 될 수 있다. 3D CNN·CNN-LSTM·시간 attention·flow 결합은 시간 정보를 사용하는 다른 설계다. 모델이 시간 차원을 받는다는 사실만으로 실제 움직임을 이용했다고 입증되지는 않는다. 단일 프레임·순서 변경·배경 대조 등을 통해 어떤 단서가 기여하는지 검토한다.

프레임 수·fps·stride가 관찰 시간과 계산비용을 정한다. 같은 16프레임이어도 구간 길이가 다르면 모델이 보는 행동의 범위가 달라진다. 짧은 영상 패딩·가림·동작 속도와 카메라 이동을 처리하는 규칙도 맞춘다. RGB와 flow·음성을 결합하면 시간 동기화가 필요하다.

## 4. 데이터 분할과 지표

같은 원본 비디오의 겹친 clip을 학습·검증에 나누면 내용 누수가 생길 수 있다. 사람·장소·촬영 세션의 일반화가 목적이면 그 단위의 분리도 검토한다. 데이터셋에 공식 분할이 있으면 조건을 명시해 따르고, 검증에 선택한 하이퍼파라미터의 성능은 독립 시험 자료로 최종 평가한다.

단일 레이블에는 top1·topk·클래스별 정확도·혼동행렬을 목적에 맞게 쓴다. 불균형 자료에서는 전체 정확도만으로 소수 행동을 놓칠 수 있다. multi-label에서는 클래스별 AP·임계값 기반 정밀도·재현율 등을 정의하고, 구간 탐지에서는 temporal IoU 매칭을 포함한 별도 AP를 사용한다. 서로 다른 과제의 mAP를 같은 값으로 비교하지 않는다.

## 5. 여러 clip과 실시간 사용

평가 시 한 비디오의 여러 clip·crop을 평균할 수 있으나 로짓 평균·확률 평균·투표는 다르다. 최종 평가 단위를 clip인지 원본 비디오인지 밝히고 추가 추론 횟수와 비용을 보고한다. 학습·검증·시험의 전처리 차이도 설명한다.

실시간에서는 모델 연산 시간뿐 아니라 클립을 모으는 관찰 지연, 디코딩·전송·대기·후처리도 있다. 양방향 모델이나 미래 프레임을 포함한 clip은 그 정보를 기다려야 한다. 높은 offline 정확도만으로 온라인 응답 요건을 만족한다고 볼 수 없다.

## 정리하며

행동 인식은 과제와 레이블 단위를 먼저 정한 뒤 시간 샘플링·모델·분할·지표를 연결해야 한다. 클립 분류를 행동 위치 탐지로 확대 해석하지 않고, 여러 clip의 offline 결과와 온라인 지연을 구분한다. 기존 코드는 구현이 아닌 시작용 파일이다.
