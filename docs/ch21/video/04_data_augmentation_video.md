# 비디오 데이터 어그멘테이션과 시간적 일관성

비디오 어그멘테이션은 공간·색상·시간 변형으로 학습 입력을 다양화한다. 변형 뒤에도 정답의 의미가 유지되어야 하며, 프레임별 무작위 변화가 원래 없던 액션을 만들 수 있다는 점이 이미지 어그멘테이션과 다르다. 이 페이지의 기존 코드는 import와 메시지 출력뿐인 시작용 파일이며 어그멘테이션 함수나 학습·시각화를 구현하지 않는다.

## 2. 공간 변형을 클립 전체에 공유하기

하나의 clip에 crop 위치·resize 비율·회전·flip 여부를 한 번 뽑아 모든 프레임에 같이 적용하면 인위적인 화면 흔들림을 줄일 수 있다. 프레임마다 crop을 독립적으로 뽑으면 고정된 객체도 움직이는 것처럼 보일 수 있다. 카메라 액션을 의도한 어그멘테이션과 이런 우발적 변화는 구분한다.

탐지 상자·분할 마스크·키포인트에도 같은 기하 변환을 적용해야 한다. 마스크는 클래스 ID가 섞이지 않는 보간을 사용하고 잘린 객체·빈 상자·가려진 키포인트의 처리 규칙을 정한다. 좌우 뒤집기가 ‘왼손으로 액션’처럼 방향을 포함한 정답을 바꾸는 과제에서는 레이블도 수정하거나 해당 어그멘테이션을 제외한다.

Optical flow는 두 채널 벡터장이므로 그림처럼 뒤집기만 하면 안 된다. 좌우 반사 시 위치를 뒤집고 수평 성분의 부호를 바꾸며, 가로·세로 resize 시 각 축의 픽셀 이동량도 해당 비율로 조정한다. 정규화 거리 등 다른 단위의 flow에는 그 표현에 맞는 규칙을 적용한다.

## 3. 시간 변형과 액션 의미

시간 crop은 긴 비디오의 일부 구간을 선택한다. 선택 구간에 목표 액션이 남는지와 비디오 전체 레이블을 그대로 부여할 수 있는지가 중요하다. 균일 샘플링·stride 변경은 같은 프레임 수에서도 관찰 시간과 속도를 바꾸며 빠른 액션을 놓칠 수 있다.

시간 뒤집기는 열기↔닫기처럼 동작의 의미를 바꿀 수 있다. RGB 프레임을 역순으로 놓을 때 flow도 단순 순서 반전이나 부호 반전만으로 정확한 역방향장이 되지는 않는다. 대응 좌표가 달라 역방향 추정·재표집의 정의가 필요하다. 짧은 영상 반복·패딩은 길이를 맞추지만 실제 동작을 추가하지 않으므로 마스크와 집계 규칙도 고려한다.

## 4. 색상 변형과 평가

클립 전체에서 같은 색상·밝기 변형을 공유하면 프레임 사이의 일관성을 유지하기 쉽다. 프레임별 flicker를 의도적으로 추가할 수도 있지만 밝기 불변 가정을 사용하는 flow 추정과 정답 의미에 미치는 영향을 확인해야 한다. 기하와 달리 색상 변형을 정수 마스크에 적용해서는 안 된다.

어그멘테이션의 종류·강도는 학습 자료에서 설계하고 검증·시험은 목적에 맞는 고정된 전처리로 평가한다. 여러 clip·crop을 평가 때 합치는 test-time augmentation은 추가 추론 비용과 집계 방식을 보고한다. 어그멘테이션이 언제나 일반화를 높이는 것은 아니며 어그멘테이션 없는 대조와 독립 분할에서 확인해야 한다.

## 정리하며

비디오 어그멘테이션은 프레임별 모양뿐 아니라 시간적 관계와 레이블을 보존해야 한다. 공간·시간·색상 변형의 목적과 flow 벡터·상자·마스크의 변환 규칙을 정한다. 기존 코드는 시작용 파일이므로 어그멘테이션이 구현·검증되었다고 해석하지 않는다.
