# 36장: 그래프 생성

이 장은 **그래프 생성**을 다룬다.

그래프 생성은 그래프 구조 데이터에 대한 분포를 배우고 학습 표본과 통계로 가려낼 수 없는 새 그래프를 낸다. 이 장은 차원이 제각각이고 이산적이며 순열 불변인 구조를 만드는 근본 어려움을 다루고 자기회귀, 원샷 생성, 확산 기반 방법을 살핀다. 쓰임새는 분자 설계, 금융 네트워크 합성, 거래 그래프 생성에 걸친다.

---

## 1. 차례

### 36.1 기초

- [그래프 생성 입문](foundations/introduction.md) -- 생성 문제, 조합적 출력 공간, 순열 대칭, 엄밀한 문제 정의
- [생성을 위한 그래프 표현](foundations/representations.md) -- 인접 행렬, 엣지 목록, 시퀀스 표현과 그것이 생성 모델 설계에 주는 뜻
- [평가 지표](foundations/metrics.md) -- 생성한 그래프의 품질을 재는 차수 분포, 군집 계수, 분포 비교 지표

### 36.2 자기회귀 방법

- [순차 그래프 생성](autoregressive/sequential.md) -- 표준 순서와 확률의 사슬 규칙으로 그래프 분포를 자기회귀로 인수 분해하기
- [GraphRNN](autoregressive/graphrnn.md) -- 노드와 엣지를 차례로 만드는 그래프 수준과 엣지 수준의 회귀를 가진 계층적 순환 뉴럴 네트워크 구조
- [GRAN](autoregressive/gran.md) -- 확장 가능한 자기회귀 생성을 위해 그래프 뉴럴 네트워크 기반 어텐션을 쓰는 블록 단위 그래프 생성

### 36.3 원샷 생성 방법

- [한 번에 인접 행렬 생성](one_shot/adjacency.md) -- 연속값으로 완화하기와 순열 불변성으로 한 번의 순전파에 인접 행렬 전체를 출력하기
- [GraphVAE](one_shot/graphvae.md) -- 그래프 뉴럴 네트워크 인코더, 확률 디코더, 그래프 매칭 로스를 가진 그래프용 변분 오토인코더
- [GraphGAN](one_shot/graphgan.md) -- 암묵적 밀도 표현과 이산화 전략을 쓰는 적대적 그래프 생성

### 36.4 확산 기반 방법

- [그래프 확산 모델](diffusion/graph_diffusion.md) -- 연속값으로 완화하기와 이산 노이즈 정의로 디노이징 확산을 그래프 구조 데이터에 넓히기
- [DiGress](diffusion/digress.md) -- 그래프 트랜스포머 디노이저로 범주형 노드 속성과 엣지 속성을 다루는 이산 디노이징 확산
- [GDSS](diffusion/gdss.md) -- 노드와 이웃 관계를 함께 만드는 결합된 확률 미분 방정식으로 하는 스코어 기반 그래프 생성

### 분자 생성

- 분자 그래프 -- 원자 종류, 결합 종류, 화학 원자가 제약을 가진 속성 그래프로 분자 나타내기
- SMILES 기반 생성 -- SMILES 문자열 표현과 언어 모델 기법으로 분자 생성을 시퀀스 표현으로 줄이기
- 3차원 분자 생성 -- SE(3) 등변인 모델로 분자 그래프와 원자 좌표를 함께 생성
- 성질 최적화 -- 강화학습, 베이즈 최적화, 잠재 공간 탐색으로 타깃 성질에 맞춘 분자 생성

### 36.5 금융 응용

- 금융 네트워크 생성 -- 스트레스 테스트와 시스템 위험 측정을 위한 그럴듯한 은행 간, 상관, 파생상품 네트워크 합성
- [거래 그래프 생성](finance/transactions.md) -- 자금 세탁 방지 모델 개발과 사기 탐지 학습을 위한 시간 거래 그래프 생성
- 합성 시장 네트워크 -- 꾸러미 스트레스 테스트와 국면 분석을 위한 자산 상관과 시장 구조 네트워크 생성
