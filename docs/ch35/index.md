# 36장: 그래프 생성

이 장은 **그래프 생성**을 다룬다.

그래프 생성은 그래프 구조 데이터에 대한 분포를 배우고 학습 표본과 통계로 가려낼 수 없는 새 그래프를 낸다. 이 장은 차원이 제각각이고 띄엄띄엄하며 자리바꿈에 안 바뀌는 구조를 만드는 근본 어려움을 다루고 자기회귀, 한 번에 만들기, 확산 기초 길을 살핀다. 쓰임새는 분자 설계, 금융 네트워크 지어내기, 거래 그래프 생성에 걸친다.

---

## 1. 차례

### 31.1 기초

- [그래프 생성 입문](foundations/introduction.md) -- 만들기 문제, 얽음의 내놓기 자리, 자리바꿈 맞섬, 엄밀한 문제 적기
- [생성을 위한 그래프 표현](foundations/representations.md) -- 인접 행렬, 엣지 목록, 차례 나타냄과 그것이 짓는 모델 설계에 주는 뜻
- [따지기 잣대](foundations/metrics.md) -- 만들어 낸 그래프의 품질을 재는 차수 분포, 뭉침 계수, 분포 비교 잣대

### 31.2 자기회귀 방법

- [차례로 하는 그래프 생성](autoregressive/sequential.md) -- 표준 차례와 확률의 사슬 규칙으로 그래프 분포를 자기회귀로 인수 분해하기
- [GraphRNN](autoregressive/graphrnn.md) -- 노드와 엣지를 차례로 만드는 그래프 켜와 엣지 켜의 되돌이를 가진 켜진 순환 신경망 구조
- [GRAN](autoregressive/gran.md) -- 커질 수 있는 자기회귀 만들기를 위해 그래프 신경망 기초 어텐션을 쓰는 덩이 단위 그래프 생성

### 31.3 한 번에 만들기 방법

- [한 번에 인접 행렬 만들기](one_shot/adjacency.md) -- 이어진 값으로 느슨히 하기와 자리바꿈에 안 바뀜으로 한 번의 앞으로 가기에 인접 행렬 전체를 내놓기
- [GraphVAE](one_shot/graphvae.md) -- 그래프 신경망 인코더, 확률 디코더, 그래프 짝짓기 손실을 가진 그래프용 변분 오토인코더
- [GraphGAN](one_shot/graphgan.md) -- 숨은 밀도 나타내기와 띄엄띄엄하게 하기 셈속을 쓰는 적대적 그래프 생성

### 31.4 확산 기반 방법

- [그래프 확산 모델](diffusion/graph_diffusion.md) -- 이어진 값으로 느슨히 하기와 띄엄띄엄 잡소리 적기로 잡소리 없애기 확산을 그래프 구조 데이터에 넓히기
- [DiGress](diffusion/digress.md) -- 그래프 트랜스포머 잡소리 없애개로 갈래 노드와 엣지 갈래를 다루는 이산 디노이징 확산
- [GDSS](diffusion/gdss.md) -- 노드와 이웃 관계를 함께 만드는 얽힌 확률 미분 방정식으로 하는 스코어 기반 그래프 생성

### 31.5 분자 만들기

- 분자 그래프 -- 원자 갈래, 결합 갈래, 화학 원자가 매임을 가진 속성 그래프로 분자 나타내기
- SMILES 기초 만들기 -- SMILES 문자열 나타냄과 언어 모델 재주로 분자 만들기를 차례 나타내기로 줄이기
- 3차원 분자 만들기 -- SE(3)에 같이 바뀌는 모델로 분자 그래프와 원자 자리를 함께 만들기
- 성질 최적화 -- 강화학습, 베이즈 최적화, 잠재공간 찾기로 과녁 성질에 맞춘 분자 만들기

### 31.6 금융 응용

- 금융 네트워크 만들기 -- 버거움 시험과 체계 위험 재기를 위한 그럴듯한 은행 사이, 얽힘, 파생 네트워크 지어내기
- [거래 그래프 생성](finance/transactions.md) -- 자금 세탁 막기 모델 개발과 속임수 찾기 학습을 위한 때 거래 그래프 생성
- 지어낸 시장 네트워크 -- 꾸러미 버거움 시험과 국면 살피기를 위한 자산 얽힘과 시장 구조 네트워크 만들기
