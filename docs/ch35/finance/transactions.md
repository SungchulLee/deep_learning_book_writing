# 거래 그래프 생성

거래 그래프는 시간에 따라 개체 사이를 오가는 돈의 흐름을 기록한다. 고정된 금융 네트워크와 달리 거래 그래프는 본질적으로 **시간 의존적**이고 **동적**이다. 엣지 하나하나가 특정 시점의 특정 거래를 나타내며 금액, 통화, 그리고 흔히 메타데이터(거래 유형, 메모, 위험 표시)를 지닌다. 그럴듯한 합성 거래 그래프를 만드는 일은 자금 세탁 방지 모델 개발, 사기 탐지 학습, 프라이버시를 보존하는 데이터 공유, 지급 시스템 스트레스 테스트에 꼭 필요하다.

---

## 1. 거래 그래프의 구조

거래 그래프 $\mathcal{G} = (V, E, T)$는 다음으로 이루어진다.

- **노드** $V$: 개체(계좌, 개인, 사업체)
  - 노드 피처: 개체 유형(개인/법인), 관할, 계좌 개설 기간, 위험 등급, 평균 잔고
- **엣지** $E$: 송금인에서 수취인으로 가는 방향 있는 거래
  - 엣지 피처: 금액, 타임스탬프, 통화, 거래 유형(전신 송금, 자동 이체, 카드), 채널
- **시계열** $T$: 거래가 시간순으로 놓이며, 시간 패턴(빈도, 주기, 집중)이 결정적인 앎을 담는다

생성 모델이 담아야 할 핵심 구조 패턴은 다음과 같다.

**팬인 / 팬아웃**: 정상적인 사업 계좌는 작은 지급을 많이 받거나(팬인) 여럿에게 지급을 나눈다(팬아웃). 자금 세탁에는 흔히 **레이어링**(출처를 흐리려는 복잡한 팬아웃 패턴)이 든다.

**사이클 패턴**: 월급, 집세, 구독이 규칙적인 시간 패턴을 만든다. 비정상적인 사이클은 라운드트리핑(중개인을 거쳐 돈이 출처로 돌아옴)을 가리킬 수 있다.

**금액 분포**: 거래 금액은 꼬리가 두꺼운 분포를 따르며, 딱 떨어지는 금액(\$100, \$500)과 보고 임곗값 바로 아래에서 치솟는다. 미국에서는 \$10,000을 넘는 현금 거래를 보고해야 하므로, 세탁하는 쪽이 임곗값 아래로 거래를 쪼개는 "스트럭처링"이 생긴다.

**시간적 집중**: 거래가 특정 시기에 몰린다. 월급날, 월말, 명절 시즌이 그렇다. 정상 계좌는 예측 가능한 주기를 보이고, 사기 계좌는 비정상적인 집중 패턴을 보일 수 있다.

## 2. 합성 거래 생성의 길

### 규칙 기반 생성

개체 유형과 행동 규칙을 정의한 뒤 시뮬레이션한다.

1. **개체 프로필**: 계좌마다 유형(개인, 소상공인, 대기업)과 그에 딸린 행동 파라미터(거래 빈도, 전형적인 금액, 거래 상대의 다양성)를 가진다.

2. **거래 템플릿**: 월급 입금, 요금 납부, 기업 간 청구서 같은 전형적인 거래 패턴을, 시간과 금액을 파라미터로 두어 정의한다.

3. **이상 패턴 주입**: 정상 활동의 베이스라인을 만든 뒤 특정 자금 세탁 유형(스트럭처링, 레이어링, 라운드트리핑)을 통제된 비율로 넣는다.

이 방법은 이상 패턴의 비율과 유형을 완전히 통제할 수 있게 하지만, "정상" 거래가 실제 데이터의 복잡성과 의존성을 갖추지 못할 수 있다.

### 심층 생성의 길

**시간 점 과정 모델**: 조건부 강도 함수 — 이력이 주어졌을 때 단위 시간당 사건이 일어날 순간 비율 — 로 거래를 연속 시간의 사건으로 나타낸다.

$$\lambda(t \mid \mathcal{H}_t) = f_\theta(t, \mathcal{H}_t)$$

여기서 $\mathcal{H}_t$는 시각 $t$까지의 거래 이력이다. 뉴럴 호크스 과정과 트랜스포머 기반 점 과정은 복잡한 시간 의존성을 담을 수 있다.

**그래프 수준의 시간 생성**: (위상을 위한) 그래프 생성과 (거래 시각과 금액을 위한) 시간 모델링을 결합한다. 시간 스텝마다 네트워크의 이력을 조건으로 어느 노드 쌍이 거래하는지, 금액과 유형이 무엇인지 정한다.

**GAN 기반 거래 생성**: 제너레이터가 거래 시퀀스를 내고 디스크리미네이터가 실제 거래 이력과 합성 거래를 가려내는 GAN을 학습한다. 핵심 어려움은 그럴듯한 시간 패턴을 지키면서 관계 구조(거래가 특정 개체를 잇는다)를 지키는 것이다.

## 3. 프라이버시를 보존하는 합성 데이터

거래 그래프 생성의 큰 동기 하나는, 개별 거래를 드러내지 않으면서 실제 거래 데이터의 통계적 성질을 보존하는 **프라이버시 보존 합성 데이터**를 만드는 것이다.

**차등 프라이버시**: 생성 과정에 보정된 양의 노이즈를 더해 엄밀한 프라이버시 보장을 준다. 어려움은 프라이버시 제약 아래에서 데이터의 유용성(그럴듯한 패턴)을 지키는 것이다.

**합성 데이터 검증**: 합성 거래 데이터를 세 축으로 평가한다.

1. **충실도**: 집계 통계(금액 분포, 시간 패턴, 차수 분포)가 실제 데이터와 맞는가?
2. **유용성**: 합성 데이터로 학습한 머신러닝 모델이 실제 데이터로 학습한 모델과 비슷한 성능을 내는가(보기로 사기 탐지에서)?
3. **프라이버시**: 적대자가 합성 데이터에서 개인을 재식별하거나 민감한 속성을 추론할 수 있는가?

---

## 4. 자금 세탁 유형 주입

자금 세탁 탐지 모델을 학습하려면 합성 데이터에 그럴듯한 자금 세탁 패턴이 들어 있어야 한다.

**스트럭처링**: 큰 거래를 보고 임곗값(미국은 \$10,000) 아래 금액으로 쪼갠다. 보기로 짧은 기간에 여러 지점에서 \$9,500씩 여러 번 입금한다.

**레이어링**: 출처를 흐리려고 중간 계좌의 복잡한 사슬로 돈을 옮긴다. 거래 그래프에 출발지에서 도착지까지 여러 홉을 거치는 경로로 나타난다.

**라운드트리핑**: 돈이 계좌를 떠났다가 우회 경로로 같은 계좌(또는 관련 계좌)로 돌아온다. 거래 그래프의 사이클로 탐지한다.

**무역 기반 자금 세탁**: 국경을 넘어 가치를 옮기려고 무역 거래의 청구 금액을 부풀리거나 줄인다. 신고된 물품과 금액이 어긋나는 거래로 나타난다.

---

## 5. 평가 지표

일반 그래프 통계를 넘어 거래 그래프의 품질은 다음으로 잰다.

**시간 충실도**: 실제 데이터와 합성 데이터의 도착 간격 분포, 일별·주별 거래량 패턴, 자기상관 함수를 비교한다.

**금액 충실도**: 거래 금액 분포(평균, 분산, 분위수, 딱 떨어지는 금액에서의 치솟음)를 비교한다.

**다운스트림 유용성**: 합성 데이터로 사기·자금 세탁 탐지 모델을 학습하고 실제 데이터에서 평가한다. 실제 데이터로 학습한 모델의 성능에 가까울수록 합성 데이터의 품질이 높다.

**그래프 구조**: 차수 분포, 군집 계수, 연결 요소의 크기, 커뮤니티 구조를 비교한다.

## 연습문제

<div class="drillbox" markdown>

**연습문제 1.** <span class="diff med" title="중간"></span>
순열 불변성 문제 때문에 그래프 생성이 이미지 생성보다 왜 근본적으로 더 어려운지 설명하여라. 레이블이 붙은 노드 $n$개의 그래프에는 같은 뜻의 인접 행렬 표현이 몇 개 있는가?

</div>

??? success "풀이"
    노드 $n$개의 그래프는 서로 다른 인접 행렬 $n!$개로 나타낼 수 있다(노드 레이블의 순열마다 하나). $n = 10$이면 같은 뜻의 표현이 $10! = 3{,}628{,}800$개다. 생성 모델은 다음 가운데 하나를 해야 한다. (1) 이 중복을 줄이려 표준 순서를 정한다, (2) 순열 불변인 로스 함수를 쓴다(보기로 그래프 매칭), (3) 처음부터 불변인 표현 위에서 다룬다(보기로 스펙트럼 피처). 이미지 생성은 픽셀에 고정된 위치 순서가 있어 이 문제를 겪지 않는다. $\square$

<div class="drillbox" markdown>

**연습문제 2.** <span class="diff med" title="중간"></span>
확장성, 품질, 유효성 제약 준수의 측면에서 그래프 생성의 자기회귀 길과 원샷 생성 길을 비교하여라.

</div>

??? success "풀이"
    자기회귀 방법은 노드와 엣지를 차례로 만들어 스텝마다 국소 제약(보기로 원자가)을 자연스럽게 지키지만, 엣지 결정의 수가 $O(n^2)$으로 커진다. 원샷 생성 방법은 인접 행렬 전체를 한꺼번에 만들어 병렬 계산에는 더 잘 커지지만 이산적인 구조와 전역 제약에 애를 먹는다. 자기회귀 방법은 작은 크기($n < 100$)에서 대개 더 좋은 그래프를 내지만 큰 그래프에서는 느려진다. 순열 불변인 로스를 쓰는 원샷 생성 방법은 더 빠르지만 매칭 문제를 조심스레 다루어야 한다. $\square$

<div class="drillbox" markdown>

**연습문제 3.** <span class="diff hard" title="어려움"></span>
자기회귀 인수 분해 $p(G) = \prod_{i=1}^n p(\text{node}_i | \text{nodes}_{<i}) \prod_{j<i} p(e_{ij} | \text{node}_i, \text{nodes}_{<i})$ 아래에서 그래프의 우도를 이끌어 내어라.

</div>

??? success "풀이"
    고정된 노드 순서 $\pi$ 아래에서 결합 확률은 $p(G | \pi) = \prod_{i=1}^n p(v_{\pi(i)} | G_{\pi(<i)}) \prod_{j < i} p(e_{\pi(i),\pi(j)} | v_{\pi(i)}, G_{\pi(<i)})$로 인수 분해된다. 여기서 $G_{\pi(<i)}$는 앞서 만든 노드의 부분 그래프다. 주변 우도 $p(G) = \frac{1}{n!}\sum_\pi p(G | \pi)$는 모든 순서에 대한 합이라 계산할 수 없다. 실제로는 표준 순서(보기로 너비 우선)를 써서 우도를 그 순서에 의존하는 것으로 만든다. 순서의 품질이 생성 품질에 영향을 준다. $\square$

<div class="drillbox" markdown>

**연습문제 4.** <span class="diff med" title="중간"></span>
분포 지표를 넘어 화학적 유효성과 약물 유사성을 재는, 생성한 분자 그래프의 평가 규약을 내놓아라.

</div>

??? success "풀이"
    분포 지표(차수 분포, 군집 계수)를 넘어 다음을 평가한다. (1) 화학적 유효성 -- 원자가 제약을 만족하는 분자의 몫(RDKit으로 확인), (2) 고유성 -- 서로 다른 유효한 분자의 몫, (3) 참신성 -- 학습 집합에 없는 몫, (4) 약물 유사성 -- QED 점수, 리핀스키의 다섯 규칙 준수, (5) 합성 용이성 -- 합성이 얼마나 쉬운지 나타내는 SA 점수, (6) 성질 최적화 -- 목표 성질과 얻은 성질의 상관. 여러 번 만들어 얻은 신뢰 구간과 함께 모든 지표를 알린다. $\square$
