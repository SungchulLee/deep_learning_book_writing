# Leapfrog 적분기

Leapfrog는 분리 가능한 해밀턴 함수의 두 흐름을 대칭으로 합성하는 이차 적분기다. HMC에서는 가역성·체적 보존과 비교적 작은 에너지 오차를 이용하되, 안정성 조건과 MH 보정을 함께 고려한다.

## 1. 수치 적분 문제

표준 방정식은 ẋ=M⁻¹p, ṗ=−∇U(x)다. 정확한 흐름을 계산하기 어려우면 수치 사상으로 대체한다. 간단한 HMC 수락식에는 적절한 역방향 제안과 체적 보존이 유용하다. 심플렉틱 구조는 이를 제공하는 더 강한 성질이지만 모든 가능한 MCMC 적분기가 반드시 심플렉틱이어야 하는 것은 아니다.

명시적 Euler는 일반적으로 가역적·심플렉틱이지 않고 조화 진동자에서 에너지가 증가한다. 일반적인 명시적 RK4도 심플렉틱이지 않다. 고차 정확도만으로 긴 해밀턴 궤적의 보존 성질을 보장할 수 없다. 반면 모든 Runge–Kutta 방법이 비심플렉틱인 것은 아니며 암시적인 심플렉틱 방법도 존재한다.

## 2. 연산자 쪼개기

H=U(x)+K(p)를 나누면 U의 흐름은 위치를 고정한 운동량 이동 A_h:(x,p)↦(x,p−h∇U(x)), K의 흐름은 운동량을 고정한 위치 이동 B_h:(x,p)↦(x+hM⁻¹p,p)다. 각 부분은 정확히 풀 수 있다.

순차 합성은 일반적으로 가환하지 않는다. BCH 전개에서 단순 A_hB_h는 한 단계 O(h²) 국소 오차를 갖는다. 대칭 Strang 합성 A_{h/2}B_hA_{h/2}는 O(h³) 국소 오차를 가져 전역 이차 방법이 된다. 연산자 지수의 작용 순서와 상태 사상의 합성 순서를 구분하되 대칭 합성의 실제 갱신 순서를 명시한다.

## 3. Leapfrog 알고리즘

운동량–위치–운동량의 표준 갱신은 다음과 같다.

$$p_{n+1/2}=p_n-\frac h2\nabla U(x_n),\quad x_{n+1}=x_n+hM^{-1}p_{n+1/2},\quad p_{n+1}=p_{n+1/2}-\frac h2\nabla U(x_{n+1}).$$

운동량을 반정수 시간에 저장하면 위치와 엇갈려 진행하는 leapfrog 표현을 얻는다. 아래 도식은 이 시간 격자를 나타낸다. 일부 코드에서는 운동량을 v로 표기한다.

위치 반 걸음–운동량 한 걸음–위치 반 걸음 방식도 이차 대칭 분할이다. 그러나 같은 초기 정수시점 상태에 적용한 두 사상이 유한 h에서 완전히 동일한 것은 아니다. 에너지 오차와 안정성 세부도 달라질 수 있으므로 같은 계열의 서로 다른 순서로 구분한다.

```
Time:     0      ½      1      3/2     2
          |      |      |      |       |
Position: x₀ -------- x₁ -------- x₂ ---
Momentum: v₀ -- v½ -------- v3/2 -------
```

## 4. 여러 Leapfrog 걸음

연속 단계의 운동량 반 걸음을 합치면 L≥1 단계에 경사 평가 L+1회가 필요하다. 시작점 경사를 이미 저장하면 새로운 평가는 L회다. 이는 구현의 캐시·합성 방식에 따른 수치다.

적분시간 T=Lh는 이동 거리 자체가 아니다. 긴 T가 더 먼 끝점을 보장하지 않고 공진·되돌아옴으로 이동이 작아질 수 있다. 보편적인 L·h 범위를 외우기보다 목표의 단위·곡률·질량 행렬과 경사 비용을 고려한다. 아래 코드는 입력 L이 양의 정수임을 가정한다.

```python
def leapfrog(x, v, epsilon, L, grad_U, M_inv):
    # 운동량의 첫 반 걸음
    v = v - (epsilon / 2) * grad_U(x)
    
    # 온 걸음
    for i in range(L - 1):
        x = x + epsilon * M_inv @ v
        v = v - epsilon * grad_U(x)
    
    # 마지막 자리 새로 고치기
    x = x + epsilon * M_inv @ v
    
    # 운동량의 마지막 반 걸음
    v = v - (epsilon / 2) * grad_U(x)
    
    return x, v
```

## 5. 심플렉틱 성질

두 부분 갱신의 야코비안은 다음과 같다.

$$A_p=\begin{pmatrix}I&0\\-h\nabla^2U&I\end{pmatrix},\qquad A_x=\begin{pmatrix}I&hM^{-1}\\0&I\end{pmatrix}.$$

M⁻¹과 U의 헤세 행렬이 대칭이면 각각 AᵀΩA=Ω를 만족한다. Ω=[[0,I],[−I,0]]이며 합성도 심플렉틱이고 행렬식은 1이다. 이로써 체적 보존을 얻는다.

심플렉틱이라는 사실만으로 임의 h·무한 시간의 에너지 안정성이 따라오지는 않는다. 안정영역·매끄러움·수치 정밀도와 궤적 범위를 확인해야 한다. 단순 MH 에너지 비에는 가역적인 제안 구성도 필요하다.

## 6. 시간가역성과 반전

운동량 반전 R(x,p)=(x,−p)에 대해 각 부분 흐름은 R A_h R=A_−h, R B_h R=B_−h를 만족한다. 대칭 합성 Φ_h=A_{h/2}B_hA_{h/2}에서는 RΦ_hR=Φ_h⁻¹가 된다.

따라서 고정 L 단계와 반전을 결합한 RΦ_h^L는 자기 역 사상이다. 체적 보존과 함께 MH 에너지 차이 보정을 정당화한다. R 자체는 반심플렉틱이지만 절대 야코비안은 1이다. 상태에 따라 임의로 h·L을 바꾸면 같은 가역성 증명을 그대로 적용할 수 없다.

## 7. 오차 분석

Leapfrog는 국소 상태 오차 O(h³), 고정된 유한 적분시간에서 전역 상태 오차 O(h²)를 갖는 이차 방법이다. 이 차수는 충분한 매끄러움과 안정적인 해의 범위를 가정하며 상수는 시간·곡률·차원에 의존할 수 있다. 국소 오차가 삼차라고 삼차 적분기라고 부르지는 않는다.

역방향 오차 분석은 H+h²H₂+h⁴H₄+⋯의 수정 해밀턴 함수를 형식적 또는 적절히 절단된 전개로 설명한다. 일반적으로 수렴하는 무한급수가 존재해 수치 사상이 그것을 영원히 정확히 푼다는 뜻은 아니다. 작은 안정적 h와 적절한 정칙성 아래 장시간 에너지 오차가 작게 유지되는 결과를 얻는다.

수락확률은 α=min(1,e⁻ΔH)다. ΔH≤0이면 1, 양수 0.1·0.5·1·2이면 각각 약 0.905·0.607·0.368·0.135다. 개별 ΔH 범위를 전체 평균 수락률의 보편적인 목표로 대체하지 않는다. MH 보정은 목표 불변성을 위한 것이며 유한 실행의 독립성·정밀도를 보장하지 않는다.

## 8. 걸음 크기 고르기

양의 정부호 이차 퍼텐셜 U=xᵀAx/2에서 고유 주파수 제곱은 M⁻¹/²AM⁻¹/²의 고윳값이다. 비퇴화한 안정영역에는 다음 조건이 필요하다.

$$0<h<\frac2{\sqrt{\lambda_{\max}(M^{-1/2}AM^{-1/2})}}.$$

M=I일 때 원래 A의 최대 고윳값 식으로 줄어든다. 경계에서 고윳값 절댓값만 1이라고 안정적인 거듭제곱을 보장할 수는 없다. 비선형 목표에는 이 전역 이차식 기준을 그대로 적용하지 않는다.

아래 함수는 수락률을 보고 1.1배·0.9배로 조정하는 휴리스틱이다. 쌍대 평균 구현이 아니며 워밍업의 평가 창·잡음·종료 규칙은 별도다. h∝d⁻¹/⁴는 특정 정칙 곱 목표의 HMC 점근 분석이고 보편적인 모든 고차원 문제의 공식은 아니다.

```python
def adapt_step_size(epsilon, accept_rate, target=0.65):
    if accept_rate > target:
        epsilon *= 1.1  # 더 큰 걸음을 감당할 수 있음
    else:
        epsilon *= 0.9  # 더 작은 걸음이 필요함
    return epsilon
```

## 9. 수치적 안정성

큰 경사·급변 곡률·경계·비유한 로그확률은 궤적을 불안정하게 만들 수 있다. 두꺼운 꼬리가 항상 경사 폭발을 뜻하는 것은 아니다. 재매개변수화와 제약변환을 고려할 때는 목표밀도의 야코비안 항을 확인한다.

경사를 잘라낸 위치 의존 힘으로 운동량 전단을 만들어도 그 전단은 가역적·체적 보존일 수 있다. 따라서 원래 H로 올바르게 MH 보정한다면 잘라내기가 반드시 상세균형을 깨는 것은 아니다. 다만 일반적으로 심플렉틱·에너지 정확도 성질을 잃거나 효율이 나빠질 수 있고, 임의의 적응적 수정에는 별도 검토가 필요하다.

작은 h·긴 궤적에서도 반올림·조건수·누적 오차가 남는다. 이론의 정확 산술 가역성과 실제 부동소수점 구현을 구분하며 비유한 값과 에너지 차이를 기록한다.

## 10. 구현

기본·진단·벡터화 코드는 상수 M⁻¹과 유효한 경사를 가정한다. 벡터화 입력은 체인×차원이며 행 벡터 운동량에 M_inv.T를 오른쪽 곱한다. 경사 함수도 같은 형태로 반환해야 한다. L≥1, 유한한 양의 h와 호환되는 배열 차원·자료형을 확인한다.

leapfrog_with_diagnostics의 중간 energies는 정수 위치에 반시점 운동량을 대응시켜 기록한다. 이 중간 값은 동기화된 (x_n,p_n)의 H와 다르다. 초기·마지막 값은 정수시점 상태지만 중간 곡선의 변동을 원래 Leapfrog 에너지 오차로 그대로 해석하지 않는다. 현재 조각은 MH 수락·거절까지 포함한 전체 샘플러가 아니다.

```python
import numpy as np

def leapfrog(x, v, epsilon, L, grad_U, M_inv=None):
    """
    HMC를 위한 개구리뜀 적분기.
    
    인수:
        x: 첫 자리 (d,)
        v: 첫 운동량 (d,)
        epsilon: 걸음 크기
        L: 개구리뜀 걸음 수
        grad_U: 퍼텐셜 에너지의 기울기를 돌려주는 함수
        M_inv: 질량 행렬의 역행렬(기본값: 항등 행렬)
    
    반환값:
        x_new, v_new: 마지막 자리와 운동량
    """
    if M_inv is None:
        M_inv = np.eye(len(x))
    
    x = x.copy()
    v = v.copy()
    
    # 운동량의 반 걸음
    v = v - (epsilon / 2) * grad_U(x)
    
    # 온 걸음을 번갈아 밟기
    for i in range(L - 1):
        x = x + epsilon * (M_inv @ v)
        v = v - epsilon * grad_U(x)
    
    # 자리의 마지막 온 걸음
    x = x + epsilon * (M_inv @ v)
    
    # 운동량의 반 걸음
    v = v - (epsilon / 2) * grad_U(x)
    
    return x, v
```
```python
def leapfrog_with_diagnostics(x, v, epsilon, L, H, grad_U, M_inv=None):
    """진단을 위해 에너지를 기록하는 개구리뜀."""
    if M_inv is None:
        M_inv = np.eye(len(x))
    
    x = x.copy()
    v = v.copy()
    
    energies = [H(x, v)]
    
    v = v - (epsilon / 2) * grad_U(x)
    
    for i in range(L - 1):
        x = x + epsilon * (M_inv @ v)
        v = v - epsilon * grad_U(x)
        energies.append(H(x, v))
    
    x = x + epsilon * (M_inv @ v)
    v = v - (epsilon / 2) * grad_U(x)
    energies.append(H(x, v))
    
    return x, v, np.array(energies)
```
```python
def leapfrog_vectorized(x, v, epsilon, L, grad_U, M_inv=None):
    """
    사슬 여럿을 위한 벡터 꼴 개구리뜀.
    
    인수:
        x: 자리 (n_chains, d)
        v: 운동량 (n_chains, d)
        ...
    """
    if M_inv is None:
        M_inv = np.eye(x.shape[1])
    
    x = x.copy()
    v = v.copy()
    
    v = v - (epsilon / 2) * grad_U(x)
    
    for i in range(L - 1):
        x = x + epsilon * (v @ M_inv.T)
        v = v - epsilon * grad_U(x)
    
    x = x + epsilon * (v @ M_inv.T)
    v = v - (epsilon / 2) * grad_U(x)
    
    return x, v
```

## 11. 고차 적분기와 비용

더 높은 차수는 추가 부분 단계를 합성해 얻을 수 있다. 대칭 이차 사상 S_h에서 대표적인 사차 합성은 S_{a h}S_{b h}S_{a h}이며 다음 계수를 사용한다.

$$a=\frac1{2-2^{1/3}},\qquad b=-\frac{2^{1/3}}{2-2^{1/3}},\quad 2a+b=1,\quad 2a^3+b^3=0.$$

음의 부분 시간이 포함되며 매끄러움·안정성·경사 평가비용을 고려해야 한다. 더 높은 차수가 항상 더 큰 안정 스텝이나 좋은 시간당 ESS를 주는 것은 아니다. 현재 수락률이 높다는 사실만으로 높은 차수의 필요성을 판단하지 않는다.

## 12. 다른 적분기와 비교

명시적 Euler는 일차이고 일반적으로 비심플렉틱·비가역적이다. 심플렉틱 Euler는 일차 심플렉틱이지만 하나의 순서만 쓰면 시간대칭이 아니다. Leapfrog는 대칭 이차이며 L 단계에서 경사 L+1회 또는 시작 경사 캐시가 있으면 새 평가 L회가 든다.

명시적 RK4는 사차지만 일반적으로 심플렉틱이지 않다. 대칭 사차 합성은 추가 경사 평가와 음의 부분 시간 등의 비용을 갖는다. 비교에서는 같은 물리적 적분시간과 경사 비용·수락 보정을 맞춘다.

## 연습문제

1. 표준 조화계의 한 단계 행렬을 유도하라. 위치·운동량 순서에서 [[1−h²/2,h],[−h+h³/4,1−h²/2]]이며 행렬식 1, 대각합 2−h²다.

2. 위 행렬의 안정영역을 설명하라. 0<h<2에서는 서로 다른 켤레 고윳값의 절댓값이 1이다. h=2는 중복 고윳값과 Jordan 구조로 반복이 증가할 수 있으므로 포함하지 않는다.

3. 같은 고정 시간에서 h를 절반으로 하면 점근 전역 오차는 어떻게 바뀌는가? 이차 방법이므로 충분히 작은 안정적 h에서 대략 1/4이다. L을 그대로 고정해 적분시간까지 바꾸는 비교와 구분한다.

4. 진단 구현의 중간 에너지는 동기화되어 있는가? 정수 위치와 반시점 운동량을 섞어 사용하므로 정수시점 H의 오차를 직접 나타내지 않는다. 초기·최종 에너지와 같은 시점 상태를 비교해야 한다.

5. 고차 적분기를 비교할 설계를 제시하라. 같은 목표·적분시간·총 경사 평가 예산에서 에너지 차이와 수락률뿐 아니라 관심 함수의 시간당 MCSE를 비교한다.

## 정리하며

Leapfrog는 대칭 분할로 가역성·심플렉틱 체적 보존과 이차 정확도를 얻는다. 장시간 에너지 안정성은 조건부 결과이며, 안정영역·반올림·진단 시점과 MH 보정을 함께 확인한다.
