# 온도의 통합적 해석

온도는 에너지와 엔트로피를 조절하는 여러 방법에 공통된 비유를 제공한다. 볼츠만 거듭제곱 목표와 정확히 대응하는 경우, 확산의 노이즈 수준처럼 관련은 있지만 다른 경우를 구분한다.

## 1. 온도가 두루 하는 일

정규화 가능한 π_T∝exp(−E/T)에서 T>0는 에너지 차이의 상대 스케일이다. 분포 q에 대한 E_qE−T H(q)를 최소화하면 해당 볼츠만 목표를 얻는 것이 기본적인 변분 원리다.

T=1은 선택한 에너지 단위의 기준일 뿐 모든 응용에서 특별히 최적인 균형이 아니다. 유한 상태에서는 높은 T가 균등, 낮은 T가 최소 에너지에 집중하지만 비유계 연속 공간의 고온 균등분포·정규화는 별도로 확인한다. 높은 엔트로피가 항상 높은 품질 또는 충분한 탐색을 뜻하지는 않는다.

## 2. MCMC에서의 온도

π_T∝π^(1/T)는 T=1의 목표 자체와 다른 분포다. 뜨거운 체인이 장벽 탐색을 도울 수 있지만 차가운 분포가 원래 목표를 더 정확하게 근사한다는 뜻은 아니다. 병렬 템퍼링은 고정 온도들의 곱 목표와 올바른 교환 보정을 사용한다.

β_i=1/T_i, E_i=E(x_i)일 때 상태 교환의 로그비는 (β_i−β_j)(E_i−E_j)다. 아래 parallel_tempering_step은 에너지 차이를 반대로 써 이 비의 부호가 뒤집혀 있으므로 의도한 곱 목표의 교환 규칙으로 해석할 수 없다. metropolis_step·np도 외부 정의가 필요하다.

Annealed importance sampling은 정확한 쉬운 초기분포와 중간 미정규화 밀도 γ_t, 각 정규화 목표를 보존하는 전이를 결합한다. 웨이트는 경로에 맞춰 ∏γ_t(x_{t−1})/γ_{t−1}(x_{t−1})로 구성한다. 정규화된 p_t와 미지 정규화 상수비를 혼용하지 않는다. 적절한 조건에서 상수비를 추정할 수 있지만 모든 경로가 직접 IS보다 작은 분산을 보장하지는 않는다. [AIS 원 논문](https://arxiv.org/abs/physics/9803008)을 참고한다.

```python
def parallel_tempering_step(chains, temperatures, E):
    """병렬 온도 다루기의 한 걸음."""
    n_chains = len(chains)
    
    # 온도마다의 가까운 액션
    for i in range(n_chains):
        chains[i] = metropolis_step(chains[i], E, temperatures[i])
    
    # 이웃한 온도 사이의 맞바꿈 시도
    for i in range(n_chains - 1):
        delta = (1/temperatures[i] - 1/temperatures[i+1]) * \
                (E(chains[i+1]) - E(chains[i]))
        
        if np.random.rand() < np.exp(delta):
            chains[i], chains[i+1] = chains[i+1], chains[i]
    
    return chains
```

## 3. 랑주뱅 동역학에서의 온도

고정 T에서 dX=−∇Edt+√(2T)dW는 exp(−E/T)를 목표로 한다. 시간 단위를 바꾸면 dX=−∇E/Tdt+√2dW도 같은 정상 목표를 가질 수 있다. 따라서 온도를 드리프트로 표현하면 언제나 틀리다는 설명은 아니다.

이산 근사 X′=X−h∇E+√(2hT)η에는 유한 스텝 바이어스·안정성 조건이 남는다. T→0의 고정 시간 극한은 경사 흐름과 연결되지만 비볼록 전역 최적을 자동으로 보장하지 않는다. T→∞에서는 잡음이 커지지만 시간·공간 재조정 없이 하나의 유한 계수 브라운 운동으로 수렴한다고 표현하지 않는다.

## 4. 확산 모델에서의 온도

분산 보존 정방향 확산 dX=−β(t)Xdt/2+√β(t)dW의 β(t)는 노이즈 주입률이다. 고정 E의 온도와 동일한 역온도가 아니며, 이 과정은 잡음을 더하면서 신호도 축소한다.

역전은 시간별 스코어 ∇log p_t를 사용한다. τ=T−t로 시간을 반대로 증가시키면 드리프트는 β(t)X/2+β(t)∇log p_t이고 잡음 계수는 √β(t)다. 이는 일반적으로 고정 에너지의 냉각 Langevin과 같은 방정식이 아니다.

생성 잡음을 cσ_t로 조절하는 휴리스틱은 가능하지만 최종 분포를 정확히 π^(1/T)로 만든다고 보장하지 않는다. σ_t^(1/T)라는 식은 온도 0에서 정의되지 않고 단위와 크기에 따라 방향도 달라져 보편적인 온도 공식으로 쓰지 않는다. DDIM의 결정적 극한은 평균·전이식 전체를 맞춘 별도 샘플러이며 임의 DDPM 역잡음만 0으로 놓는 것과 동일시하지 않는다.

## 5. 뉴럴 넷트웍에서의 온도

유한 로짓 z_i에서 softmax_T(z)_i=exp(z_i/T)/∑exp(z_j/T)다. T→∞는 균등, T→0은 최대 로짓 집합에 균등 집중하며 유일 최대일 때 one-hot이 된다. 양의 T는 클래스 argmax 순서를 바꾸지 않는다.

지식 증류는 온도로 부드럽게 한 교사·학생 분포를 비교한다. 아래 함수는 KL(교사‖학생)에 T² 배율을 쓰고 hard label CE와 α로 섞는다. torch.nn.functional의 F 정의, T>0·0≤α≤1과 교사 경사 차단 여부를 확인해야 한다.

스케일 점곱 어텐션의 √d_k는 로짓 스케일을 조절해 고차원 내적의 분산을 관리하는 동기와 연결된다. 온도 비유는 가능하지만 모든 주의 메커니즘의 확률적 온도라고 동일시하지 않는다. Temperature scaling은 별도 캘리브레이션 자료로 T를 맞추며 모든 데이터셋의 정확도·보정 개선을 보장하지는 않는다.

```python
def distillation_loss(student_logits, teacher_logits, labels, T=4.0, alpha=0.5):
    """온도를 쓴 앎 내리기."""
    soft_targets = F.softmax(teacher_logits / T, dim=1)
    soft_student = F.log_softmax(student_logits / T, dim=1)
    
    # 앎 내리기 로스(힌턴을 따라 T^2으로 크기 맞춤)
    distill_loss = F.kl_div(soft_student, soft_targets, 
                            reduction='batchmean') * T * T
    
    # 딱 잘라 붙인 이름표의 로스
    hard_loss = F.cross_entropy(student_logits, labels)
    
    return alpha * distill_loss + (1 - alpha) * hard_loss
```

## 6. 강화 학습에서의 온도

유한 액션에서 고정 Q(s,a)에 대해 엔트로피 정규화된 선택은 분포 π를 최적화한다.

$$V(s)=\max_\pi\{E_{a\sim\pi}Q(s,a)+T H(\pi(\cdot|s))\}=T\log\sum_a\exp(Q(s,a)/T).$$

해는 π*(a|s)∝exp(Q(s,a)/T)다. 단일 액션의 max 안에 그 액션의 −Tlog π만 넣는 원래 식과 다르다. 실제 soft Bellman에는 할인·리워드·상태 전이와 미래 soft value를 일관되게 정의해야 한다.

SAC의 엔트로피 계수 α는 리워드와 엔트로피의 상대 가중이다. 목표 엔트로피에 대한 적응을 사용할 수 있지만 학습 성공이나 모든 액션 탐색의 보증은 아니다. 연속 액션에서는 밀도·미분 엔트로피와 적분 가능성도 확인한다.

## 7. 최적화에서의 온도

유한 상태 에너지 E_i와 확률벡터 p에서 min_{p∈Δ}∑p_iE_i−T H(p)의 해는 볼츠만 분포다. 일반적인 결정변수 x의 E(x)−T H[x]를 최소화하면 x∝exp(−E(x)/T)가 된다는 자기참조식으로 일반화하지 않는다.

엔트로피 최적수송은 행·열 주변 제약을 갖는 수송행렬 γ에 대해 ⟨C,γ⟩−εH(γ)를 최소화한다. 해는 일반적으로 γ=diag(u)exp(−C/ε)diag(v) 꼴로 주변 제약의 스케일 u,v가 필요하다. 비용 커널의 단순 전역 정규화와 다르며 큰 ε는 최적수송 목적 자체도 바꾼다.

## 8. 정확한 대응과 비유의 경계

볼츠만 분포·유한 softmax·고정 Q의 최대엔트로피 폴리시에는 지수 가중과 엔트로피 변분 원리가 직접 대응한다. 최적수송에는 주변 제약, 확산 생성에는 시간별 오염·역과정이 추가되어 같은 수식 하나로 모두 환원되지는 않는다.

아래 p_wrong=softmax(z)^(1/T)는 합이 1이 아닐 수 있다. 하지만 이 벡터를 다시 합으로 나누면 정확히 softmax(z/T)와 같다. 거듭제곱 자체가 틀렸다기보다 재정규화가 빠진 조각이다. T와 정규화 상수는 비교 목적에 맞게 처리한다.

```python
# 틀림: 확률에 온도 쓰기
p_wrong = softmax(z) ** (1/T)

# 옳음: 로짓에 온도 쓰기
p_right = softmax(z / T)
```

## 9. 계량 금융의 눈으로

정수·종목 수 제약 최적화의 SA, 배분 분포의 엔트로피 정규화, 사후 탐색의 템퍼링을 검토할 수 있다. 각각의 목적·기준 측도·제약과 실제 비용을 명시한다.

희귀 payoff의 지수 틸팅 q∝p exp(λh)는 밀도 거듭제곱 p^(1/T)와 다른 제안족이다. 적절한 밀도비 보정과 함수별 분산 조건 없이 금융 가격·위험 추정의 정확성이나 개선을 보장하지 않는다.

## 10. 역사의 눈으로

통계역학의 볼츠만 가중에서 출발한 아이디어는 Metropolis 샘플링·SA·템퍼링과 여러 엔트로피 정규화 방법에 연결된다. 스코어 기반 확산도 노이즈 수준을 바꾸는 생성 경로와 관련된 직관을 공유한다.

그러나 시간에 따라 잡음을 바꾸는 현대 생성모형을 SA 최적화의 단순한 새 이름으로 읽지 않는다. 목표·전이식·학습 대상과 실제 보존 성질을 기준으로 각 방법의 관계를 이해한다.

지수 가중과 엔트로피는 여러 방법을 연결하지만 온도·노이즈·전처리·학습 계수의 역할은 구분해야 한다. 템퍼링의 교환 부호, 정규화와 제약, 역확산의 시간·목표를 정확히 맞춘다.
