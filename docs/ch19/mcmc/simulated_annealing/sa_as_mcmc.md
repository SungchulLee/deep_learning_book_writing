# 시간 비균질 MCMC로 본 시뮬레이티드 어닐링

SA는 시간에 따라 전이 커널과 고정 온도 불변분포가 바뀌는 마르코프 방법이다. 비균질이라는 말은 알고리즘이 멈추지 않는다는 뜻이 아니라 같은 전이 법칙을 모든 시점에 쓰지 않는다는 뜻이다.

## 1. 시간별 커널과 목표

고정 목표의 커널 P가 πP=π를 만족하는 것과 시간별 P_t가 π_tP_t=π_t를 만족하는 것을 구분한다. SA의 π_t∝exp(−E/T_t)는 각 온도의 기준 분포이며 실제 μ_t와 같을 필요가 없다.

고정된 외생 온도 일정에서 과정은 시간 비균질 마르코프 체인이다. 과거 성과로 온도를 조정하면 현재 위치만의 마르코프 표현은 일반적으로 충분하지 않을 수 있고 적응 상태를 추가해야 한다. 비대칭 제안의 수락비에는 exp(−ΔE/T_t)뿐 아니라 정·역 제안 비도 포함한다.

## 2. 순간 상세균형과 실제 비평형 분포

같은 시점의 고정 T_t에 대해 π_t(x)q(y|x)α_t(x,y)는 min{π_t(x)q(y|x),π_t(y)q(x|y)}로 대칭이다. 거절로 제자리에 남는 항까지 포함하면 상세균형과 불변성을 얻는다.

하지만 μ_{t+1}=μ_tP_t가 다음 목표 π_{t+1}와 같다는 결론은 나오지 않는다. 온도 변화 속도·현재 오차·커널의 수축과 탐색 특성을 함께 분석해야 한다. 매 순간의 상세균형만으로 냉각 체인의 전역 최적화 수렴을 증명할 수 없다.

## 3. 냉각과 평형 추적의 시간 스케일

준정적 또는 단열 추적은 온도 변화가 관련 완화 시간보다 충분히 느릴 때의 근사 직관이다. 실제로 필요한 속도는 온도별 커널·거리·목표 변화에 달린다.

로그 일정만이 준정적 과정일 필요충분조건이라는 주장은 하지 않는다. 이산 SA의 특정 장벽 기반 냉각 정리와 모든 시간에서 평형에 가깝다는 더 강한 추적 주장은 다르다. 반복 횟수와 한 온도에서 수행한 전이 수의 단위도 명시한다.

## 4. 비균질 커널의 곱과 에르고드성

유한 상태의 행 분포는 μ_n=μ_0P_1⋯P_n이다. 하나의 P^n이 아니므로 고정 커널의 고윳값만으로 전체 일정을 평가할 수 없다.

고정 시작 시점 m에서 n→∞일 때 P_{m+1}⋯P_n의 두 초기 행 사이 TV 거리가 0으로 가면 초기 상태를 잊는 약한 에르고드성을 말한다. 강한 에르고드성은 모든 초기분포가 공통된 극한분포로 가는 추가 조건을 포함한다. 그 극한을 정의부터 전역 최소점의 디랙으로 정하는 것은 아니다.

최적 집합에 있을 확률이 1로 간다는 수렴은 집합 안에서 하나의 점으로 수렴하거나 균등 혼합으로 수렴한다는 주장보다 약하다. 냉각 조건과 극한의 형태를 분리해 기술한다.

## 5. 섞임 시간의 어려움

에너지 장벽이 있는 국소 제안은 낮은 T에서 장벽 통과가 드물어질 수 있다. 그러나 모든 목표·제안에서 T→0이면 혼합시간이 반드시 무한해지는 것은 아니다. 고정 T의 혼합시간과 시간 변화 체인의 추적 성능도 구분한다.

느린 냉각은 장벽 탈출 기회를 늘릴 수 있지만 실제 비용은 제안 그래프·깊이·평가비용과 정밀도 목표에 달린다. 로그 정리를 모든 문제의 정확한 최적 냉각 속도나 실용 시간 경계로 읽지 않는다.

## 6. 수락률의 조건부 해석

대칭 제안에서 고정 ΔE의 수락확률은 min(1,e⁻ΔE/T)다. 고정된 에너지 증가 분포 F에 대한 평균은 P(ΔE≤0)+∫_{(0,∞)}e⁻u/T dF(u)다. T→0에서 동률까지 포함한 P(ΔE≤0)로 간다.

실제 실행에서는 위치와 제안 적응으로 F 자체가 바뀌므로 온도만 낮춘다고 관측 수락률이 매번 단조 감소하지는 않는다. 높은 수락률은 평평한 구간·작은 제안에서도 생기고 낮은 수락률은 제안 스케일 문제일 수 있다. 20~50% 같은 범위만으로 좋은 최적화나 충분한 탐색을 보장하지 않는다.

## 7. 고정 목표 샘플링과 병렬 템퍼링

병렬 템퍼링은 여러 고정 온도의 곱 목표에서 각 체인의 이동과 올바른 상태 교환을 수행하는 샘플링 방법이다. T=1 성분의 목표가 원래 분포다. SA는 온도를 바꿔 최적화하는 과정이며 냉각 궤적 전체를 같은 사후의 표본으로 평균하면 안 된다.

둘 다 탐색 실패 가능성이 있고 교환률·모드 방문·함수별 정밀도 또는 최선 해의 품질을 목적에 맞게 평가한다. 필요하면 둘을 결합할 수 있지만 결합한 알고리즘의 목표와 보정을 명시해야 한다.

## 8. 적응·임계 수락과 관련 휴리스틱

아래 adaptive_sa는 max_iter·propose·compute_recent_rate가 외부에서 정의되어야 하는 조각이다. 온도를 올리거나 내리는 수락률 조정이 T→0이나 전역 수렴을 보장하지 않는다. 반환값도 최선 기록이 아니라 최종 현재 상태다.

Threshold accepting은 ΔE<τ_t라는 결정적 수락 규칙을 사용하며 확률적 SA와 다른 휴리스틱이다. SA의 무작위 U를 조건으로 보면 ΔE<−T log U라는 무작위 임계 표현이 있지만 고정 임계 알고리즘이 자동으로 SA의 저온 극한과 같은 것은 아니다.

Great Deluge도 절대 에너지 한계 아래 제안을 허용하는 별도 방식이다. 최소화 문제에서는 보통 허용 에너지 한계를 줄여 가며, 물 높이 은유와 에너지 수치의 방향을 혼동하지 않는다.

```python
def adaptive_sa(E, x0, T0, target_accept=0.4):
    T = T0
    x = x0
    
    for t in range(max_iter):
        # 메트로폴리스 걸음
        x_new = propose(x)
        accept = np.random.rand() < min(1, np.exp(-(E(x_new) - E(x)) / T))
        if accept:
            x = x_new
        
        # 최근 받아들임에 따라 온도 맞추기
        recent_accept_rate = compute_recent_rate()
        if recent_accept_rate > target_accept:
            T *= 0.99  # 더 빠르게 식힘
        else:
            T *= 1.01  # 살짝 데움
    
    return x
```

## 9. 이론적 이음

저온 평형에서 높은 에너지 상태의 질량 감소와 실제 비평형 장벽 탈출 확률은 다르다. Arrhenius 형태의 exp(장벽/T)는 특정 준안정 분석의 시간 스케일 직관이며 자유에너지 차이 하나로 임의 SA의 실패확률을 표현할 수는 없다.

준안정성은 한 영역 안의 빠른 완화와 영역 사이의 느린 이동을 뜻한다. 이산 저온 SA의 극한은 제안에 따른 탐욕적 이동이지 일반적으로 미분방정식 경사하강 그 자체가 아니다. 냉각 Langevin과의 관계에는 적절한 연속시간·제안 스케일 가정이 필요하다.

## 10. 유한 예산과 독립 재시작

전역 최적 집합에 있을 확률이나 최선 목적값의 gap을 유한 예산에서 평가하려면 문제별 분석·기준이 필요하다. 로그 온도가 η에 도달하는 데 t≈exp(c/η)가 든다는 계산은 최적화 실패확률을 η로 만드는 실행시간 공식이 아니다.

독립 재시작의 한 실행 성공확률이 같은 p라면 k번 모두 실패할 확률은 (1−p)^k다. p를 알거나 보증할 수 없는 경우 이 식만으로 실제 성공률을 계산할 수 없다. 아래 multi_start 조각에는 초기화 함수·SA 함수가 외부 정의되어야 하고 에너지와 해를 구분해 보존해야 한다.

```python
def multi_start_sa(E, n_restarts, schedule, max_iter):
    best_x, best_E = None, float('inf')
    
    for _ in range(n_restarts):
        x0 = random_initialization()
        x, E_x = simulated_annealing(E, x0, schedule, max_iter)
        if E_x < best_E:
            best_x, best_E = x, E_x
    
    return best_x, best_E
```

## 정리하며

SA는 시간별 불변 커널을 사용하지만 실제 분포는 비균질 커널의 곱으로 변한다. 순간 상세균형·평형 추적·초기 기억 소멸·최적 집합 집중을 구분하고 유한 실행의 품질을 별도로 평가한다.
