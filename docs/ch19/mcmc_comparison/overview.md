# MCMC 방법의 비교

방법을 비교할 때는 원래 목표, 필요한 연산, 전이의 단위와 관심 함수의 계산 오차를 먼저 맞춘다. MH는 일반적인 보정 틀이며 MALA·HMC와 깁스 갱신도 이 틀과 연결된다. 서로 완전히 분리된 네 가지 정확도 등급으로 보지 않는다.

## 1. 전이의 구성

랜덤 워크 MH는 y=x+ση를 제안하고 목표·정역 제안의 비로 수락한다. 깁스는 완전조건부에서 정확히 생성해 해당 좌표를 항상 수락한다. 순차 갱신에는 앞에서 갱신한 최신 값을 사용한다.

```
For each coordinate i = 1, ..., d:
    Sample x_i ~ π(x_i | x_{-i})
```

MALA는 y=x+ε²∇log π(x)/2+εη의 비대칭 가우스 제안을 보정한다. 여기의 ε는 표준편차이며 MALA 본문에서 제안 분산으로 쓰는 스텝과 제곱 관계다. HMC는 운동량을 유지한 다단계 적분을 에너지 차이로 보정한다.

```
1. Resample momentum: v ~ N(0, M)
2. Simulate Hamiltonian dynamics: (x, v) → (x', v') via L leapfrog steps
3. Negate momentum: v' → -v'
4. Accept with probability: α = min(1, exp(-ΔH))
```

고정 스텝 ULA는 MH 보정이 없어 일반적으로 원래 목표의 이산 편향이 남는다. 올바른 MALA·HMC의 목표 불변성과 유한 실행 오차를 구분한다.

## 2. 필요한 정보와 블록 구성

| 방법 | 핵심 연산 | 조정할 구조 |
|---|---|---|
| 랜덤 워크 MH | 목표와 제안의 비 | 제안 스케일·공분산·블록 |
| 깁스 | 완전조건부 생성 | 블록·스캔 순서·주변화 |
| MALA | 목표·경사와 정역 가우스 밀도 | 스텝·전처리 |
| HMC | 목표·경사와 적분 | 스텝·시간·질량 |

깁스의 조건부 생성은 밀도값 평가보다 강한 구조를 요구한다. 따라서 깁스를 아무 구조 없는 0차 신탁 알고리즘과 동일시하지 않는다. 조건부 생성 자체가 비쌀 수 있고 100% 수락에도 상관·접근성 문제가 남는다.

다룰 수 있는 블록에는 깁스, 다른 블록에는 해당 조건부를 보존하는 MH를 사용할 수 있다.

```python
for i in range(d):
    if conditional_tractable[i]:
        x[i] = sample_from_conditional(x, i)  # 깁스
    else:
        x[i] = metropolis_update(x, i)  # MH
```

예를 들어 β|τ~N(0,τ⁻¹I), τ~Gamma(a,b)의 로지스틱 회귀에서 τ|β,y는 Gamma(a+d/2,b+‖β‖²/2)이며 β 블록에는 다른 커널을 쓸 수 있다. 모형 전체의 결합 목표를 일관되게 유지해야 한다.

## 3. 이동 거리와 계산비용

다음 도식은 MALA 여러 전이와 HMC 한 궤적의 보정 위치를 비교한다.

```
x₀ → x₁ → x₂ → x₃ → ... → xₗ
     MH   MH   MH        MH
```

```
x₀ → x₁ → x₂ → x₃ → ... → xₗ
                              MH
```

짧은 구간의 확산·탄도 직관은 유용하지만 HMC가 같은 경사 평가마다 항상 √L배 효율적이라는 정리는 아니다. 긴 궤적은 되돌아오거나 공진할 수 있고 경사 캐시·수락 보정과 함수별 상관도 영향을 준다.

대표적인 정칙 곱 목표의 정상상태 점근 분석에서 RWM은 O(d), MALA는 O(d¹/³) 반복 시간 스케일을 갖는다. 각 밀도·경사 비용을 O(d)로 가정하면 비용은 O(d²)·O(d⁴/³)다. 고정 물리적 적분시간의 HMC는 Leapfrog O(d¹/⁴)개, 경사당 비용 O(d)에서 O(d⁵/⁴)의 대표 비용을 얻는다. 이는 모든 목표의 엄밀한 혼합시간 표가 아니며 상세한 조건은 [스케일링 절](scaling.md)을 참고한다.

## 4. 상관·다봉성과 직접 생성

강한 상관에서는 좌표별 깁스·등방 제안이 느릴 수 있다. 상관 ρ인 표준 이변량 정규의 순차 깁스는 한 스윕 후 한 좌표에 ρ² 계수를 남긴다. HMC에서 K=pᵀM⁻¹p/2 관례의 M≈Σ⁻¹는 가우스 모드 주파수를 맞춘다. 그러나 상관만으로 모든 방법의 정확한 혼합시간 거듭제곱을 정하지 않는다.

공분산이 알려진 가우스에서 직접 Cholesky 생성이 가능하면 MCMC 자체가 불필요할 수 있다. HMC를 언제나 가장 좋은 방법으로 순위화하지 않는다. 여러 모드는 국소 커널에 추가 장벽을 만들 수 있으며 템퍼링·모드 제안·주변화 등을 검토한다. SA 최적화·변분 근사·학습 플로로 바꾸면 추론 대상과 근사도 달라질 수 있다.

## 5. 수락률과 진단

0.234·0.574·약 0.651은 특정 고차원 점근 분석의 효율 목적에 연결된 참고값이다. 높은 수락률 자체가 빠른 혼합을 뜻하지 않고 깁스 100%와 다른 방법의 수락률을 같은 척도로 순위화할 수 없다.

목표 불변성·수렴 조건과 실제 계산은 구분한다. 여러 시작점·체인, R-hat·bulk/tail ESS·관심 함수의 MCSE와 에너지 경고를 평가한다. ESS는 함수별이고 음의 상관에서 추출 수보다 클 수 있다. 같은 비용에서 원하는 오차를 달성하는지가 핵심이다.

## 6. 이산·연속 구조와 모형별 선택

표준 HMC·MALA는 연속 미분 가능한 좌표에 적합하다. 이산 잠재변수에는 조건부·MH·열거를 쓰거나 이를 합으로 주변화해 연속 목표를 만들 수 있다. 비미분 목표에도 특화된 근사 제안·보정 방법이 있을 수 있어 모든 경사 활용이 원리적으로 불가능하다고 단정하지 않는다.

```python
# 띄엄띄엄한 변수에 쓰는 깁스
z = sample_categorical(p(z | theta, data))

# 이어진 변수에 쓰는 HMC
theta = hmc_step(theta, z, data)
```

정규-가우스 사전 로지스틱 회귀에는 HMC·MALA 외에도 [Pólya–Gamma 보조변수 깁스](https://arxiv.org/abs/1205.0310)가 가능하다. 혼합모형의 조건부는 사전·주변화에 따라 달라지며 라벨 교환·공분산 붕괴·분리 모드를 확인한다. 모형 이름이나 차원만으로 고정 승자를 정하지 않는다.

## 7. 선택 도식과 구현 범위

아래 도식은 시작 후보를 고르는 예이며 차원 10·1000 등의 경계는 수학적인 사용 한계가 아니다. 조건부 생성 비용·대칭성·목표의 매끄러움·전체 평가 비용과 진단 결과로 후보를 수정한다.

```
Start
  │
  ├─ Are all conditionals tractable?
  │    ├─ Yes → Try Gibbs
  │    │         ├─ Fast convergence? → Use Gibbs ✓
  │    │         └─ Slow mixing? → Switch to HMC
  │    └─ No → Continue
  │
  ├─ Is target differentiable?
  │    ├─ No → Use Metropolis-Hastings ✓
  │    └─ Yes → Continue
  │
  ├─ What's the dimension?
  │    ├─ Low (d < 10) → MALA is fine ✓
  │    ├─ Medium (10 ≤ d ≤ 1000) → Use HMC/NUTS ✓
  │    └─ High (d > 1000) → HMC with diagonal M ✓
  │
  ├─ Strong correlations?
  │    ├─ Yes → HMC with adaptive mass matrix ✓
  │    └─ No → MALA or HMC ✓
  │
  ├─ Multimodal?
  │    ├─ Yes → Parallel tempering ✓
  │    └─ No → Standard HMC/NUTS ✓
  │
  └─ Want minimal tuning?
       ├─ Yes → Use NUTS (Stan/PyMC) ✓
       └─ No → Custom implementation ✓
```

NUTS는 궤적 길이 선택 부담을 줄이지만 스텝·질량 적응과 기하·탐색 진단은 남는다. 자동 샘플러의 설정·자료 형태·분포 제약은 실제 인터페이스를 확인해야 한다. 손수 만든 구현도 독립 기준과 불변성·수치 처리를 검토한다.

## 8. 메모리와 병렬 계산

상태 저장 O(d)와 밀집 질량 O(d²), 전체 체인 저장 O(Nd), 자동미분·자료 메모리를 구분한다. 차원만으로 총 메모리나 속도를 판단할 수 없다. 여러 독립 체인은 병렬화할 수 있지만 체인 내부 표본을 독립으로 만들지는 않는다.

목표·경사·조건부 계산의 구조를 활용한 병렬화도 가능하다. 조건부 독립이 없는 좌표를 무조건 동시에 갱신하면 깁스 목표를 바꿀 수 있다. 하드웨어 처리량과 워밍업·통신·동기화 비용을 포함해 비교한다.

## 정리하며

방법 선택은 필요한 구조·평가비용·목표 기하와 관심량의 오차로 판단한다. 조건부 수락·스케일링·병렬 처리의 단위를 맞추고 고정 차원 경계나 수락률 순위를 보편 규칙으로 쓰지 않는다.
