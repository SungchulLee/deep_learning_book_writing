# 우도 계산 없이 하는 시뮬레이션 기반 추론

시뮬레이터에서 자료를 생성할 수 있지만 관측 우도 평가가 어렵다면 시뮬레이션 기반 추론을 고려할 수 있다. 우도가 모형에 존재하지 않는다는 뜻이 아니라 직접 값을 계산하지 않고 추론한다는 뜻이다.

## 1. 다룰 수 없는 우도 문제

베이즈 사후는 p(θ|y)∝p(y|θ)p(θ)다. θ를 주면 X=f(θ,U)로 자료를 생성할 수 있어도 잠재 경로·구조를 적분한 관측 우도 p(y|θ)는 평가하기 어려울 수 있다. 우도 정규화 상수만 미지인 상황과 우도값 자체를 모르는 상황을 구분한다.

집단유전의 계보, 감염의 접촉·전이 경로, 개체 기반 생태·시장 모형과 복잡한 관측 과정을 가진 물리 시뮬레이터가 예다. 분야 전체의 모든 모형이 우도 계산 불가능한 것은 아니다. 어떤 생성 과정·관측 잡음·잠재변수의 주변화가 어려운지 구체적으로 확인한다.

## 2. 우도값을 직접 쓰는 공식의 한계

일반적인 MH는 우도비, 중요도 샘플링은 우도가 포함된 가중치, 표준 ELBO는 로그우도 평가를 요구한다. 관측 우도값을 알 수 없으면 이 공식을 그대로 구현하기 어렵다.

그렇다고 모든 MCMC·변분 방법이 원리적으로 불가능한 것은 아니다. 잠재변수 확장·비음수 불편 우도 추정의 pseudo-marginal 방법·학습한 밀도나 비율 등 문제에 맞는 대안이 있다. ABC는 시뮬레이션 결과를 비교하는 한 가지 접근이다.

## 3. ABC의 생각

사전에서 θ를 생성하고 X~p(·|θ)를 시뮬레이션한 뒤 요약통계량의 거리 ρ(S(X),S(y))<ε이면 θ를 채택한다. 고정된 S·ρ·ε와 독립 시뮬레이션에서 채택된 θ는 다음 ABC 목표를 따른다.

$$\pi_\epsilon(\theta|y)\propto p(\theta)A_\epsilon(\theta),\qquad A_\epsilon(\theta)=P_\theta\{\rho(S(X),S(y))<\epsilon\}.$$

사전 이외의 제안에서 θ를 생성하면 일반적으로 사전/제안 가중이나 MH 보정이 필요하다. 이산 자료 전체에 양의 확률의 정확 일치 조건을 사용할 수 있으면 원래 사후를 얻지만, 연속 자료의 X=y는 보통 확률 0이라 직접 거절 채택이 불가능하다.

## 4. ABC 사후확률

ABC는 고정 관측 y의 주변에 시뮬레이션 요약이 들어온다는 사건을 조건으로 한 목표다. 작은 ε의 극한은 밀도의 정칙성·양의 예측밀도 등 조건 아래 p(θ|S(y))다. S가 충분하거나 원자료를 보존하는 경우에 원래 p(θ|y)와 연결된다.

유한 ε의 목표가 항상 원래 사후보다 단순히 더 넓거나 분산이 큰 것은 아니다. 거리·요약·커널에 따라 위치·모양·질량이 달라질 수 있다. ε를 줄이면 같은 조건의 채택 사건은 작아져 비용이 늘지만, 모든 유한 설정에서 특정 함수 편향이 단조 감소한다는 보장은 없다. 고정 시뮬레이션 예산과 고정 채택 표본 수의 분산 비교도 구분한다.

## 5. 요약통계량과 충분성

요약통계량 S는 고차원 비교를 줄이지만 정보를 잃을 수 있다. 충분성은 자료의 조건부분포 p(y|S(y),θ)가 θ에 의존하지 않는다는 조건 또는 적절한 인수분해 정리로 정의한다. 단순히 p(y|θ)를 조건부·주변의 곱으로 쓸 수 있다는 항등식은 충분성 조건이 아니다.

S가 충분하면 p(θ|S(y))=p(θ|y)지만 유한 ε의 ABC까지 정확해지는 것은 아니다. 복잡한 모형에서는 유용한 저차원 충분 요약이 없을 수 있다. 모형 크기만큼 긴 원자료 자체도 통계량이므로 유한 차원 통계량이 아예 없다고 말하지 않는다.

분야 지식·보조 모형·회귀·신경망 임베딩 등으로 요약을 설계할 수 있다. 어떤 매개변수·관심량을 보존하는지, 식별 가능성과 검증 자료의 정보 손실을 평가한다.

## 6. 거리 함수

유클리드 거리는 요약 성분의 단위·분산에 민감하다. 양의 정부호 W를 쓰는 √((s−s_obs)ᵀW(s−s_obs))나 사전예측 공분산의 역을 사용하는 마할라노비스 거리를 고려할 수 있다. 공분산이 특이하거나 성분 분산이 0이면 정규화와 입력 검사가 필요하다.

하드 지시함수 대신 비음수 커널 K(ρ/ε)를 사용하면 목표가 p(θ)E_θK로 바뀐다. 고정 ε에서 θ에 공통인 커널 정규화는 사후 비율에서 소거될 수 있지만 주변우도·모형 비교·서로 다른 ε 간 비교에는 상수가 중요할 수 있다. 부드러운 커널을 썼다는 이유로 정확도가 보장되는 것은 아니다.

## 7. 이론의 기초

서로 다른 극한을 구분한다. 시뮬레이션 수를 늘리면 고정 ε·요약의 ABC 목표를 더 정밀하게 계산할 수 있다. ε→0은 정칙성 아래 요약 조건 사후에 접근한다. 실제 자료 수 n→∞의 매개변수 일치성에는 요약의 식별 가능성·집중률과 ε_n의 상대 속도 등이 추가로 필요하다.

ε_n∝n⁻¹/(d+4)를 모든 ABC의 MSE 최적 일정으로 쓰면 안 된다. 이런 차수는 특정 커널 추정·편향·분산·시뮬레이션 예산의 설정에 의존하며 관측 수와 시뮬레이션 수를 혼동하지 않는다. 점근 정규성·공분산도 모형·요약·ε의 속도에 따라 달라진다.

## 8. 기본 ABC 너머

ABC 거절·MCMC·SMC는 같은 ε·요약 목표를 서로 다른 계산 방식으로 다룰 수 있다. 회귀 조정은 유한 허용오차의 영향을 줄이려는 별도의 근사다.

NPE는 조건부 사후밀도, NLE는 우도, NRE는 우도/주변비 등을 학습한다. NPE는 적합한 모형에서 직접 생성할 수 있지만 NLE·NRE는 학습 후에도 사후 샘플러가 필요할 수 있다. 한 번 학습으로 모든 관측에 추론이 자동으로 저렴해진다고 일반화하지 않는다.

Synthetic likelihood는 요약의 조건부분포를 가우스로 근사하고 시뮬레이션으로 평균·공분산을 추정한다. 유한 시뮬레이션으로 대입한 가우스 우도가 정확한 원자료 우도의 불편 추정인 것은 아니다. 요약의 정규 근사·수치 오차를 별도로 평가한다.

## 9. 우도 없는 방법을 언제 쓰나

우도 평가가 실제 병목인지, 시뮬레이터가 적절한 관측 과정을 포함하는지, 예산과 요약 정보가 충분한지 확인한다. 우도가 가능해도 해석적 기준을 가진 작은 문제는 ABC를 검증·학습하기에 유용하다.

복잡한 시뮬레이터나 신경망 추론은 모형 오류를 자동으로 해결하지 않는다. 매개변수 차원·요약 차원·시뮬레이션 비용·희귀 관측과 사전예측의 겹침을 고려한다. 단순한 차원·시간 임계값만으로 적용 가능성을 정하지 않는다.

## 10. 실전 일머리

사전예측 시뮬레이션으로 생성 범위·관측 과정을 확인하고, 요약·거리·스케일을 정한 뒤 pilot 거리로 허용오차의 비용을 살핀다. pilot의 1%·5%·10% 분위수는 비용 탐색의 시작점이며 정확도 보증이 아니다. prior.sample 인터페이스는 사용하는 분포 객체에 맞춰야 한다.

아래 summary_statistics는 스칼라 셋과 길이 3의 분위수 배열을 같은 np.array에 넣어 ragged 구조를 만든다. 현대 NumPy에서 오류가 날 수 있으며 flatten이 이를 해결하지 않는다. 짧거나 상수인 시계열의 상관 NaN도 확인해야 한다.

posterior_predictive_check 조각은 요약을 계산할 뿐 결과를 반환·비교·시각화하지 않는다. 따라서 완결된 사후예측 점검이 아니다. 선택에 쓰지 않은 특징·반복 자료의 재현과 ε·요약 민감도, 가능하면 알려진 사후 기준으로 검증해야 한다.

def prior_predictive_check(simulator, prior, n_sims=100):
    """앞확률 미리봄 표본 만들기."""
    samples = []
    for _ in range(n_sims):
        theta = prior.sample()
        x = simulator(theta)
        samples.append({'theta': theta, 'x': x})
    
    # 그려 보기: 참 자료처럼 보이는 표본이 있는가?

```python
def summary_statistics(x):
    """보기: 시계열의 간추린 통계량."""
    return np.array([
        np.mean(x),
        np.std(x),
        np.corrcoef(x[:-1], x[1:])[0, 1],  # 뒤짐 1의 자기상관
        np.percentile(x, [25, 50, 75]),
    ]).flatten()
```
```python
def calibrate_epsilon(simulator, prior, summary_fn, y_obs, n_pilot=1000):
    """그럴듯한 엡실론 범위 정하기."""
    distances = []
    
    s_obs = summary_fn(y_obs)
    
    for _ in range(n_pilot):
        theta = prior.sample()
        x = simulator(theta)
        s_x = summary_fn(x)
        distances.append(np.linalg.norm(s_x - s_obs))
    
    # 앞확률 미리봄 거리의 분위수로 잡은 엡실론
    return {
        'q01': np.percentile(distances, 1),
        'q05': np.percentile(distances, 5),
        'q10': np.percentile(distances, 10),
    }
```

## 연습문제

1. 충분성의 조건을 설명하라. p(y|S(y),θ)가 θ와 무관해야 하며 단순한 확률 인수분해 항등식만으로는 부족하다.

2. ε→0과 자료 수 n→∞의 목표를 구분하라. 전자는 요약 조건 사후의 근사, 후자는 식별·집중 조건 아래 매개변수 일치성과 연결된다.

3. 사전 이외의 제안에서 채택 표본을 모으면 같은 ABC 사후인가? 일반적으로 q(θ)A_ε(θ)를 따르므로 사전/제안 보정이 필요하다.

4. 요약 평균과 사분위수의 단위가 다르면 무엇을 고려하는가? 사전예측 또는 적절한 기준의 스케일·공분산으로 거리를 맞추되 특이성과 선택 편향을 검토한다.

5. 예측 조각이 실제 점검을 끝냈는가? 계산한 요약을 반환·비교하지 않으므로 아니다. 관측의 중요한 특징과 독립적인 사후예측의 차이를 평가하는 절차가 필요하다.

## 정리하며

시뮬레이션 기반 추론은 관측 우도 평가를 다른 계산으로 대체한다. ABC의 목표는 요약·거리·허용오차로 정해지며 요약 조건 사후·원자료 사후·큰 자료의 일치성을 구분해야 한다.
