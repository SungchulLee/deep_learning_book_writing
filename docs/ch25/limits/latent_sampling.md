# 잠재공간 샘플링의 한계

오토인코더의 좋은 재구성은 인코더가 만든 코드에서 디코더가 원본을 복원한다는 뜻이다. 여기에 임의의 N(0,I) 코드를 넣어 좋은 새 표본을 얻는 것은 다른 문제다. 일반적인 재구성 목표는 코드 전체의 분포를 정해진 사전에 맞추지 않는다.

## 1. 재구성과 생성의 차이

재구성은 x→f(x)→g(f(x))를, 잠재 샘플링은 z∼p(z), x̃=g(z)를 사용한다. 후자의 출력 분포는 선택한 p(z)와 디코더로 정해진다. 인코더가 만드는 경험적 코드 분포와 p(z)가 다르면 디코더가 학습 중 거의 방문하지 않은 영역을 평가하게 될 수 있다.

코드의 위치·회전·척도를 바꾸고 이를 디코더에서 상쇄해도 같은 재구성을 얻을 수 있는 경우가 있다. 그러므로 좋은 복원만으로 코드 평균이 0이고 분산이 1이라고 결론 내릴 수 없다. 코드를 멀리 놓는 것이 언제나 재구성에 유리하다거나 모든 빈 구간이 나쁜 출력으로 이어진다는 법칙도 아니다.

## 2. 보존된 그림과 실험 기록

아래 그림과 표는 기존 문서에 수록된 비교 기록이다. 문서에는 16차원 코드, 20에포크와 시드 42, 정규 잠재 샘플 1,000개를 사용했다고 적혀 있다. 이 페이지에는 해당 학습·평가 코드나 체크포인트가 없어 정확한 구조·손실 정규화·분류기 보정과 전체 재현 조건을 확인할 수는 없다. 따라서 이 기록을 모든 AE·VAE의 일반적인 성능 수치로 해석하지 않는다.

![오토인코더와 변분 오토인코더에 같은 z를 넣어 얻은 그림](../figures/ae_vae_samples.svg)

| 기존 기록의 모델 | 재구성 MSE | 분류기 평균 최대 확률 | 최대 확률 >0.9 비율 |
|---|---:|---:|---:|
| 일반 AE | 0.00880 | 0.354 | 0.2% |
| VAE | 0.01379 | 0.839 | 57.4% |
| 실제 테스트 이미지 | — | 0.981 | 95.1% |

이 기록에서 AE의 MSE는 VAE보다 약 36% 낮고, 분류기의 확률이 문턱을 넘은 생성 표본은 각각 2장과 574장이다. **후자의 비율은 숫자로 보이는 표본의 실제 비율이나 정답률이 아니다.** 분류기는 일반적으로 주어진 입력을 어떤 숫자 클래스로든 분류하며, 최대 확률이 높은 분포 밖 이미지도 있을 수 있다. 실제 MNIST에서의 높은 분류 정확도가 생성 표본에서의 확신도 보정을 보장하지는 않는다.

시각 검토, 클래스별 분포와 다양성·중복도, 학습 표본 유사성 등을 함께 평가해야 한다. 모든 출력이 같은 숫자여도 확신도 비율은 높을 수 있다. 한 표의 수치를 개별 학습 변경 두 줄의 인과 효과로 단정하지 않는다.

## 3. 2차원 코드 그림이 보여 주는 범위

![두 모델이 시험 데이터를 어디에 코딩하는지](../figures/ae_vae_latent.svg)

다음은 기존 기록의 2차원 코드 요약이다. 16차원 실험과 별개의 차원 설정이며 그림이 VAE의 평균 μ(x)인지 확률적 샘플인지도 해석에 중요하다.

| 모델 | 기록된 좌표 범위 | 반지름 3 안의 코드 비율 |
|---|---|---:|
| 일반 AE | x: −15.0~30.3, y: −33.1~15.9 | 46.7% |
| VAE | x: −4.2~4.3, y: −4.2~3.6 | 97.2% |

2차원 표준정규에서 반지름 3 안의 확률은 1−exp(−9/2)≈98.89%다. 그러나 반지름 안에 얼마나 많은 **데이터 코드**가 있는지는 정규 샘플이 디코더가 잘 학습한 영역에 놓이는 확률과 같지 않다. 내부에서도 밀도·방향·빈 구간이 다를 수 있다. 높은 차원 표준정규의 전형적인 반지름은 대략 √d여서 2차원 원 그림을 16차원에 그대로 적용할 수도 없다.

VAE의 평균 코드 μ(x) 분포는 조건부 분산까지 섞은 집계 사후 q(z)=E_xq(z|x)와 다르다. 평균의 산점도나 한 개의 전체 표준편차만으로 사전 일치나 샘플 품질을 증명하지 않는다.

## 4. VAE가 바꾸는 확률 모형과 목표

VAE는 사전 p(z), 확률적 디코더 p_θ(x|z)와 근사 사후 q_φ(z|x)를 둔다. 대각 가우시안 사후라면 다음과 같이 표기한다.

$$q_\phi(z|x)=\mathcal N(\mu_\phi(x),\operatorname{diag}(\sigma_\phi^2(x))).$$

재매개변수화는 z=μ+σ⊙ε, ε∼N(0,I)다. 학습은 일반적으로 다음 증거 하한(ELBO)을 최대화한다.

$$\log p_\theta(x)\ge\mathbb E_{q_\phi(z|x)}[\log p_\theta(x|z)]
-D_{KL}(q_\phi(z|x)\|p(z)).$$

이 관계는 [VAE 원 논문](https://arxiv.org/abs/1312.6114)에 제시되어 있다. 복원 항은 선택한 관측 분포의 로그우도이며 임의 MSE와 항상 같은 단위는 아니다. 출력 분포·샘플링·학습 손실과 호출 계약까지 맞추어야 하므로 단순히 어느 모델에 두 줄을 더하면 모든 실험 조건이 같아지는 것은 아니다.

KL은 사후를 사전 쪽으로 제약하지만 q(z)가 p(z)와 정확히 같아지거나 잠재공간의 빈 구간이 모두 없어지는 보장은 없다. 너무 강한 제약은 입력 정보가 사라지는 사후 붕괴를 만들 수도 있다. 재구성과 샘플 품질의 절충은 모델·학습·평가에 따라 확인해야 한다.

## 5. 학습 뒤 코드 분포를 모델링하는 방법

AE 코드를 수집해 가우시안·혼합모형·흐름·다른 잠재 생성 모델을 적합하고 디코더와 결합할 수도 있다. 단일 가우시안은 다봉 분포의 빈 영역에 확률을 둘 수 있지만 항상 부적절하거나 혼합 성분 수를 클래스 수로 정하면 최선이라는 규칙은 없다. 검증 데이터로 밀도와 생성 품질을 평가한다.

잠재 분포와 결정적 디코더는 적어도 출력의 확률 법칙을 정의하므로 생성 모형의 일부가 될 수 있다. 다만 입력 공간의 보통 밀도가 존재하는지, 그 우도를 계산할 수 있는지는 별개다. 저차원 결정적 디코더의 출력은 고차원 공간에서 특이한 분포일 수 있다. 명시적인 관측 잡음·확률적 디코더 등을 두면 모델과 평가가 달라진다.

보간이나 코드 주변 잡음도 탐색에 사용할 수 있지만 새롭고 다양한 표본을 보장하지 않는다. 데이터 코드 재사용은 주로 재구성·재표집이며, 중간 코드가 매끄럽게 디코딩된다는 것과 그 분포가 실제 데이터와 같다는 것은 다르다. 일반 AE만으로 정규 사전 샘플링이 보장되지 않는다는 한계를 모든 AE 기반 생성이 불가능하다는 주장으로 확대하지 않는다.

## 정리하며

일반 AE의 재구성 목표는 임의 정규 잠재 샘플의 품질을 보장하지 않는다. 기존 비교 기록의 분류기 확신도와 실제 샘플 유효률, 평균 코드와 집계 사후를 구분해야 한다. VAE와 사후 잠재 모델링은 서로 다른 확률적 접근이며 품질·다양성·재구성과 비용을 함께 검증한다.
