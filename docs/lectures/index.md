# 강의 노트

수업에서 실제로 다룬 내용을 학생 필기를 바탕으로 정리한 기록이다. 본문 장(章)이 주제별로 짜여 있는 것과 달리, 여기서는 강의가 진행된 날짜 차례를 따른다. 그날 칠판에서 오간 순서와 예시를 그대로 살려, 뒤에 본문을 찾아볼 때 길잡이가 되도록 했다.

## 읽는 법

- 필기에 적힌 용어는 강의에서 쓰인 그대로 두었다. 영어로 말한 것은 영어로, 우리말로 말한 것은 우리말로 적었다.
- 필기가 흐릿하거나 앞뒤가 잘리는 곳은 짐작으로 메우지 않고 그렇다고 밝혀 두었다.
- 관련된 본문 쪽이 있으면 링크를 걸어 두었다.
