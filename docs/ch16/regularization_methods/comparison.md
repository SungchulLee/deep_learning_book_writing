# 정칙화 방법의 비교(EWC, SI, MAS)

정칙화 기반 지속 학습 방법은 정보 이론의 틀에서 기울기 기반과 시냅스 재기까지, 매개변수 중요도를 어림하는 여러 길을 보여 준다. 강점과 약점, 쓸 수 있는 조건을 비교하여 이해하면 상황에 가장 알맞은 정칙화 전략을 고를 수 있다.

---

## 1. 방법의 자세한 비교

### 탄성 가중치 통합(EWC)

$$\mathcal{L}_{\text{EWC}} = \mathcal{L}_{\text{task}} + \frac{\lambda}{2} \sum_i F_i (\theta_i - \theta_i^*)^2$$

여기서 피셔 정보는 다음과 같다.

$$F_i = \mathbb{E}\left[\left(\frac{\partial \log p(y|\mathbf{x}, \theta)}{\partial \theta_i}\right)^2\right]$$

**이론적 기초**: 정보 기하와 자연 기울기 내려가기

**중요도의 뜻**: 매개변수가 출력의 불확실성에 이바지하는 정도

### 시냅스 지능(SI)

$$\mathcal{L}_{\text{SI}} = \mathcal{L}_{\text{task}} + \lambda \sum_i \frac{S_i}{(\omega_i + \epsilon)^2} (\theta_i - \theta_i^*)^2$$

여기서 시냅스 관련도가 다음과 같이 쌓인다.

$$\omega_i \leftarrow \omega_i + \left|\frac{dL}{d\theta_i} \cdot \Delta\theta_i\right|$$

**이론적 기초**: 신경과학의 시냅스 다지기

**중요도의 뜻**: 잇단 과제에 걸쳐 매개변수가 학습에 이바지한 정도

### 기억을 아는 시냅스(MAS)

$$\mathcal{L}_{\text{MAS}} = \mathcal{L}_{\text{task}} + \lambda \sum_i M_i (\theta_i - \theta_i^*)^2$$

여기서 과제와 맞닿은 중요도는 다음과 같다.

$$M_i = \left|\frac{\partial f(\mathbf{x})}{\partial \theta_i}\right|$$

**이론적 기초**: 출력에 대한 기울기의 민감도

**중요도의 뜻**: 매개변수가 모델 예측에 미치는 영향

---

## 2. 두루 갖춘 비교 표

| 갈래 | EWC | SI | MAS |
|--------|-----|----|----|
| **중요도 재기** | 피셔 정보 | 가중치 변화 | 출력 기울기 |
| **이론적 엄밀함** | 매우 높음 | 높음 | 보통 |
| **계산 비용** | 보통 | 낮음 | 낮음 |
| **기억 요구** | 보통 | 높음 | 낮음 |
| **중요도의 한결같음** | 높음 | 매우 높음 | 보통 |
| **하이퍼파라미터 손질** | 보통 | 많음 | 적음 |
| **규모 확장성** | 좋음 | 매우 좋음 | 매우 좋음 |

## 3. 성질의 자세한 분석

### 중요도 재기의 비교

#### 피셔 정보(EWC)

**정의**: 로그 확률 기울기 제곱의 기댓값

**좋은 점**:

- 정보 이론에 뿌리를 둔다
- 어떤 통계 학습 상황에서는 가장 좋다
- 이차 정보를 담는다
- 풀이할 수 있다. 곧 출력에 대한 불확실성이다

**나쁜 점**:

- 계산이 값비싸다
- 규모를 키우려면 대각 어림이 필요하다
- 헤세-벡터 곱 구조를 놓는다
- 배치의 영향에 민감하다

**쓸 때**:

- 이론적 분석이 필요할 때
- 판단 경계가 복잡할 때
- 계산 예산이 넉넉할 때

#### 시냅스 관련도(SI)

**정의**: 가중치 변화의 중요도를 쌓은 값

**좋은 점**:

- 학습에 이바지한 정도를 곧바로 잰다
- 과제에 걸쳐 쌓인다
- 신경과학에서 영감을 얻었다
- 계산이 효율적이다

**나쁜 점**:

- 이론적 뒷받침이 약하다
- 최적화 자취에 기댄다
- 학습률에 치우칠 수 있다
- 감쇠율을 꼼꼼히 손질해야 한다

**쓸 때**:

- 과제 차례가 길 때
- 증분 학습 상황
- 계산 효율이 결정적일 때
- 가중치 움직임으로 과제의 관계를 볼 때

#### 출력 기울기의 크기(MAS)

**정의**: 검증 집합에서의 기울기 크기

**좋은 점**:

- 계산 단순하다
- 과제를 가리지 않는다(레이블이 필요 없다)
- 풀이할 수 있다. 곧 예측에 미치는 곧은 영향이다
- 계산이 빠르다

**나쁜 점**:

- 미묘한 매개변수 어울림을 놓칠 수 있다
- 검증 데이터를 쓸 수 있어야 한다
- 이차 효과를 무시한다
- 검증 집합을 어떻게 짜느냐에 민감하다

**쓸 때**:

- 실시간 맞춤이 필요할 때
- 레이블 붙은 과제 데이터가 없을 때
- 계산 예산이 아주 빠듯할 때
- 재빠른 맞춤이 필요할 때

---

## 4. 중요도 재기 사이의 관계

!!! note "수학적 관계"
    
    망의 거동에 대한 어떤 가정 아래에서는 다음이 성립한다.
    
    $$\text{EWC} \geq \text{MAS} \text{ (for classification)}$$
    
    EWC의 피셔 정보는 일차 효과에 참 레이블에서 오는 분산까지 담는다.

## 5. 잇단 과제에서의 성능 비교

### 과제 5개 차례 잣대

| 과제 | EWC | SI | MAS | 무작위 |
|------|-----|----|----|--------|
| 1 | 95.0% | 95.0% | 95.0% | 95.0% |
| 2 | 90.2% | 90.5% | 90.1% | 87.3% |
| 3 | 83.4% | 84.8% | 82.9% | 75.2% |
| 4 | 74.1% | 76.5% | 73.8% | 61.4% |
| 5 | 62.3% | 68.1% | 61.9% | 48.2% |
| 평균 | 81.0% | 83.0% | 80.7% | 73.4% |

SI은 중요도가 쌓이므로 긴 차례에서 가장 좋은 성능을 보인다.

### 계산의 짐

| 방법 | 한 번 드는 비용 | 배치마다 | 전체 시간 | 기억 |
|--------|----------|-----------|-----------|--------|
| **EWC** | O(n²) | 0 | 1.3배 | 2배 |
| **SI** | 0 | O(n) | 1.1배 | 3배 |
| **MAS** | 0 | O(n) | 1.05배 | 1.5배 |
| **소박한 방법** | 0 | 0 | 1배 | 1배 |

EWC는 앞단에서 드는 비용이 크고, SI과 MAS은 흐르는 내내 짐이 있다.

## 6. 방법 고르기 틀

### 방법 고르기를 위한 결정 트리

```
Computational Budget Available?
├─ Very Limited (< 10% overhead)
│  └─> Use MAS
├─ Moderate (10-50% overhead)
│  └─> Use SI or MAS
└─ Generous (> 50% overhead)
   └─> Use EWC or SI

Task Sequence Length?
├─ Short (< 5 tasks)
│  └─> EWC sufficient
├─ Medium (5-20 tasks)
│  └─> SI preferred
└─> Long (> 20 tasks)
   └─> SI with decay recommended

Task Relationship?
├─ Unrelated
│  └─> SI (weight-based importance)
├─ Related
│  └─> EWC (preserves relationships)
└─> Unknown
   └─> MAS (safe choice)
```

## 7. 하이퍼파라미터 손질

### 결정적인 하이퍼파라미터

| 방법 | 매개변수 | 몫 | 손질 범위 |
|--------|-----------|------|--------------|
| **EWC** | $\lambda$ | 정칙화 세기 | [0.01, 5.0] |
| **EWC** | $F$ 눈금 | 중요도의 크기 | 자동 또는 [0.1, 10] |
| **SI** | $\lambda$ | 정칙화 세기 | [0.01, 5.0] |
| **SI** | $\rho$ | 감쇠율 | [0.0001, 0.01] |
| **SI** | c | 상대 눈금 | [0.001, 0.1] |
| **MAS** | $\lambda$ | 정칙화 세기 | [0.01, 5.0] |

### 검증 규약

1. 데이터셋을 잇단 과제와 검증으로 쪼갠다
2. (방법, 하이퍼파라미터) 쌍마다 다음을 한다.
   - 정칙화를 곁들여 잇단 과제로 학습된이다
   - 모든 과제에 걸친 평균 성능을 평가한다
3. 평균을 가장 크게 하는 방법과 하이퍼파라미터를 고른다
4. 고른 설정으로 잇단 과제 전체를 다시 학습된이다

## 8. 튼튼함 분석

### 과제의 닮음에 대한 튼튼함

| 상황 | EWC | SI | MAS |
|----------|-----|----|----|
| **아주 닮음** | 좋음 | 매우 좋음 | 좋음 |
| **닮음** | 매우 좋음 | 매우 좋음 | 좋음 |
| **다름** | 좋음 | 좋음 | 매우 좋음 |
| **아주 다름** | 좋음 | 좋음 | 매우 좋음 |

SI은 과제가 서로 쌓아 올릴 때 뛰어나고, MAS은 과제가 서로 다를 때 더 튼튼하다.

### 하이퍼파라미터가 어긋날 때의 튼튼함

$\lambda$이 틀렸을 때 성능이 얼마나 떨어지는지이다.

| $\lambda$ 오차 | EWC | SI | MAS |
|---|---|---|---|
| **2배 작음** | -5% | -3% | -4% |
| **2배 큼** | -8% | -10% | -6% |
| **10배 작음** | -15% | -8% | -12% |
| **10배 큼** | -25% | -20% | -15% |

EWC가 가장 민감하고 SI과 MAS은 더 너그럽다.

## 9. 금융에서의 쓰임새

### 상황 1: 국면 바뀜에 맞추기

시장 국면이 바뀔 때(오름장 → 내림장)이다.

- **SI을 쓰라**: 쌓인 중요도가 국면을 가로질러 어떤 요인이 계속 결정적이었는지 담아낸다
- **까닭**: 시냅스 관련도가 튼튼한 관계에 힘을 싣는다

### 상황 2: 실시간 포트폴리오 갱신

쉼 없이 포트폴리오의 균형을 다시 잡는 경우이다.

- **MAS을 쓰라**: 계산의 짐이 가볍고 중요도를 온라인으로 계산한다
- **까닭**: 효율이 결정적이고 기울기 기반 중요도로 충분하다

### 상황 3: 시장을 넘나드는 옮김

미국 주식 모델을 신흥국 시장에 쓰는 경우이다.

- **EWC를 쓰라**: 피셔 정보가 어떤 매개변수 관계가 옮겨 가는지 담아낸다
- **까닭**: 시장 관계가 복잡하여 원칙 있는 중요도가 필요하다

## 10. 혼합형 접근

### EWC와 SI 섞기

두 중요도 재기를 함께 쓴다.

$$\mathcal{L} = \mathcal{L}_{\text{task}} + \lambda_1 F_i (\theta_i - \theta_i^*)^2 + \lambda_2 \frac{S_i}{(\omega_i + \epsilon)^2} (\theta_i - \theta_i^*)^2$$

**이점**: 여러 눈으로 보아 튼튼하다

**흠**: 하이퍼파라미터 손질이 늘어난다

### 과제로 무게 준 정칙화

과제 종류마다 다른 $\lambda$을 쓴다.

$$\lambda_t = \text{Learned}(\text{task\_features}_t)$$

과제마다 알맞은 정칙화 세기를 메타 학습한다.

## 11. 연구의 앞머리

- 모든 중요도 재기를 아우르는 하나의 이론 틀
- 지속 학습의 하이퍼파라미터를 알아서 고르기
- 정칙화를 다른 지속 학습 틀과 섞기
- 오늘날의 구조(트랜스포머 등)를 위한 중요도 재기

<div class="drillbox" markdown>

**연습문제 3.** <span class="diff med" title="중간"></span>
이 방법을 효과와 계산 비용 면에서 EWC와 비교하여라.

</div>

??? success "연습문제 3 풀이"
    EWC는 대각 피셔 정보로 중요한 가중치를 짚어낸다. 이 방법은 다른 트레이드오프를 준다. 옛 과제의 성능을 더 잘 지킬 수 있고, 기억 요구가 다르며, 과제 구조에 대한 가정도 다르다. 실험으로 비교하여 보면 잣대에 따라 서로 보완되는 강점을 보일 때가 많다.
