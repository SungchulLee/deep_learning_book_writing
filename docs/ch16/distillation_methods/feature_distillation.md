# 지속 학습을 위한 피처 증류

피처 증류는 이전 모델과 현재 모델의 중간 표현을 비교해 새 과제 학습 중 표현 변화를 제한한다. 출력 분포만 맞추는 증류와 달리 선택한 레이어의 엑티베이션도 제약한다. 어느 입력·레이어·좌표에서 비교하는지와 새 과제 적응에 미치는 영향을 명시해야 한다.

## 1. 핵심 개념

- **고정 교사**: 이전 과제 학습을 마친 모델
- **학생 피처**: 새 과제를 학습하면서 증류 대상이 되는 엑티베이션
- **정렬**: 채널·공간·토큰 위치를 대응시키는 연산
- **어댑터**: 차원이 다를 때 학생 피처를 교사 차원으로 변환
- **증류 입력**: 새 데이터·과거 버퍼·생성 표본 등 비교할 분포
- **로스 스케일**: 레이어 크기와 평균·합산 방식에 따른 상대 크기

## 2. 수학적 틀

### 피처 비교

교사 피처를 h_old, 학생 피처를 h_new, 학생 측 어댑터를 P라 하자. 증류 입력 분포 D에서 다음 로스를 계산할 수 있다.

$$L_{\mathrm{feat}}=\mathbb E_{x\sim D}\sum_{\ell\in\mathcal I}\alpha_\ell\|P_\ell(h_{\mathrm{new}}^\ell(x))-h_{\mathrm{old}}^\ell(x)\|^2$$

교사 출력은 미분 그래프에서 분리한다. 새 데이터에서만 비교하면 과거 입력 전체의 피처를 직접 제한하는 것은 아니다. 저장한 이전 표본을 쓰면 리플레이 데이터 접근이 추가된다.

### 전체 학습 목표

$$L=L_{\mathrm{task}}+\lambda_oL_{\mathrm{output}}+\lambda_fL_{\mathrm{feat}}$$

모든 항을 반드시 써야 하는 것은 아니다. 각 항의 배치·피처 원소 평균 방식을 정하고 독립적인 검증에서 계수를 선택한다.

## 3. 피처 맞추기 전략

### 직접 비교

같은 모양의 피처를 L2로 비교할 수 있다. 그러나 모양만 같다고 채널이나 토큰의 의미가 대응하는 것은 아니다. 학생을 교사에서 초기화하는 경우와 서로 다른 표현을 비교하는 경우를 구분한다.

### 투영 후 비교

학생 측의 선형 레이어·1×1 컨볼루션·토큰 투영으로 교사 차원을 맞출 수 있다. 공간 해상도가 다르면 보간이나 풀링 위치도 정한다. 교사와 학생 양쪽 투영을 제약 없이 함께 학습하면 모두 0으로 보내 로스를 줄일 수 있으므로 목표가 무너지지 않도록 고정 기준을 둔다.

### 관계 비교

표본 피처를 정규화한 뒤 코사인 관계를 비교할 수도 있다. 이는 좌표별 엑티베이션 대신 표본 간 관계를 보존한다. B개 표본이면 B×B 관계 행렬을 사용하므로 배치 크기에 대한 계산·메모리 비용을 고려한다.

## 4. 레이어 고르기 전략

앞쪽 레이어의 공간 피처, 중간 표현과 출력 가까운 표현은 서로 다른 정보를 담는다. 어느 레이어를 보존할지는 과제와 구조에 따라 검증하며 중간 레이어 3~5개 같은 수를 보편적인 규칙으로 정하지 않는다.

초기 피처 맵은 공간 크기가 커 메모리가 많이 들 수도 있다. 경사 노름에 비례해 레이어 웨이트를 정하는 방법은 스케일과 레이어 크기에 민감하며 중요도를 직접 증명하지는 않는다. 합이 0인 경사와 로스 간 충돌도 처리해야 한다.

## 5. 피처의 크기 차이 다루기

정규화는 비교할 크기 정보를 바꾸므로 정규화 축을 명시한다. 표본별 전체 피처를 평균 0·분산 1로 만드는 것, 채널별 공간 정규화, LayerNorm과 L2 정규화는 서로 다르다.

$$\tilde h=\frac{h-\mu_{\mathcal A}(h)}{\sqrt{\operatorname{Var}_{\mathcal A}(h)+\epsilon}}$$

여기서 축 집합 A를 구체적으로 정한다. LayerNorm의 학습 가능한 스케일·바이어스를 쓰는지도 구분한다. 같은 수식을 서로 다른 이름으로 두 번 적는 것만으로 별도 전략이 정의되지는 않는다.

## 6. 계산에 대한 고려

선택 레이어의 표본당 원소 수를 d_l, 배치 크기를 B, 원소 바이트 수를 q라 하면 두 모델의 피처 값만 저장하는 데 대략 qBΣ_l(d_l^teacher+d_l^student)가 필요하다. 이는 모델·학생 역전파 그래프·옵티마이저 등 전체 메모리는 아니다.

교사 피처를 미리 저장하면 반복 순전파를 줄일 수 있지만 저장 용량과 증강 일관성이 필요하다. 입력 증강이 바뀌면 같은 원본의 캐시 피처를 그대로 정답으로 쓰는 것이 의도한 비교인지 확인한다.

## 7. 지속 학습의 액션

### 순차 학습 흐름

아래 도식은 과제 2에서 D_1_subset을 사용하므로 이전 데이터에 접근하는 예시다. 과거 표본 없이 새 데이터만 쓰는 방식과 구분한다. 각 단계의 교사를 고정하고 같은 입력을 양쪽 모델에 전달해야 한다.

```
Task 1: Train f_1 on D_1
        Store f_1

Task 2: Initialize f_2 with f_1 or random
        Train f_2 on D_2 with distillation:
        L = L_task(f_2, D_2) + λ·L_feat(f_2, f_1, D_1_subset)
        f_2 learns D_2 while preserving f_1's features

Task 3: Initialize f_3 with f_2 or random
        Train f_3 on D_3 with distillation from f_2
        ...
```

### 긴 순서에서의 표현 변화

매 단계 직전 모델만 교사로 쓰면 작은 오차가 누적될 수 있다. 과거 입력이나 별도의 고정 기준 표현으로 평가해 오래된 과제의 보존을 확인한다. 초기 과제의 증류를 항상 더 강하게 하는 것이 최선인지는 검증해야 한다.

## 8. 쓰임새 보기

### 파라메터를 아끼는 미세 조정

기본 모델을 고정하고 어댑터만 학습할 때도 어떤 피처를 맞추는지 중요하다. 어댑터 이전의 고정 피처만 비교하면 그 로스는 학습 가능한 어댑터를 제약하지 않는다. 아래 그림은 구조를 보여 주며 로스 연결과 실제 학습 코드는 별도로 필요하다.

```
Base Model (Frozen)
    ↓
Shared Features
    ↓
Task Adapter ← Feature Distillation Loss
    ↓
Task Output
```

어댑터 출력처럼 학습 가능한 경로에 연결된 피처를 증류해야 그 경로에 경사가 전달된다. 이전 어댑터와 공유 상태를 변경하면 과거 과제의 출력이 달라질 수 있다.

### 서로 다른 과제의 피처

수익률과 변동성처럼 출력 목표가 달라도 공통 입력 표현을 활용할 수는 있다. 그러나 같은 좌표의 피처를 유지하는 것이 두 목표에 모두 유리한지는 데이터로 검증해야 한다. 이름이 비슷한 경제적 개념이 특정 은닉 채널에 대응한다고 가정하지 않는다.

## 9. 출력 증류와의 비교

출력 증류는 클래스나 예측값의 대응이 필요하고 피처 증류는 중간 표현의 정렬이 필요하다. 두 방법의 저장·계산 비용은 모델과 텐서 크기에 따라 달라진다.

함께 사용하면 서로 다른 수준의 제약을 추가하지만 새 과제 적응을 과도하게 제한할 수도 있다. 같은 학습·검증 예산에서 각각의 항과 조합을 비교한다.

## 10. 금융에서의 구현

서로 다른 자산이나 예측 기간의 모델을 연결할 때 입력 관측 시점과 목표 정답 확정 시점을 맞춘다. 하루·한 달 예측의 차이는 단순한 피처 해상도 변화가 아니므로 공통 피처를 무조건 재사용할 수는 없다.

시간 순서에 따른 검증에서 과거 과제와 새 과제를 함께 평가한다. 증류 자체가 시장 관계의 안정성이나 거래 성과를 보장하지는 않는다.

## 11. 연구의 방향

- 서로 다른 구조의 피처 정렬
- 증류 입력의 선택과 표현 보존 범위
- 긴 과제 순서에서 교사 오차 누적
- 비용을 고려한 레이어·로스 웨이트 선택

    두 투영이 모두 0을 출력하면 피처 일치 로스는 작아질 수 있다. 교사 측 기준을 고정하거나 다른 제약과 로스로 의미 있는 목표를 유지해야 한다. 로스가 작다는 사실만으로 유용한 피처가 보존되었다고 볼 수 없다.

## 정리하며

피처 증류는 비교할 입력·레이어·축과 교사 기준을 정해야 의미가 있다. 차원 정렬과 로스 연결, 캐시·증강의 일관성을 확인하고, 표현 변화 제한이 실제 이전 성능 유지로 이어지는지 새 학습 성능과 함께 평가한다.
