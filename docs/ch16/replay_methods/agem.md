# A-GEM: 평균 경사 제약을 이용한 지속 학습

A-GEM(averaged gradient episodic memory)은 과거 표본 버퍼에서 계산한 참조 경사와 충돌하지 않도록 새 경사를 투영한다. 과제별 여러 제약을 쓰는 GEM보다 단순한 평균 제약을 사용한다. 과거 로스에 대한 국소적인 갱신 조건이며 모든 과제의 망각이 없다는 보장은 아니다.

## 1. 핵심 개념

- **표본 버퍼**: 과거 데이터 일부를 보관
- **참조 경사**: 버퍼에서 추출한 표본의 평균 로스 경사
- **충돌 검사**: 새 경사와 참조 경사의 내적 부호 확인
- **반공간 투영**: 충돌할 때 가장 가까운 허용 경사로 변경
- **평균 제약**: 과거 개별 과제마다가 아닌 참조 평균 로스에 대한 조건
- **유한 갱신의 한계**: 곡률·추정 오차와 옵티마이저를 고려해야 하는 국소 근사

## 2. 수학적 틀

현재 배치 경사를 g, 버퍼 참조 경사를 r라 하자. 작은 SGD 갱신에서 버퍼 로스 변화는 다음과 같다.

$$L_M(\theta-\eta v)-L_M(\theta)\approx-\eta r^\top v$$

따라서 rᵀv≥0을 만족하는 방향 v를 사용하면 1차 근사에서 참조 로스를 늘리지 않는다. 이 조건은 직교 조건이 아니라 반공간 제약이다. g가 이미 조건을 만족하면 그대로 사용하고, 위반할 때 투영한다.

$$v=\begin{cases}g,&g^\top r\ge0\\g-\dfrac{g^\top r}{r^\top r}r,&g^\top r<0\end{cases}$$

r=0이면 제약은 모든 방향을 허용한다. 작은 노름의 수치 처리와 허용 오차를 정해야 한다. 모멘텀이나 Adam이 이 경사를 다른 실제 갱신 방향으로 바꾸면 위 SGD 근사를 그대로 적용할 수 없다.

## 3. A-GEM 알고리즘

### 학습 절차

참조 경사를 계산할 때 현재 배치의 경사와 별도로 저장해 덮어쓰이지 않게 한다. 실제 A-GEM은 버퍼 전체 대신 참조 미니배치를 추출해 사용할 수 있다. 아래 의사 코드는 과제 종료 시 버퍼를 갱신하는 설정이며 과제 경계가 전혀 필요 없는 완성 알고리즘을 뜻하지 않는다.

```
procedure A-GEM(tasks, memory_size M):
    θ ← random initialization
    buffer ← empty episodic memory
    
    for each task t:
        for epoch in 1 to num_epochs:
            for minibatch (x, y) from task_t:
                g_t ← ∇L(θ, x, y)
                
                if buffer not empty:
                    g_bar ← average_gradient(buffer, θ)
                    
                    if g_t · g_bar < 0:  // constraint violation
                        g_t ← project_gradient(g_t, g_bar)
                
                θ ← update(θ, g_t)  // optimizer step
        
        // Update memory buffer
        buffer ← update_exemplars(buffer, task_t, M)
    
    return θ, buffer
```

### 버퍼 표본 선택

과거 스트림 전체를 균등하게 대표하려면 저수지 샘플링을 사용할 수 있다. 과제별 균등 배분은 과제 크기와 무관하게 같은 수를 저장하므로 다른 분포를 만든다. 불확실성이나 피처 평균에 따른 선택도 가능하지만 라벨 오류와 이상치에 치우치는지 확인한다.

## 4. 경사 투영의 구조

### 투영 도식

도식은 충돌하는 경사를 허용 영역으로 바꾸는 개념을 보여 준다. 실제 한 개 참조 경사의 허용 영역은 rᵀv≥0인 반공간이며 여러 과제의 개별 제약을 동시에 만족하는 영역과 다르다.

```
        g_t (new task)
         /
        /  feasible region (forward progress on both)
       /___
      |    \
      |     \ (g_t · g_bar > 0)
   g_bar    \
(past task)  \
              \__g_t_projected
```

### 최소 거리 투영의 유도

제약 rᵀv≥0 아래에서 $\frac12\|v-g\|^2$를 최소화한다. 제약을 위반하면 최적점은 경계 rᵀv=0에 있고, 라그랑주 승수로 앞의 투영식을 얻는다. 하나의 식으로 쓰면 다음과 같다.

$$v=g-\min\left(0,\frac{g^\top r}{r^\top r}\right)r$$

min 대신 max를 쓰면 이미 허용된 성분을 제거하고 위반 경사를 그대로 두므로 부호가 반대가 된다. r=0은 별도 분기로 처리한다.

## 5. 기억 다스리기

고정 버퍼 예산 안에서 균등 스트림 표본, 과제별·클래스별 배분 등 보존할 분포를 정한다. 모든 방식이 같은 로스를 근사하는 것은 아니다.

불확실성이 높은 표본만 남기면 쉬운 과거 영역을 잃거나 이상치가 과대표집될 수 있다. 표본당 입력·라벨·메타데이터 바이트와 경사 저장 비용도 포함하고, 클래스나 과제의 로컬 라벨이 충돌하지 않게 관리한다.

## 6. 제약과 수렴의 한계

정확한 투영은 현재 참조 경사에 대한 내적 조건을 만족시킨다. 그러나 참조 경사가 버퍼 전체의 경사를 추정할 수 있고, 유한 스텝의 고차항과 이후 갱신도 있으므로 실제 과거 로스가 매번 줄어든다는 뜻은 아니다.

평균 조건을 만족해도 개별 과제 성능은 떨어질 수 있다. 볼록성만으로 로스가 일정량씩 영원히 감소하는 수렴식을 도출할 수는 없으며, 러닝레이트·매끄러움·확률 경사 오차 등의 가정이 필요하다.

## 7. 이웃한 방법과의 비교

GEM은 저장된 과제별 제약을 사용하는 반면 A-GEM은 하나의 참조 평균 제약으로 투영을 단순화한다. 경험 리플레이는 현재 표본과 과거 표본의 로스를 함께 학습하는 접근이다.

EWC나 SI는 원본 표본 대신 통계·기준 웨이트를 저장할 수 있지만 메모리가 0인 것은 아니다. 정확도와 비용은 같은 버퍼·모델·학습 예산에서 비교한다.

## 8. 실용적인 고려

참조 배치가 과거 데이터를 충분히 대표하는지와 버퍼 크기에 따른 성능 변화를 검증한다. 표본 1000개가 보편적인 포화점이라는 근거는 없다.

P개 파라메터의 내적·투영 자체는 O(P)다. 추가 참조 순전파·역전파의 비용은 참조 배치와 모델 연산량에 달려 있다. 버퍼 전체 크기와 한 번에 추출하는 참조 배치 수를 구분하고 시간·메모리 배수를 실제로 측정한다.

## 9. 금융에서의 쓰임

과거 시기의 예측 표본을 버퍼에 유지하고 새 데이터 학습과 충돌하는 평균 경사를 제한하는 설계를 검토할 수 있다. 버퍼를 위기 자료에 집중하면 그 분포를 더 강하게 보존하는 목표가 되므로 표본 웨이트와 평가 목표를 명시한다.

참조 로스의 국소 조건은 새 위기의 성과나 위험 한도를 보장하지 않는다. 입력·정답의 관측 시점을 지키고 시간 분리 검증으로 예측 성능을 평가한다.

### 자산별 버퍼 예시

```
Equities Buffer: Historical equity returns + crashes
Bonds Buffer: Interest rate moves, credit events
Commodities Buffer: Supply shocks, seasonal patterns
```

아래 목록처럼 자산별 표본을 분리해 관리할 수 있다. 실제 참조 배치를 어떤 비율로 뽑는지와 공통 예측 목표·라벨을 별도로 정해야 한다.

## 10. 더 깊은 주제

### 가중 참조 경사

비음수 웨이트의 합이 양수이면 가중 버퍼 로스의 참조 경사를 계산할 수 있다.

$$r=\frac{\sum_iw_i\nabla L_i}{\sum_iw_i}$$

이는 원래 균등 평균과 다른 목표다. 과제별 메모리 배분과 표본 웨이트를 함께 정의한다.

### 분산·연합 환경

아래 도식은 구현이 아닌 아이디어다. 표본(exemplars)은 원본 데이터의 일부일 수 있으므로 공유한다고 개인정보 보호가 보장되지는 않는다. 여러 클라이언트의 경사를 합치는 방식과 로컬 투영 후 평균이 글로벌 제약을 만족하는지도 별도 분석해야 한다.

```
Local A-GEM on each client
Share exemplars (not raw data) across clients
Global gradient projection
```

공유 데이터와 모델 업데이트의 정보 노출은 별도 조건이며 A-GEM의 경사 제약만으로 해결되지 않는다.

## 연습문제

<div class="drillbox" markdown>

**연습문제 1.** <span class="diff med" title="중간"></span>
참조 로스의 1차 변화에서 rᵀv≥0 조건을 유도하라.

</div>

??? success "연습문제 1 풀이"
    θ를 θ−ηv로 갱신하면 참조 로스 변화는 약 −ηrᵀv다. η>0일 때 이 값이 양수가 되지 않으려면 rᵀv≥0이어야 한다. 이는 작은 스텝의 국소 근사이며 전체 학습의 망각 없음 보장은 아니다.

---

<div class="drillbox" markdown>

**연습문제 2.** <span class="diff easy" title="쉬움"></span>
g=(−1,1), r=(1,0)일 때 투영 경사를 계산하라.

</div>

??? success "연습문제 2 풀이"
    내적은 −1, 참조 노름 제곱은 1이다. v=g−(−1)r=(0,1)로 경계에 투영된다. 내적이 이미 양수인 경사는 그대로 둔다.

---

<div class="drillbox" markdown>

**연습문제 3.** <span class="diff med" title="중간"></span>
평균 경사 제약이 개별 과제를 모두 지키는가?

</div>

??? success "연습문제 3 풀이"
    평균 경사와의 내적이 음이 아니어도 어떤 개별 과제의 경사와는 음수일 수 있다. 따라서 평균 로스 제약과 과제별 제약은 다르며, 개별 과제의 실제 성능을 함께 평가해야 한다.

---

<div class="drillbox" markdown>

**연습문제 4.** <span class="diff hard" title="어려움"></span>
그래디언트를 투영한 뒤 Adam으로 갱신할 때 무엇을 확인해야 하는가?

</div>

??? success "연습문제 4 풀이"
    Adam은 모멘트와 좌표별 스케일로 실제 갱신 방향을 바꾼다. 투영한 경사와 참조 경사의 조건만으로 실제 파라미터 갱신이 같은 조건을 만족한다고 볼 수 없다. 제약이 어느 방향에 적용되는지와 실제 로스 변화를 확인해야 한다.

## 정리하며

A-GEM은 버퍼 참조 경사와 충돌하는 새 경사를 반공간에 투영한다. 투영식의 부호, 영노름 처리와 실제 옵티마이저 갱신을 구분한다. 평균의 국소 조건을 모든 과제의 성능 보장으로 해석하지 말고 버퍼·참조 배치와 자원 조건을 함께 보고한다.

**참고**: [Chaudhry 등, Efficient Lifelong Learning with A-GEM](https://arxiv.org/abs/1812.00420).
