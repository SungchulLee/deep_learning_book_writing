# 지속 학습을 위한 Expert Gate

Expert Gate는 과제별 전문가를 추가하고 입력에 맞는 전문가를 선택하는 지속 학습 방법이다. 원 방법은 과제별 오토인코더의 재구성 오차를 게이팅에 활용한다. 이 페이지의 가중 혼합 수식과 도식은 일반적인 mixture of experts(MoE)를 설명하는 것으로, 원 Expert Gate와 구분한다.

## 1. 핵심 개념

- **과제별 전문가**: 해당 과제를 학습한 예측 모델
- **선택기**: 입력에 맞는 전문가를 고르는 장치
- **Expert Gate의 오토인코더**: 입력이 각 과제 분포에 얼마나 맞는지 재구성 오차로 평가
- **일반 MoE의 게이트**: 전문가별 혼합 가중치나 희소 선택 점수를 출력
- **구조 확장 비용**: 새 전문가·선택 통계가 늘어나는 저장량
- **조건부 보존**: 기존 전문가뿐 아니라 전처리와 선택 경로도 유지해야 하는 요구

## 2. 수학적 정식화

### 원 Expert Gate의 선택

과제별 오토인코더로 입력 특징의 재구성 오차를 계산하고 그 오차를 바탕으로 적합한 전문가를 선택한다. 새 전문가를 학습할 때도 기존 과제와의 관련성을 이용해 초기화·전이 전략을 정할 수 있다. 이전 원본 데이터에 다시 접근하지 않는 설정을 다룬다.

### 일반적인 소프트 전문가 혼합

아래 식은 공통 출력 공간을 가진 전문가의 가중 혼합이다.

$$\hat y=\sum_{e=1}^Eg_e(x)E_e(x),\qquad g_e\ge0,\quad\sum_eg_e=1$$

게이트 점수에 소프트맥스를 적용해 가중치를 만들 수 있다. 로짓을 평균하는 것과 확률을 평균하는 것은 일반적으로 다른 예측을 만든다. 과제별 클래스 의미가 다르면 출력 차원이 같아도 그대로 합산할 수 없다. 이것을 원 Expert Gate의 재구성 기반 선택과 동일한 알고리즘으로 설명하지 않는다.

## 3. 전문가의 전문화

### 활용 균형

일반 MoE에서는 게이트가 일부 전문가만 선택하는 편향이 생길 수 있다. 평균 게이트 가중치 $\bar g_e$에 대한 $\alpha\sum_e\bar g_e^2$ 같은 벌점은 균등 활용을 유도하는 한 설계다. α>0이고 가중치 합이 1이면 균등할 때 최솟값을 갖는다.

다만 균등한 활용이 항상 과제에 유리한 것은 아니며, 게이트 확률과 실제 top-k 배정 수가 같지도 않다. 잡음 추가도 모든 전문가의 전문화나 망각 방지를 보장하지 않는다. 과제별로 분리해 학습하는 원 Expert Gate의 전문화와 구분한다.

## 4. Expert Gate을 쓰는 지속 학습

새 과제가 도착하면 적절한 기존 모델에서 전이하거나 새로 초기화한 전문가를 학습하고 과제 선택 정보를 추가한다. 이전 전문가의 가중치와 버퍼를 고정하면 그 전문가 자체의 함수는 유지할 수 있다.

그러나 선택기가 바뀌어 이전 입력을 다른 전문가로 보내면 시스템의 최종 정확도는 달라질 수 있다. 낮은 학습률로 이전 전문가를 계속 갱신하는 것은 동결과 같은 보장이 아니다. 테스트 시 과제 ID를 주는 평가와 입력만으로 선택하는 평가도 따로 보고한다.

## 5. 이론적 성질

### 저장량

동일 크기의 전문가 E개라면 저장량은 공유 부품과 선택기 크기에 더해 E×전문가 크기에 비례한다. 전문화만으로 저장량의 선형 증가가 저절로 느려지는 것은 아니다. 병합·압축·재사용 규칙이 있으면 별도로 정의한다.

### 소프트 혼합의 경사

게이트를 고정해 전문가 출력으로 미분하면 다음과 같다.

$$\frac{\partial L}{\partial E_e(x)}=g_e(x)\frac{\partial L}{\partial\hat y}$$

실제 전문가 매개변수 경사에는 전문가의 야코비안도 곱해진다. 공유 매개변수나 게이트와 연결된 경로가 있으면 추가 미분 항을 고려한다. 작은 게이트 가중치는 해당 출력 경로의 경사를 줄이지만 완전한 보존이나 유용한 전문화를 보장하지 않는다.

## 6. 실전 구현

### 구조 도식

아래 도식은 여러 전문가의 출력을 가중 합산하는 일반 MoE다. 오토인코더 재구성 기반 선택기나 실제 학습·확장 코드는 포함되어 있지 않다. 모든 전문가를 계산하는 소프트 혼합은 하나를 선택해 실행하는 방식과 추론 비용이 다르다.

```
Input
  │
  ├────────────────────────────────────────┐
  │                                        │
Gating Network ─────────────────────┐      │
  │                                 │      │
  └─────────────────────────┐        │      │
                            │        │      │
                    Expert 1 │    Expert 2  Expert 3
                      │      │       │         │
                      └──────┼───────┼─────────┘
                             │       │
                      Weighted Combination
                             │
                           Output
```

### 초기화와 선택 온도

기존 전문가의 복사 초기화는 전이의 출발점이 될 수 있지만 새 과제에서 도움이 되는지는 검증해야 한다. 서로 독립적으로 학습한 전문가의 가중치를 단순 평균하면 뉴런의 대응이 달라 성능이 손상될 수 있다.

일반 소프트 게이트에서 $g_e=\operatorname{softmax}(s_e/T)$이며 T>0이다. 낮은 T는 고정 점수의 선택을 날카롭게 하지만 모든 전문가를 계산한다면 계산 비용을 자동으로 줄이지는 않는다.

---

## 7. 이어 배우는 상황에서의 학습 움직임

전이 초기화의 효과, 각 전문가의 이전 성능과 전체 선택 정확도를 분리해 측정한다. 전문가 자체가 유지되어도 선택 오류가 늘 수 있고 공유 특징이 갱신되면 모든 전문가의 입력 표현이 달라질 수 있다.

이전 과제 입력을 새 전문가가 얼마나 자주 선택받는지, 실제 선택 후 예측이 맞는지를 평가한다. 전문화가 있다는 사실만으로 과제 구별이 해결되는 것은 아니다.

## 8. 다른 구조 방법과의 비교

다중 헤드는 공유 백본과 과제별 출력층을, 어댑터는 작은 과제별 변환을 추가한다. 독립 전문가는 과제별 모델 저장이 더 클 수 있지만 실행 시 선택된 모델만 로드하는 설계도 가능하다.

점진 네트워크의 측면 연결처럼 과제 간 연결을 늘리는 방법은 연결 규칙에 따라 증가 비용이 달라진다. 과제 수 T만으로 모든 방법의 복잡도를 비교하지 말고 공유·과제별 매개변수와 선택 비용을 합산한다.

## 9. 금융에서의 쓰임

시장 상태나 자산별 예측 모델을 전문가로 두는 설계를 검토할 수 있다. 게이트는 예측 시점에 관측 가능한 정보만 사용하고, 전문가가 서로 같은 목표·시간 범위의 값을 출력하는지 확인한다.

특정 전문가에 추세·평균 회귀 같은 이름을 붙였다고 그 전략이 자동으로 학습되는 것은 아니다. 시간 순서에 맞춘 검증에서 선택 오류·전문가 성능과 전체 비용을 함께 측정한다.

## 10. 연구의 방향

- 과제 선택 오류와 전문가 보존의 분리 평가
- 전문가 확장·재사용·압축의 저장 비용
- 입력 분포가 겹칠 때의 선택 불확실성
- 공유 표현의 변화와 전문가 간 간섭

**연습문제 3.** <span class="diff med" title="중간"></span>

??? success "연습문제 3 풀이"

??? success "연습문제 4 풀이"

## 정리하며

Expert Gate의 과제별 재구성 기반 선택과 일반 MoE의 소프트 혼합을 구분한다. 기존 전문가의 고정만으로 선택 경로까지 보존되지는 않는다. 저장 증가·실행 전문가 수와 과제 선택 오류를 포함해 전체 시스템을 평가한다.
