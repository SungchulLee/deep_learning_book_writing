# 언어 모델과 시퀀스 모델

---

## 1. 언어 모델이란 무엇인가

언어 모델은 시퀀스에 확률을 매긴다. 엄밀히는 시퀀스에 대한 결합 확률 분포를 추정한다.

$$P(x_1, x_2, \ldots, x_T)$$

여기서 $x_1,\ldots,x_T$는 단어·문자·서브워드 등의 토큰이다. 같은 자기회귀 분해를 가격 변화나 사건열에도 사용할 수 있지만, 이는 더 일반적인 시퀀스 모델링이며 연속값에서는 확률 질량과 확률 밀도를 구분해야 한다.

### 연쇄 법칙 분해

확률의 연쇄 법칙으로 이 결합 확률을 쪼갠다.

$$P(x_1, x_2, \ldots, x_T) = P(x_1) \cdot P(x_2 | x_1) \cdot P(x_3 | x_1, x_2) \cdots P(x_T | x_1, \ldots, x_{T-1})$$

더 간결하게 쓰면 다음과 같다.

$$P(x_1, x_2, \ldots, x_T) = \prod_{t=1}^T P(x_t | x_{<t})$$

여기서 $x_{<t} = (x_1, x_2, \ldots, x_{t-1})$은 문맥(앞선 모든 원소)을 나타낸다.

**핵심 착상:** 시퀀스 전체의 확률이 각 원소가 자신의 이력에 조건을 둔 예측으로 쪼개진다. 그러면 문제를 다룰 만해진다. $T$개가 얽힌 의존을 곧바로 다루는 대신 한 스텝 앞을 예측하는 일을 되풀이하면 된다.

## 2. N-그램 모델: 고전적인 방법

뉴럴 넷트웍이 나오기 전에는 n-그램 모델이 시퀀스 모델의 일꾼이었다.

### 원리

n-그램 모델은 **마르코프 가정**을 둔다. 다음 원소의 확률이 이력 전체가 아니라 앞선 $n-1$개의 원소에만 기댄다는 것이다.

$$P(x_t | x_{<t}) \approx P(x_t | x_{t-n+1}, \ldots, x_{t-1})$$

**흔한 판본:**

- **유니그램** $(n=1)$: $P(x_t) = P(x_t)$ — 문맥과 무관한 빈도
- **바이그램** $(n=2)$: $P(x_t | x_{t-1})$ — 한 스텝의 문맥
- **트라이그램** $(n=3)$: $P(x_t | x_{t-2}, x_{t-1})$ — 두 스텝의 문맥

### 세기와 추정

관측된 문맥의 최대우도 확률은 다음 단어로 이어진 횟수를 그 문맥 뒤에 다음 단어가 관측된 전체 횟수로 나누어 추정한다. 문장 끝의 처리와 경계 토큰도 이 규칙에 맞춰야 한다.

$$P(x_t = w | x_{t-1} = v) = \frac{\text{count}(v, w)}{\text{count}(v)}$$

학습 말뭉치에서 전이를 세어 정규화하면 된다.

### 스무딩

중요한 문제가 하나 있다. **데이터의 성김**이다. 대부분의 n-그램 조합은 학습 데이터에 아예 나타나지 않아 횟수가 0이고 확률도 0이 된다.

**스무딩 기법**은 본 적 없는 n-그램에도 0이 아닌 확률을 준다.

1. **1 더하기 스무딩 (라플라스 스무딩):**

   $$P(x_t = w | \text{context}) = \frac{\text{count}(\text{context}, w) + 1}{\text{count}(\text{context}) + V}$$

   여기서 $V$은 어휘의 크기이다

2. **백오프:** 드문 문맥이나 관측되지 않은 조합에는 낮은 차수 모델을 사용한다. 전체 확률이 정규화되도록 할인과 웨이트를 함께 정한다.

3. **보간:** 여러 차수의 n-그램 예측을 학습된 웨이트로 섞는다.

!!! note "N-그램 모델의 한계"

    - $n-1$스텝을 넘어서는 의존을 붙잡지 못한다
    - $n$이 커지면 파라메터가 지수적으로 는다(차원의 저주)
    - 고정 차수 모델은 창 밖의 문맥을 직접 사용하지 않는다. 백오프·보간은 여러 차수의 정보를 결합할 수 있다
    - 실제 어휘에서는 매끄럽게 하는 작업이 많이 필요하다

## 3. 뉴럴 넷트웍 언어 모델: 시퀀스를 위한 RNN

뉴럴 넷트웍 언어 모델에는 고정 문맥의 피드포워드 모델, RNN과 트랜스포머 등이 있다. 이 절은 RNN이 과거 문맥의 표현을 갱신하는 방식을 설명한다.

### 언어 모델을 위한 RNN 구조

RNN은 은닉 상태 $h_t$을 지니며 시퀀스를 원소 하나씩 처리한다.

$$h_t = f(h_{t-1}, x_t; \theta)$$

여기서 $f$은 순환 셀(엘만, LSTM, GRU)이고 $\theta$은 학습 가능한 파라메터이다.

시각마다 은닉 상태에서 출력 분포를 계산한다.

$$P(x_{t+1} | x_1, \ldots, x_t) = \text{softmax}(\mathbf{W} h_t + \mathbf{b})$$

**RNN의 문맥 표현:**

- 고정된 최근 $n-1$개보다 앞선 입력도 은닉 상태를 통해 영향을 줄 수 있다.
- 실제로 유지되는 정보는 은닉 차원과 학습 과정의 제약을 받는다.
- 단어와 문맥의 학습된 표현으로 관측이 드문 조합 사이에서도 정보를 공유할 수 있다.
- 같은 웨이트를 여러 시점에 사용한다.

### 펼치기와 시간을 거슬러 가는 역전파 (BPTT)

RNN 언어 모델을 학습시키는 일은 다음으로 이루어진다.

1. **순전파:** 시퀀스에 걸쳐 뉴럴 넷트웍을 펼치며 스텝마다 $h_t$과 출력 분포를 계산한다
2. **로스 계산:** 자리마다의 교차 엔트로피 로스를 더한다
3. **역전파:** 시간을 거슬러 역전파(BPTT)하여 그래디언트를 계산한다
4. **갱신:** 파라메터에 경사 하강을 적용한다

!!! warning "그래디언트 소실과 폭발"
    장기 의존은 여전히 어렵다. 시간을 거슬러 전파되는 그래디언트가 (지수적으로 줄어) 사라지거나 폭발할 수 있어 실제로 쓸 수 있는 문맥의 길이가 제한된다. 이 때문에 게이트를 갖춘 LSTM과 GRU 구조가 나왔다.

## 4. 퍼플렉시티: 평가 지표

퍼플렉시티는 언어 모델의 표준 평가 지표로, 모델이 시험 시퀀스를 얼마나 잘 예측하는지를 수로 나타낸다.

### 정의

시험 시퀀스 $x_1, \ldots, x_T$에 대해 퍼플렉시티를 다음과 같이 정의한다.

$$\text{PPL} = P(x_1, \ldots, x_T)^{-1/T} = \exp\left(-\frac{1}{T}\sum_{t=1}^T \log P(x_t | x_{<t})\right)$$

### 해석

- **같은 평가 조건에서는 낮을수록 평균 음의 로그 우도가 작다.** 토큰화, 평가 데이터, 문맥과 집계 기준이 같아야 한다
- **기준선:** 크기가 $V$인 어휘에 대한 균등 분포의 퍼플렉시티는 $V$이다
- **직관:** 확률의 역수의 기하 평균이며 평균적인 갈림의 수를 나타낸다

**예:**

- 어휘 크기 10,000
- 균등 모델의 퍼플렉시티: 10,000
- 퍼플렉시티의 비율은 200이다. 이는 정답 토큰 확률의 기하 평균 비율이며 정확도가 200배 높다는 뜻은 아니다
- 해석: 모델이 똑같이 그럴듯한 대안 50개 가운데 하나를 고르는 것만큼 "헷갈려" 한다

### 로스과의 관계

학습할 때는 교차 엔트로피 로스를 최소로 한다.

$$\mathcal{L} = -\frac{1}{T}\sum_{t=1}^T \log P(x_t | x_{<t})$$

관계는 곧바르다.

$$\text{PPL} = e^{\mathcal{L}}$$

같은 토큰 집합에서 자연로그로 구한 토큰 평균 음의 로그 우도라면 로스와 퍼플렉시티는 단조 관계다. 클래스 웨이트나 레이블 스무딩이 들어간 로스, 배치 평균의 단순 평균에는 이 식을 그대로 적용하면 안 된다. 토큰화가 다른 모델의 토큰당 퍼플렉시티도 직접 비교하기 어렵다. 가변 길이 문장 전체의 확률 모델에는 종료 토큰이나 길이 모델이 필요하다.

## 5. 학습에서의 티처 포싱

### 개념

티처 포싱 학습에서는 이전 정답 토큰을 입력한다. 자유 생성에서는 이전에 선택한 모델 토큰을 입력한다. 검증 데이터의 음의 로그 우도를 평가할 때도 실제 앞 토큰을 조건으로 쓰므로, 모든 추론이 자유 생성인 것은 아니다.

**티처 포싱:** 학습할 때 모델이 무엇을 예측했든 참된 이전 원소 $x_t$을 넣는 것이다.

$$P(x_{t+1} | x_1, \ldots, x_t) \text{ conditioned on true } x_t$$

추론에서는 (모델이 가장 그럴듯하다고 본) $\hat{x}_t$에 조건을 두는 것과 대비된다.

### 이점과 트레이드오프

**학습에서의 역할:**

- 관측된 문맥에서 다음 정답의 로그 우도를 직접 최적화한다.
- 이전 예측 오류가 이후 입력 토큰을 바꾸는 상황을 피한다.
- 이것이 은닉 상태를 통한 BPTT 그래디언트 연결까지 끊는다는 뜻은 아니다.

**단점:**

- **분포의 어긋남:** 추론 중에 모델이 학습 때 본 것과 다른 분포(제 오류)를 만난다
- **노출 바이어스:** 모델이 교사가 준 문맥에 기대므로 제 예측에 조건을 걸어야 할 때 무너질 수 있다
- 먼 지평까지 생성하는 데 약한 무른 모델이 될 수 있다

### 스케줄드 샘플링

절충안은 학습 도중 티처 포싱에서 모델의 예측으로 차츰 옮겨 가는 것이다.

$$x_t^{\text{input}} = \begin{cases} x_t & \text{with probability } 1 - \epsilon(k) \\ \hat{x}_t & \text{with probability } \epsilon(k) \end{cases}$$

여기서 $\epsilon(k)$은 0 가까이에서 시작하여 세대 $k$에 따라 커진다.

스케줄드 샘플링은 학습 입력의 일부를 모델 예측으로 바꾸는 방법이다. 노출 바이어스를 완화하려는 목적이지만 원래의 최대우도 학습과 다른 목표가 될 수 있으며, 모든 설정에서 생성 품질이 좋아진다고 보장하지 않는다.

## 6. 금융 시계열과의 이음새

자기회귀 조건부 분포의 관점은 금융 시계열에도 적용할 수 있다. 다만 토큰 범주 분포와 연속 수익률의 밀도는 출력 레이어와 로스가 다르며, 분포 가정과 평가 방법을 새로 정해야 한다.

### 수익률 시퀀스 모델링

토큰 대신 로그 수익률 $r_t = \log(P_t / P_{t-1})$을 다룬다.

$$P(r_t | r_{t-1}, r_{t-2}, \ldots) = \mathcal{N}(\mu_t, \sigma_t^2)$$

여기서 $\mu_t$와 $\sigma_t^2$는 과거 관측으로부터 추정하는 조건부 평균과 분산이다. 분산은 양수가 되도록 파라메터화해야 한다. 정규분포는 선택한 모형 가정이지 실제 수익률 분포가 반드시 정규적이라는 뜻은 아니다.

**응용:**

- 다음 시점의 수익률 예측
- 변동성 예측
- 위험 관리를 위한 조건부 확률 분포

### 주문 흐름과 미시 구조

체결과 주문 사건의 시퀀스를 다룬다.

- 매수·매도 호가 차이의 변화
- 체결 수량의 시퀀스
- 주문 흐름의 이력에 조건을 둔 가격 액션의 방향

RNN으로 사건열의 조건부 의존성을 모델링할 수 있다. 실제로 유용한 예측 정보를 학습했는지는 시간순으로 분리한 데이터와 적절한 기준 모델에서 확인해야 한다.

### 다변량 시퀀스

다음과 같이 여러 자산으로 넓힌다.

$$P(x_t^{(1)}, x_t^{(2)}, \ldots, x_t^{(n)} | \text{history})$$

RNN의 상태는 여러 자산의 과거 입력을 함께 표현할 수 있다. 다만 자산 사이의 조건부 상관을 모델링하려면 출력 분포에도 결합 구조나 공분산 등을 반영해야 한다. 독립적인 단변량 출력만으로 모든 동시 의존성이 표현되는 것은 아니다.

!!! info "금융 시퀀스 모델의 이점"

    - 과거 관측으로부터 조건부 평균·분산이나 사건 확률을 추정하는 데 사용할 수 있다.
    - 시나리오 생성은 선택한 분포 가정을 따른다.
    - 분포 변화와 불확실성의 보정은 별도로 검증해야 한다.
    - 확률 예측을 만든 것만으로 실제 의사결정의 유용성이 입증되지는 않는다.

## 7. 트랜스포머로 가는 다리 (13장)

RNN 언어 모델은 성공을 거두었지만 근본적인 한계가 있다.

1. **순차적인 계산:** 원소를 하나씩 처리해야 하므로 효율적으로 병렬 처리할 수 없다
2. **그래디언트 소실:** LSTM과 GRU가 있어도 장기 의존은 어렵다
3. **은닉 상태의 병목:** 모든 정보를 크기가 고정된 벡터 $h_t$에 눌러 담는다

(다음 장의) **트랜스포머**는 다음으로 이 한계를 다룬다.

- **셀프 어텐션:** 마스크와 문맥 창이 허용하는 위치 사이의 직접 연결을 만든다.
- **학습 시 병렬화:** 정답 문맥이 주어지면 여러 위치를 함께 계산할 수 있다. 자기회귀 생성에서는 다음 토큰 선택이 순차적이다.
- **문맥 처리 비용:** 직접 연결이 장거리 전달 경로를 줄이지만, 전체 어텐션은 시퀀스 길이에 따른 메모리·계산 비용이 크다.
- **사전 학습과 전이:** 사전 학습 모델의 표현을 다른 과제에 활용할 수 있다. 이는 트랜스포머만의 성질은 아니다.

언어 모델의 목표는 $P(x_t | x_{<t})$을 예측하는 것으로 그대로이지만, 구조가 문맥을 처리하고 아우르는 방식을 근본적으로 바꾼다.

GPT와 같은 인과적 언어 모델은 앞선 토큰으로 다음 토큰을 예측한다. BERT는 양방향 문맥에서 가린 토큰을 예측하도록 학습하므로 같은 자기회귀 인수분해를 그대로 사용하는 모델로 묶으면 안 된다.

**연습문제 1.** <span class="diff hard" title="어려움"></span>
자기회귀 언어 모델의 분해와 RNN의 조건부 예측 방식을 설명하라.

??? success "풀이"
    $P(w_1,\ldots,w_T)=\prod_tP(w_t\mid w_{<t})$다. RNN은 이전 토큰을 은닉 상태에 반영하고 출력 로짓을 정규화해 다음 토큰 분포를 만든다. 은닉 상태는 학습된 요약이며 실제 데이터 생성 과정의 충분통계량이라고 보장되지는 않는다. 가변 길이 문장 모델에는 종료 조건도 필요하다.

<div class="drillbox" markdown>

**연습문제 4.** <span class="diff hard" title="어려움"></span>
글자 단위의 간단한 RNN 언어 모델을 PyTorch로 구현하라.

</div>

??? success "풀이"
    ```python
    class CharRNN(nn.Module):
        def __init__(self, vocab_size, hidden_size):
            super().__init__()
            self.embed = nn.Embedding(vocab_size, hidden_size)
            self.rnn = nn.LSTM(hidden_size, hidden_size, batch_first=True)
            self.fc = nn.Linear(hidden_size, vocab_size)
        def forward(self, x, h=None):
            x = self.embed(x)
            out, h = self.rnn(x, h)
            return self.fc(out), h
    ```

## 정리하며

자기회귀 언어 모델은 과거 토큰을 조건으로 다음 토큰 분포를 학습한다. 퍼플렉시티는 공통 평가 규약 아래에서 비교하고, 티처 포싱의 우도 평가와 자유 생성은 구분해야 한다. 연속 시계열이나 다른 사전 학습 목표로 확장할 때는 분포와 목적 함수의 차이를 명시한다.
