# Teacher forcing과 자기회귀 우도 학습

Teacher forcing은 다음 토큰을 예측할 때 관측된 실제 접두사를 입력으로 사용하는 방식이다. 자기회귀 모델에서 이는 관측 시퀀스의 조건부 로그확률을 계산하는 표준 최대우도 절차다. 학습 초기에 모델의 예측이 서툴기 때문에만 쓰는 임시 기법이 아니며 학습 내내 사용할 수 있다.

## 1. 입력·타깃의 한 칸 이동

관측 x₁,…,x_T에서 입력을 x₁,…,x_(T−1), 타깃을 x₂,…,x_T로 둔다. 입력 위치 t까지의 관측으로 타깃 x_(t+1)을 예측한다. 이 경우 첫 토큰이 주어진 조건부 우도를 학습하며 전체 시퀀스 분포에는 첫 토큰 또는 BOS·EOS 규칙도 필요하다.

$$-\log p_\theta(x_2,\ldots,x_T|x_1)
=-\sum_{t=1}^{T-1}\log p_\theta(x_{t+1}|x_{1:t}).$$

현재 입력 토큰을 볼 수 있다는 것과 타깃인 다음 토큰을 볼 수 있다는 것은 다르다. 미래 타깃을 입력·attention·정규화 등 다른 경로로 보지 않도록 해야 한다.

## 2. 구현과 반환 형식

```python
"""자기 회귀 모델의 스승 밀어 넣기 익히기 스텝."""
import torch.nn.functional as F

def teacher_forced_loss(model, x, vocab_size):
    """스승 밀어 넣기로 어긋 엔트로피 로스를 셈한다.

    인수:
        model: (배치, 차례 길이) -> (배치, 차례 길이, 낱말 수)으로 옮기는 자기 회귀 모델
        x: 참값 토큰 아이디, 꼴 (배치, 차례 길이)
        vocab_size: 낱말의 크기

    반환값:
        낱값 어긋 엔트로피 로스.
    """
    logits = model(x[:, :-1])   # 들임: 마지막을 뺀 모든 토큰
    targets = x[:, 1:]           # 목표: 첫 토큰을 뺀 모든 토큰
    return F.cross_entropy(
        logits.reshape(-1, vocab_size),
        targets.reshape(-1),
    )
```

이 함수는 model이 `(B,T−1,V)` logits를 반환하고 x가 정수 토큰 `(B,T)`이라고 가정한다. logits와 타깃을 펼쳐 토큰별 평균 교차엔트로피를 계산하며 별도의 softmax는 필요 없다. 패딩 제외·유효 토큰 수 가중·BOS·EOS 처리는 이 함수에 없다.

앞의 [문자 모델](../foundations/model.md)은 마지막 문맥의 다음 토큰 하나만 반환한다. 그 CharRNN은 튜플 `(B,V),hidden`, SimpleCharTransformer는 `(B,V)`이므로 이 함수를 그대로 적용하는 출력 계약과 다르다. 모든 위치 logits를 반환하도록 설계하거나 문맥당 타깃 하나의 로스를 사용해야 한다.

## 3. 병렬 계산과 그래디언트

실제 앞 토큰을 알고 있어 모델 예측 토큰을 입력으로 뽑는 단계가 필요하지 않다. 마스크 CNN·인과적 Transformer는 주어진 전체 시퀀스에서 여러 위치를 병렬 계산할 수 있다. RNN은 단일 함수 호출로 전체 시퀀스를 처리해도 시간축 은닉 재귀가 남는다. 모든 자기회귀 모델이 완전 병렬·길이에 무관한 비용으로 학습되는 것은 아니다.

이산 표본 선택을 거쳐 그래디언트를 전파할 필요가 없다는 점은 유용하지만, 긴 재귀 경로의 그래디언트 소실·폭발이나 불안정한 최적화를 자동으로 막지는 않는다. 모델 구조·러닝레이트·정밀도와 자료 정렬도 필요하다.

## 4. Exposure bias와 학습 목표

자유 생성에서는 관측 접두사 대신 모델이 생성한 접두사를 사용한다. 모델 오차가 이후 문맥 분포를 바꾸고 장기 품질에 영향을 줄 수 있으며 이를 exposure bias 관점에서 분석한다. 하지만 관측 접두사에서의 최대우도 자체가 잘못된 우도라는 뜻은 아니다. 모델이 참 조건부를 정확히 표현·학습했다면 조상 샘플링도 참 분포와 일치한다. 실제 영향은 오차·자료·모델·디코딩 폴리시에 달려 있고 길이에 따라 반드시 일정하게 증가하지는 않는다.

[Scheduled sampling](scheduled_sampling.md)은 실제 입력과 모델 입력을 혼합하는 휴리스틱이다. 원래 최대우도와 다른 목적이며 [일관성에 관한 비판](https://arxiv.org/abs/1511.05101)이 있어 생성 개선을 보장하지 않는다. 시퀀스 수준 학습·입력 잡음도 목적·타깃의 의미와 추정량을 명시해야 한다.

빔 서치는 여러 출력 가설을 탐색하고 온도·top-p는 생성 조건부를 바꾼다. 이들은 teacher-forced 학습 목적을 수정하거나 참 조건부를 복원하는 방법 자체는 아니다. 특정 방법을 노출 바이어스의 보편적 해결책으로 제시하지 않는다.

## 5. 평가에서의 사용

알려진 정답 시퀀스의 로그확률·perplexity를 평가할 때도 teacher forcing을 사용할 수 있다. 자유 생성에서는 알 수 없는 미래 토큰을 정답으로 공급할 수 없으므로 생성한 토큰으로 진행한다. 두 평가 목적을 구분해 검증 NLL과 실제 사용 조건의 생성 품질을 함께 본다.

## 정리하며

Teacher forcing은 관측 접두사로 자기회귀 우도를 계산한다. 타깃 이동·모든 위치 logits·패딩 규칙을 맞추고 구조별 병렬성을 구분해야 한다. 검증 우도와 자유 생성은 서로 다른 평가이며 입력 혼합·디코딩 변경의 효과는 별도로 검증한다.
