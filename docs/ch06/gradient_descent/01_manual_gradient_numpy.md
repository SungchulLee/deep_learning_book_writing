# NumPy로 직접 구현하는 경사 하강법

자동 미분이 대신해 주는 일이 정확히 무엇인지 알려면 한 번은 손으로 해 보아야 한다. 이 쪽은 절편 없는 선형 모델 하나를 놓고 네 단계를 전부 직접 적는다.

$$\text{순전파} \rightarrow \text{로스} \rightarrow \text{경사(손으로 민 식)} \rightarrow \text{갱신}$$

자료는 $x = [1,2,3,4,5]$, $y = 2x$다. **답이 $w = 2$임을 미리 알고 있다.** 답을 아는 문제로 시작하는 까닭이 있다. 모르는 문제에서 틀렸을 때는 그것이 알고리즘 탓인지 문제 탓인지 가릴 수 없기 때문이다.

이 자료는 작고 단순해서 **모든 것을 손으로도 풀 수 있다.** 그래서 코드가 찍는 수를 식과 자리까지 맞춰 볼 수 있고, 이 쪽은 실제로 그렇게 한다.

---

## 1. 세 조각

모델은 $\hat{y} = wx$, 로스는 평균제곱오차다.

$$L(w) = \frac{1}{N}\sum_{i=1}^{N}(wx_i - y_i)^2$$

경사는 연쇄 법칙으로 민다.

$$\frac{dL}{dw} = \frac{1}{N}\sum_i 2(wx_i - y_i)\,x_i = \frac{2}{N}\sum_i x_i(\hat{y}_i - y_i)$$

코드로는 `np.mean(2 * x * (y_pred - y_true))` 한 줄이다.

### 쓰기 전에 검사한다

손으로 민 식은 틀리기 쉽다. **쓰기 전에 수치 미분과 견주는 것** 이 경사 검사(gradient check)이고, 자동 미분이 없던 시절에는 반드시 거치는 절차였다.

```
  w        손으로 민 식      중앙 차분         차이
  0.0        -44.00000000    -44.00000000  2.60e-09
  0.5        -33.00000000    -33.00000000  3.38e-09
  2.0         +0.00000000     +0.00000000  3.24e-15
  3.5        +33.00000000    +33.00000001  7.28e-09
```

여덟 자리까지 맞는다. 차이 $10^{-9}$는 중앙 차분의 절단 오차다.

$w = 2$에서 경사가 정확히 0인 것도 확인된다. 거기가 최솟값이다.

!!! note "중앙 차분을 쓰는 까닭"
    앞으로 차분 $\frac{f(w+h)-f(w)}{h}$의 오차는 $O(h)$지만 중앙 차분 $\frac{f(w+h)-f(w-h)}{2h}$의 오차는 $O(h^2)$다. 같은 $h$에서 훨씬 정확하다. 경사 검사에는 중앙 차분을 쓴다.

---

## 2. 이 자료의 로스는 포물선 하나다

$y_i = 2x_i$를 대입하면 로스가 접힌다.

$$L(w) = \frac{1}{N}\sum_i (wx_i - 2x_i)^2 = (w-2)^2 \cdot \frac{1}{N}\sum_i x_i^2$$

```
  mean(x^2) = 11.0
  y = 2x 이므로 L(w) = mean(x^2) (w-2)^2 = 11(w-2)^2
  따라서 L''(w) = 2 * 11 = 22 이고, 이것이 곡률이다
  수렴 조건 0 < eta < 2/L'' = 0.090909
  한 걸음에 끝내는 eta = 1/L'' = 0.045455

  식이 맞는지 몇 점에서 확인한다
  w      직접 잰 로스      11(w-2)^2
  0.0         44.000000       44.000000
  1.0         11.000000       11.000000
  2.0          0.000000        0.000000
  3.0         11.000000       11.000000
```

로스가 $11(w-2)^2$이라는 포물선 하나다. 그러면 [러닝레이트 쪽](learning_rate.md)에서 본 것이 전부 그대로 적용된다. 곡률이 $L'' = 22$이므로 수렴 조건은 $0 < \eta < 2/22 = 0.0909$이고, 한 걸음에 끝내는 값은 $\eta = 1/22 = 0.04545$다.

**이 수들을 미리 알고 학습에 들어간다.** 그래서 학습이 예상대로 가는지 아닌지를 판정할 수 있다.

---

## 3. 학습 루프

갱신은 $w \leftarrow w - \eta \frac{dL}{dw}$ 한 줄이다. 오차에 대해 풀면

$$w_{t} - 2 = (1 - 22\eta)^{t}(w_0 - 2)$$

이므로 **매 걸음의 값을 미리 적을 수 있다.** 루프가 찍는 값과 견준다.

```
  걸음   w            로스          경사        (1-22*eta)^t
     1      0.440000    44.000000    -44.0000      0.440000
     5      1.422565     6.028503    -16.2866      1.422565
     9      1.786262     0.825974     -6.0285      1.786262
    13      1.920885     0.113168     -2.2315      1.920885
    17      1.970715     0.015505     -0.8260      1.970715
    20      1.986103     0.003492     -0.3920      1.986103
  마지막 w = 1.986103,  목표 2.0,  오차 0.013897
```

두 번째 열과 마지막 열이 소수점 아래 여섯 자리까지 같다. **식과 코드가 같은 것을 하고 있다는 뜻이다.** 루프를 잘못 짰다면 여기서 갈렸을 것이다.

20걸음으로는 $w = 1.9861$까지밖에 못 간다. $0.78^{20} = 0.0069$이므로 처음 오차 2의 0.69%, 곧 0.0139가 남는다. 식이 그렇게 말하고 측정도 그렇다.

### 예측해 보면

```
  x     예측        참값      오차
  1        1.9861       2.0  0.0139
  2        3.9722       4.0  0.0278
  3        5.9583       6.0  0.0417
  4        7.9444       8.0  0.0556
  5        9.9305      10.0  0.0695
  자료에 없던 x 로도
  6       11.9166      12.0  0.0834
  7       13.9027      14.0  0.0973
  8       15.8888      16.0  0.1112
```

오차가 $x$에 정비례해 커진다. 당연하다. 예측 오차가 $(w - 2)x = -0.0139x$이기 때문이다.

!!! warning "이것은 일반화 성능이 아니다"
    $x = 6, 7, 8$은 "새 자료"처럼 보이지만 $y = 2x$라는 **생성 규칙에 대입해 만든 값** 이다. 모델이 그 규칙을 거의 맞혔으니 당연히 가깝다. 따로 모은 현실 자료에서 재어 본 일반화 성능이 아니다.

## 4. 러닝레이트를 바꾸면

2절에서 경계를 $\eta < 0.0909$로 미리 구해 두었다. 맞는지 본다.

```
  eta         20 걸음 뒤 w        오차          1-22*eta
  0.001000            0.718239      1.281761  +0.9780
  0.010000            1.986103      0.013897  +0.7800
  0.045455            2.000000      0.000000  +0.0000
  0.080000            1.991734      0.008266  -0.7600
  0.090909            0.000000      2.000000  -1.0000
  0.100000          -74.675200     76.675200  -1.2000
```

네 번째 열이 모든 것을 설명한다.

- $\eta = 1/22 = 0.045455$에서 $1 - 22\eta = 0$이고, **한 걸음에 정확히 2에 닿는다**
- $\eta = 0.01$과 $\eta = 0.08$은 $1-22\eta$가 $+0.78$과 $-0.76$으로 크기가 비슷하다. 그래서 20걸음 뒤 오차도 0.0139와 0.0083으로 비슷하다. 한쪽은 아래에서 올라오고 한쪽은 좌우로 튕기며 오는데 속도는 엇비슷하다
- $\eta = 0.090909 = 2/22$에서 $1-22\eta = -1$이다. 20걸음(짝수) 뒤 **출발점 0으로 정확히 돌아와 있다.** 0과 4를 오가며 제자리걸음이다
- $\eta = 0.1$은 $-74.68$로 발산한다

## 5. 잡음이 섞인 자료라면

지금까지는 $y$가 정확히 $2x$였다. 현실에서는 그렇지 않다.

```
  y 에 표준편차 1.0 인 잡음을 더하고 2000번 돌린다
  최소제곱 해 2000개:  평균 2.0028  퍼짐 1.4154~2.4388
  표준편차 0.1358
  이론값 sigma / sqrt(sum(x^2)) = 0.1348
```

평균은 2.0028로 참값 2에 모인다. **불편추정량이다.**

그러나 한 번의 답은 1.4154에서 2.4388까지 흩어진다. 표준편차 0.1358이고, 이론값 $\sigma/\sqrt{\sum x_i^2} = 1/\sqrt{55} = 0.1348$과 네 자리 중 셋이 맞는다.

**경사 하강법이 찾아 주는 것은 '참값 2'가 아니라 '이 자료의 최소제곱 해'다.** 자료가 흔들리면 그 답도 함께 흔들린다. 최적화를 아무리 잘해도 이 흔들림은 줄지 않는다. 줄이려면 자료를 더 모아야 한다($\sum x_i^2$가 커진다).

## 6. 전체 코드와 출력

```python
"""넘파이로 직접 하는 경사 하강법 — 자동 미분 없이.

자동 미분이 대신해 주는 일이 정확히 무엇인지 알려면 한 번은 손으로
해 보아야 한다. 절편 없는 선형 모델 하나를 놓고 네 단계를 직접 적는다.

    순전파 -> 로스 -> 경사(손으로 민 식) -> 갱신

자료는 x = [1,2,3,4,5], y = 2x 이므로 답이 w = 2 임을 미리 알고 있다.
답을 아는 문제로 시작하는 까닭은, 모르는 문제에서 틀렸을 때 그것이
알고리즘 탓인지 문제 탓인지 가릴 수 없기 때문이다.

실행: 이 쪽의 코드를 파일로 갈무리해 돌린다
"""
import numpy as np

X = np.array([1, 2, 3, 4, 5], dtype=np.float64)
Y = 2 * X                       # 참 관계: y = 2x, 곧 w* = 2


def header(title):
    print(f"\n=== {title} ===")


# ========================================================================
# 1. 세 조각을 손으로 적는다
# ========================================================================

def forward(x, w):
    """순전파 — 예측."""
    return w * x


def loss(y_true, y_pred):
    """평균제곱오차 L(w) = (1/N) sum (y_pred - y_true)^2."""
    return np.mean((y_pred - y_true) ** 2)


def gradient(x, y_true, y_pred):
    """dL/dw 를 손으로 민 식.

    L(w)  = (1/N) sum (w x_i - y_i)^2
    dL/dw = (1/N) sum 2 (w x_i - y_i) x_i
          = (2/N) sum x_i (y_pred_i - y_i)
    """
    return np.mean(2 * x * (y_pred - y_true))


# ========================================================================
# 2. 손으로 민 식이 맞는지 먼저 확인한다
# ========================================================================

def check_gradient():
    header("1. 손으로 민 식 vs 수치 미분")
    print("  믿고 쓰기 전에 차분으로 견준다. 이것이 경사 검사다")
    print("  w        손으로 민 식      중앙 차분         차이")
    h = 1e-6
    for w in (0.0, 0.5, 2.0, 3.5):
        analytic = gradient(X, Y, forward(X, w))
        numeric = (loss(Y, forward(X, w + h)) - loss(Y, forward(X, w - h))) / (2 * h)
        print(f"  {w:<8.1f} {analytic:+14.8f}  {numeric:+14.8f}  "
              f"{abs(analytic - numeric):.2e}")
    print("  w = 2 에서 경사가 0 이다. 거기가 최솟값이다")


# ========================================================================
# 3. 이 자료의 로스는 사실 포물선 하나다
# ========================================================================

def closed_form():
    header("2. 이 자료에서 로스의 꼴")
    m = np.mean(X ** 2)
    print(f"  mean(x^2) = {m:.1f}")
    print(f"  y = 2x 이므로 L(w) = mean(x^2) (w-2)^2 = {m:.0f}(w-2)^2")
    print(f"  따라서 L''(w) = 2 * {m:.0f} = {2*m:.0f} 이고, 이것이 곡률이다")
    print(f"  수렴 조건 0 < eta < 2/L'' = {2/(2*m):.6f}")
    print(f"  한 걸음에 끝내는 eta = 1/L'' = {1/(2*m):.6f}")

    print("\n  식이 맞는지 몇 점에서 확인한다")
    print("  w      직접 잰 로스      {:.0f}(w-2)^2".format(m))
    for w in (0.0, 1.0, 2.0, 3.0):
        print(f"  {w:<6.1f} {loss(Y, forward(X, w)):14.6f}  "
              f"{m * (w - 2) ** 2:14.6f}")


# ========================================================================
# 4. 학습 루프
# ========================================================================

def train(lr=0.01, steps=20, w0=0.0, verbose=True):
    w = w0
    ws, ls = [w], []
    if verbose:
        print("  걸음   w            로스          경사        (1-22*eta)^t")
    for t in range(steps):
        y_pred = forward(X, w)
        L = loss(Y, y_pred)
        g = gradient(X, Y, y_pred)
        w = w - lr * g
        ws.append(w)
        ls.append(L)
        if verbose and (t % 4 == 0 or t == steps - 1):
            # 오차가 매 걸음 (1 - 22*eta) 배가 된다는 예측
            pred = (w0 - 2) * (1 - 2 * np.mean(X ** 2) * lr) ** (t + 1) + 2
            print(f"  {t+1:>4}   {w:11.6f}  {L:11.6f}  {g:+10.4f}   "
                  f"{pred:11.6f}")
    return w, ws, ls


def training_loop():
    header("3. 학습 (lr = 0.01, 20 걸음, w0 = 0)")
    w, ws, ls = train()
    print(f"  마지막 w = {w:.6f},  목표 2.0,  오차 {abs(w-2):.6f}")
    print("  마지막 열은 손으로 푼 식 w_t - 2 = (1 - 22*eta)^t (w_0 - 2) 다")
    print("  루프가 찍는 값과 자리까지 같다 — 식과 코드가 같은 것을 한다")

    print("\n  배운 모델로 예측해 본다")
    print("  x     예측        참값      오차")
    for x, y in zip(X, Y):
        p = forward(x, w)
        print(f"  {x:<5.0f} {p:9.4f}  {y:8.1f}  {abs(p-y):.4f}")
    print("  자료에 없던 x 로도")
    for x in (6.0, 7.0, 8.0):
        print(f"  {x:<5.0f} {forward(x, w):9.4f}  {2*x:8.1f}  "
              f"{abs(forward(x, w)-2*x):.4f}")
    print("  x 가 클수록 오차가 크다. w 가 아직 2 에 못 미쳐서이고,")
    print("  그 모자람이 x 에 곱해지기 때문이다")


# ========================================================================
# 5. 러닝레이트를 바꿔 본다
# ========================================================================

def sweep_lr():
    header("4. 러닝레이트를 바꾸면 (20 걸음)")
    limit = 1 / np.mean(X ** 2)
    print(f"  2절에서 구한 경계는 eta < {limit:.6f} 였다")
    print("  eta         20 걸음 뒤 w        오차          1-22*eta")
    for lr in (0.001, 0.01, 1 / 22, 0.08, limit, 0.1):
        w, _, _ = train(lr=lr, steps=20, verbose=False)
        shown = f"{w:16.6f}" if abs(w) < 1e12 else f"{w:16.3e}"
        err = abs(w - 2)
        err_s = f"{err:.6f}" if err < 1e12 else f"{err:.3e}"
        print(f"  {lr:<11.6f} {shown}  {err_s:>12}  {1-22*lr:+.4f}")
    print(f"  eta = 1/22 = {1/22:.6f} 에서 한 걸음에 끝난다 (1-22*eta = 0)")
    print(f"  eta = {limit:.6f} 가 경계다. 거기서는 0 과 4 를 오가며 제자리다")
    print("  그 너머는 발산한다")


# ========================================================================
# 6. 자료에 잡음이 있으면
# ========================================================================

def with_noise():
    header("5. 잡음이 섞인 자료라면")
    rng = np.random.default_rng(0)
    print("  y 에 표준편차 1.0 인 잡음을 더하고 2000번 돌린다")
    print("  (자료가 바뀔 때마다 답도 바뀌므로 여러 번 재어야 한다)")
    found = []
    for _ in range(2000):
        Yn = Y + rng.normal(0, 1.0, size=Y.shape)
        # 최소제곱 해는 손으로도 나온다: w = sum(x y) / sum(x^2)
        found.append(float(np.sum(X * Yn) / np.sum(X ** 2)))
    found = np.array(found)
    print(f"  최소제곱 해 2000개:  평균 {found.mean():.4f}  "
          f"퍼짐 {found.min():.4f}~{found.max():.4f}")
    print(f"  표준편차 {found.std(ddof=1):.4f}")
    print("  이론값 sigma / sqrt(sum(x^2)) = "
          f"{1.0/np.sqrt(np.sum(X**2)):.4f}")
    print("  경사 하강법이 찾아 주는 것은 '참값 2' 가 아니라")
    print("  '이 자료의 최소제곱 해' 다. 자료가 흔들리면 그 답도 흔들린다")


def main():
    check_gradient()
    closed_form()
    training_loop()
    sweep_lr()
    with_noise()


if __name__ == "__main__":
    main()
```

## 연습문제

<div class="drillbox" markdown>

**연습문제 1.** <span class="diff easy" title="쉬움"></span>
$w = 0$일 때 (a) 로스 $L(0)$과 (b) 경사 $dL/dw$를 손으로 구하고, (c) $\eta = 0.01$로 한 걸음 뗀 뒤의 $w$를 구하라. 본문 1절과 3절의 출력과 맞는지 확인하라.

</div>

??? success "풀이"
    (a) $\hat{y} = 0$이므로 $L(0) = \frac{1}{5}(4 + 16 + 36 + 64 + 100) = \frac{220}{5} = 44$다. 2절의 식 $11(0-2)^2 = 44$와도 맞고, 3절 출력의 첫 줄 로스 44.000000과도 맞는다.

    (b) $\frac{dL}{dw} = \frac{2}{5}\sum_i x_i(0 - 2x_i) = -\frac{4}{5}\sum_i x_i^2 = -\frac{4}{5}(55) = -44$다. 1절 출력의 $w = 0$ 줄과 맞는다.

    (c) $w_1 = 0 - 0.01 \times (-44) = 0.44$다. 3절 출력의 첫 줄과 맞는다.

    경사가 음수라는 것은 $w$를 **키워야** 로스가 준다는 뜻이고, 실제로 0에서 0.44로 올라갔다.

**연습문제 2.** <span class="diff med" title="중간"></span>
입력 $x$를 모두 10배로 늘리고 정답은 다시 $y = 2x$로 두었다고 하자. 로스의 곡률과 수렴 가능한 러닝레이트 범위는 어떻게 바뀌는가?

</div>

??? success "풀이"
    $\frac{1}{N}\sum_i x_i^2$가 $11$에서 $1100$으로 **100배** 가 된다. 로스가 $1100(w-2)^2$이므로 곡률 $L''$도 $22$에서 $2200$으로 100배다.

    수렴 조건 $0 < \eta < 2/L''$의 상한이 $0.0909$에서 $0.000909$로, 곧 **100분의 1** 로 줄어든다.

    본문에서 쓴 $\eta = 0.01$을 그대로 두면 $1 - 2200 \times 0.01 = -21$이 되어 **걸음마다 오차가 21배씩 커진다.** 20걸음이면 $21^{20} \approx 2.8 \times 10^{26}$이다.

    **이것이 입력 정규화가 필요한 가장 직접적인 까닭이다.** 모델도 목표도 그대로이고 입력의 단위만 바꾸었는데(미터를 센티미터로 적었다든지) 러닝레이트를 100배 줄여야 한다. 특징마다 단위가 제각각이면 어느 하나에 맞춘 러닝레이트가 다른 것에는 맞지 않는다.

**연습문제 3.** <span class="diff med" title="중간"></span>
이 자료에서 $L(w) = 11(w-2)^2$임을 보이고, $w_0 = 0$, $\eta = 0.01$에서 첫 두 걸음을 손으로 계산하라.

</div>

??? success "풀이"
    $y_i = 2x_i$이므로

    $$L(w) = \frac{1}{N}\sum_i (wx_i - 2x_i)^2 = \frac{1}{N}\sum_i x_i^2 (w-2)^2 = 11(w-2)^2$$

    이다. $\frac{1}{5}(1+4+9+16+25) = \frac{55}{5} = 11$을 썼다.

    경사는 $\frac{dL}{dw} = 22(w-2)$다. 갱신은

    $$w_{t+1} = w_t - 0.01 \times 22(w_t - 2) = w_t - 0.22(w_t - 2)$$

    이고, 정리하면 $w_{t+1} - 2 = 0.78(w_t - 2)$다.

    - $w_1 = 0 - 0.22(0-2) = 0.44$
    - $w_2 = 0.44 - 0.22(0.44-2) = 0.44 + 0.3432 = 0.7832$

    확인: $w_2 - 2 = -1.2168 = 0.78^2 \times (-2) = -1.2168$. 맞는다.

**연습문제 4.** <span class="diff hard" title="어려움"></span>
모델에 절편을 넣어 $\hat{y} = wx + b$로 확장하라. 두 경사를 유도하고, 경사 검사로 확인한 뒤 $y = 2x + 1$인 자료에 맞춰 보라. 1차원일 때와 달라지는 점은 무엇인가?

</div>

??? success "풀이"
    오차를 $e_i = wx_i + b - y_i$라 두면

    $$\frac{\partial L}{\partial w} = \frac{2}{N}\sum_i x_i e_i, \qquad \frac{\partial L}{\partial b} = \frac{2}{N}\sum_i e_i$$

    이다. 두 경사는 **같은(갱신 전) 파라메터에서** 계산한 뒤 함께 적용해야 한다. 하나를 갱신하고 그 값으로 다른 하나를 계산하면 경사 하강법이 아니다.

    ```python
    import numpy as np

    X = np.array([1., 2., 3., 4., 5.])
    Y = 2 * X + 1.0                      # 절편 1 을 넣은 자료

    def L(w, b):
        return np.mean((w * X + b - Y) ** 2)

    def grads(w, b):
        e = w * X + b - Y
        return np.mean(2 * X * e), np.mean(2 * e)

    h = 1e-6
    for (w, b) in [(0., 0.), (1.5, 0.5)]:
        gw, gb = grads(w, b)
        nw = (L(w + h, b) - L(w - h, b)) / (2 * h)
        nb = (L(w, b + h) - L(w, b - h)) / (2 * h)
        print(f"  (w,b)=({w},{b})  dL/dw 손 {gw:+.6f} 차분 {nw:+.6f}   "
              f"dL/db 손 {gb:+.6f} 차분 {nb:+.6f}")

    w, b = 0., 0.
    for _ in range(3000):
        gw, gb = grads(w, b)
        w -= 0.01 * gw
        b -= 0.01 * gb
    print(f"  3000 걸음 뒤  w = {w:.6f}, b = {b:.6f}   (참값 2, 1)")

    A = np.vstack([X, np.ones_like(X)]).T
    sol = np.linalg.lstsq(A, Y, rcond=None)[0]
    print(f"  정규방정식    w = {sol[0]:.6f}, b = {sol[1]:.6f}")

    w2 = np.sum(X * Y) / np.sum(X * X)         # 절편 없는 모델이라면
    print(f"  절편 없는 모델의 최적 w = {w2:.6f},  "
          f"그때 로스 {np.mean((w2 * X - Y) ** 2):.6f}")
    print(f"  절편 있는 모델의 로스 {np.mean((sol[0]*X+sol[1]-Y)**2):.2e}")

    H = 2 * np.array([[np.mean(X * X), np.mean(X)], [np.mean(X), 1.0]])
    ev = np.linalg.eigvalsh(H)
    print(f"  헤세의 고윳값 {ev[0]:.4f}, {ev[1]:.4f}  조건수 {ev[1]/ev[0]:.2f}")
    print(f"  수렴 조건 eta < 2/{ev[1]:.4f} = {2/ev[1]:.6f}")
    ```

    **달라지는 점 셋.**

    첫째, **걸음이 훨씬 많이 든다.** 1차원에서는 20걸음에 0.0139까지 갔는데 여기서는 3,000걸음을 써야 $10^{-5}$ 자리다. 까닭은 마지막 두 줄에 있다 — 헤세의 고윳값이 0.338과 23.66이고 **조건수가 70** 이다. [러닝레이트 쪽](learning_rate.md) 2절대로, 수렴 속도가 $\frac{\kappa-1}{\kappa+1} = \frac{69}{71} = 0.972$에 묶인다. 한 걸음에 2.8%씩밖에 못 줄인다.

    조건수가 커진 까닭도 분명하다. $x$가 1에서 5까지라 평균이 3이고, $w$와 $b$가 **강하게 상관되어 있다** — 기울기를 조금 키우면 절편을 내려서 메울 수 있다. 입력을 중심화하면($x \to x - \bar{x}$) 이 상관이 사라지고 조건수가 크게 준다.

    둘째, **모델을 잘못 고르면 최적화로는 못 고친다.** 같은 자료를 절편 없는 모델로 맞추면 최선이 $w = 2.2727$이고 로스가 0.1818에서 멈춘다. 절편을 넣으면 로스가 $10^{-30}$이다. 0.1818은 최적화가 덜 된 것이 아니라 **그 모델이 낼 수 있는 가장 좋은 값** 이다.

    셋째, **경사 검사가 더 중요해진다.** 파라메터가 둘이면 한쪽 식만 틀려도 학습이 조용히 이상해진다. 위 코드가 두 점에서 두 경사를 모두 확인하는 까닭이다.

## 정리하며

1. **경사 검사를 먼저 한다**: 손으로 민 식과 중앙 차분이 여덟 자리까지 맞는 것을 보고 나서 쓴다
2. **이 자료의 로스는 $11(w-2)^2$이다**: 그래서 곡률 22, 수렴 경계 0.0909, 한 걸음 해 0.04545를 학습 전에 미리 알 수 있다
3. **루프가 찍는 값이 손으로 푼 식과 여섯 자리까지 같다**: $w_t - 2 = (1-22\eta)^t(w_0-2)$
4. **$\eta$를 바꾸면 $1-22\eta$ 하나가 전부를 설명한다**: 0이면 한 걸음, $-1$이면 제자리, 절댓값이 1을 넘으면 발산
5. **입력의 척도가 바뀌면 러닝레이트도 바뀌어야 한다**: $x$를 10배 하면 허용 범위가 100분의 1이 된다
6. **최적화가 찾아 주는 것은 참값이 아니라 그 자료의 최소제곱 해다**: 잡음이 있으면 답이 표준편차 0.1358로 흔들리고, 이것은 더 잘 최적화해서 줄일 수 있는 것이 아니다
7. **절편을 넣으면 조건수가 70이 된다**: 파라메터가 하나 늘었을 뿐인데 걸음이 150배 든다. 입력을 중심화하면 줄어든다
