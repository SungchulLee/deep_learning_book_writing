# 37장: 기초와 밸류 함수

강화학습은 에이전트가 둘레(환경)와 상호작용하며 리워드 신호를 받아 순차적 결정을 내리는 법을 배우는 문제를 다룬다. 이 장은 마르코프 결정 과정, 밸류 함수, 동적 계획법, 몬테카를로 방법, 시간차 학습, 탐험 전략을 다루며 강화학습의 수학적 기초를 맨바닥부터 쌓는다. 이 기초가 뒤 장의 심층 강화학습 방법에 꼭 필요한 벽돌이 된다.

이 장을 읽으면 하나의 짜임새 있는 틀처럼 보인다. 리워드를 할인하고, 밸류를 정의하고, 재귀식(벨먼 방정식)을 세우고, 표본으로 그것을 배운다. 그런데 이 장의 각 쪽에 달아 둔 상자들이 가리키는 날짜를 한 줄에 모아 보면 **예순일곱 해**가 나온다. 그리고 가져온 자리가 저마다 다르다.

![가로로 뻗은 시간선에 열 개의 날짜가 찍혀 있다. 1937년 새뮤얼슨의 할인, 1957년 벨먼의 최적성 원리, 1960년 하워드의 폴리시 반복, 1961년 민스키의 신용 배분, 1972년 클로프의 자격, 1988년 서턴의 TD 람다, 1989년 왓킨스의 Q 학습, 물결표가 붙은 1990년 서턴과 리트먼의 리워드 가설, 1992년 왓킨스와 데이안의 수렴 증명, 2004년 서턴의 밸류 함수 가설이다. 색으로 경제학, 운영과학, 인공지능, 신경과학, 강화학습 다섯 갈래를 구분해 두었다.](figures/chapter_timeline.svg)

리워드를 $\gamma^t$ 로 할인하는 셈법은 **경제학**에서 왔고(1937), 벨먼 방정식과 그것을 푸는 알고리즘은 **운영과학**에서 왔다(1957, 1960). 공로를 누구에게 돌릴 것인가라는 물음은 **인공지능**이 내놓았고(1961), 자격 추적은 **신경과학**의 시냅스 이론에서 왔다(1972). 강화학습이라는 이름 아래에서 만들어진 것은 사실 뒤쪽 다섯 개뿐이다.

**그러니 이 장의 짜임새는 뒤늦게 생긴 것이다.** 1937년의 새뮤얼슨은 에이전트를 생각하지 않았고, 1961년의 민스키는 밸류 함수를 염두에 두지 않았다. 각자 자기 문제를 풀려고 만든 조각들이 나중에 **맞아떨어지는 것으로 밝혀졌을** 뿐, 하나에서 다른 하나가 연역되어 나온 것이 아니다. 이어진 순서대로 읽으면 필연처럼 보이는데, 실제로는 그렇게 자라지 않았다.

**그리고 시간선의 가장 최근 두 자리가 모두 "가설"이다.** 리워드 가설(~1990)과 밸류 함수 가설(2004) — 이 장이 딛고 선 두 전제가 증명된 정리가 아니라 **이름 붙은 추측**이다. 하나는 연도에 물결표까지 달려 있다. 기초를 맨바닥부터 쌓는다는 이 장의 말은 그래서 **증명된 바닥에서 출발한다는 뜻이 아니라**, 무엇을 가정하고 들어가는지를 또렷이 적어 두고 출발한다는 뜻으로 읽는 편이 맞다.

_확인한 곳 — 이 시간선의 열 개 날짜는 모두 이 장의 쪽들에 쓴 상자에서 왔고, 그림을 그리는 코드가 날짜마다 그 출처 쪽이 실제로 있는지 `assert` 로 확인한 뒤에 그린다. 각 날짜의 원 출처는 그 쪽의 「확인한 곳」에 적어 두었다._

## 1. 세 트레인 틀 가운데 어디인가

강화학습이 남다른 까닭은 다른 두 틀과 견주어야 또렷해진다.

| | 입력 데이터 | 출력 | 목표 |
|---|---|---|---|
| 지도 학습 | $\{(x_i, y_i)\}$ | 정답 $Y$ | 문제와 정답의 짝을 배운다 |
| 비지도 학습 | $\{x_i\}$ | 축소된 표현 $X'$ | 구조를 찾아 모델을 가볍게 한다 |
| 강화학습 | $x_0 \xrightarrow{a_0} x_1 \xrightarrow{a_1} \cdots$ | 액션 | 목표를 향해 액션을 고른다 |

**지도 학습**에는 정답이 있고 액션이 없다. 한 번 답하고 끝난다. MNIST 손글씨 분류, 우편 번호 인식, 주차장 정산기의 번호판 읽기가 여기에 든다.

**비지도 학습**에는 정답이 없다. 대신 데이터 안의 구조를 찾는다. 대표적인 예가 차원 축소다. 공이 날아가는 화면이라면 픽셀을 모두 들고 있을 까닭 없이 공의 위치·속도·가속도만 알면 된다. 차원이 줄면 모델도 함께 줄어든다. $10$차원 입력에 파라미터가 $10 \times 10 = 100$개 들던 선형 레이어가, 입력이 $3$차원으로 줄면 $3 \times 3 = 9$개로 준다.

**강화학습**의 데이터는 장면 1, 장면 2로 이어지는 시퀀스다. 출력이 정답이 아니라 **액션**이며, 목표를 향해 그 액션을 고쳐 나간다. 방을 가장 짧은 시간에 다 쓸어야 하는 로봇 청소기가 매 순간 어디로 갈지 고르는 일, 알파고와 DQN이 모두 이 틀이다. 곧 여기서 배우는 것은 **액션 결정하기**다.

## 2. 차례

### 32.1 소개

- 강화학습 둘러보기 -- 셋째 트레인 틀로서의 강화학습, 남다른 점, 지도 학습·비지도 학습과의 비교
- 에이전트-둘레 인터페이스 -- 상호작용 루프, 궤적, 상태, 액션, 리워드, 에이전트와 둘레의 엄밀한 추상화
- [리워드 가설](introduction/reward_hypothesis.md) -- 모든 목표를 누적 리워드의 최대화로 적을 수 있다는 기초 가정

### 32.2 마르코프 결정 과정

- 마르코프 결정 과정의 기초 -- 엄밀한 정의, 마르코프 성질, 순차적 결정의 수학 틀
- 상태와 액션 -- 이산·연속 상태와 액션 공간, 상태 표현의 설계 원칙
- 전이 동역학 -- 전이 함수, 행렬 표현, 모델 기반 설정과 모델 없는 설정
- 리워드 함수 -- 인수가 하나, 둘, 셋인 리워드 표기와 설계에서 살필 것
- [할인율](mdp/discount.md) -- 수렴을 위한 할인, 경제학적 해석, 에이전트 행동에 주는 영향

### 32.3 밸류 함수

- [상태 밸류 함수](value_functions/state_value.md) -- 폴리시 아래의 기대 리턴, 성질, 유한 마르코프 결정 과정의 계산
- [액션 밸류 함수](value_functions/action_value.md) -- Q 함수의 정의, 상태 밸류와의 관계, 모델 없는 제어에서의 역할
- [벨먼 방정식](value_functions/bellman.md) -- 모든 강화학습 알고리즘의 수학 기초가 되는 밸류 함수의 재귀 분해
- 벨먼 최적 방정식 -- 최적 밸류 함수, 그리고 폴리시 평균을 대신하는 최대 연산자

### 32.4 동적 계획법

- 폴리시 평가 -- 벨먼 갱신으로 주어진 폴리시의 상태 밸류 함수를 되풀이해 계산
- 폴리시 개선 -- 그리디 액션 선택으로 밸류 함수에서 더 좋은 폴리시 만들기
- [폴리시 반복](dynamic_programming/policy_iteration.md) -- 평가와 개선을 번갈아 하여 최적 폴리시로 수렴시키기
- 가치 반복 -- 벨먼 최적 연산자를 써서 최적 밸류 함수를 직접 계산

### 32.5 몬테카를로 방법

- 몬테카를로 예측 -- 샘플링한 에피소드의 리턴을 평균 내어 모델 없이 값 추정하기
- 몬테카를로 제어 -- 탐험적 시작과 엡실론 소프트 폴리시로 Q 값을 추정해 최적 폴리시 찾기
- 오프폴리시 몬테카를로 -- 다른 행동 폴리시가 낸 데이터로 타깃 폴리시를 학습하기
- 중요도 샘플링 -- 오프폴리시 추정을 위해 리턴에 웨이트를 다시 매기는 일반 버전과 가중 버전

### 32.6 시간차 학습

- 시간차 예측 -- 몬테카를로의 경험 기반 트레인과 동적 계획법의 부트스트래핑을 결합해 스텝마다 값 갱신하기
- TD(0) -- 시간차 오차 신호로 상태 값을 추정하는 가장 단순한 한 스텝 시간차 알고리즘
- SARSA -- Q 값 트레인을 위해 상태-액션-리워드-상태-액션 다섯 값을 쓰는 온폴리시 시간차 제어
- Q 학습 -- 탐험 폴리시와 상관없이 최적 액션 밸류 함수를 곧바로 배우는 오프폴리시 시간차 제어
- 기대 SARSA -- 다음 액션 분포에 대한 기대 Q 값을 써서 분산을 줄인 시간차 제어

### 32.7 n-step 방법

- n-step 시간차 예측 -- 실제 리워드를 n-step 받은 뒤에 부트스트랩해 TD(0)과 몬테카를로를 잇기
- n-step SARSA -- 편향과 분산의 트레이드오프를 조절할 수 있도록 n-step 리턴으로 SARSA 확장
- [TD(람다)](n_step/td_lambda.md) -- 람다 리턴으로 모든 n-step 리턴을 지수 웨이트로 합치기
- [자격 추적(Eligibility Traces)](n_step/eligibility_traces.md) -- TD(람다)를 후방 관점으로 효율적으로 구현한 단기 기억 구조

### 32.8 함수 근사

- 선형 함수 근사 -- 큰 상태 공간을 위한 선형 웨이트의 파라미터화된 밸류 함수와 준그래디언트 시간차 갱신
- 강화학습의 피처 설계 -- 쓸모 있는 상태 표현을 위한 다항식, 타일 코딩, 방사 기저 함수 피처
- 수렴 문제 -- 함수 근사, 부트스트래핑, 오프폴리시 학습의 죽음의 삼각

### 32.9 탐험 전략

- 엡실론 그리디 -- 확률 엡실론으로 하는 단순한 무작위 탐험과 흔한 감쇠 스케줄
- 상한 신뢰 구간(UCB) -- 방문 횟수에 기반한 탐험 보너스로 구현하는 불확실성 앞의 낙관주의
- 볼츠만 탐험 -- 온도로 탐험과 활용의 트레이드오프를 조절하는 소프트맥스 액션 선택
- 탐험 보너스 -- 카운트 기반, 밀도 기반, 예측 오차 기반의 참신성 리워드로 구현하는 내재적 동기
