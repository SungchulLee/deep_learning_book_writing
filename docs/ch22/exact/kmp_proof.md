# KMP의 옳음
커누스-모리스-프랫(KMP) 알고리즘은 글월 $T[0..n-1]$에서 본 $P[0..m-1]$이 나오는 곳을 모두 $O(n+m)$ 시간에 찾는다. 이 쪽은 그 옳음과 도는 시간의 엄밀한 증명을 보인다.

---

## 1. 알고리즘 되짚기

KMP는 글월 가리개 $i$과 본 가리개 $j$을 둔다. $T[i] = P[j]$이면 둘 다 앞으로 간다. 맞지 않거나 온전히 맞은 뒤에는 $\pi$이 어긋남 함수일 때 $j$을 $\pi[j-1]$(또는 $\pi[m-1]$)으로 되돌린다. 글월 가리개 $i$은 결코 뒤로 가지 않는다.

```python
def kmp_search(text: str, pattern: str) -> list[int]:
    """KMP 글줄 찾기 알고리즘."""
    n, m = len(text), len(pattern)
    if m == 0:
        return []

    # 어긋남 함수를 세운다
    pi = [0] * m
    k = 0
    for i in range(1, m):
        while k > 0 and pattern[k] != pattern[i]:
            k = pi[k - 1]
        if pattern[k] == pattern[i]:
            k += 1
        pi[i] = k

    # 탐색
    occurrences = []
    j = 0
    for i in range(n):
        while j > 0 and pattern[j] != text[i]:
            j = pi[j - 1]
        if pattern[j] == text[i]:
            j += 1
        if j == m:
            occurrences.append(i - m + 1)
            j = pi[j - 1]
    return occurrences

# 예
text = "ABABDABACDABABCABAB"
pattern = "ABABCABAB"
print(kmp_search(text, pattern))
# 내놓기: [9]
```

**출력:**

```
[10]
```

## 2. 옳음의 증명

**정리.** KMP가 자리 $s$을 알릴 필요충분조건은 $T[s..s+m-1] = P[0..m-1]$인 것이다.

**증명.** 다음 되풀이 불변량을 밝힌다:

*글월 번호 $i$의 되풀이가 시작할 때 $j$의 값은 $T[0..i-1]$의 뒷가지와 맞는 $P$의 가장 긴 진앞가지의 길이와 같다.*

**첫자리매김:** 되풀이 앞에서 $i = 0$, $j = 0$이다. 아직 글자를 견주지 않았으므로 맞는 가장 긴 앞가지의 길이는 0이다. 불변량이 성립한다.

**지킴:** 되풀이 $i$이 시작할 때 불변량이 성립한다고 하자. 그러면 $P[0..j-1] = T[i-j..i-1]$이다.

- $T[i] = P[j]$이면 $P[0..j] = T[i-j..i]$이므로 $j$을 하나 늘린 뒤 $i+1$에 대해 불변량이 성립한다.
- $T[i] \neq P[j]$이고 $j > 0$이면 $j = \pi[j-1]$으로 둔다. $\pi$의 정의에 따라 $P[0..\pi[j-1]-1]$은 $P[0..j-1]$의 진앞가지이면서 뒷가지인 가장 긴 것이다. $P[0..j-1] = T[i-j..i-1]$이므로 $P[0..\pi[j-1]-1] = T[i-\pi[j-1]..i-1]$이 되어 불변량이 지켜진다. 맞는 것을 찾거나 $j = 0$이 될 때까지 되풀이한다.
- $j = 0$이고 $T[i] \neq P[0]$이면 $P$의 어떤 앞가지도 $T[0..i]$의 어떤 뒷가지와도 맞지 않으므로 $j$은 0에 머문다.

**끝남:** $j = m$일 때 불변량이 $P[0..m-1] = T[i-m+1..i]$을 주므로 자리 $i - m + 1$의 옳은 맞음을 알린다. $j = \pi[m-1]$으로 두면 겹치는 맞음도 옳게 다룬다. $\square$

---

## 3. 시간 복잡도 증명

**정리.** KMP는 $O(n + m)$ 시간에 돈다.

**증명.** 위치 에너지 $\Phi = j$(본에서의 지금 자리)을 정한다. for 되풀이마다:

- $j \gets j + 1$으로 이어지는 글자 견줌마다 $\Phi$이 1 는다.
- 물러남 $j \gets \pi[j-1]$마다 ($\pi[j-1] < j$이므로) $\Phi$이 딱 잘라 줄어든다.
- $\Phi$은 늘 음이 아니고 for 되풀이마다 많아야 1 는다.

$n$번의 되풀이 전체에서 $\Phi$은 많아야 $n$번 는다. $\Phi \ge 0$이므로 줄어드는 총 횟수(물러남 연산)도 많아야 $n$이다. 따라서 찾기 마디의 전체 일감은 $O(n)$이다. 미리 다듬기 마디도 같은 논증으로 $O(m)$이 든다. 모두 $O(n + m)$이다. $\square$

## 연습문제

**연습문제 1.**
막무가내 글자열 짝짓기 알고리즘, KMP, 보이어-무어의 가장 나쁜 경우 시간 복잡도를 견주어라.

??? success "연습문제 1 풀이"
    | 알고리즘 | 가장 나쁜 경우 | 가장 좋은 경우 | 공간 |
    |-----------|-----------|-----------|-------|
    | 막무가내 | $O(nm)$ | $O(n)$ | $O(1)$ |
    | KMP | $O(n + m)$ | $O(n)$ | 어그러짐 함수에 $O(m)$ |
    | 보이어-무어 | $O(nm)$(병적인 경우) | $O(n/m)$(선형 아래!) | $O(m + |\Sigma|)$ |

    KMP는 한 줄 시간을 보장한다. 보이어-무어는 (글자를 건너뛰므로) 실전에서 대개 더 빠르지만 갈릴 다듬기를 쓰지 않으면 가장 나쁜 경우 $O(nm)$이다.

**연습문제 2.**
글 $T$ = "ABABCABABD"과 무늬 $P$ = "ABABD"에 대해 알고리즘이 도는 과정을 견줌마다 보이며 좇아라.

??? success "연습문제 2 풀이"
    자리 0에서 시작: P[0]='A'와 T[0]='A' 견줌(맞음), P[1]='B'와 T[1]='B'(맞음), P[2]='A'와 T[2]='A'(맞음), P[3]='B'와 T[3]='B'(맞음), P[4]='D'와 T[4]='C'(어긋남). 어그러짐 함수 또는 밀기 규칙으로 무늬를 민다. 자리 2에서 시작(KMP는 어그러짐 함수로 다시 견주지 않는다). 끝내 자리 5에서 맞는 곳을 찾는다. 이 알고리즘은 모두 많아야 $2n$번 견준다.

---

**연습문제 3.**
KMP의 어그러짐 함수란 무엇인가? 무늬 "ABABCAB"에 대해 셈하여라.

??? success "연습문제 3 풀이"
    어긋남 함수 $\pi[i]$은 $P[0..i]$의 앞가지이면서 뒷가지이기도 한 가장 긴 진앞가지의 길이를 준다. "ABABCAB"에 대해:

    | $i$ | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
    |-----|---|---|---|---|---|---|---|
    | $P[i]$ | A | B | A | B | C | A | B |
    | $\pi[i]$ | 0 | 0 | 1 | 2 | 0 | 1 | 2 |

    예컨대 "AB"이 "ABAB"의 앞가지이자 뒷가지이므로 $\pi[3] = 2$이다.

---

**연습문제 4.**
라빈-카프에 쓰이는 굴리는 해시 재주를 설명하여라. 헛맞음이 일어날 확률은 얼마인가?

??? success "연습문제 4 풀이"
    라빈-카프는 본의 흩는 값을 셈하고 글월 위로 흩는 창을 미끄러뜨린다. **구르는 흩는 값**은 $O(1)$에 새로 고친다. 곧 $d$이 밑이고 $q$이 소수일 때 $h(T[i+1..i+m]) = (h(T[i..i+m-1]) - T[i] \cdot d^{m-1}) \cdot d + T[i+m] \pmod{q}$이다. 흩는 값은 맞는데 글줄이 다르면 헛맞음이 난다. 아무 소수 $q$에 대해 헛맞음 한 번의 확률은 $O(1/q)$이고 자리 $n-m+1$개에 대한 헛맞음의 기댓값은 $O(n/q)$이다. $q \approx n^2$을 고르면 헛맞음이 기대상 $O(1)$이다.
