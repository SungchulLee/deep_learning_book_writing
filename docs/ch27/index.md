# 28장: 정규화 흐름

정규화 흐름(normalizing flow)은 계산하기 쉬운 기저 분포를 가역 변환으로 옮겨 복잡한 연속 분포를 모델링한다. 같은 차원의 가역 변환과 계산 가능한 야코비안 행렬식을 이용하면 주어진 모형의 밀도를 직접 계산할 수 있다. 실제 데이터 분포를 정확히 학습한다거나 생성 품질이 자동으로 보장된다는 뜻은 아니다.

## 1. 변수 변환과 방향

생성 방향을 x=g(z), z~p_Z로 두면 다음과 같다.

$$p_X(x)=p_Z(g^{-1}(x))\left|\det Dg^{-1}(x)\right|.$$

로그밀도는 기저 로그밀도와 역방향 로그 절댓값 행렬식의 합이다. 생성 방향의 값을 사용하면 부호를 바꾼다. 이 장의 RealNVP 예제는 forward가 데이터→기저이고 공통 도구는 기저→데이터이므로 각 구현의 계약을 먼저 확인한다.

밀도 계산·역변환·표본 생성의 비용은 구조에 따라 달라진다. 모든 흐름에서 양방향이 똑같이 빠른 것은 아니며 수치적으로 유한한 스케일과 적절한 입력 영역도 필요하다.

## 2. 읽기 순서

- [RealNVP와 아핀 커플링 레이어](flow_architectures/realnvp.md): 삼각 야코비안, 교대 마스크와 양방향 계산
- [정규화 흐름의 공통 도구](flow_architectures/flow_utils.md): 기저 분포·합성·아핀·planar 예제와 학습·시각화 계약
- [MNIST 정규화 흐름 예제](flow_architectures/example_mnist_flows.md): 커플링 학습, 이미지 연속화와 bits/dim 해석

커플링에서는 한 그룹에서 계산한 스케일·이동으로 다른 그룹을 바꾼다. 조건 네트워크를 가역적으로 만들 필요는 없지만 같은 입력에서 같은 값을 계산해야 하고 그 계산비용도 남는다. planar 예제는 가역성 제약과 역변환이 미완성이므로 완성된 밀도 모델로 사용할 수 있는 범위를 구분한다.

## 3. 우도와 생성 결과를 평가하는 기준

연속 밀도와 정수 이미지의 확률 질량은 다르다. Dequantization·전처리 야코비안·픽셀 구간 보정을 맞춰야 bits/dim을 비교할 수 있다. 또한 학습 중 현재 배치 통계로 정규화하는 연산은 고정 통계의 가역 선형 변환과 다른 계산이다. 각 절에서 제공 코드의 한계를 설명한다.

검증 로그밀도, 사전 표본의 품질·다양성, 계산비용을 각각 평가한다. 출력 clipping은 생성 후처리로 분포를 바꾸므로 원래 흐름 표본과 구분하고, 체크포인트에는 구조·전처리·평가 설정도 기록해야 한다.

## 정리하며

이 장은 커플링의 수학, 공통 도구와 MNIST 예제를 연결한다. 핵심은 변환 방향·가역성·야코비안과 데이터 전처리의 일관성이다. 계산 가능한 밀도와 실제 생성 성능을 구분하면 흐름의 장점과 구현 한계를 정확히 이해할 수 있다.
