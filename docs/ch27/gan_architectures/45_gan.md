# 맞겨루기 만들개

맞겨루기 만들개(GAN)는 맞겨루기 익히기로 만들어 내는 모델에 뒤엎는 방식을 들여왔다. 신경망 둘, 곧 만들개와 가름개가 서로 겨룬다. 만들개는 그럴듯한 자료를 내려 하고 가름개는 실제 표본과 만든 표본을 가려내려 한다. 이 맞겨루는 움직임이 두 신경망을 함께 나아지게 하여 마침내 품질 높은 자료를 만들어 낸다.

## 1. 코드

```python
#!/usr/bin/env python3
'''
GAN - 맞겨루기 만들개
논문: "Generative Adversarial Networks" (2014)
고갱이: 맞겨루며 익히는 두 그물(만들개와 가름개)
'''
import torch
import torch.nn as nn

# ========================================================================
# 메인
# ========================================================================

class Generator(nn.Module):
    def __init__(self, latent_dim=100, img_size=28):
        super().__init__()
        self.img_size = img_size
        
        self.model = nn.Sequential(
            nn.Linear(latent_dim, 128),
            nn.LeakyReLU(0.2, inplace=True),
            nn.Linear(128, 256),
            nn.BatchNorm1d(256),
            nn.LeakyReLU(0.2, inplace=True),
            nn.Linear(256, 512),
            nn.BatchNorm1d(512),
            nn.LeakyReLU(0.2, inplace=True),
            nn.Linear(512, 1024),
            nn.BatchNorm1d(1024),
            nn.LeakyReLU(0.2, inplace=True),
            nn.Linear(1024, img_size * img_size * 1),
            nn.Tanh()
        )
    
    def forward(self, z):
        img = self.model(z)
        img = img.view(img.size(0), 1, self.img_size, self.img_size)
        return img

class Discriminator(nn.Module):
    def __init__(self, img_size=28):
        super().__init__()
        
        self.model = nn.Sequential(
            nn.Linear(img_size * img_size * 1, 512),
            nn.LeakyReLU(0.2, inplace=True),
            nn.Linear(512, 256),
            nn.LeakyReLU(0.2, inplace=True),
            nn.Linear(256, 1),
            nn.Sigmoid()
        )
    
    def forward(self, img):
        img_flat = img.view(img.size(0), -1)
        validity = self.model(img_flat)
        return validity

class GAN(nn.Module):
    def __init__(self, latent_dim=100, img_size=28):
        super().__init__()
        self.generator = Generator(latent_dim, img_size)
        self.discriminator = Discriminator(img_size)
    
    def forward(self, z):
        return self.generator(z)

if __name__ == "__main__":
    model = GAN()
    print(f"Generator Parameters: {sum(p.numel() for p in model.generator.parameters()):,}")
    print(f"Discriminator Parameters: {sum(p.numel() for p in model.discriminator.parameters()):,}")
```

**출력:**

```
Generator Parameters: 1,510,032
Discriminator Parameters: 533,505
```

## 2. 논의

맞겨루기 만들개 얼개는 겨루는 신경망 둘로 이루어진다. 만들개는 아무 숨은 벡터 $z \sim \mathcal{N}(0, I)$을 묶음 고르게 맞추기와 LeakyReLU 깨움을 갖춘 온전 이음 층 여러 개를 지나 옮기고 마침내 Tanh 내놓기로 그림을 만든다. 가름개는 (실제이든 만든 것이든) 그림을 받아 들임이 실제인지 나타내는 확률을 내놓는다. 이 맞겨루기 채비는 최소최대 목표로 갖추어 적는다.

$$
\min_G \max_D \; \mathbb{E}_{x \sim p_{\text{data}}}[\log D(x)] + \mathbb{E}_{z \sim p_z}[\log(1 - D(G(z)))]
$$

이 짜기의 만들개는 차츰 넓히는 얼개를 써서 그림 공간으로 쏘기 앞에 낱개를 128에서 1024까지 늘린다. 묶음 고르게 맞추기는 중간 깨움을 고르게 맞추어 익히기를 안정시키고, 기울기 0.2인 LeakyReLU은 신경 세포가 죽는 것을 막는다. 가름개는 이를 거울처럼 뒤집은 오그리는 얼개로 펼친 그림에서 시그모이드 내놓기 하나로 차원을 줄인다.

맞겨루는 움직임 탓에 맞겨루기 만들개를 익히기는 몹시 어렵기로 이름났다. 만들개가 좁은 범위의 내놓기만 내는 봉우리 무너짐과 익히기의 불안정이 흔한 문제이다. 만들개와 가름개 익히기의 균형이 결정적이다. 곧 가름개가 너무 세면 만들개의 기울기가 사라지고, 너무 여리면 쓸모 있는 신호를 주지 못한다. 이런 어려움에도 맞겨루기 만들개 틀은 놀랍도록 두루 쓸 만함이 드러났고 여러 앞선 만들어 내는 얼개의 바탕이 된다.

`latent_dim=100`과 `img_size=28`에서 만들개와 가름개의 매개변수 총수를 셈하라. 어느 신경망이 매개변수가 더 많은가? 그것이 익히기의 안정에 왜 중요할 수 있는가?

</div>

??? success "연습문제 1 풀이"
    만들개: Linear(100, 128) = 12,928; Linear(128, 256) + BN(256) = 33,536; Linear(256, 512) + BN(512) = 132,096; Linear(512, 1024) + BN(1024) = 527,360; Linear(1024, 784) = 803,600. 만들개 매개변수 총수는 약 1,509,520이다.

**연습문제 2.** <span class="diff med" title="중간"></span>
만들개는 왜 마지막 깨움으로 `nn.Tanh()`을 쓰고 가름개는 `nn.Sigmoid()`을 쓰는지 설명하라. 둘을 바꾸면 어떻게 되는가?

</div>

??? success "연습문제 2 풀이"
    만들개는 Tanh으로 $[-1, 1]$ 안의 값을 내어 고르게 맞춘 실제 그림의 범위와 맞춘다. 가름개는 시그모이드로 $[0, 1]$ 안의 확률을 내어 들임이 실제일 가능도를 나타낸다. 가름개에 Tanh을 쓰면 내놓기가 올바른 확률이 아니어서 두값 어긋 엔트로피 손실이 깨진다. 만들개에 시그모이드를 쓰면 내놓기가 $[0, 1]$으로 갇히는데, 이는 올바른 범위이긴 하나 Tanh에 견주어 가장자리 가까이에서 기울기가 여려 익히기가 느려질 수 있다.

**연습문제 3.** <span class="diff med" title="중간"></span>
맞겨루기 만들개를 크기 $64 \times 64$인 RGB 그림에 맞게 고쳐라. 만들개와 가름개 얼개에 어떤 바꿈이 필요한가? 고친 판을 짜고 새 매개변수 총수를 세어라.

</div>

??? success "연습문제 3 풀이"
    $64 \times 64$ RGB 그림에서는 만들개의 마지막 선형 층이 `nn.Linear(1024, 64 * 64 * 3)`으로 바뀌고 내놓기를 `(batch, 3, 64, 64)`으로 다시 꼴 잡는다. 가름개의 들임 층은 `nn.Linear(64 * 64 * 3, 512)`으로 바뀐다. 그림 공간이 커지므로 숨은 층과 담이를 더 두어야 할 수 있다. 만들개 내놓기 차원이 784에서 12,288으로 늘고 가름개 들임도 마찬가지로 는다. 그래서 매개변수가 크게 늘며(만들개 마지막 층만 해도 $1024 \times 12288 + 12288 = 12,595,200$), 더 큰 그림에는 DCGAN 같은 겹말기 얼개로 옮겨 갈 까닭이 된다.

**연습문제 4.** <span class="diff easy" title="쉬움"></span>
적대적 생성망의 두 그물이 각각 무엇을 하는가?

</div>

??? success "연습문제 4 풀이"
    | | 받는 것 | 내놓는 것 | 바라는 것 |
    |---|---|---|---|
    | 생성기 $G$ | 잡음 $z$ | 그림 | 판별기를 속이기 |
    | 판별기 $D$ | 그림 | 참일 확률 | 참과 거짓을 가리기 |

    둘의 목표가 정면으로 맞선다. 그래서 하나의 손실을 함께 내리는 것이 아니라
    **서로 겨루는** 꼴이 된다.

    $$\min_G \max_D \; \mathbb{E}_{x \sim p_{\text{data}}}[\log D(x)]
      + \mathbb{E}_{z}[\log(1 - D(G(z)))]$$

    이 식이 [24장의 손실](../../ch24/architecture/47_vae.md)과 근본적으로 다른 점이
    있다. 저쪽은 최소화할 하나의 값이 있었고 이쪽은 없다. 그래서 "손실이 내려간다"는 것이
    좋은 뜻이 아니다.

    익히고 나면 판별기는 버린다. 표본을 만드는 데는 생성기만 필요하다. 변분 자기
    부호기에서 부호기를 버리는 것과 같다.

**연습문제 5.** <span class="diff med" title="중간"></span>
판별기의 손실이 낮은 것이 좋은 일인가?

</div>

??? success "연습문제 5 풀이"
    아니다. 판별기가 너무 잘하면 생성기가 배울 것이 없어진다.

    까닭은 기울기에 있다. 판별기가 $D(G(z)) \approx 0$으로 확신하면 원래 손실
    $\log(1-D(G(z)))$의 기울기가 거의 0이 된다. 생성기가 신호를 못 받는다
    ([원래 손실](../gan_losses/original.md)).

    그래서 적대적 생성망에서는 **균형**이 목표다. 이상적으로는 판별기가 반쯤 속아
    $D \approx 0.5$인 자리다.

    실무의 결과가 이렇다.

    | 손실이 보이는 것 | 뜻 |
    |---|---|
    | $D$ 손실이 0으로 | 판별기가 이겼다. 생성기가 멈춘다 |
    | $D$ 손실이 크게 | 판별기가 약하다. 생성기가 엉뚱한 것을 배운다 |
    | 둘이 오르내린다 | 대개 정상이다 |

    그러므로 **손실 곡선으로 익히기를 판단할 수 없다.** FID를 재거나 고정된 $z$의 표본
    격자를 보아야 한다([FID](../gan_evaluation/fid.md)).

    이것이 초보자가 가장 자주 헷갈리는 자리다. 지도 학습에서는 손실이 내려가는 것이
    곧 좋은 것인데 여기서는 아니다.

**연습문제 6.** <span class="diff med" title="중간"></span>
생성기가 $z$를 무시하면 어떻게 되는가? 어떻게 알아채는가?

</div>

??? success "연습문제 6 풀이"
    **무너짐**이며, $z$가 무엇이든 같은 그림을 내놓는다.

    이 장에서 실제로 겪었다. 배치 정규화와 드롭아웃을 뺀 설정으로 익히니 이렇게 되었다.

    | | 인셉션 점수 | FID | 부류 쏠림 |
    |---|---|---|---|
    | 무너진 모델 | **1.000** | 1792.8 | 한 부류에 100% |
    | 제대로 익은 모델 | 6.964 | 40.7 | 두루 |

    인셉션 점수 1.000은 그 잣대의 **하한**이다. 모든 표본이 같은 예측을 내놓는다는 뜻이다.

    알아채는 법이 셋이다.

    - **고정된 $z$로 격자를 그린다.** 칸들이 서로 닮아 가면 무너지는 중이다
    - **부류 엔트로피를 잰다.** 0에 가까우면 한 부류만 낸다
    - **인셉션 점수를 잰다.** 1에 가까우면 무너졌다

    손실로는 알 수 없다는 점을 거듭 짚어 둘 만하다. 무너진 모델의 손실이 오히려 안정되어
    보일 수 있다.

    왜 일어나는가는 [내시 균형](../gan_foundations/nash.md)에서 다룬다. 생성기가 판별기의
    약점 하나를 찾아 거기에 모든 것을 걸면 그 순간에는 이득이기 때문이다.

**연습문제 7.** <span class="diff med" title="중간"></span>
적대적 생성망과 변분 자기 부호기의 표본을 잣대로 견주면 어떻게 나오는가?

</div>

??? success "연습문제 7 풀이"
    MNIST 분류기 기준, 표본 10,000개로 재면 이렇다.

    | | 인셉션 점수 | FID |
    |---|---|---|
    | 참 시험 자료 | 9.467 | 2.52 |
    | **적대적 생성망** | **6.964** | **40.7** |
    | 변분 자기 부호기 | 5.804 | 148.2 |

    적대적 생성망이 두 잣대에서 모두 이긴다. FID로는 세 배 넘는 차이다.

    까닭은 두 모델이 무엇을 요구받는지에 있다. 변분 자기 부호기는 가능도를 크게 하려고
    **자료의 모든 점에 확률을 주어야** 하므로 넓게 퍼지고, 그 결과가 흐릿함이다. 적대적
    생성망에는 그런 항이 없어 일부를 버리고 날카로움을 얻을 수 있다
    ([가능도 잣대](../gan_evaluation/02_likelihood_metrics.md)).

    대가가 있다. 그 "일부를 버림"이 지나치면 무너짐이 되고, 적대적 생성망이 익히기
    어려운 까닭이 그것이다. 변분 자기 부호기는 무너지지 않지만 흐릿하다.

    **잣대가 한쪽 이야기만 한다**는 점도 새겨야 한다. 가능도로 재면 순서가 뒤집힐 것이고,
    애초에 적대적 생성망에는 가능도가 정의되지 않는다.

**연습문제 8.** <span class="diff hard" title="어려움"></span>
이론적으로 최적의 판별기는 무엇인가? 그것을 대입하면 무엇이 나오는가?

</div>

??? success "연습문제 8 풀이"
    생성기를 고정하면 판별기의 목적이 각 $x$마다 따로 풀린다.

    $$\max_{D(x)} \; p_{\text{data}}(x) \log D(x) + p_g(x) \log(1 - D(x))$$

    $D(x)$로 미분해 0으로 두면

    $$\frac{p_{\text{data}}}{D} - \frac{p_g}{1-D} = 0
      \quad \Longrightarrow \quad
      D^*(x) = \frac{p_{\text{data}}(x)}{p_{\text{data}}(x) + p_g(x)}$$

    이것을 원래 목적에 대입하면

    $$2 \, D_{\mathrm{JS}}(p_{\text{data}} \,\|\, p_g) - \log 4$$

    가 된다. $D_{\mathrm{JS}}$가 옌센–섀넌 벌어짐이다. $\square$

    그러므로 **생성기는 옌센–섀넌 벌어짐을 줄이고 있다.** 그리고 그 최솟값이
    $p_g = p_{\text{data}}$에서 0이므로, 이론적으로 자료 분포를 정확히 되찾는다.

    이 결과가 좋은 소식과 나쁜 소식을 함께 준다.

    **좋은 소식**: 적대적 익히기가 임의로 꾸민 것이 아니라 분포 사이의 잘 정의된 거리를
    줄이는 일이다.

    **나쁜 소식**: 옌센–섀넌 벌어짐은 두 분포가 겹치지 않으면 상수 $\log 2$가 되어
    **기울기가 0**이다. 그리고 높은 차원에서 생성기의 분포는 낮은 차원 다양체에 놓이므로
    자료 분포와 거의 겹치지 않는다. 곧 이론이 약속한 자리에 이르는 길이 막혀 있다.

    이 문제를 다루려고 거리를 바꾼 것이 바서슈타인 적대적 생성망이다. 그쪽은 겹치지
    않아도 뜻 있는 기울기를 준다.

**연습문제 9.** <span class="diff med" title="중간"></span>
왜 판별기를 여러 번 갱신하고 생성기를 한 번 갱신하는 관례가 있는가?

</div>

??? success "연습문제 9 풀이"
    이론에서 나온 것이다. 앞의 유도가 **판별기가 최적일 때** 생성기가 옌센–섀넌 벌어짐을
    줄인다고 말하므로, 판별기를 충분히 익혀 두는 것이 그 조건에 가까워지는 길이다.

    원 논문이 $k$번 판별기, 한 번 생성기를 적어 두었다.

    그런데 실무에서는 대개 **1:1로 쓴다.** 까닭이 둘이다.

    판별기가 너무 강해지면 기울기가 사라져 생성기가 멈춘다(연습문제 2). 곧 이론이 바라는
    조건이 실무에서는 해로울 수 있다.

    그리고 값이 든다. 판별기를 다섯 번 돌리면 한 에포크가 훨씬 길어진다.

    균형을 맞추는 다른 손잡이도 있다. 이 장에서 재어 보면 이렇다.

    | 설정 (모두 30 에포크) | FID |
    |---|---|
    | 기본 (1:1) | 49.85 |
    | 판별기 학습률 절반 | 51.06 |
    | 표지 매끄럽게 0.1 | **40.68** |

    학습률로 판별기를 약하게 하는 것보다 **표지를 매끄럽게 하는 것**이 잘 들었다. 판별기가
    지나치게 확신하지 못하게 막아 주기 때문이다.

    바서슈타인 적대적 생성망에서는 사정이 다르다. 그쪽은 비평자가 강할수록 좋으므로 5:1
    같은 비율이 실제로 쓰인다.

    **생성기만** 쓴다. 판별기는 익히는 동안 신호를 주는 역할이며, 끝나면 버린다.

    ```python
    torch.save(g.state_dict(), 'generator.pt')     # 이것만 있으면 된다
    z = torch.randn(n, latent_dim)
    imgs = g(z)
    ```

    변분 자기 부호기에서 부호기를 버리는 것과 같은 모양이다
    ([24장](../../ch24/architecture/47_vae.md)). 만들어 내는 데는 풀개만 필요하다.

    판별기를 남겨 두면 쓸 데가 있기는 하다. 이상 탐지에 쓰거나, 만든 표본을 골라 내는
    데 쓰거나, 이어서 익히려면 필요하다. 그래서 실무에서는 둘 다 저장하는 편이다.

    한 가지 재미있는 점이 있다. 판별기가 배운 특징이 쓸모 있다는 것이 알려져 있고,
    표지 없이 특징을 배우는 방법으로 적대적 생성망을 쓰는 갈래가 여기서 나왔다. 그때는
    **판별기가 결과물**이고 생성기가 도구다.
