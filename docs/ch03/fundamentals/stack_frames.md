# 스택 프레임

활성 상태인 각 함수 호출은 호출 스택 위에 **스택 프레임**(활성 레코드라고도 한다)을 하나씩 차지한다. 재귀 함수에서는 같은 함수의 여러 프레임이 동시에 공존한다. 재귀의 각 수준마다 하나씩이다. 각 프레임에 무엇이 담기는지 이해하면 재귀가 각 호출의 상태를 어떻게 "기억"하는지 알 수 있다.

---

## 1. 스택 프레임의 구조

스택 프레임은 보통 다음을 저장한다.

| 구성 요소 | 용도 |
|---|---|
| 매개변수 | 이 호출에 넘겨진 인수 |
| 지역 변수 | 함수 안에서 선언된 변수 |
| 반환 주소 | 이 호출이 반환된 뒤 실행을 재개할 위치 |
| 반환값 | 호출자에게 돌려줄 값 |

---

## 2. 예제: 계승의 스택 프레임

`factorial(4)`를 계산한다고 하자. 재귀 호출마다 새 프레임이 만들어지고, 각 프레임은 자기만의 `n`을 가진다.

```python
"""재귀적 계승 계산 중의 스택 프레임 시각화."""

# === 프레임을 추적하는 계승 ===

def factorial(n, depth=0):
    """스택 프레임 정보를 출력하며 n!을 계산한다."""
    indent = "  " * depth
    print(f"{indent}PUSH frame: factorial({n})")
    if n <= 1:
        print(f"{indent}  return 1")
        print(f"{indent}POP  frame: factorial({n})")
        return 1
    result = n * factorial(n - 1, depth + 1)
    print(f"{indent}  return {n} * ... = {result}")
    print(f"{indent}POP  frame: factorial({n})")
    return result

# === 메인 ===

if __name__ == "__main__":
    answer = factorial(4)
    print(f"\nfactorial(4) = {answer}")
```

**출력:**
```
PUSH frame: factorial(4)
  PUSH frame: factorial(3)
    PUSH frame: factorial(2)
      PUSH frame: factorial(1)
        return 1
      POP  frame: factorial(1)
      return 2 * ... = 2
    POP  frame: factorial(2)
    return 3 * ... = 6
  POP  frame: factorial(3)
  return 4 * ... = 24
POP  frame: factorial(4)

factorial(4) = 24
```

## 3. 메모리에 대한 함의

깊이가 $d$인 재귀에서는 호출 스택이 동시에 $d$개의 프레임을 담는다. 각 프레임은 지역 변수를 위해 $O(1)$의 공간을 쓰므로 전체 스택 공간은 $O(d)$이다. `factorial(n)`의 깊이는 $n$이므로 스택 공간은 $O(n)$이다.

깊은 재귀가 스택 넘침을 일으킬 수 있는 이유가 이것이다. 프레임마다 메모리를 소비하는데 시스템 스택의 크기에는 고정된 한계가 있다.

## 연습문제

**연습문제 1.**
스택 프레임에 대해 기저 사례와 재귀 사례를 찾아라. 모든 유효한 입력에 대해 재귀가 종료됨을 증명하라.

??? success "연습문제 1 풀이"
    기저 사례는 가장 작은 유효한 입력을 직접 처리한다. 재귀 사례는 호출마다 감소하는 잘 정의된 척도로 문제 크기를 줄인다. 이 척도가 (기저 사례의 문턱값으로) 아래로 유계이면서 엄격히 감소하므로 재귀는 반드시 유한한 단계 안에 종료된다.

---

**연습문제 2.**
스택 프레임의 시간 복잡도에 대한 점화식을 유도하고 풀어라.

??? success "연습문제 2 풀이"
    $T(n)$을 재귀 호출과 호출당 일의 함수로 표현한다. 이 점화식은 분기 계수, 부분문제 크기의 감소, 결합 비용을 담는다. 펼치기, 마스터 정리, 치환 중 하나로 풀어 닫힌 형태를 얻는다.

---

**연습문제 3.**
$n = 8$일 때 스택 프레임의 재귀 트리를 그려라. 각 층에서의 일과 전체 일을 계산하라.

??? success "연습문제 3 풀이"
    트리의 깊이는 입력이 기저 사례까지 얼마나 빨리 줄어드는지로 정해진다. 각 층에서 모든 노드의 일을 더한다. 모든 층에 걸친 총합이 실행 시간을 준다. $n = 8$이면 트리가 작아서 전부 열거할 수 있다.

---

**연습문제 4.**
재귀 구현을 반복 버전으로 변환하라. 공간 복잡도를 비교하라.

??? success "연습문제 4 풀이"
    호출 스택을 명시적 스택이나 반복 변수로 대체한다. 꼬리 재귀 형태는 while 반복문으로 곧바로 바뀐다. 꼬리가 아닌 형태는 호출 스택을 흉내 내기 위해 명시적 스택이 필요하다. 반복 버전은 보통 $O(\text{depth})$의 스택 공간을 아낀다.
