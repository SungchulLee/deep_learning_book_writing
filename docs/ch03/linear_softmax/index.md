# 선형 모델과 소프트맥스

[1단계](../mnist/01_template_learning.md)에서 템플릿을 클래스 평균으로 **못박아** 82.03%를 얻었다. 그 절 끝에서 보았듯 이 방법은 선형 분류기이고, 가중치가 평균으로 고정되어 있을 뿐이다. 이제 그 가중치를 풀어 데이터에 맞추어 움직인다. 이것이 이 장에서 처음으로 "학습"이라 부를 만한 일이다.

그런데 무엇을 기준으로 움직여야 하는가? 이 절은 그 물음에 답한다. 답을 따라가면 **최대가능도 추정 → 가능도 → 로그가능도 → 손실 → 경사 하강법**이라는 하나의 사슬이 나온다. 딥러닝의 모든 학습이 이 사슬 위에 있다.

---

## 사슬 전체

이 절은 여섯 쪽으로 나뉘어 있고, 각 쪽이 사슬의 한 고리를 맡는다.

| 단계 | 하는 일 | 왜 필요한가 |
|---|---|---|
| [선형 모델](01_linear_model.md) | $y = xA + b$로 클래스마다 점수 하나 | 무엇을 학습할지 정한다 (7,850개) |
| [소프트맥스](02_softmax.md) | 점수를 확률로 | 가능도를 쓸 수 있게 만든다 |
| [최대가능도 추정](03_mle.md) | 데이터를 가장 그럴듯하게 만드는 값을 고른다 | 학습의 **기준**을 정한다 |
| [교차 엔트로피 손실](04_cross_entropy.md) | 가능도 → 로그가능도 → 부호 뒤집기 | 미분이 쉽고 수치적으로 안정 |
| [경사 하강법](05_gradient_descent.md) | 기울기의 반대로 조금씩 내려간다 | 7,850차원에서 최솟값을 찾는다 |
| [구현과 결과](06_implementation.md) | 위 다섯을 코드로 | 82.03% → 92.51% |

읽는 순서는 위에서 아래가 자연스럽다. 다만 각 쪽은 홀로 읽어도 되게 쓰여 있으므로, 이미 아는 고리는 건너뛰어도 좋다.

!!! note "이 절과 7장의 관계"
    같은 주제를 [7장](../../ch07/index.md)이 더 깊이 다룬다. [소프트맥스 회귀 기초](../../ch07/softmax_regression/01_fundamentals.md)는 모델 자체를, [표지-재포획 MLE](../../ch07/mle/capture_recapture_mle.md)는 최대가능도 추정을 각각 본격적으로 파헤친다.

    이 절의 몫은 다르다. **MNIST라는 하나의 예를 끝까지 끌고 가며 사슬 전체가 어떻게 맞물리는지 보이는 것**이다. 유도를 더 보고 싶으면 7장으로 가고, 사다리의 두 번째 칸이 궁금하면 여기를 읽으면 된다.

---

## 이 절이 얻는 것

| | 1단계 템플릿 학습 | 2단계 선형 모델 |
|---|---|---|
| 매개변수 | 7,850개 (고정) | 7,850개 (학습) |
| 결정 경계 | 선형 | 선형 |
| 시험 정확도 | 82.03% | **92.51%** |

매개변수의 **수가 같다**는 점이 이 절의 요점이다. 모델을 키우지 않고, 층을 쌓지도 않고, 같은 수를 데이터에 맞추어 움직인 것만으로 10%포인트를 넘게 얻는다. 학습이라는 일이 그 자체로 얼마나 큰 몫인지를 보여 준다.

그리고 여기서 막히는 자리도 분명하다. 결정 경계가 여전히 선형이라는 것이다. [3.3 다층 퍼셉트론](../mnist/03_mlp.md)이 그 제약을 푼다.
