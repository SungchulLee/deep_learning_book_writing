# 꼬리 재귀

재귀 호출이 가장 마지막 연산이어서 호출이 반환된 뒤에 할 계산이 남아 있지 않으면 그 재귀 함수는 **꼬리 재귀** 이다. 이 구분이 중요한 이유는, 컴파일러가 꼬리 재귀 함수를 최적화하여 현재 스택 프레임을 재사용함으로써 표준 재귀의 $O(n)$ 스택 부담을 없앨 수 있기 때문이다.

## 꼬리 재귀와 꼬리가 아닌 재귀

표준(꼬리가 아닌) 재귀에서는 함수가 재귀 호출 뒤에 일을 한다.

```python
def factorial(n):
    if n <= 1:
        return 1
    return n * factorial(n - 1)  # 재귀 호출이 반환된 뒤에 곱셈을 한다
```

꼬리 재귀에서는 재귀 호출이 마지막 연산이다.

```python
"""계승으로 보여주는 꼬리 재귀."""


# === 꼬리 재귀 계승 ===

def factorial_tail(n, acc=1):
    """누적자를 쓰는 꼬리 재귀로 n!을 계산한다."""
    if n <= 1:
        return acc
    return factorial_tail(n - 1, acc * n)  # 이 호출 뒤에는 아무 일도 일어나지 않는다


# === 메인 ===

if __name__ == "__main__":
    for n in [0, 1, 5, 10]:
        print(f"{n}! = {factorial_tail(n)}")
```

**출력:**
```
0! = 1
1! = 1
5! = 120
10! = 3628800
```

## 꼬리 재귀가 중요한 이유

꼬리가 아닌 재귀에서는 각 프레임이 (곱셈이라는) 대기 중인 일을 가지므로 스택에 남아 있어야 한다. 꼬리 재귀에서는 현재 프레임이 더 할 일이 없으므로, 컴파일러가 새 프레임을 쌓는 대신 현재 프레임을 다음 프레임으로 대체할 수 있다.

| 성질 | 표준 재귀 | 꼬리 재귀 |
|---|---|---|
| 대기 연산 | 있음 | 없음 |
| 스택 증가 | $O(n)$ | (최적화 시) $O(1)$ |
| 누적자 필요 여부 | 아니오 | 대개 필요 |

## 파이썬에서의 한계

파이썬은 꼬리 호출 최적화를 **하지 않는다.** 꼬리 재귀로 쓴 파이썬 함수도 $O(n)$의 스택 공간을 쓴다. 그러나 꼬리 재귀를 이해하는 것은 최적화를 수행하는 언어(Scheme, Haskell, Scala)를 위해서도, 재귀를 반복으로 바꾸기 위해서도 여전히 가치가 있다.

## 연습문제

**연습문제 1.**
$f(0) = 1$인 재귀 계승 $f(n) = n \cdot f(n-1)$을 꼬리 재귀 형태로 바꾸어라.

??? success "연습문제 1 풀이"
    꼬리 재귀 형태: $f(0, \text{acc}) = \text{acc}$인 $f(n, \text{acc}) = f(n-1, n \cdot \text{acc})$이며 $f(n, 1)$로 호출한다. 누적자가 부분 곱을 나르고, 재귀 호출이 마지막 연산(꼬리 위치)이다.

---

**연습문제 2.**
(꼬리 호출 최적화가 있을 때) 꼬리 재귀가 $O(1)$의 스택 공간을 쓰는 반면 꼬리가 아닌 재귀가 $O(n)$을 쓰는 이유를 설명하라.

??? success "연습문제 2 풀이"
    꼬리가 아닌 재귀에서는 함수가 (예를 들어 $n$을 곱하는) 추가 계산을 하기 위해 호출자로 돌아가야 한다. 이를 위해 스택 프레임을 보존해야 한다. 꼬리 재귀에서는 재귀 호출이 마지막 연산이므로 현재 프레임을 새 프레임으로 대체할 수 있다(돌아갈 필요가 없다). 이렇게 프레임 하나를 재사용하므로 $O(1)$ 공간이 된다.

---

**연습문제 3.**
파이썬은 꼬리 호출 최적화를 구현하지 않는다. 그 이유를 설명하고 이 한계를 우회하는 방법을 기술하라.

??? success "연습문제 3 풀이"
    파이썬을 만든 귀도 반 로섬은 디버깅에 유용한 스택 추적을 보존하기 위해 TCO를 구현하지 않기로 했다. 우회책은 다음과 같다. (1) 직접 반복으로 변환한다(누적자를 쓰는 while 반복문). (2) `sys.setrecursionlimit()`으로 한계를 높인다(근본적인 해결책은 아니다). (3) 재귀 호출을 하는 대신 thunk를 반환하는 트램펄린 패턴을 쓴다.

---

**연습문제 4.**
역전파의 경사 누적을 꼬리 재귀 계산으로 표현하고 반복적으로 구현할 수 있음을 보여라.

??? success "연습문제 4 풀이"
    역전파는 층 $L$부터 1까지 $\delta_l = W_{l+1}^\top \delta_{l+1} \odot \sigma'(z_l)$을 계산한다. 이는 꼬리 재귀이다. 각 단계의 출력($\delta_l$)이 다음 단계의 입력이 되며 남겨진 연산이 없다. 반복 형태는 다음과 같다. `delta = grad_output; for l in range(L, 0, -1): delta = W[l].T @ delta * sigma_prime(z[l])`. PyTorch가 역방향 순회를 구현하는 방식이 정확히 이것이다.
