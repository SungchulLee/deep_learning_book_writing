# 메모화

메모화(memoization)는 비용이 큰 재귀 호출의 결과를 저장해 두었다가 같은 입력이 다시 오면 캐시된 결과를 반환하는 기법이다. 중복 계산을 없앰으로써 지수 시간 재귀 알고리즘을 다항 시간으로 바꾼다. 동적 계획법의 핵심 통찰이 바로 이것이다.

## 문제: 중복 계산

소박한 재귀 피보나치는 같은 값을 거듭 계산한다. 예를 들어 `fib(5)`는 `fib(3)`을 두 번, `fib(2)`를 세 번 호출한다.

$$
T(n) = T(n-1) + T(n-2) + O(1) \implies T(n) = O(2^n)
$$

## 해결책: 결과를 캐시하기

계산한 결과를 사전에 저장한다. 재귀하기 전에 답이 이미 캐시되어 있는지 확인한다.

```python
"""피보나치 수로 보여주는 메모화."""


# === 메모화 없는 피보나치 ===

def fib_naive(n):
    """피보나치 수를 계산한다 — 지수 시간."""
    if n <= 1:
        return n
    return fib_naive(n - 1) + fib_naive(n - 2)


# === 메모화를 쓰는 피보나치 ===

def fib_memo(n, cache=None):
    """피보나치 수를 계산한다 — 메모화로 O(n) 시간."""
    if cache is None:
        cache = {}
    if n in cache:
        return cache[n]
    if n <= 1:
        return n
    cache[n] = fib_memo(n - 1, cache) + fib_memo(n - 2, cache)
    return cache[n]


# === 메인 ===

if __name__ == "__main__":
    print("With memoization:")
    for i in [10, 20, 30, 40]:
        print(f"  fib({i}) = {fib_memo(i)}")
```

**출력:**
```
With memoization:
  fib(10) = 55
  fib(20) = 6765
  fib(30) = 832040
  fib(40) = 102334155
```

## 복잡도 개선

| 접근 | 시간 | 공간 |
|---|---|---|
| 소박한 재귀 | $O(2^n)$ | $O(n)$ 스택 |
| 메모화 사용 | $O(n)$ | $O(n)$ 캐시 + 스택 |

각 부분문제가 한 번만 풀리므로 메모화는 시간을 지수에서 선형으로 줄인다. 공간 비용은 항목을 $O(n)$개 저장하는 캐시이다.

## 메모화를 언제 쓰는가

메모화는 재귀 함수에 **중복되는 부분문제** 가 있을 때, 즉 같은 입력을 여러 번 마주칠 때 효과적이다. 동적 계획법의 하향식 접근법이다.

## 연습문제

**연습문제 1.**
메모화가 효과적이기 위해 필요한 두 조건, 즉 중복되는 부분문제와 최적 부분구조를 설명하라.

??? success "연습문제 1 풀이"
    **중복되는 부분문제**: 같은 부분문제가 여러 번 풀린다. 이것이 없으면 메모화는 다시 쓰이지 않을 값을 저장하여 공간을 낭비한다. **최적 부분구조**: 최적해를 부분문제의 최적해로부터 만들 수 있다. 이것이 없으면 부분문제를 따로 푸는 것이 전역 최적으로 이어지지 않는다.

**연습문제 2.**
하향식 메모화와 상향식 동적 계획법을 비교하라. 어느 쪽이 메모리를 더 쓰고 어느 쪽이 구현하기 쉬운가?

??? success "연습문제 2 풀이"
    하향식(메모화): 재귀적이며 실제로 마주친 부분문제만 저장하고 구현이 더 쉽다(기존 재귀에 캐시를 붙이면 된다). 재귀 깊이 때문에 스택 공간을 더 쓸 수 있다. 상향식(표 채우기): 반복적이며 표 전체를 체계적으로 채우고 스택 없이 $O(n)$의 메모리를 쓴다. 배열을 순차적으로 접근하므로 캐시 성능이 더 좋은 경우가 많다.

**연습문제 3.**
자기회귀 트랜스포머의 KV 캐시는 메모화의 한 형태이다. 무엇이 메모화되는지와 공간-시간 절충을 설명하라.

??? success "연습문제 3 풀이"
    KV 캐시는 이전 모든 토큰의 키와 값 사영을 메모화한다. $K_i = W_K h_i$이고 $V_i = W_V h_i$이다. 캐시가 없으면 토큰 $t$를 생성할 때마다 이전 $t-1$개의 키/값을 모두 다시 계산해야 하며 층당 $O(t \cdot d)$가 든다. 캐시를 쓰면 층당 $O(d)$이다(새 토큰의 K, V만 계산한다). 공간 비용은 층이 $L$개일 때 $O(t \cdot d \cdot L)$이다. $O(tdL)$의 메모리를 대가로 토큰당 $O(t)$의 시간을 아끼는 셈이다.

**연습문제 4.**
점화식 $\binom{n}{k} = \binom{n-1}{k-1} + \binom{n-1}{k}$을 사용하여 $\binom{n}{k}$를 계산하는 메모화를 구현하라. 서로 다른 부분문제는 몇 개인가?

??? success "연습문제 4 풀이"
    서로 다른 부분문제는 $0 \leq j \leq i \leq n$인 모든 쌍 $(i, j)$이며 총 $\binom{n+1}{2} = O(n^2)$개이다. 각각은 $O(1)$의 비용으로 한 번씩 계산된다. 총합은 시간과 공간 모두 $O(n^2)$이다. 메모화가 없으면 재귀는 피보나치와 마찬가지로 지수적인 중복을 가진다.
