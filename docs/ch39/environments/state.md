## 2. 소개

상태 표현은 금융 강화학습 시스템에서 아마도 가장 중요한 설계 결정이다. 에이전트가 무엇을 볼 수 있는지, 따라서 어떤 결을 배울 수 있는지를 정하기 때문이다. 전체 상태가 흔히 드러나는 게임 둘레와 달리 금융 시장은 부분적으로만 관측된다. 에이전트는 훨씬 복잡한 기저 구조가 잡음에 섞여 드러난 일부를 볼 뿐이다.

---

## 3. 상태 피처의 종류

### 1. 가격 기반 피처

원시 가격은 비정상적(통계적 성질이 시간에 따라 바뀜)이므로 정상성에 가까운 피처로 바꿔야 한다.

| 피처 | 식 | 해석 |
|---------|---------|---------------|
| 로그 수익률 | $r_t = \ln(p_t / p_{t-1})$ | 가격의 백분율 변화 |
| 정규화한 가격 | $(p_t - \mu_{w}) / \sigma_{w}$ | 창 $w$에 대한 Z 점수 |
| 수익률 모멘텀 | $\sum_{i=0}^{k-1} r_{t-i}$ | $k$ 기간에 걸친 누적 수익률 |
| 실현 변동성 | $\sqrt{\sum_{i=0}^{k-1} r_{t-i}^2}$ | 가격 변동 정도 |

### 2. 기술 지표

가격과 거래량 데이터에서 계산한다.

| 지표 | 윈도 | 신호 |
|-----------|--------|--------|
| RSI(상대강도지수) | 14 | 과매수·과매도 |
| MACD | 12/26/9 | 추세의 방향과 모멘텀 |
| 볼린저 밴드 위치 | 20 | 평균 회귀 신호 |
| ATR(평균 실제 범위) | 14 | 변동성 측정 |
| OBV(온밸런스 거래량) | -- | 거래량과 가격의 흐름 |

### 3. 포트폴리오 상태

에이전트는 자신의 현재 포지션을 알아야 한다.

- 현재 포트폴리오 웨이트 $w_t \in \mathbb{R}^N$
- 포지션마다 미실현 손익
- 자산마다 마지막 거래 뒤 경과 시간
- 가용 자본 / 매수 여력
- 현재 레버리지 비율

### 4. 시장 미시구조(고빈도 거래에서)

- 매수·매도 스프레드
- 주문 장부 불균형
- 거래 흐름 불균형
- 호가 도착률

### 5. 자산 간 피처

- 상관 행렬(롤링 윈도)
- 섹터/업종 노출
- 시장 레짐 지표(VIX 수준, 수익률 곡선의 기울기)

## 4. 상태 공간 설계

### 평탄한 벡터로 표현하기

가장 단순한 방법은 모든 피처를 벡터 하나로 이어 붙이는 것이다.

$$s_t = [f_t^{\text{값}}, f_t^{\text{재주}}, f_t^{\text{밑천}}, f_t^{\text{저자}}] \in \mathbb{R}^D$$

다층 퍼셉트론 폴리시에 잘 맞지만 시간 구조를 담지 못한다.

### 시간 텐서로 표현하기

시퀀스 모델(LSTM, 트랜스포머)에서는 피처를 2차원 텐서로 구성한다.

$$S_t = \begin{bmatrix} f_{t-L+1}^{(1)} & \cdots & f_{t-L+1}^{(F)} \\ \vdots & \ddots & \vdots \\ f_t^{(1)} & \cdots & f_t^{(F)} \end{bmatrix} \in \mathbb{R}^{L \times F}$$

여기서 $L$은 룩백 윈도(과거를 돌아보는 길이)이고 $F$은 피처의 개수다.

### 다채널로 표현하기

컨볼루션 네트워크 폴리시에서는 피처 종류를 채널로 쌓는다.

$$S_t \in \mathbb{R}^{C \times L \times N}$$

여기서 $C$은 피처 채널 수, $L$은 룩백 길이, $N$은 자산 개수다.

---

## 5. 정규화 전략

강화학습이 안정적으로 트레인되려면 정규화가 중요하다.

### 롤링 Z 점수

$$\hat{f}_t = \frac{f_t - \mu_t^{(w)}}{\sigma_t^{(w)} + \epsilon}$$

여기서 $\mu_t^{(w)}$과 $\sigma_t^{(w)}$은 창 $w$에 대한 롤링 평균과 표준편차다.

### 순위 정규화

횡단면(같은 시점의 자산들) 안에서의 순위로 피처를 $[0, 1]$에 균등하게 옮긴다.

$$\hat{f}_{t,i} = \frac{\text{rank}(f_{t,i})}{N}$$

이상치에 강건하고 상대 순서를 지킨다.

### 적응형 정규화

지수 이동 통계를 유지한다.

$$\mu_t = \alpha f_t + (1 - \alpha) \mu_{t-1}$$

$$\sigma_t^2 = \alpha (f_t - \mu_t)^2 + (1 - \alpha) \sigma_{t-1}^2$$

---

## 6. 결측 데이터 다루기

금융 데이터에는 결측값이 흔하다(휴장일, 거래 정지, 상장 폐지).

1. **전방 채우기**: 마지막으로 관측된 값을 이어 쓴다(가격에 가장 흔하다)
2. **마스킹**: 데이터가 있는지를 알리는 이진 마스크를 함께 넣는다
3. **대체**: 횡단면이나 모델로 메운다
4. **센티널 값**: 특별한 값(예를 들어 0)을 지시 피처와 함께 쓴다

## 7. 구현 시 고려할 점

### 관찰 공간 정하기

```python
# 납작한 봄
observation_space = spaces.Box(
    low=-np.inf,
    high=np.inf,
    shape=(num_features,),
    dtype=np.float32
)

# Dict 공간으로 나타낸 때 봄
observation_space = spaces.Dict({
    'market': spaces.Box(-np.inf, np.inf, (lookback, num_assets, num_features)),
    'portfolio': spaces.Box(-1, 1, (num_assets,)),
    'account': spaces.Box(-np.inf, np.inf, (3,)),  # 남은 돈, 자기 밑천, 지렛대
})
```

### 피처 계산 파이프라인

```python
def _get_obs(self):
    window = self.data_feeder.get_window()

    # 값 피처
    returns = np.diff(np.log(window['prices']), axis=0)
    volatility = returns.std(axis=0)
    momentum = returns.sum(axis=0)

    # 재주 지표
    rsi = self._compute_rsi(window['prices'])

    # 밑천 상태
    weights = self.portfolio.get_weights()

    # 고르게 하기
    market_features = self._normalize(
        np.column_stack([returns[-1], volatility, momentum, rsi])
    )

    return {
        'market': market_features.astype(np.float32),
        'portfolio': weights.astype(np.float32),
    }
```

## 8. 흔히 빠지는 함정

1. **미래 참조 바이어스**: 미래 정보를 상태에 결코 넣지 말라. 중심화와 스케일링조차 과거 데이터만 써야 한다.
2. **비정상성**: 원시 가격, 거래량, 금액을 그대로 피처로 쓰면 트레인이 불안정해진다.
3. **피처 폭증**: 피처가 너무 많으면 필요한 샘플 수가 는다. 적게 시작해 하나씩 더하고, 하나씩 빼 보는 실험으로 효과를 확인하라.
4. **포트폴리오 상태 빠뜨리기**: 에이전트가 자신의 현재 포지션을 알아야 제대로 판단할 수 있다.

</div>

??? success "풀이"

(3) 낙폭 벌점을 곁들인 로그 수익률 $r_t = \log(V_t/V_{t-1}) - \lambda \max(0, DD_t - \tau)$ -- 수익률과 위험 관리의 균형을 맞춘다. 퍼텐셜 기반 셰이핑 정리는 $\gamma\Phi(s') - \Phi(s)$을 더해도 최적 폴리시가 보존됨을 보장한다. 샤프 기반 리워드는 최적화 목표 자체를 바꾸므로(최적 폴리시가 달라질 수 있다) 그렇지 않고, 원시 손익은 폴리시를 보존하지만 더디게 배운다. $\square$

## 정리하며

효과적인 상태 표현은 가격에서 얻은 피처(수익률, 변동성, 모멘텀), 기술 지표, 포트폴리오 상태, 그리고 경우에 따라 시장 미시구조 데이터를 엮는다. 미래 참조 바이어스를 막으려면 모든 피처를 그 시점까지 얻을 수 있었던 정보만으로 정규화해야 한다. 평탄한 벡터, 시간 텐서, 다채널 표현 가운데 무엇을 고를지는 폴리시 구조에 달렸다.
