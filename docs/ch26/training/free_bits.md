# Free Bits: 작은 KL에 대한 압력 완화

Free Bits는 작은 KL 구간에서 추가 KL 감소의 이득을 없애는 손실 변형이다. 이름과 달리 각 차원의 최소 정보량을 강제하는 제약은 아니다. 재구성 경로가 잠재 변수를 활용할 여지를 주려는 방법이며 사후 붕괴 방지나 모든 차원의 활성화를 보장하지 않는다.

## 1. 배치 평균에 적용하는 문턱

대각 가우시안 사후와 표준정규 사전에서 표본 i, 차원 j의 KL을 K_ij라고 하자. 배치 크기 B에 대해 이 절의 손실은 다음과 같다.

$$\overline K_j=\frac1B\sum_{i=1}^{B}K_{ij},\qquad
L_{\mathrm{free}}=\sum_{i=1}^{B}R_i+B\sum_{j=1}^{d}\max(\lambda,\overline K_j).$$

λ는 차원당 문턱이며 자연로그를 쓰므로 단위는 nat이다. 1 bit=ln 2 nat이므로 함수 인수 이름 free_bits가 곧 bit 단위를 뜻하지는 않는다. 원래 제안은 잠재 변수의 그룹에도 적용하며 여기서는 차원 하나를 그룹으로 사용한다. [IAF 논문 부록 C.8](https://arxiv.org/pdf/1606.04934)은 미니배치 평균 KL에 문턱을 적용하는 목적을 설명한다.

## 2. 구현과 반환값

```python
import torch
import torch.nn.functional as F

def vae_loss_free_bits(recon_x, x, mu, logvar, free_bits=0.5):
    """
    공짜 비트 제약을 곁들인 변분 오토인코더 손실.
    
    인수:
        recon_x: 다시 세운 내놓기
        x: 본디 들임
        mu: 인코더의 평균 [배치 크기, 숨은 차원]
        logvar: 인코더의 로그 흩어짐 [배치 크기, 숨은 차원]
        free_bits: 차원마다의 최소 KL(냇 단위)
    
    반환값:
        total_loss, recon_loss, kl_loss
    """
    # 되살림 손실
    recon_loss = F.binary_cross_entropy(recon_x, x, reduction='sum')
    
    # 차원마다의 KL: [배치 크기, 숨은 차원]
    kl_per_dim = -0.5 * (1 + logvar - mu.pow(2) - logvar.exp())
    
    # 배치에 걸쳐 먼저 평균 낸 뒤 공짜 비트를 적용한다
    kl_mean_per_dim = kl_per_dim.mean(dim=0)  # [숨은 차원]
    kl_free = torch.clamp(kl_mean_per_dim, min=free_bits)
    kl_loss = kl_free.sum() * x.size(0)  # 배치 잣수로 되돌린다
    
    total_loss = recon_loss + kl_loss
    return total_loss, recon_loss, kl_loss
```

입력 μ·logvar는 `(B,d)`이며 재구성과 타깃의 모양이 같아야 한다. BCE는 모든 원소의 합이다. 차원별 KL을 배치 평균한 뒤 문턱 처리하고 B를 곱해 재구성 합과 단위를 맞춘다. 마지막 배치가 작으면 실제 x.size(0)을 사용한다. 타깃 범위·유한값과 비어 있지 않은 배치도 필요하다.

반환되는 kl_loss는 수정된 KL 비용이다. 실제 KL 합은 따로 계산해 기록해야 한다. 붕괴 상태에서도 반환 비용은 B d λ가 될 수 있으므로 이것을 정보량이나 실제 사용 KL로 읽으면 안 된다. 이 함수에는 β 인수가 없다. β와 함께 사용하려면 호출부에서 수정 비용의 비중을 명확히 정의해야 한다.

## 3. 기울기의 의미와 문턱 선택

평균 KL이 λ보다 작은 차원에서는 수정 KL 항이 상수여서 그 경로의 기울기가 0이다. 재구성 기울기는 여전히 존재할 수 있지만 이를 통해 반드시 KL이 증가한다는 보장은 없다. 문턱과 정확히 같은 지점은 미분 불가능하므로 구현의 경계 기울기 관례를 따른다.

λ=0이면 음이 아닌 해석적 KL에 대해 표준 비용과 같다. λ를 크게 하면 더 많은 구간에서 KL의 복원 압력이 약해지지만 잠재 정보가 반드시 늘거나 품질이 좋아지는 것은 아니다. λ d가 전체 문턱 비용의 크기이므로 잠재 차원·그룹 정의·손실 합산 기준을 함께 보고 검증 자료로 선택한다.

## 4. Warm-up과 평가

KL warm-up은 시간에 따라 β를 바꾸고 Free Bits는 현재 차원·그룹의 평균 KL에 따라 비용을 바꾼다. 함께 사용할 수 있지만 효과와 상호작용을 따로 확인해야 한다. 어느 방법도 모든 붕괴를 막는 보증은 아니다.

수정 비용은 원래 KL 이상이므로 β=1에서 대응하는 최대화 목표는 표준 ELBO 이하이며 여전히 평균 로그우도의 하한이다. 표준 ELBO 자체와는 다르므로 모델 비교용으로 수정 없는 재구성·KL도 별도로 기록한다. 미니배치 평균에 max를 적용하는 것은 데이터 전체 평균에 적용하는 것과 확률적으로도 다르다. 작은 배치에서는 문턱 활성화의 변동도 커질 수 있다.

**연습문제 2.** <span class="diff med" title="중간"></span>
배치 평균 뒤 문턱을 적용하는 것과 표본마다 먼저 적용하는 것의 차이는 무엇인가?

</div>

??? success "연습문제 2 풀이"

    본문은 Σ_j max(λ,(1/B)Σ_i K_ij)를 사용한다. 표본별 방식은 (1/B)Σ_iΣ_j max(λ,K_ij)이며 일반적으로 다르다. max의 볼록성 때문에 후자가 전자 이상이다. 아래 골격은 본문처럼 배치 평균 뒤 문턱을 적용하지만 배치 평균 재구성 항과 결합하는 형태다. lam은 호출부에서 정의해야 한다. 전체 데이터 평균을 매 스텝 정확히 구하는 것이 아니라 미니배치로 계산한다.

    ```python
    kl = -0.5 * (1 + logvar - mu.pow(2) - logvar.exp())   # (B, k)
    kl = torch.clamp(kl.mean(0), min=lam).sum()           # 먼저 평균, 그다음 자름
    ```

## 정리하며

Free Bits는 차원·그룹의 배치 평균 KL이 문턱 아래일 때 KL 감소의 이득을 없앤다. 최소 정보량을 강제하지 않으며 수정 KL 비용과 실제 KL을 구분해 기록해야 한다. 문턱·잠재 차원·배치 크기와 정규화 기준을 함께 검토한다.
