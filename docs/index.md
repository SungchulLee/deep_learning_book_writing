# 딥러닝

이 책은 딥러닝의 기본 원리부터 모델 구현과 활용까지 단계적으로 설명한다. 수학적 설명과 Python 예제를 함께 제시하여, 모델이 어떻게 작동하는지 이해하고 그 원리를 코드로 확인할 수 있도록 구성했다.

이미지 한 장을 분류하는 문제를 생각해 보자. 모든 픽셀을 완전 연결 층에 입력하면 이미지 크기에 따라 매개변수 수가 빠르게 늘어난다. 합성곱 층은 가까운 픽셀의 관계를 이용하고 같은 필터를 여러 위치에 적용하여 매개변수를 공유한다. 이처럼 데이터의 특성에 맞는 구조를 선택하는 것이 딥러닝 모델 설계의 출발점이다.

책은 컴퓨터 구조와 데이터 분석 도구에서 시작한다. MNIST, CIFAR-10, IMDB 예제를 통해 분류와 생성 모델의 원리를 익힌 뒤, PyTorch의 기능과 주요 신경망 아키텍처를 체계적으로 다룬다. 이후 다양한 학습 패러다임과 확률적 방법을 살펴보고, 모델 해석, 편향과 공정성, 적대적 강건성, 불확실성, 배포로 범위를 넓힌다.

---

## 1. 이 책을 읽는 법

처음 읽을 때는 **I 기초**의 순서를 따르는 것이 좋다. 앞에서 익힌 개념을 다음 모델에 적용하면서, 어떤 변화가 성능과 계산 비용에 영향을 주는지 비교할 수 있다. 각 절의 수식, 코드, 출력, 해설을 함께 읽고 연습문제로 이해를 확인하라.

이미 알고 있는 주제는 건너뛰어도 된다. 다만 새로운 기호나 구현 방식이 나오면 해당 절의 앞부분이나 연결된 설명을 먼저 확인하라. 예제에 기록된 결과는 특정 데이터와 실행 조건에서 얻은 값이며, 모든 환경에서 같은 결과를 보장하지는 않는다.

## 2. 선수 지식

- 고등학교 수준의 대수와 기초 확률
- 벡터, 행렬, 미분에 대한 기초 지식. 필요한 개념은 본문에서도 설명한다
