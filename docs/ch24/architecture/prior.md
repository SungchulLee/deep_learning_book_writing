# 사전 분포 고르기
숨은 공간의 사전 분포 $p(z)$을 고르고 설계하기.

---

## 1. 학습 목표

이 절을 마치면 다음을 할 수 있게 된다.

- 변분 자기 부호기의 만들어 내기와 벌주기에서 사전 분포의 노릇 설명하기
- 표준 정규 사전 분포가 왜 붙박이 고름인지 이해하기
- 다른 사전 분포와 그 맞바꿈 적기
- 표준이 아닌 사전 분포를 쓴 변분 자기 부호기 짜기

---

## 2. 사전 분포의 노릇

사전 분포 $p(z)$은 변분 자기 부호기에서 결정적인 노릇을 둘 한다. **익히는 동안** KL 벌어짐 $D_{KL}(q_\phi(z|x) \| p(z))$이 부호기가 내놓는 것을 사전 분포에 맞도록 옭아매어 숨은 공간의 기하를 빚는다. **만들어 낼 때**는 $z \sim p(z)$을 뽑아 푸므로 사전 분포가 숨은 부호를 뽑는 분포를 정한다.

사전 분포와 모은 사후 분포 $q_\phi(z) = \mathbb{E}_{p_{\text{data}}}[q_\phi(z|x)]$이 어긋나면 만들어 내기가 나빠진다. 곧 풀개가 만들어 낼 때 익히는 동안 본 적 없는 숨은 부호를 만난다.

---

## 3. 표준 정규 사전 분포

### 왜 N(0, I)인가?

방향에 무관한 정규 사전 분포 $p(z) = \mathcal{N}(0, I)$이 표준 고름인 까닭은 여럿이다:

| 성질 | 좋은 점 |
|----------|---------|
| **닫힌 꼴 KL** | 정규 $q_\phi(z\|x)$과의 KL 벌어짐을 손으로 셈할 수 있다 |
| **뽑기 쉬움** | 뽑기가 뻔하다 |
| **방향에 무관함** | 숨은 공간에 두드러진 방향이 없다 |
| **최대 엔트로피** | 평균과 흩어짐이 주어진 분포 가운데 정규 분포의 엔트로피가 가장 크다 |

### 한계

표준 정규 사전 분포는 지나치게 옭아맬 수 있다. 모은 사후 분포가 봉우리 하나이고 공처럼 대칭이라고 여기는데 이는 자료의 참 짜임과 맞지 않을 수 있다. 뚜렷한 무리나 다양체 짜임이 있는 복잡한 자료에서는 정규 사전 분포가 덜 좋은 숨은 배치를 강요한다.

---

## 4. 사전 분포의 구멍 문제

### 무엇인가?

**사전 분포의 구멍**은 모은 사후 분포 $q_\phi(z)$이 사전 분포 $p(z)$과 맞지 않을 때 생긴다. $p(z)$에는 질량이 있으나 $q_\phi(z)$에는 없는 자리가 "구멍"이다. 풀개가 그런 숨은 부호에 뜻 있는 것을 내는 법을 배우지 못해 만들어 내기 품질이 나빠진다.

```
Prior p(z):              Aggregated q(z):        Gap:
   ┌─────────┐             ┌─────────┐          ┌─────────┐
   │  ░░░░░  │             │         │          │  ░░░░░  │
   │ ░░░░░░░ │             │  ▓▓ ▓▓  │          │ ░░   ░░ │
   │ ░░░░░░░ │      -      │  ▓▓ ▓▓  │    =     │ ░░   ░░ │
   │ ░░░░░░░ │             │         │          │ ░░░░░░░ │
   │  ░░░░░  │             │         │          │  ░░░░░  │
   └─────────┘             └─────────┘          └─────────┘
   Smooth bell          Clustered data          Decoder unseen
```

### 결과

사전 분포에서 뽑으면 이런 구멍에 떨어져 품질이 낮거나 실제 같지 않은 것이 나올 수 있다. 자료 짜임이 복잡할 때의 근본 한계이다.

## 5. 다른 사전 분포

### 정규 분포를 섞은 사전 분포

섞은 사전 분포는 봉우리 여럿인 짜임을 잡을 수 있다:

$$p(z) = \sum_{k=1}^{K} \pi_k \mathcal{N}(z; \mu_k, \Sigma_k)$$

```python
import torch
import torch.nn as nn

class GaussianMixturePrior(nn.Module):
    """배울 수 있는 정규 섞기 사전 분포."""
    
    def __init__(self, latent_dim, num_components=10):
        super().__init__()
        self.num_components = num_components
        
        # 배울 수 있는 섞기 매개변수
        self.logits = nn.Parameter(torch.zeros(num_components))
        self.means = nn.Parameter(torch.randn(num_components, latent_dim) * 0.5)
        self.logvars = nn.Parameter(torch.zeros(num_components, latent_dim))
    
    def log_prob(self, z):
        """섞기 아래에서 log p(z)을 셈한다."""
        # z: [묶음, 숨은 차원]
        # 퍼뜨리려 넓힌다: [묶음, K, 숨은 차원]
        z_exp = z.unsqueeze(1)
        
        # 성분마다의 로그 확률
        log_var = self.logvars.unsqueeze(0)
        means = self.means.unsqueeze(0)
        
        log_p_per_component = -0.5 * (log_var + (z_exp - means).pow(2) / log_var.exp())
        log_p_per_component = log_p_per_component.sum(dim=2)  # [묶음, K]
        
        # 무게로 섞는다
        log_weights = torch.log_softmax(self.logits, dim=0)
        log_p = torch.logsumexp(log_p_per_component + log_weights, dim=1)
        
        return log_p
    
    def sample(self, num_samples):
        """섞기 사전 분포에서 뽑는다."""
        # 성분을 고른다
        weights = torch.softmax(self.logits, dim=0)
        indices = torch.multinomial(weights, num_samples, replacement=True)
        
        # 고른 성분에서 뽑는다
        means = self.means[indices]
        stds = torch.exp(0.5 * self.logvars[indices])
        
        return means + stds * torch.randn_like(means)
```

### VampPrior(사후 분포를 변분으로 섞기)

VampPrior(Tomczak & Welling, 2018)은 배운 가짜 들임에서 따진 부호기 내놓기를 섞어 사전 분포를 정한다:

$$p(z) = \frac{1}{K}\sum_{k=1}^{K} q_\phi(z | u_k)$$

여기서 $u_1, \ldots, u_K$은 자료 공간의 배울 수 있는 가짜 들임이다. 그러면 사전 분포가 모은 사후 분포의 짜임에 저절로 맞는다.

```python
class VampPrior(nn.Module):
    """VampPrior: 사후 분포를 변분으로 섞기."""
    
    def __init__(self, encoder, input_dim, num_pseudoinputs=100):
        super().__init__()
        self.encoder = encoder
        self.pseudoinputs = nn.Parameter(torch.randn(num_pseudoinputs, input_dim) * 0.05)
    
    def get_prior_params(self):
        """가짜 들임에서 섞기 성분 매개변수를 얻는다."""
        with torch.no_grad():
            mu, logvar = self.encoder(torch.sigmoid(self.pseudoinputs))
        return mu, logvar
```

### 고르게 하는 흐름으로 배우는 사전 분포

고르게 하는 흐름은 표준 정규 분포를 표현력이 더 좋은 사전 분포로 바꿀 수 있다:

$$z_0 \sim \mathcal{N}(0, I), \quad z = f(z_0), \quad p(z) = p(z_0)|det \frac{\partial f^{-1}}{\partial z}|$$

그러면 밀도를 다룰 수 있게 지키면서도 사전 분포가 복잡하고 봉우리 여럿인 짜임을 잡는다.

## 6. 조건부 사전 분포

조건부 변분 자기 부호기에서는 사전 분포가 조건 앎에 기댈 수 있다:

$$p(z|y) = \mathcal{N}(z; \mu_{\text{prior}}(y), \sigma^2_{\text{prior}}(y))$$

배운 조건부 사전 분포는 모든 조건이 같은 $\mathcal{N}(0, I)$ 사전 분포를 나눠 쓰도록 강요하는 대신 갈래나 조건마다 숨은 공간의 다른 자리를 자연스럽게 차지하게 한다.

---

## 7. 실전 권고

대개의 쓰임새에서는 표준 정규 분포 $\mathcal{N}(0, I)$으로 시작하라. 단순하고 잘 알려졌으며 웬만큼 복잡한 자료에 잘 통한다. 다시 세우기는 좋은데 만들어 내기 품질이 나쁠 때, 자료에 뚜렷한 무리 짜임이 있을 때(섞은 사전 분포), 사전 분포가 자료에 맞춰지길 바랄 때(VampPrior), 복잡하고 봉우리 여럿인 분포를 다룰 때(흐름 바탕 사전 분포) 다른 사전 분포를 헤아려라.

<div class="drillbox" markdown>

**연습문제 1.** <span class="diff easy" title="쉬움"></span>
사전 분포로 $\mathcal{N}(0, I)$을 고르는 까닭을 세 가지 들어라.

</div>

??? success "연습문제 1 풀이"
    **KL이 닫힌 꼴로 떨어진다.** $q$도 가우시안이면 KL을 표집 없이 정확히 셈할 수 있어
    기울기에 잡음이 섞이지 않는다([KL 항](../theory/kl_term.md)).

    **뽑기가 쉽다.** `torch.randn(n, k)` 한 줄이면 된다. 만들어 내는 모델에서 이것은
    작은 편의가 아니다. 사전 분포에서 못 뽑으면 표본을 얻을 수 없다.

    **매개변수가 없다.** 배울 것이 없으므로 부호기와 풀개만 익히면 된다. 사전 분포를
    함께 배우면 풀개와 사전 분포가 서로를 좇는 불안정이 생길 수 있다.

    여기에 하나 더 보탤 수 있다. 각 차원이 독립이므로 차원마다 KL을 따로 볼 수 있고,
    그 덕에 어느 차원이 죽었는지 진단할 수 있다([자유 비트](../training/free_bits.md)).

**연습문제 2.** <span class="diff med" title="중간"></span>
사전 분포의 구멍(prior hole) 문제란 무엇인가?

</div>

??? success "연습문제 2 풀이"
    사전 분포 $p(z)$는 확률을 주는데 **아우른 사후 분포**
    $q(z) = \mathbb{E}_{p(x)}[q(z \mid x)]$는 거의 주지 않는 영역을 말한다.

    거기서 뽑은 $z$는 풀개가 익히는 동안 본 적이 없는 코드이므로, 풀개가 무엇을
    내놓을지 보장이 없다. 대개 얼룩이 나온다.

    이것이 자기 부호기와 변분 자기 부호기의 차이를 재는 자리이기도 하다. 자기 부호기는
    사전 분포를 아예 맞추지 않으므로 구멍이 공간 대부분이고, 그래서
    $\mathcal{N}(0,I)$에서 뽑은 표본 가운데 숫자로 보이는 것이 0.2%뿐이다. 변분 자기
    부호기는 57.4%다([23.5절](../../ch23/limits/latent_sampling.md)).

    다만 변분 자기 부호기에서도 구멍이 **사라지지는 않는다.** 57.4%라는 것은 42.6%가
    여전히 실패한다는 뜻이다. KL 항은 $q(z \mid x)$를 하나하나 $p(z)$에 가깝게 하지만,
    그 합인 $q(z)$가 $p(z)$와 같아지도록 직접 요구하지는 않기 때문이다.

    이 구별이 중요하다. **낱낱의 사후 분포를 맞추는 것과 아우른 사후 분포를 맞추는
    것은 다른 일이다.**

**연습문제 3.** <span class="diff hard" title="어려움"></span>
KL 항을 자료 전체에 걸쳐 평균 내면 두 조각으로 나눌 수 있다. 그 분해가 구멍 문제에 대해 무엇을 말해 주는가?

</div>

??? success "연습문제 3 풀이"
    자료 분포에 걸쳐 평균 낸 KL 항은 이렇게 갈린다.

    $$\mathbb{E}_{p(x)}\big[ D_{\mathrm{KL}}(q(z \mid x) \,\|\, p(z)) \big]
      = \underbrace{I(x; z)}_{\text{서로 앎}}
      + \underbrace{D_{\mathrm{KL}}(q(z) \,\|\, p(z))}_{\text{맞춤 어긋남}}$$

    오른쪽 둘의 성격이 정반대다.

    | 조각 | 무엇을 뜻하는가 | 줄이면 |
    |---|---|---|
    | $I(x;z)$ | 코드가 나르는 정보 | 코드가 쓸모없어진다 |
    | $D_{\mathrm{KL}}(q(z) \| p(z))$ | 아우른 사후 분포와 사전 분포의 어긋남 | 구멍이 줄어든다 |

    우리가 원하는 것은 **뒤쪽만** 줄이는 것이다. 그런데 손실은 둘의 **합**을 줄이라고
    하므로, 최적화기는 더 쉬운 쪽을 고른다. 그리고 $I(x;z)$를 줄이는 것이 흔히 더 쉽다.
    차원 하나를 죽이면 바로 줄어들기 때문이다.

    그래서 $\beta$를 올리면 구멍이 메워지기보다 **차원이 죽는다.** 실제로
    $\beta = 1$에서 4개, $\beta = 4$에서 9개가 죽는다([베타 VAE](beta_vae.md)).

    이 분해가 여러 후속 방법의 출발점이다. 뒤쪽 항만 따로 벌하자는 것이 InfoVAE와
    적대적 자기 부호기의 생각이고, 앞쪽 항이 너무 줄지 않게 바닥을 받치자는 것이
    [자유 비트](../training/free_bits.md)다.

**연습문제 4.** <span class="diff med" title="중간"></span>
정규 분포를 섞은 사전 분포를 쓰면 무엇이 나아지는가? 무엇이 나빠지는가?

</div>

??? success "연습문제 4 풀이"
    **나아지는 것**은 표현력이다. MNIST의 코드는 부류마다 덩이를 이루므로
    ([23.5절의 그림](../../ch23/limits/latent_sampling.md)) 봉우리 하나인 가우시안보다
    여러 봉우리인 혼합이 그 모양에 훨씬 잘 맞는다. 맞춤 어긋남 항이 줄고 구멍이 준다.

    **나빠지는 것**이 셋이다.

    - KL이 닫힌 꼴로 떨어지지 않는다. 혼합에 대한 KL은 표집해야 하므로 기울기에
      잡음이 늘어난다
    - 배울 매개변수가 는다. 봉우리의 개수, 자리, 퍼짐, 무게를 정해야 한다
    - 봉우리의 개수를 미리 정해야 한다. MNIST라면 10이 자연스럽지만 대개는 모른다

    그래서 실무의 순서는 이렇다. 먼저 $\mathcal{N}(0,I)$로 해 보고, 표본이 나쁘고
    그 까닭이 구멍으로 보일 때 손을 댄다. 그리고 손을 댈 때도 사전 분포를 바꾸기보다
    **부류를 알고 있으면 조건부로 가는 편**이 쉽고 효과가 크다. 실제로 조건부 변분
    자기 부호기는 지정한 부류대로 90.1%가 나온다([조건부 VAE](conditional_vae.md)).

**연습문제 5.** <span class="diff easy" title="쉬움"></span>
사전 분포를 $\mathcal{N}(0, \sigma^2 I)$로 두고 $\sigma$를 바꾸면 무엇이 달라지는가?

</div>

??? success "연습문제 5 풀이"
    본질적으로 아무것도 달라지지 않는다. 숨은 공간의 자 단위만 바뀐다.

    풀개의 첫 층 가중치를 $1/\sigma$배 하고 부호기의 출력을 $\sigma$배 하면 정확히 같은
    모델이 되므로, 그물이 스스로 그 눈금을 흡수한다.

    그래서 $\sigma = 1$로 고정하는 것이 관례다. 자유롭게 두어도 얻는 것이 없고 배울
    것만 는다.

    주의할 것은 **$\beta$와 헷갈리지 않는 것**이다. $\beta$는 두 항의 무게를 바꾸므로
    진짜로 다른 모델을 만들지만, 사전 분포의 $\sigma$는 눈금일 뿐이다. 겉보기에 둘 다
    "KL을 조절하는 것"처럼 보여도 하나는 뜻이 있고 하나는 없다.

    |---|---|---|---|---|---|
    | 살아 있는 차원 | 2 | 8 | 12 | 17 | **11** |
    | 다시 세우기 | 136.57 | 89.19 | **81.22** | 82.06 | 83.33 |

    16을 넘어서면 늘려 준 차원을 모델이 **쓰지 않는다.** 64개를 주었는데 11개만 쓴다.

    읽는 법이 두 가지다.

    좋게 보면 **모델이 스스로 차원을 고른다.** 사전 분포와 KL 항이 함께 "필요 없는
    차원은 꺼라"는 압력을 주므로, 병목을 정확히 맞추지 않아도 대충 크게 잡아 두면
    알아서 쓸 만큼만 쓴다. 자기 부호기에서는 이런 일이 없어 병목이 곧 코드 크기였다.

    나쁘게 보면 **더 쓸 수 있는데 안 쓴다.** 다시 세우기가 16에서 이미 바닥이고 32, 64에서
    오히려 조금 나빠지는 것은, 남는 차원이 도움이 안 되었을 뿐 아니라 최적화를 약간
    방해했다는 뜻이다. 32개에서 17개가 살아 있는데 16개짜리보다 못하다.

    실무의 교훈은 간단하다. **숨은 차원을 넉넉히 주고 죽는 차원의 수로 적정 크기를
    읽어라.** 다만 넉넉함이 공짜는 아니니 두 배쯤에서 멈추는 것이 좋다.

**연습문제 7.** <span class="diff hard" title="어려움"></span>
구멍 문제를 재는 방법을 하나 설계하라.

</div>

??? success "연습문제 7 풀이"
    핵심은 $p(z)$에서 뽑은 코드가 $q(z)$에서 보아 얼마나 그럴듯한지 재는 것이다.
    몇 가지 길이 있다.

    **판별기를 익힌다.** $q(z)$에서 뽑은 코드(자료를 부호기에 넣어 얻은 것)와 $p(z)$에서
    뽑은 코드를 가르는 분류기를 익힌다. 잘 갈라내면 두 분포가 다른 것이고, 정확도가
    50%에 가까우면 잘 맞은 것이다. 이 판별기를 손실에 직접 넣으면 적대적 자기
    부호기가 된다.

    **가장 가까운 이웃까지의 거리.** $p(z)$에서 뽑은 $z$마다 학습 자료의 코드 가운데
    가장 가까운 것까지의 거리를 재고, 학습 코드끼리의 같은 거리와 견준다. 전자가
    훨씬 크면 구멍에 떨어진 것이다.

    **가장 간단한 대리 잣대.** 뽑아서 풀개에 넣고 결과를 분류기에게 보인다. 이 책이
    쓴 방법이며 0.2% 대 57.4%가 그것이다. 구멍을 직접 재지는 않지만 구멍이 만드는
    **결과**를 재므로 실용적이다.

    셋 가운데 무엇을 고를지는 목적에 달렸다. 진단이 목적이면 두 번째가 어디가 빈지
    알려 주어 좋고, 보고가 목적이면 세 번째가 읽는 사람에게 뜻이 분명하다.

    어느 잣대든 한 가지를 조심해야 한다. **다양성을 보지 않는다**는 점이다. 모든 표본이
    같은 3이어도 세 잣대 모두 좋은 점수를 준다. 그것까지 보려면
    [27장](../../ch27/index.md)의 잣대가 필요하다.

**연습문제 8.** <span class="diff med" title="중간"></span>
사전 분포를 배우게 하면 다시 세우기 오차가 0이 되도록 퇴화할 위험이 있는가?

</div>

??? success "연습문제 8 풀이"
    있다. 사전 분포에 충분한 자유를 주면 $p(z)$를 $q(z)$에 정확히 맞출 수 있고, 그러면
    맞춤 어긋남 항이 0이 된다.

    그 자체는 좋은 일처럼 보인다. 구멍이 사라지니까. 그런데 앞의 분해를 보면

    $$\mathbb{E}_{p(x)}[\text{KL}] = I(x;z) + D_{\mathrm{KL}}(q(z) \| p(z))$$

    에서 뒤쪽이 0이 되면 KL 항이 $I(x;z)$만 남는다. 곧 **정보량에 대한 벌점만 남고
    모양에 대한 제약이 사라진다.** 코드가 어떤 모양으로 흩어져도 사전 분포가 따라가
    주므로, 부호기는 되돌리기에만 좋은 아무 모양이나 고를 수 있다.

    극단으로 가면 사전 분포가 학습 자료의 코드에 델타 함수를 얹은 꼴이 되어, 뽑기가
    곧 **학습 자료를 되읽는 것**이 된다. 다시 세우기는 완벽하고 표본은 새롭지 않다.

    VampPrior가 이 위험을 다루는 방식이 눈여겨볼 만하다. 사전 분포를 자유롭게 두지
    않고 **학습 가능한 가짜 입력 $K$개의 사후 분포를 섞은 것**으로 묶는다. $K$가 자료
    수보다 훨씬 작으므로 외울 그릇이 없다.

    곧 사전 분포를 배우게 할 때는 그 표현력에 예산을 매겨야 한다. 자유롭게 두면
    정칙화가 사라진다.

**연습문제 9.** <span class="diff easy" title="쉬움"></span>
사전 분포를 조건부 $p(z \mid y)$로 두는 것과 풀개에 $y$를 넣는 것은 어떻게 다른가?

</div>

??? success "연습문제 9 풀이"
    둘 다 부류 정보를 쓰지만 들어가는 자리가 다르다.

    | 방식 | 부류가 하는 일 |
    |---|---|
    | $p(z \mid y)$ | 부류마다 코드가 놓일 **자리**를 정한다 |
    | 풀개에 $y$를 넣는다 | 같은 코드를 부류에 따라 **다르게 푼다** |

    첫 번째는 숨은 공간이 부류별로 갈라진다. 뽑을 때 해당 부류의 봉우리에서 뽑으면
    되고, 코드만 보고도 부류를 알 수 있다.

    두 번째는 숨은 공간이 부류와 무관해진다. 부류는 풀개가 따로 받으므로 코드에는
    **부류를 뺀 나머지**(기울기, 굵기, 모양새)만 남는다. 그래서 같은 $z$에 다른 $y$를
    넣어 "같은 글씨체의 다른 숫자"를 얻을 수 있다.

    이 책의 [조건부 변분 자기 부호기](conditional_vae.md)는 두 번째를 쓴다. 부호기와
    풀개 양쪽에 $y$를 넣으므로 코드가 부류를 나를 까닭이 없어진다.

    둘을 함께 쓸 수도 있고, 무엇을 원하는지가 고르는 기준이다. 부류별로 갈린 숨은
    공간을 보고 싶으면 첫 번째, 부류와 글씨체를 떼어 놓고 싶으면 두 번째다.

**연습문제 10.** <span class="diff med" title="중간"></span>
이 절이 권하는 순서는 무엇인가? 언제 사전 분포에 손을 대야 하는가?

</div>

??? success "연습문제 10 풀이"
    **먼저 $\mathcal{N}(0,I)$로 한다.** 배울 것이 없고 KL이 닫힌 꼴이며 뽑기가 한
    줄이다. 이 세 가지 편의가 크다.

    손을 대기 전에 확인할 것이 있다. 표본이 나쁠 때 그 까닭이 정말 사전 분포인지
    가려야 한다. 흔한 까닭이 따로 있다.

    | 증상 | 더 그럴듯한 까닭 |
    |---|---|
    | 표본이 흐릿하다 | 풀개가 약하거나, 가우시안 가능도 자체의 한계 |
    | 표본에 다양성이 없다 | 차원이 죽었다 → [자유 비트](../training/free_bits.md) |
    | 표본이 얼룩이다 | 구멍. 여기서야 사전 분포 이야기 |

    가운데 칸이 특히 그렇다. $\beta$가 조금만 높아도 차원이 절반 넘게 죽는데
    ([베타 VAE](beta_vae.md)), 그것은 사전 분포의 모양 문제가 아니라 무게 문제다.
    자유 비트로 고칠 일에 혼합 사전 분포를 가져오면 복잡해지기만 한다.

    부류를 알고 있다면 **조건부로 가는 것이 거의 언제나 먼저**다. 얻는 것이 크고
    (지정한 부류대로 90.1%) 구현이 쉽다.

    정리하면 이 순서다. 표준 정규 → 차원이 죽는지 확인 → 부류를 쓸 수 있으면 조건부 →
    그래도 구멍이 문제이면 사전 분포.

## 정리하며

| 사전 분포 | KL 셈하기 | 표현력 | 복잡함 |
|-------|---------------|----------------|------------|
| **표준 정규** | 닫힌 꼴 | 낮음 | 가장 적음 |
| **정규 분포 섞기** | 뽑기가 필요 | 가운데 | 웬만함 |
| **VampPrior** | 뽑기가 필요 | 높음 | 웬만함 |
| **흐름 바탕** | 정확(변수 바꿈) | 높음 | 높음 |
| **조건부** | 꼴에 따라 다름 | 일마다 다름 | 웬만함 |
