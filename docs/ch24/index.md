# 장 개요
이 장은 주성분 분석과 그 변형부터 매니폴드 학습 방법까지 선형과 비선형 차원 줄이기 재주를 다룬다. 절마다 수학의 기초를 엄밀히 세우고 차원 높은 데이터 살피기에 어떻게 쓰는지 보이며, 특히 수익률 곡선 쪼개기, 자산 꾸러미 최적화, 국면 그려 보기 같은 금융 응용에 무게를 둔다.

# 참고 문헌

---

## 1. 주성분 분석

선형 차원 줄이기를 위한 주성분 분석과 그 넓힘.

- [주성분 분석의 기초](pca/pca_fundamentals.md) -- 분산 최대화, 직교 쏘기, 가장 좋은 선형 눌러 담기
- [주성분 분석 유도](pca/pca_derivation.md) -- 분산 최대화와 어긋남 최소화 관점에서의 엄밀한 유도
- 고윳값 쪼개기 -- 공분산 행렬의 스펙트럼 쪼개기로 주성분 계산
- 주성분 분석을 위한 특잇값 분해 -- 특잇값 분해로 효율 좋고 수치가 안정된 주성분 분석 계산
- [커널 PCA](pca/kernel_pca.md) -- 커널 트릭로 하는 비선형 차원 줄이기
- 확률 주성분 분석 -- 주성분 분석과 변분 오토인코더를 잇는 만들어 내는 잠재변수 꼴
- 주성분 분석 쓰임새 -- 쏘기, 눌러 담기, 잡음 없애기, 특징 샘플링의 실전 짜기
- 선형 오토인코더로 본 주성분 분석 -- 주성분 분석과 선형 오토인코더의 수학적 같음

---

## 2. 매니폴드 학습

속에 든 낮은 차원 구조를 되찾는 비선형 차원 줄이기 방법.

- 매니폴드 학습 들어가기 -- 매니폴드 가설, 이웃 지키기, 방법의 갈래 나누기
- t-SNE -- 그려 보기를 위해 꼬리가 두꺼운 분포를 쓰는 확률 이웃 임베딩
- UMAP -- 규모를 키울 수 있는 차원 줄이기를 위한 위상 데이터 살피기와 확률 기울기 내려가기
- Isomap -- 비선형 매니폴드를 펴려고 측지 거리를 지키기
- LLE -- 그때그때의 재구성 무게를 지키는 국소 선형 임베딩
- [MDS](manifold/mds.md) -- 둘씩의 거리를 지키는 여러 차원 스케일링

---

## 3. 금융

계량 금융 문제에 차원 줄이기를 쓰기.

- 요인 모델을 위한 주성분 분석 -- 차원 높은 금융 데이터에서 체계 위험 요인 샘플링
- [수익률 곡선 분해](finance/yield_curve.md) -- 높이, 기울기, 굽음 성분으로 주성분 쪼개기
- 자산 꾸러미 차원 줄이기 -- 요인 기초 눌러 담기로 자산 꾸러미 최적화를 낫게 하기
- 국면 그려 보기 -- 주성분 분석, t-SNE, 매니폴드 학습으로 시장 국면 그려 보기
