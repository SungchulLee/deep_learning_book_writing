# 앤드루의 단조 사슬

앤드루의 단조 사슬 알고리즘은 평면 위 점 모임의 볼록 껍질을 **아래 껍질**과 **위 껍질**로 따로 나누어 세우며, 각각을 x자리값으로 정렬한 단조 다각 사슬로 만든다. 먼저 정렬한 뒤 왼쪽에서 오른쪽으로(아래), 오른쪽에서 왼쪽으로(위) 훑으면 단순하고 저장턱에 친한 코드로 $O(n \log n)$ 시간이 된다.

## 직관

모든 점을 x자리값으로 정렬한다(같으면 y로 가른다). 왼쪽에서 오른쪽으로 걸으며 늘 **왼쪽**으로(반시계) 돈다. 마지막 세 점이 오른쪽으로 돌거나 한 줄에 놓이면 가운데 점을 빼낸다. 살아남은 점이 껍질의 아래 가장자리를 이룬다. 위 가장자리는 거꾸로 되풀이한 뒤 두 사슬을 잇는다.

## 정의

**볼록 껍질.** 유한한 점 모임 $S \subset \mathbb{R}^{2}$이 주어질 때 볼록 껍질 $\operatorname{CH}(S)$은 $S$의 모든 점을 담는 가장 작은 볼록 다각형이다.

**어긋 곱 살피기.** 세 점 $o, a, b$에 대해 평행사변형의 부호 있는 넓이는 다음과 같다.

$$
\operatorname{cross}(o, a, b)
  = (a_x - o_x)(b_y - o_y) - (a_y - o_y)(b_x - o_x)
$$

- $> 0$: 반시계(왼쪽 돌기)
- $= 0$: 한 줄에 놓임
- $< 0$: 시계(오른쪽 돌기)

## 알고리즘

1. $n$개 점을 $(x, y)$ 사전 차례로 **정렬한다**.
2. **아래 껍질.** 빈 쌓기를 첫자리매김한다. 정렬된 차례로 각 점 $p$에 대해, 쌓기의 마지막 두 점과 $p$이 왼쪽으로 돌지 **않는** 동안($\operatorname{cross} \le 0$) 쌓기에서 빼낸다. 그런 다음 $p$을 밀어넣는다.
3. **위 껍질.** 거꾸로 된 정렬 차례로 같은 훑기를 한다.
4. 두 사슬을 **이어 붙인다**(겹친 끝점은 없앤다).

## 올바름

!!! note "주장"
    이 알고리즘은 정확히 $\operatorname{CH}(S)$의 꼭짓점을 반시계 차례로 내놓는다.

**증명 얼개.**
아래 껍질 쌓기에서 빠진 점은 모두 그 앞 점, $p$, 그리고 뒤의 어떤 껍질 꼭짓점이 이루는 삼각형 안에 엄격히 놓이므로 껍질 꼭짓점일 수 없다. 살아남은 점은 뒤따르는 어떤 점도 그것을 빼내지 않으므로 가장자리에 놓이며, 따라서 어떤 끝 방향을 증언한다. 위 껍질 논증은 대칭이다. 이어 붙이면 안쪽 각이 모두 $\pi$보다 작은 단순 다각형이 되므로 볼록하다.

## 복잡도

| 잣대 | 비용 |
|---------|------|
| 시간 | $O(n \log n)$ — 정렬이 도맡는다. 점마다 많아야 한 번 밀어넣고 한 번 빼낸다 |
| 자리 | $O(n)$ — 정렬한 배열과 쌓기 두 개 |

$O(n \log n)$ 한계는 견줌에 바탕한 볼록 껍질에서 **가장 좋다**(아래 한계 쪽을 보라).

## 구현

```python
"""
앤드루의 단조 사슬 — O(n log n) 볼록 껍질.
"""

from __future__ import annotations


# === 어긋 곱 방향 살피기 ======================================================

def cross(o: tuple[float, float],
          a: tuple[float, float],
          b: tuple[float, float]) -> float:
    """벡터 OA과 OB이 이루는 평행사변형의 부호 있는 넓이를 돌려준다.

    양수 ⟹ 반시계, 0 ⟹ 한 줄에 놓임, 음수 ⟹ 시계.
    """
    return (a[0] - o[0]) * (b[1] - o[1]) - (a[1] - o[1]) * (b[0] - o[0])


# === 단조 사슬 ==============================================================

def convex_hull(points: list[tuple[float, float]]) -> list[tuple[float, float]]:
    """볼록 껍질 꼭짓점을 반시계 차례로 돌려준다.

    껍질 가장자리에서 한 줄에 놓인 점은 빠진다(엄격한 부등호가
    쓰였기 때문이며 넣으려면 ``<= 0``을 ``< 0``으로 바꾸면 된다).
    """
    pts = sorted(set(points))
    if len(pts) <= 1:
        return list(pts)

    # 아래 껍질(왼쪽에서 오른쪽)
    lower: list[tuple[float, float]] = []
    for p in pts:
        while len(lower) >= 2 and cross(lower[-2], lower[-1], p) <= 0:
            lower.pop()
        lower.append(p)

    # 위 껍질(오른쪽에서 왼쪽)
    upper: list[tuple[float, float]] = []
    for p in reversed(pts):
        while len(upper) >= 2 and cross(upper[-2], upper[-1], p) <= 0:
            upper.pop()
        upper.append(p)

    # 사슬이 만나는 곳의 겹친 끝점을 없앤다
    return lower[:-1] + upper[:-1]


# === 보임 ====================================================================

if __name__ == "__main__":
    sample = [(0, 0), (1, 1), (2, 2), (0, 2), (2, 0), (1, 0)]
    hull = convex_hull(sample)
    print(f"Input:  {sample}")
    print(f"Hull:   {hull}")
    print(f"Vertices on hull: {len(hull)}")
```

**출력:**

```
Input:  [(0, 0), (1, 1), (2, 2), (0, 2), (2, 0), (1, 0)]
Hull:   [(0, 0), (1, 0), (2, 0), (2, 2), (0, 2)]
Vertices on hull: 5
```

한 줄에 놓인 점 $(0,0), (1,0), (2,0)$은 껍질 가장자리에 있으므로 모두 나타나지만, 안쪽 점 $(1,1)$과 $(2,2) \to (0,2)$ 도막의 가운데 점은 빠진다.

## 변형

- **한 줄에 놓인 점 넣기.** 빼내기 조건에서 `<= 0`을 `< 0`으로 바꾼다. 그러면 껍질 가장자리의 모든 점이 알려진다.
- **온라인 / 조금씩 늘리기.** 껍질 모서리를 고른 이진 찾기 나무로 지키면 넣기마다 $O(\log n)$이 되지만 상수는 더 크다.

앤드루의 단조 사슬의 핵심 기하 통찰과 그 시간 복잡도를 설명하라.

??? success "연습문제 1 풀이"
    앤드루의 단조 사슬은 기하의 성질(방향, 거리, 각 차례, 훑는 선 사건)을 이용해 점이나 선, 다각형의 모임을 효율 좋게 다룬다. 시간 복잡도는 흔히 $O(n \log n)$(견줌에 바탕한 기하 문제에서 가장 좋다)에서, 본디 이차 짜임을 지닌 문제의 $O(n^2)$까지이다. 핵심 통찰은 기하 문제를 여느 알고리즘이 풀 수 있는 조합 문제로 줄이는 것이다. $\square$

**연습문제 2.**
작은 점 모임 $\{(0,0), (1,3), (3,1), (4,4), (2,2)\}$에서 앤드루의 단조 사슬을 좇아라.

??? success "연습문제 2 풀이"
    알고리즘의 방책(자리값으로 정렬하기, 각으로 훑기, 사건에 따라 다루기)에 따라 점을 다룬다. 걸음마다 기하 짜임(볼록 껍질, 만남 목록, 보로노이 칸 등)을 새로 고친다. 마지막 결과가 이 들임에 대한 알고리즘의 내놓기이다. 손으로 셈한 것과 견주어 기하의 성질을 살펴 옳음을 확인하라. $\square$

**연습문제 3.**
앤드루의 단조 사슬은 어떤 찌그러진 경우를 다루어야 하는가? 흔히 어떻게 푸는가?

??? success "연습문제 3 풀이"
    흔한 찌그러진 경우는 이렇다. (1) **한 줄에 놓인 점**: 셋 이상이 한 선 위에 있으면 방향 살피기가 애매해진다. (2) **겹친 점**: 자리값이 똑같다. (3) **세로선**: 기울기 셈에서 0으로 나누게 된다. (4) **한 동그라미 위의 점**: 네 점이 한 동그라미 위에 있으면 들로네 삼각 나누기에 영향을 준다. 푸는 방책은 튼튼한 판정(정확한 셈)을 쓰거나, 기호로 살짝 흔들거나(일반 자리를 흉내 냄), 찌그러진 경우를 따로 다루는 코드를 두는 것이다. $\square$

**연습문제 4.**
앤드루의 단조 사슬을 막무가내 방식과 견주어라. 점 $n = 10^6$개에서 얼마나 빨라지는지 수로 나타내라.

??? success "연습문제 4 풀이"
    막무가내 방식은 짝이나 세 짝을 모두 살피므로 흔히 $O(n^2)$이나 $O(n^3)$이 든다. 앤드루의 단조 사슬은 $O(n \log n)$ 또는 그보다 좋다. $n = 10^6$이면 막무가내는 셈이 $10^{12}$번이나 $10^{18}$번(몇 시간에서 몇 해) 필요하지만 효율 좋은 알고리즘은 $\approx 2 \times 10^7$번(몇 초)이면 된다. 빨라지는 갑절은 $10^5$에서 $10^{11}$이므로 들임이 클 때는 효율 좋은 알고리즘이 꼭 필요하다. $\square$
