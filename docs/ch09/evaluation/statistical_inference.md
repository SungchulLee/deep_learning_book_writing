# 모델 평가를 위한 통계적 추론

---

## 1. 들어가며: 신호와 잡음의 차이

두 모델의 평가 지표가 조금 다르다고 실제 성능 차이가 확실한 것은 아니다. 표본 변동, 학습의 무작위성, 모델 선택의 영향을 나누어 분석해야 한다. 많은 후보를 같은 데이터에서 비교할수록 우연히 좋아 보이는 후보를 고를 가능성이 커진다.

## 2. 추정량의 성질

모델을 비교하기 전에 추정값을 믿을 수 있게 해 주는 성질이 필요하다.

**바이어스**: $E[\hat{\theta}] = \theta$이면 추정량 $\hat{\theta}$은 불편이다

$$\text{Bias}(\hat{\theta}) = E[\hat{\theta}] - \theta$$

**분산**: 표본이 달라질 때 추정량이 얼마나 안정적인지를 잰다

$$\text{Var}(\hat{\theta}) = E[(\hat{\theta} - E[\hat{\theta}])^2]$$

**평균제곱오차**: 편향과 분산을 합친다

$$\text{MSE}(\hat{\theta}) = \text{Bias}(\hat{\theta})^2 + \text{Var}(\hat{\theta})$$

**일치성**: $n \to \infty$일 때 $\hat{\theta} \xrightarrow{p} \theta$이면 추정량은 일치추정량이다

독립·동일분포이고 유한한 분산을 갖는 표본의 평균 $\bar{X}_n = \frac{1}{n}\sum_{i=1}^n X_i$에 대해 다음과 같다.

- 불편: $E[\bar{X}_n] = \mu$
- 분산: $\text{Var}(\bar{X}_n) = \frac{\sigma^2}{n}$ (표본이 커질수록 줄어든다)
- 일치: 큰 수의 법칙에 의해

이 가정에서 분모 n-1의 표본분산은 모집단 분산의 불편추정량이다. 표본평균과 서로 다른 모수를 추정하므로 단위와 분산의 크기를 직접 비교할 수 없다.

## 3. 신뢰구간

95% 신뢰구간은 같은 표집 절차를 반복해 구간을 만들면 약 95%가 고정된 참 모수를 포함하도록 설계한 절차이다. 관측된 특정 구간에 참 모수가 95%의 확률로 들어간다는 빈도주의 해석은 아니다. [NIST의 정의](https://csrc.nist.gov/glossary/term/confidence_interval)를 참고한다.

**고정된 분류기의 정확도에 대한 정규 근사:**
($n$이 클 때) 정규 근사를 쓰면 다음과 같다.

$$\hat{p} \pm z_{1-\alpha/2} \sqrt{\frac{\hat{p}(1-\hat{p})}{n}}$$

**샤프 비율의 경우:**
샤프 비율처럼 평균과 표준편차의 비인 지표는 그 자체의 표집 특성을 고려한다. 정확도에 대한 위 이항 표준오차 공식을 수익률 평균이나 샤프 비율에 적용할 수 없다. 시계열 의존성과 지표의 단위·연율화 관례도 확인해야 한다.

!!! note "재표집의 단위"
    부트스트랩도 표본이 어떻게 생성되는지에 관한 가정이 필요하다. 독립 표본은 개별 표본을, 군집 자료는 군집을, 시계열은 의존성을 유지하는 블록 등을 재표집한다. 경로 의존적인 지표나 극값에는 단순 분위수 구간의 타당성이 자동으로 성립하지 않는다.

## 4. 가설 검정

**독립적인 대응 차이에 대한 t 검정:**

각 시험 기간 $i$에 대해 짝지어진 성능 지표 $(Y_{1i}, Y_{2i})$이 주어졌을 때 다음과 같다.

$$t = \frac{\bar{D}}{\frac{S_D}{\sqrt{n}}} \sim t_{n-1}$$

여기서 D_i는 같은 평가 단위에서 측정한 두 모델의 차이이다. 차이들이 독립·동일분포인 정규 표본이면 귀무가설 아래 정확한 t 분포를 쓰고, 충분한 표본에서는 적절한 근사를 검토할 수 있다. 겹치는 기간·교차 검증 폴드를 독립 반복으로 다루면 안 된다.

**귀무가설**: $H_0: \mu_D = 0$ (성능에 차이가 없다)

**p 값**: $H_0$ 아래에서 이 검정통계량(또는 더 극단적인 값)을 관측할 확률

!!! danger "다중 비교 문제"
    모델 100개를 기준선과 비교하여 시험하면 유의수준 $\alpha=0.05$에서 모든 귀무가설이 참이고 각 검정이 유효하면 거짓 기각 수의 기댓값이 5이다. 실제로 반드시 5개가 나온다는 뜻은 아니다. 보정이 꼭 필요한 까닭이 여기에 있다.

## 5. 다중 검정 보정

**본페로니 보정:**

유효한 p 값을 가진 검정 $m$개에 대해, 검정 간 독립성을 요구하지 않고 개별 유의수준을 조정하여 집단별 오류율을 통제한다.

$$\alpha_{adjusted} = \frac{\alpha}{m}$$

매우 보수적이어서 참 신호도 많이 버린다. 검정이 $m=100$개라면 $\alpha_{adjusted} = 0.0005$이다.

**거짓 발견율(FDR) 통제:**

벤저미니-호크버그 절차는 덜 보수적이다.

1. p 값을 정렬한다. $p_{(1)} \leq p_{(2)} \leq ... \leq p_{(m)}$
2. $p_{(i)} \leq \frac{i}{m} \alpha$을 만족하는 가장 큰 $i$을 찾는다
3. 가설 $1, ..., i$을 모두 기각한다

FDR은 기각한 가설 중 거짓 기각 비율의 **기댓값**을 통제한다. 표준 벤저미니–호크버그 절차의 보장은 독립성 또는 특정 양의 의존 조건에서 성립한다. 임의의 의존 구조나 선택 후 p 값에 아무 보정 없이 적용할 수는 없다.

## 6. 부트스트랩 방법

**비모수 부트스트랩 알고리즘:**

```
for b = 1 to B:
    Sample with replacement from original data: X*_b
    Compute estimator: θ̂*_b = f(X*_b)
end
Estimated variance: Var(θ̂) ≈ Var(θ̂*_1, ..., θ̂*_B)
```

위 코드는 독립 관측을 재표집하는 기본 예이다. 같은 표본에서 두 모델을 비교하려면 동일 인덱스로 짝을 유지해야 한다. 시계열이나 군집 데이터에는 그 구조에 맞는 재표집 방법이 필요하다.

예를 들어 지표가 기준값보다 큰지 보려면 해당 단측 가설과 일치하는 구간·검정을 설계해야 한다. 양측 구간이 기준값을 포함하지 않는다는 사실만으로 더 크다고 결론 내리면 안 된다. 구간 전체가 기준보다 아래일 수도 있다.

## 7. 통계적 절차로서의 교차 검증

K겹 교차 검증은 일반화 오차 $\mathcal{L}$을 추정한다.

$$\widehat{\text{CV}} = \frac{1}{k} \sum_{i=1}^k L_i$$

여기서 $L_i$은 $i$번째 홀드아웃 겹에서의 로스다.

**핵심**: 교차 검증의 추정값은 서로 독립이 아니다. 겹들이 학습 데이터를 나누어 쓰므로 상관이 생긴다.

**교차 검증 추정량의 분산:**

$$\operatorname{Var}(\widehat{CV})=\frac1{k^2}\left[\sum_i\operatorname{Var}(L_i)+2\sum_{i<j}\operatorname{Cov}(L_i,L_j)\right]$$

공분산의 영향은 분할 방식과 데이터에 따라 달라진다. 표준오차에 보편적인 10~30% 가산율이 있는 것은 아니다. 폴드 표준편차를 sqrt(k)로 나눈 값을 독립 반복의 표준오차처럼 해석하지 않는다.

!!! warning "시계열 교차 검증"
    표준 K겹은 시계열에 알맞지 않다. 앞으로 이어 가는 검증을 쓰라.

    - 1~5년으로 학습하고 6년으로 시험한다
    - 1~6년으로 학습하고 7년으로 시험한다
    - 시간 순서만 맞춰도 전처리·레이블 기간·중복 데이터의 누출이 남을 수 있다. 각 시점에 실제 사용 가능한 정보만 사용한다

## 8. 퀀트 실무자를 위한 실용 지침

평가 계획과 후보 탐색 기록을 남기고, 시간 순서를 지킨 검증과 독립적인 최종 평가를 마련한다. 여러 후보를 검정했다면 그 선택 과정과 다중성을 반영한다.

검정력은 효과 크기, 변동, 의존성, 유의수준과 검정 방법에 달려 있다. 특정 관측 일수나 기간만으로 99% 검정력이나 실전 성과를 보장할 수 없다. 통계적 유의성, 효과 크기, 비용을 반영한 실용적 의미도 구분한다.

<div class="drillbox" markdown>

**연습문제 1.** <span class="diff med" title="중간"></span>
모델 성능에 대한 점추정과 신뢰구간의 차이를 설명하라.

</div>

??? success "연습문제 1 풀이"
    점추정(예: 정확도 = 92%)은 수 하나를 준다. 신뢰구간(예: 92% ± 1.5%)은 불확실성을 수치로 나타낸다. 시험 표본이 $n$개일 때 정확도 $p$의 95% 신뢰구간은 대략 $p \pm 1.96\sqrt{p(1-p)/n}$이다. 구간 없이 점추정만 보고하면 오해를 부를 수 있다.

---

<div class="drillbox" markdown>

**연습문제 2.** <span class="diff hard" title="어려움"></span>
두 모델을 비교하는 대응 부트스트랩 검정을 구현하라.

</div>

??? success "연습문제 2 풀이"
    ```python
    def bootstrap_compare(scores_a, scores_b, n_bootstrap=10000):
        n = len(scores_a)
        diffs = []
        for _ in range(n_bootstrap):
            idx = torch.randint(0, n, (n,))
            diff = scores_a[idx].mean() - scores_b[idx].mean()
            diffs.append(diff.item())
        p_value = (torch.tensor(diffs) <= 0).float().mean()
        return p_value
    ```

**연습문제 3.** <span class="diff med" title="중간"></span>
교차 검증 폴드 수가 k이면 추정 분산이 항상 1/k로 줄어드는가?

</div>

??? success "연습문제 3 풀이"
    아니다. 학습 데이터를 공유하므로 폴드 로스는 상관될 수 있다. 전체 분산에는 폴드 간 공분산이 들어간다. 교차 검증은 분할에 대한 평가를 넓히지만 데이터 의존성과 모델 선택 효과를 반영해야 하며, 선택 성능에는 중첩 검증이나 독립 테스트가 필요할 수 있다.

**연습문제 4.** <span class="diff med" title="중간"></span>
같은 독립 테스트 표본의 두 분류기를 정확도로 비교할 때 맥니마 검정이 사용하는 정보는 무엇인가?

</div>

??? success "연습문제 4 풀이"
    한 모델만 맞힌 두 종류의 불일치 표본 수를 사용해 오류 확률의 차이를 검정한다. 같은 표본의 예측이라는 대응 구조를 보존한다. 불일치 수가 적으면 정확 검정을 고려하며, 시계열·군집 표본이나 테스트셋을 이용한 모델 선택에서는 추가 가정과 처리가 필요하다.

## 정리하며

평가 불확실성에는 표집, 학습과 선택 과정이 함께 영향을 준다. 신뢰구간의 반복 표집 의미와 p 값의 조건을 정확히 읽고, 대응·군집·시간 의존성에 맞는 재표집과 검정을 선택한다. 다중 보정도 유효한 기초 p 값과 적용 조건을 전제로 한다.
