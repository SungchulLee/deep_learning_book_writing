# 효율성

효율성(efficiency)은 계산 자원(시간, 메모리, 에너지)이 문제 크기에 따라 어떻게 증가하는지를 나타낸다. 딥러닝에서 효율성은 모델을 며칠 만에 학습할 수 있는지 몇 년이 걸리는지를 결정하고, 주어진 지연 시간 예산 안에서 추론을 수행할 수 있는지를 결정한다.

---

## 1. 정의

알고리즘의 효율성은 입력 크기 $n$의 함수인 시간 복잡도 $T(n)$과 공간 복잡도 $S(n)$으로 피처지어진다. 뉴럴 넷트웍에서 관련된 양은 다음과 같다.

$$
\text{학습 비용} = O(\text{epochs}\times n\times d^2\times L) \qquad \text{추론 비용} = O(d^2 \times L)
$$

이 식은 입력·출력과 은닉 차원이 모두 $d$ 차수인 밀집 MLP의 거친 추정이다. $n$은 표본 수, $L$은 선형 레이어 수이며 추론 비용은 표본 하나 기준이다. CNN과 어텐션에는 공간 크기나 시퀀스 길이를 반영한 별도 식이 필요하다.

---

## 2. 설명

효율성 개선은 알고리즘적 참신함보다 더 중요한 경우가 많다. 딥러닝과 관련된 주요 복잡도 부류는 다음과 같다.

| 복잡도 | 예 | 실현 가능성 |
|---|---|---|
| $O(1)$ | 해시 조회, 캐시된 임베딩 | 즉시 |
| $O(n)$ | 선형 탐색, 단일 순전파 | 빠름 |
| $O(n \log n)$ | 정렬, FFT 기반 컨볼루션 | 실용적 |
| $O(n^2)$ | 셀프 어텐션(표준 트랜스포머) | 시퀀스 길이 제한 |
| $O(n^3)$ | 밀집 n×n 행렬의 일반적인 분해·역행렬 계산 | 크기와 구현에 따라 비용이 빠르게 증가 |

트랜스포머의 $O(n^2)$ 어텐션 복잡도는 표준 모델이 시퀀스 길이를 수천 토큰으로 제한하는 이유를 설명한다. 일부 선형·희소 어텐션은 특정 차원과 희소 패턴을 고정할 때 시퀀스 길이에 대한 비용을 줄인다. 커널·메모리 접근과 근사 방식까지 달라지므로 점근적 차수만으로 실제 속도를 결정할 수는 없다.

메모리 효율성도 마찬가지로 중요하다. GPU 메모리에 들어가는 모델을 학습하려면 경사 체크포인팅, 혼합 정밀도 학습, 경사 누적 같은 기법이 필요하다.

---

## 3. 예제

```python
import torch
import time

# O(n^2) 어텐션과 O(n) 선형 탐색 비교
def quadratic_attention(Q, K, V):
    """표준 내적 어텐션: O(n^2 d)."""
    scores = Q @ K.transpose(-2, -1) / Q.shape[-1] ** 0.5
    weights = torch.softmax(scores, dim=-1)
    return weights @ V

# 증가 양상 측정
for n in [128, 512, 2048]:
    d = 64
    Q = K = V = torch.randn(1, n, d)
    start = time.time()
    for _ in range(10):
        _ = quadratic_attention(Q, K, V)
    elapsed = (time.time() - start) / 10
    print(f"n={n:>5d}: attention time={elapsed*1000:.2f}ms")

# 메모리: 모델 크기 추정
def model_memory_mb(params):
    return params * 4 / (1024 ** 2)  # float32 = 4바이트

d, L = 768, 12  # BERT-base 차원
params = L * (4 * d * d + 4 * d)  # 근사값
print(f"\nBERT-base-like: ~{params:,} params = {model_memory_mb(params):.1f} MB")
```

**출력:**

```
n=  128: attention time=0.38ms
n=  512: attention time=1.05ms
n= 2048: attention time=21.44ms

BERT-base-like: ~28,348,416 params = 108.1 MB
```

<div class="drillbox" markdown>

**연습문제 1.** <span class="diff med" title="중간"></span>
$n=4096$, $d=512$에서 $n^2d$와 $nd^2$의 값을 비교하라. 이 비교가 실제 속도 비율을 보장하는가?

</div>

??? success "풀이"
    각 항은 약 $8.59\times10^9$와 $1.07\times10^9$로 비율은 8이다. 같은 상수와 다른 비용을 무시하면 $n>d$에서 두 번째 항이 작다. 하지만 O 표기는 정확한 연산 횟수가 아니고 구현·메모리·커널의 상수도 다르므로 실제 8배 속도를 보장하지 않는다.

<div class="drillbox" markdown>

**연습문제 2.** <span class="diff med" title="중간"></span>
동일 비용의 100개 레이어를 10개씩 구간으로 나눠 체크포인팅할 때 활성화 저장과 재계산 비용을 근사하라.

</div>

??? success "풀이"
    단순 추정으로 구간 경계 약 10개와 역전파 중 재생성한 구간 약 10개를 함께 보관해 20개 레이어 분량이 필요하다. 전체 100개를 저장하는 경우 대비 활성화 저장 공간은 약 5분의 1이다. 파라메터·경사·옵티마이저 상태는 줄지 않는다. 추가 순전파 약 한 번이 필요하며, 역전파를 순전파 두 번 비용으로 보면 전체는 약 3회에서 4회 비용으로 늘어난다. 실제 값은 체크포인팅 방식에 따라 달라진다.

---

<div class="drillbox" markdown>

**연습문제 3.** <span class="diff med" title="중간"></span>
파라메터 $10^8$개의 FP32 저장량을 구하고, 이 수만으로 혼합 정밀도의 전체 메모리 절감을 계산할 수 없는 이유를 설명하라.

</div>

??? success "풀이"
    FP32 계수는 $4\times10^8$바이트, 약 400MB이다. PyTorch의 일반적인 autocast에서는 모델 계수를 FP32로 유지하고 일부 연산과 활성화를 낮은 정밀도로 계산한다. 전체 메모리에는 경사·옵티마이저 상태·활성화·임시 공간도 있어 파라메터 수만으로 절감 비율을 정할 수 없다. FP16에서는 작은 경사의 언더플로를 줄이려 loss scaling을 사용할 수 있고, BF16은 범위가 넓어 보통 같은 필요가 없다.

<div class="drillbox" markdown>

**연습문제 4.** <span class="diff med" title="중간"></span>
FFN 확장 배율이 4인 표준 트랜스포머의 주요 선형 웨이트 수와 순전파 FLOPs를 구하라. $d=768$, $L=12$, $n=512$이며 곱셈과 덧셈을 각각 한 FLOP으로 센다.

</div>

??? success "풀이"
    레이어마다 Q·K·V·출력 투영에 $4d^2$, FFN 두 레이어에 $8d^2$가 있어 총 $12Ld^2=84934656$개이다. 임베딩·바이어스·정규화 계수는 제외했다. 투영과 FFN은 $24nd^2$, 두 어텐션 행렬 곱은 $4n^2d$이므로 전체는 $L(24nd^2+4n^2d)=96636764160$, 약 96.6GFLOPs이다. 소프트맥스·활성화·정규화 등은 제외한 주요 연산 추정이다.

<div class="drillbox" markdown>

**연습문제 5.** <span class="diff hard" title="어려움"></span>
배치 정규화가 없다고 가정할 때, 크기 $B/k$인 마이크로배치 $k$개에 대한 경사 누적이 배치 크기 $B$인 단일 경사 단계와 수학적으로 동등함을 증명하라.

</div>

??? success "풀이"
    크기 $B$인 배치에 대한 로스의 경사는 $g = \frac{1}{B}\sum_{i=1}^{B}\nabla\ell_i$이다. 경사 누적을 사용하면 크기 $B/k$인 마이크로배치 $k$개로 분할한다. 마이크로배치 $j$에 대해 $g_j = \frac{1}{B/k}\sum_{i \in S_j}\nabla\ell_i = \frac{k}{B}\sum_{i \in S_j}\nabla\ell_i$이다. ($k$로 나누지 않고) 누적한 뒤 $k$로 나누면 $\frac{1}{k}\sum_{j=1}^{k} g_j = \frac{1}{k}\sum_{j=1}^{k}\frac{k}{B}\sum_{i \in S_j}\nabla\ell_i = \frac{1}{B}\sum_{i=1}^{B}\nabla\ell_i = g$이다. 누적된 경사는 전체 배치 경사와 같다. 단 배치 정규화는 마이크로배치마다 통계를 계산하므로 불일치를 일으킨다는 점에 유의해야 한다. $\square$

## 정리하며

복잡도는 어떤 크기와 어떤 연산을 세는지 명시해야 한다. 밀집레이어 비용은 일반적으로 너비의 제곱에, 표준 어텐션의 핵심 곱은 시퀀스 길이의 제곱에 비례한다. 실제 시간과 메모리는 구현·장치와 저장 상태를 측정해 확인한다.
