# 34.4.1 심층 결정론적 폴리시 경사(DDPG)

DDPG(릴리크랩 외, 2016)는 결정론적 폴리시 그래디언트와 오프폴리시 Actor-Critic 틀을 엮어 DQN을 연속 액션 공간으로 넓힌다. 결정론적 액터 $\mu_\theta(s)$과 Q 함수 크리틱 $Q_\phi(s,a)$을 지니며, 강건한 오프폴리시 학습을 위해 경험 리플레이와 타깃 네트워크를 쓴다.

---

## 1. 핵심 아이디어

분포를 내놓는 확률 폴리시와 달리 DDPG의 액터는 고정된 액션 하나를 내놓는다.

$$a = \mu_\theta(s)$$

결정론적 폴리시 그래디언트(실버 외, 2014)는 다음과 같다.

$$\nabla_\theta J(\theta) = \mathbb{E}_{s \sim \mathcal{D}}\left[\nabla_a Q_\phi(s, a)\big|_{a=\mu_\theta(s)} \cdot \nabla_\theta \mu_\theta(s)\right]$$

그래디언트가 Q 함수를 거쳐 액터로 흐르므로 액션에 대해 뽑을 까닭이 없다.

---

## 2. 알고리즘

### 구성 요소

1. **액터** $\mu_\theta(s)$: 결정론적 폴리시 네트워크
2. **크리틱** $Q_\phi(s, a)$: 액션 밸류 함수
3. **타깃 액터** $\mu_{\theta'}$: 천천히 갱신되는 액터의 사본
4. **타깃 크리틱** $Q_{\phi'}$: 천천히 갱신되는 크리틱의 사본
5. **리플레이 버퍼** $\mathcal{D}$: 전이 튜플 $(s, a, r, s', d)$을 갈무리한다

### 갱신 규칙

**크리틱 갱신**(시간차 오차를 최소화):

$$L(\phi) = \mathbb{E}_{(s,a,r,s',d) \sim \mathcal{D}}\left[\left(Q_\phi(s,a) - y\right)^2\right]$$

$$y = r + \gamma (1-d) Q_{\phi'}(s', \mu_{\theta'}(s'))$$

**액터 갱신**(Q를 최대화):

$$\nabla_\theta J = \mathbb{E}_{s \sim \mathcal{D}}\left[\nabla_a Q_\phi(s,a)\big|_{a=\mu_\theta(s)} \nabla_\theta \mu_\theta(s)\right]$$

**타깃 갱신**(폴리악 평균):

$$\theta' \leftarrow \tau \theta + (1-\tau) \theta'$$

$$\phi' \leftarrow \tau \phi + (1-\tau) \phi'$$

여기서 $\tau = 0.005$(소프트 업데이트 계수)이다.

### 탐험

폴리시가 결정론적이므로 탐험하려면 잡음을 더해야 한다.

$$a = \mu_\theta(s) + \mathcal{N}(0, \sigma)$$

흔한 잡음 과정은 다음과 같다.

- **가우스**: $\epsilon \sim \mathcal{N}(0, \sigma^2 I)$ -- 쉽고 잘 작동한다
- **오른슈타인-울렌벡**: 더 매끄러운 탐험을 위해 때로 서로 상관된 잡음

---

## 3. DDPG 의사코드

```
액터 μ_θ, 크리틱 Q_φ, 타깃 네트워크 θ' ← θ, φ' ← φ에 첫 값을 매긴다
되돌려 보기 버퍼 D에 첫 값을 매긴다

때 스텝마다:
    액션을 고른다: a = μ_θ(s) + ε, ε ~ N(0, σ)
    a를 벌이고 r, s'을 본다
    (s, a, r, s', done)을 D에 갈무리한다

    D에서 작은 배치를 뽑는다
    타깃을 셈한다: y = r + γ(1-d)Q_{φ'}(s', μ_{θ'}(s'))
    크리틱을 고친다: (Q_φ(s,a) - y)²을 가장 작게 한다
    액터를 고친다: Q_φ(s, μ_θ(s))을 가장 크게 한다
    타깃을 부드럽게 고친다: θ' ← τθ + (1-τ)θ', φ' ← τφ + (1-τ)φ'
```

---

## 4. 알려진 걸림돌

DDPG는 TD3과 SAC를 불러낸 여러 문제로 시달린다.

1. **Q 값 과대추정**: 크리틱이 Q 값을 지나치게 높이 추정하는 버릇이 있어 액터가 그 잘못을 파고든다
2. **부서지기 쉬움**: 파라미터, 그 가운데에서도 러닝레이트에 민감하다
3. **탐험**: 얽힌 둘레에서는 가우스 잡음이 모자랄 수 있다
4. **값 발산**: 함수 근사, 부트스트랩, 오프폴리시 학습이 맞물려 불안정해질 수 있다

---

## 5. 파라미터

| 파라미터 | 흔한 값 | 뜻 |
|-----------|--------------|-------------|
| 액터 러닝레이트 | $1 \times 10^{-4}$ | 액터의 러닝레이트 |
| 크리틱 러닝레이트 | $1 \times 10^{-3}$ | 크리틱의 러닝레이트 |
| $\tau$ | 0.005 | 소프트 업데이트 계수 |
| $\gamma$ | 0.99 | 깎기 인자 |
| 버퍼 크기 | $10^6$ | 리플레이 버퍼 용량 |
| 배치 크기 | 256 | 작은 배치 크기 |
| 잡음 $\sigma$ | 0.1 | 탐험 잡음의 표준편차 |
| 데우는 스텝 | 25000 | 학습 앞서 벌이는 아무 액션 |

## 연습문제

<div class="drillbox" markdown>

**연습문제 1.** <span class="diff hard" title="어려움"></span>
이 절에서 다룬 방법의 폴리시 경사를 유도하라. 어느 항이 추정해야 하는 것이고 어느 항이 정확히 계산할 수 있는 것인지 분명히 밝혀라.

</div>

??? success "풀이"
    폴리시 경사는 $\nabla_\theta J(\theta) = \mathbb{E}_{\tau \sim \pi_\theta}[\sum_t \nabla_\theta \log \pi_\theta(a_t | s_t) \cdot \hat{A}_t]$ 형태이며, 여기서 $\hat{A}_t$은 어드밴티지 추정값이다. 로그 확률 그래디언트 $\nabla_\theta \log \pi_\theta$은 자동 미분으로 정확히 계산할 수 있다. 어드밴티지 $\hat{A}_t$은 샘플링한 궤적에서 추정해야 하므로 분산이 들어온다. 기댓값은 궤적 배치에 걸친 평균으로 추정한다. 베이스라인으로 분산을 줄이면 불편성을 지키면서 추정 잡음을 줄인다. $\square$

<div class="drillbox" markdown>

**연습문제 2.** <span class="diff med" title="중간"></span>
연속 제어 과제에서 이 방법의 샘플 효율을 밸류 기반 방법(예를 들어 DQN)과 비교하여라. 관찰되는 차이의 이론적 까닭을 설명하라.

</div>

??? success "풀이"
    폴리시 기반 방법은 온폴리시 데이터를 쓰므로(궤적마다 한 번씩 쓴다) 밸류 기반 방법보다 샘플 효율이 대체로 낮다. DQN은 경험 리플레이로 데이터를 재사용해서 더 나은 샘플 효율을 얻는다. 그러나 폴리시 방법은 연속 액션을 자연스럽게 다루고(액션 공간에 대한 argmax가 필요 없다), 최적 폴리시가 확률적 폴리시일 때 그리로 수렴하며, 신뢰 영역 아래에서 단조로운 개선을 보장한다. 오프폴리시 Actor-Critic 방법(DDPG, SAC)은 폴리시 최적화와 경험 리플레이를 엮어 이 간극을 메운다. $\square$

<div class="drillbox" markdown>

**연습문제 3.** <span class="diff med" title="중간"></span>
간단한 연속 제어 과제(예를 들어 Pendulum-v1)에 이 방법을 구현하라. 러닝레이트와 이 방법 고유의 중요한 하이퍼파라미터에 대해 얼마나 민감한지 보고하라.

</div>

??? success "풀이"
    가우스 폴리시를 쓰는 Pendulum-v1에서 전형적인 결과는 이렇다. 러닝레이트 $3 \times 10^{-4}$이면 약 500 에피소드에 수렴하고, $10^{-3}$이면 진동하며, $10^{-5}$이면 너무 더디게 수렴한다. 이 방법 고유의 하이퍼파라미터(예를 들어 PPO의 클리핑 범위, TRPO의 쿨백-라이블러 제약)는 갱신의 공격성과 안정성 사이의 트레이드오프를 조절한다. 너무 공격적이면 성능이 무너지고 너무 보수적이면 샘플을 낭비한다. 최적 지점은 이 둘의 균형을 맞추는 곳이며 흔히 좁은 범위에서 격자 탐색으로 찾는다. $\square$

<div class="drillbox" markdown>

**연습문제 4.** <span class="diff med" title="중간"></span>
액션 공간이 단체(합이 1인 자본 웨이트)이고 리워드가 위험 조정 리턴인 포트폴리오 배분 최적화에 이 방법을 어떻게 쓸 수 있을지 논하라.

</div>

??? success "풀이"
    액션 공간은 $(n-1)$차원 단체 $\Delta^{n-1} = \{w \in \mathbb{R}^n : w_i \geq 0, \sum_i w_i = 1\}$이다. 폴리시는 디리클레 분포나 소프트맥스로 변환한 가우스 분포를 쓸 수 있다. 리워드는 그 포트폴리오 배분의 샤프 비율이나 미분 샤프 비율이다. 어려움으로는 고차원 액션 공간(자산이 많다), 잦은 리밸런싱에 벌점을 주는 거래 비용, 시장 리턴의 비정상성이 있다. 이 절의 방법은 폴리시를 안정적으로 갱신하는 자체 장치로 이를 다룬다. $\square$

## 정리하며

DDPG는 결정론적 폴리시 그래디언트와 DQN 형태 안정적으로 하기 기법을 엮어 연속 액션 심층 강화학습의 길을 텄다. 잘 듣기는 하나 부서지기 쉽고 지나치게 추정하는 걸림돌 때문에 나아진 클래스가 나왔다. TD3은 과대추정을 다루고 SAC는 결정론적 폴리시를 최대 엔트로피 틀로 갈음한다.
