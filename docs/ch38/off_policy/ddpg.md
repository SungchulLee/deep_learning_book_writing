# 심층 결정론적 폴리시 경사(DDPG)

**심층 결정론적 폴리시 경사**(DDPG; 릴리크랩 외, 2016)는 결정론적 폴리시 그래디언트와 오프폴리시 Actor-Critic 틀을 엮어 DQN 을 연속 액션 공간으로 넓힌다. 오프폴리시는 지금 폴리시가 아닌 다른 폴리시(예: 예전 폴리시)가 모은 데이터로도 학습할 수 있다는 뜻이다. DDPG 는 결정론적 액터 $\mu_\theta(s)$ 와 Q 함수 크리틱 $Q_\phi(s,a)$ 를 지니며, 안정적인 오프폴리시 학습을 위해 경험 리플레이와 타깃 네트워크를 쓴다.

---

## 1. 핵심 아이디어

분포를 내놓는 확률 폴리시와 달리 DDPG의 액터는 고정된 액션 하나를 내놓는다.

$$a = \mu_\theta(s)$$

결정론적 폴리시 그래디언트(실버 외, 2014)는 다음과 같다.

$$\nabla_\theta J(\theta) = \mathbb{E}_{s \sim \mathcal{D}}\left[\nabla_a Q_\phi(s, a)\big|_{a=\mu_\theta(s)} \cdot \nabla_\theta \mu_\theta(s)\right]$$

그래디언트가 Q 함수를 거쳐 액터로 흐르므로, 확률 폴리시처럼 액션 분포에서 표본을 뽑아 액션에 대한 기댓값을 추정할 필요가 없다. 기댓값은 상태에 대해서만 취한다.

---

## 2. 알고리즘

### 구성 요소

1. **액터** $\mu_\theta(s)$: 결정론적 폴리시 네트워크
2. **크리틱** $Q_\phi(s, a)$: 액션 밸류 함수
3. **타깃 액터** $\mu_{\theta'}$: 천천히 갱신되는 액터의 사본
4. **타깃 크리틱** $Q_{\phi'}$: 천천히 갱신되는 크리틱의 사본
5. **리플레이 버퍼** $\mathcal{D}$: 전이 튜플 $(s, a, r, s', d)$ 를 저장한다

### 갱신 규칙

**크리틱 갱신**(시간차 오차를 최소화):

$$L(\phi) = \mathbb{E}_{(s,a,r,s',d) \sim \mathcal{D}}\left[\left(Q_\phi(s,a) - y\right)^2\right]$$

$$y = r + \gamma (1-d) Q_{\phi'}(s', \mu_{\theta'}(s'))$$

**액터 갱신**(Q를 최대화):

$$\nabla_\theta J = \mathbb{E}_{s \sim \mathcal{D}}\left[\nabla_a Q_\phi(s,a)\big|_{a=\mu_\theta(s)} \nabla_\theta \mu_\theta(s)\right]$$

**타깃 갱신**(폴리악 평균):

$$\theta' \leftarrow \tau \theta + (1-\tau) \theta'$$

$$\phi' \leftarrow \tau \phi + (1-\tau) \phi'$$

여기서 $\tau = 0.005$(소프트 업데이트 계수)이다.

### 탐험

폴리시가 결정론적이므로 탐험하려면 잡음을 더해야 한다.

$$a = \mu_\theta(s) + \mathcal{N}(0, \sigma)$$

흔한 잡음 과정은 다음과 같다.

- **가우스**: $\epsilon \sim \mathcal{N}(0, \sigma^2 I)$ -- 쉽고 잘 작동한다
- **오른슈타인-울렌벡**: 이웃한 스텝끼리 상관된 잡음으로, 더 매끄러운 탐험을 위해 쓴다(원래 DDPG 논문의 선택)

---

## 3. DDPG 의사코드

```
액터 μ_θ, 크리틱 Q_φ, 타깃 네트워크 θ' ← θ, φ' ← φ에 첫 값을 매긴다
되돌려 보기 버퍼 D에 첫 값을 매긴다

때 스텝마다:
    액션을 고른다: a = μ_θ(s) + ε, ε ~ N(0, σ)
    a를 벌이고 r, s'을 본다
    (s, a, r, s', done)을 D에 갈무리한다

    D에서 작은 배치를 뽑는다
    타깃을 셈한다: y = r + γ(1-d)Q_{φ'}(s', μ_{θ'}(s'))
    크리틱을 고친다: (Q_φ(s,a) - y)²을 가장 작게 한다
    액터를 고친다: Q_φ(s, μ_θ(s))을 가장 크게 한다
    타깃을 부드럽게 고친다: θ' ← τθ + (1-τ)θ', φ' ← τφ + (1-τ)φ'
```

---

## 4. 알려진 걸림돌

DDPG 에는 TD3 과 SAC 가 나오게 한 여러 문제가 있다.

1. **Q 값 과대추정**: 크리틱이 Q 값을 지나치게 높이 추정하는 경향이 있고, 액터가 그 오차를 파고든다
2. **취약성**: 하이퍼파라미터, 그 가운데에서도 러닝레이트에 민감하다
3. **탐험**: 복잡한 환경에서는 가우스 잡음만으로 모자랄 수 있다
4. **값 발산**: 함수 근사, 부트스트랩, 오프폴리시 학습이 맞물려 불안정해질 수 있다

## 5. 파라미터

| 파라미터 | 흔한 값 | 뜻 |
|-----------|--------------|-------------|
| 액터 러닝레이트 | $1 \times 10^{-4}$ | 액터의 러닝레이트 |
| 크리틱 러닝레이트 | $1 \times 10^{-3}$ | 크리틱의 러닝레이트 |
| $\tau$ | 0.005 | 소프트 업데이트 계수 |
| $\gamma$ | 0.99 | 할인 인자 |
| 버퍼 크기 | $10^6$ | 리플레이 버퍼 용량 |
| 배치 크기 | 256 | 미니배치 크기 |
| 잡음 $\sigma$ | 0.1 | 탐험 잡음의 표준편차 |
| 워밍업 스텝 | 25000 | 학습 전에 무작위 액션으로 데이터를 모으는 스텝 수 |

## 연습문제

<div class="drillbox" markdown>

**연습문제 1.** <span class="diff hard" title="어려움"></span>
이 절에서 다룬 방법의 폴리시 경사를 유도하라. 어느 항이 추정해야 하는 것이고 어느 항이 정확히 계산할 수 있는 것인지 분명히 밝혀라.

</div>

??? success "풀이"
    목표를 $J(\theta) = \mathbb E_{s\sim\mathcal D}[Q_\phi(s, \mu_\theta(s))]$ 로 두면, 연쇄 법칙으로 $\nabla_\theta J = \mathbb E_{s\sim\mathcal D}\big[\nabla_a Q_\phi(s,a)\big|_{a=\mu_\theta(s)}\,\nabla_\theta\mu_\theta(s)\big]$ 이다. 여기서 $\nabla_\theta\mu_\theta(s)$ 와 $\nabla_a Q_\phi$ 는 두 네트워크를 거쳐 역전파하면 정확히 계산된다 — 코드에서는 `-critic(s, actor(s)).mean()` 을 로스로 두고 액터의 파라미터만 갱신하면 된다. 추정해야 하는 것은 두 가지다. 하나는 상태에 대한 기댓값으로, 리플레이 버퍼에서 뽑은 미니배치로 평균 낸다. 버퍼의 상태 분포는 지금 폴리시의 상태 분포가 아니므로 이것은 근사다. 다른 하나는 $Q_\phi$ 자체로, TD 학습으로 얻은 추정이라 그 오차가 그대로 그래디언트의 바이어스가 된다. 확률 폴리시 경사와 달리 $\log\pi$ 도, 액션 표본도 쓰지 않는다. $\square$

**연습문제 2.** <span class="diff med" title="중간"></span>
DQN 은 왜 연속 액션 공간에 바로 쓸 수 없는가? DDPG 의 액터가 DQN 의 어느 연산을 대신하는지 설명하고, 둘 다 경험 리플레이를 쓰는 오프폴리시 방법인데도 DDPG 가 온폴리시 폴리시 경사 방법(A2C, PPO)보다 샘플 효율이 대체로 좋은 까닭을 논하라.

</div>

??? success "풀이"
    DQN 의 타깃 $r + \gamma\max_{a'}Q(s',a')$ 과 행동 선택 $\arg\max_a Q(s,a)$ 는 모든 액션을 훑어야 하는데, 연속 공간에서는 매 스텝 최적화 문제를 하나씩 풀어야 해 비싸다. 액션 공간을 잘게 나누면 차원이 늘 때 액션 수가 지수로 늘어난다. DDPG 는 그 $\arg\max$ 를 액터 $\mu_\theta(s)$ 로 근사해, 타깃을 $Q_{\phi'}(s', \mu_{\theta'}(s'))$ 로 계산한다. 액터는 $Q$ 를 최대화하도록 학습되므로 「Q 를 가장 크게 하는 액션을 내는 함수」를 배우는 셈이다. 온폴리시 방법은 지금 폴리시로 모은 데이터를 몇 번 쓰고 버리지만, DDPG 는 오프폴리시라 버퍼의 오래된 전이를 여러 번 다시 쓸 수 있어 같은 환경 스텝으로 더 많은 갱신을 한다. 그 대가로 학습이 덜 안정적이고 하이퍼파라미터에 민감하다(4절). $\square$

**연습문제 3.** <span class="diff med" title="중간"></span>
5절의 $\tau = 0.005$ 에서 타깃 네트워크가 온라인 네트워크를 따라가는 속도를 계산하라. 온라인 파라미터가 어느 순간부터 고정되어 있다면, 타깃과의 차이가 처음의 절반으로 줄기까지 몇 스텝이 걸리는가? $\tau$ 를 1 로 두면 어떤 문제가 생기는가?

</div>

??? success "풀이"
    $\theta' \leftarrow \tau\theta + (1-\tau)\theta'$ 에서 $\theta$ 가 고정이면 차이 $\theta' - \theta$ 가 스텝마다 $(1-\tau)$ 배가 된다. 절반이 되는 스텝 수는 $\ln 0.5/\ln 0.995 \approx 138$ 이고, 대략 $1/\tau = 200$ 스텝이 타깃이 기억하는 시간의 눈금이다. $\tau = 1$ 이면 타깃이 매 스텝 온라인 네트워크와 같아져, 크리틱이 자기 자신의 바뀌는 출력을 타깃으로 좇게 된다. 그러면 Q 의 오차가 곧바로 타깃에 들어가 되먹임되므로 학습이 발산하기 쉽다. 반대로 $\tau$ 가 너무 작으면 타깃이 너무 늦게 따라와 학습이 더디다. $\square$

**연습문제 4.** <span class="diff med" title="중간"></span>
액션 공간이 단체(합이 1인 자본 웨이트)이고 리워드가 위험 조정 리턴인 포트폴리오 배분 최적화에 이 방법을 어떻게 쓸 수 있을지 논하라.

</div>

??? success "풀이"
    액션 공간은 $(n-1)$차원 단체 $\Delta^{n-1} = \{w \in \mathbb{R}^n : w_i \geq 0, \sum_i w_i = 1\}$이다. 확률 폴리시라면 디리클레 분포나 소프트맥스로 변환한 가우스 분포를 쓸 수 있다. 리워드는 그 포트폴리오 배분의 샤프 비율이나 미분 샤프 비율이다. 어려움으로는 고차원 액션 공간(자산이 많다), 잦은 리밸런싱에 벌점을 주는 거래 비용, 시장 리턴의 비정상성이 있다. DDPG 는 결정론적 액터라 디리클레 분포를 쓰지 않고, 액터의 마지막 레이어에 소프트맥스를 두어 출력이 곧 단체 위의 웨이트가 되게 한다. 이때 탐험 잡음을 웨이트에 바로 더하면 단체를 벗어나므로, 소프트맥스 앞의 로짓에 잡음을 더하거나 잡음을 더한 뒤 다시 정규화한다. 과거 시장 데이터를 리플레이 버퍼에 담아 여러 번 쓸 수 있는 것이 오프폴리시 방법의 이점이지만, 비정상성 때문에 오래된 전이가 지금 시장과 맞지 않을 수 있어 버퍼 크기를 줄이는 등의 조정이 필요하다. $\square$

## 정리하며

DDPG 는 결정론적 폴리시 그래디언트와 DQN 의 안정화 기법(경험 리플레이, 타깃 네트워크)을 엮어 연속 액션 심층 강화학습의 길을 텄다. 잘 작동할 때도 있지만 하이퍼파라미터에 민감하고 Q 값을 과대추정하는 문제 때문에 개선된 변형들이 나왔다. TD3 은 과대추정을 다루고, SAC 는 결정론적 폴리시를 최대 엔트로피 틀의 확률 폴리시로 바꾼다.
