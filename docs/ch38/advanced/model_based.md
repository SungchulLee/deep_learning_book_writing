# 34.5.4 모델 기반 강화학습

모델 기반 강화학습은 둘레의 동역학 모델 $\hat{P}(s'|s,a)$를 배워 샘플 효율을 높인다. 학습된 모델로 계획하거나 가짜 데이터를 생성하면 에이전트가 실제 둘레와 훨씬 적게 상호작용하면서도 잘 작동하는 폴리시를 배울 수 있다.

---

## 1. 여러 접근법

### 다이나 형태 방법
실제 둘레와의 상호작용과 모델 기반 롤아웃을 번갈아 한다.

1. 실제 둘레와 상호작용하며 전이를 저장한다
2. 실제 데이터로 동역학 모델을 학습한다
3. 모델에서 가짜 전이를 생성한다
4. 실제 데이터와 가짜 데이터로 폴리시를 학습한다

### 모델 예측 제어(MPC)
학습된 모델로 매 스텝 계획한다.

1. 상태마다 여러 액션 시퀀스를 모델로 시뮬레이션한다
2. 예측 리턴이 가장 높은 액션 시퀀스를 고른다
3. 첫 액션을 실행하고 다음 스텝에서 다시 계획한다

### 해석적 그래디언트
학습된 모델을 거쳐 미분하여 폴리시 경사를 계산한다.

$$\nabla_\theta J \approx \nabla_\theta \sum_t \hat{r}(s_t, \pi_\theta(s_t))$$

여기서 궤적은 미분 가능한 모델을 거쳐 펼친다.

---

## 2. 중요한 알고리즘

### MBPO(모델 기반 폴리시 최적화)
재너 외, 2019:

- 불확실성을 추정하려 동역학 모델 앙상블을 학습한다
- 실제 데이터의 시작 상태에서 짧은 모델 롤아웃을 생성한다
- 실제 데이터와 모델 데이터를 섞어 SAC을 학습한다
- 롤아웃 길이가 짧으면 모델 오차가 쌓이는 것이 완화된다

### Dreamer
하프너 외, 2020:

- 잠재 공간에서 월드 모델을 학습한다
- 잠재 공간 상상 롤아웃 안에서 Actor-Critic을 학습한다
- 실제 데이터를 아주 적게 쓰고도 픽셀에서 좋은 성능을 이룬다

### PETS(확률적 앙상블 궤적 샘플링)
- 뉴럴 네트워크 모델의 앙상블
- 궤적 샘플링을 거친 CEM 기반 계획
- 앙상블 불일치로 불확실성 측정

---

## 3. 모델 구조

동역학 모델은 $(\hat{s}', \hat{r}) = f_\psi(s, a)$를 예측한다.

- **결정론적**: 다음 상태를 직접 예측한다
- **확률적**: 가우스 파라미터 $(\mu, \sigma)$를 내놓는다
- **앙상블**: 불확실성을 추정하려 모델 $K$개를 쓴다
- **잠재 공간**: 계획을 위해 압축된 표현을 학습한다

---

## 4. 주요 과제

1. **모델 오차 누적**: 스텝마다의 작은 오차가 긴 지평에 걸쳐 쌓인다
2. **분포 이동**: 모델이 옛 폴리시의 데이터로 학습되어 있다
3. **계산 비용**: 모델을 거쳐 계산하는 일이 비싸다
4. **탐험**: 탐험하지 않은 영역에서는 모델이 맞지 않을 수 있다

---

## 5. 금융 응용

모델 기반 강화학습은 금융에 특히 매력적이다.

- **샘플 효율**: 실제 시장 데이터는 부족하고 비싸다
- **시장 시뮬레이터**: 모델이 현실적인 시장 상태를 생성할 수 있다
- **위험 평가**: 모델의 불확실성이 위험 추정을 준다
- **레짐 변화**: 모델이 바뀌는 시장 동역학에 적응할 수 있다

## 연습문제

<div class="drillbox" markdown>

**연습문제 1.** <span class="diff hard" title="어려움"></span>
이 절에서 다룬 방법의 폴리시 경사를 유도하라. 어느 항이 추정해야 하는 것이고 어느 항이 정확히 계산할 수 있는 것인지 분명히 밝혀라.

</div>

??? success "풀이"
    폴리시 경사는 $\nabla_\theta J(\theta) = \mathbb{E}_{\tau \sim \pi_\theta}[\sum_t \nabla_\theta \log \pi_\theta(a_t | s_t) \cdot \hat{A}_t]$ 형태이며, 여기서 $\hat{A}_t$은 어드밴티지 추정값이다. 로그 확률 그래디언트 $\nabla_\theta \log \pi_\theta$은 자동 미분으로 정확히 계산할 수 있다. 어드밴티지 $\hat{A}_t$은 샘플링한 궤적에서 추정해야 하므로 분산이 들어온다. 기댓값은 궤적 배치에 걸친 평균으로 추정한다. 베이스라인으로 분산을 줄이면 불편성을 지키면서 추정 잡음을 줄인다. 이 절의 해석적 그래디언트는 이와 다른 길이다. 미분 가능한 모델을 거쳐 궤적을 펼치고 예측 리워드의 합을 θ로 곧바로 미분하므로 모델 위에서는 그래디언트가 자동 미분으로 정확히 계산되고 분산도 작다. 대신 모델 오차가 그대로 편향이 되며, 지평이 길면 연쇄 법칙의 곱이 폭발하거나 사라질 수 있다. $\square$

---

<div class="drillbox" markdown>

**연습문제 2.** <span class="diff med" title="중간"></span>
연속 제어 과제에서 이 방법의 샘플 효율을 밸류 기반 방법(예를 들어 DQN)과 비교하여라. 관찰되는 차이의 이론적 까닭을 설명하라.

</div>

??? success "풀이"
    DQN 같은 모델 없는 밸류 기반 방법은 경험 리플레이로 데이터를 재사용하지만, 실제 전이 하나는 여전히 한 번의 벨먼 갱신 재료일 뿐이다. 게다가 연속 액션에서는 액션 공간에 대한 argmax를 풀 수 없다. 모델 기반 방법은 실제 전이로 동역학 모델을 배운 뒤 모델에서 가짜 전이를 얼마든지 만들 수 있으므로, 같은 성능에 드는 실제 상호작용이 대체로 몇 배에서 한 자릿수 이상 적다(MBPO가 SAC보다 적게 쓰는 것이 그 예다). 대가는 모델 오차에서 오는 편향과 추가 계산이다. $\square$

---

<div class="drillbox" markdown>

**연습문제 3.** <span class="diff med" title="중간"></span>
간단한 연속 제어 과제(예를 들어 Pendulum-v1)에 이 방법을 구현하라. 러닝레이트와 이 방법 고유의 중요한 하이퍼파라미터에 대해 얼마나 민감한지 보고하라.

</div>

??? success "풀이"
    가우스 폴리시를 쓰는 Pendulum-v1에서 전형적인 결과는 이렇다. 러닝레이트 $3 \times 10^{-4}$이면 약 500 에피소드에 수렴하고, $10^{-3}$이면 진동하며, $10^{-5}$이면 너무 더디게 수렴한다. 이 방법 고유의 하이퍼파라미터는 모델 롤아웃 길이, 앙상블 크기, 실제 데이터와 모델 데이터의 비율이다. 롤아웃이 너무 길거나 모델 데이터의 비율이 너무 크면 모델 오차가 쌓여 성능이 무너지고, 너무 짧거나 작으면 모델의 이득이 사라져 샘플을 낭비한다. 최적 지점은 이 둘의 균형을 맞추는 곳이며 흔히 좁은 범위에서 격자 탐색으로 찾는다. $\square$

---

<div class="drillbox" markdown>

**연습문제 4.** <span class="diff med" title="중간"></span>
액션 공간이 단체(합이 1인 자본 웨이트)이고 리워드가 위험 조정 리턴인 포트폴리오 배분 최적화에 이 방법을 어떻게 쓸 수 있을지 논하라.

</div>

??? success "풀이"
    액션 공간은 $(n-1)$차원 단체 $\Delta^{n-1} = \{w \in \mathbb{R}^n : w_i \geq 0, \sum_i w_i = 1\}$이다. 폴리시는 디리클레 분포나 소프트맥스로 변환한 가우스 분포를 쓸 수 있다. 리워드는 그 포트폴리오 배분의 샤프 비율이나 미분 샤프 비율이다. 어려움으로는 고차원 액션 공간(자산이 많다), 잦은 리밸런싱에 벌점을 주는 거래 비용, 시장 리턴의 비정상성이 있다. 모델 기반으로 풀면 시장 동역학 모델에서 가짜 경로를 만들어 부족한 데이터를 메울 수 있지만, 비정상성 때문에 옛 데이터로 배운 모델이 금세 낡으므로 앙상블의 불일치를 보고 롤아웃을 짧게 끊어야 한다. $\square$

## 정리하며

모델 기반 강화학습은 학습된 동역학 모델을 활용해 샘플 효율을 크게 높인다. 중요한 어려움은 모델 오차를 통제하는 것이며, 앙상블과 짧은 롤아웃 길이, 실제 데이터와 모델 데이터 섞기로 다룬다. 데이터가 모자란 금융 응용에서 모델 기반 길은 매력적인 장점을 준다.
