# PPO 구현

이 쪽은 「PPO 의 37가지 구현 세부 사항」(황 외, 2022)이 정리한 모범 사례 가운데 성능에 크게 영향을 주는 것들을 모아, 실제로 쓸 만한 PPO 를 구현할 때 갖출 것을 정리한다. 코드 전체는 싣지 않고, 벡터 환경, 어드밴티지 계산, 학습 루프의 구조, 흔히 빠지는 함정을 차례로 다룬다. 잘라 낸 목표 자체는 앞 쪽 [PPO](ppo.md)에서 다루었다.

---

## 1. 중요한 구현 세부 사항

### 1. 벡터 둘레
둘레(환경) 사본 $N$개를 병렬로 돌려 다양한 데이터를 값싸게 모은다. 에피소드가 끝나면 둘레마다 자동으로 리셋된다.

### 2. 어드밴티지 정규화
그래디언트 크기를 안정적으로 하려고 (전체 배치가 아니라) 미니배치 수준에서 어드밴티지를 평균 0, 표준편차 1 로 정규화한다.

$$\hat{A}_t = \frac{A_t - \mu_\text{작은배치}}{\sigma_\text{작은배치} + \epsilon}$$

### 3. 밸류 함수 자르기(선택 사항)
값이 크게 갱신되는 것을 막으려 값 예측을 자른다.

$$V_\text{자름} = V_\text{옛} + \text{clip}(V_\theta - V_\text{옛}, -\epsilon, \epsilon)$$

$$L_V = \max\left[(V_\theta - V_\text{타깃})^2, (V_\text{자름} - V_\text{타깃})^2\right]$$

### 4. 러닝레이트 어닐링
학습하는 동안 러닝레이트를 0까지 선형으로 줄이면 마지막 성능이 나아진다.

### 5. 전역 그래디언트 클리핑
(파라미터마다가 아니라) 전역 그래디언트 노름을 0.5 로 자른다.

### 6. 직교 초기화
웨이트에 직교 행렬로 초기화한다.

- 은닉 레이어: 이득 $\sqrt{2}$
- 폴리시 헤드: 이득 $0.01$
- 값 헤드: 이득 $1.0$

### 7. 관측 정규화
이동 평균/분산으로 관측을 정규화하고 $[-10, 10]$ 으로 자른다.

### 8. 리워드 정규화
환경마다 리워드 스케일이 다른 것을 다루려, 할인된 리턴의 이동 표준편차로 리워드를 나눈다. 평균은 빼지 않는다 — 평균을 빼면 리워드의 부호가 바뀌어 과제 자체가 달라질 수 있다(연습문제 4).

## 2. 학습 루프 구조

```
온 고침 수 = total_timesteps / (n_envs × n_steps)

고침마다:
    # 굴림 마디
    for t = 0, ..., n_steps-1:
        action, logprob, value = agent(obs)
        obs, reward, done = envs.step(action)
        store(obs, action, reward, done, logprob, value)

    # 마지막 값 부트스트랩
    last_value = agent.get_value(last_obs)

    # GAE 셈하기
    advantages, returns = compute_gae(rewards, values, dones, last_value)

    # 배치 납작하게 펴기
    batch = flatten(rollout)  # 형태: (n_envs × n_steps, ...)

    # 가장 좋게 하기 마디
    for epoch = 1, ..., n_epochs:
        indices = random_permutation(batch_size)
        각 작은 배치 번호에 대해:
            ratio = exp(new_logprob - old_logprob)
            clipped_loss = min(ratio × adv, clip(ratio) × adv)
            value_loss = MSE(value, returns)
            entropy = policy.entropy()
            loss = -clip_loss + c_v × value_loss - c_e × entropy
            optimizer.step(loss)

    # 러닝레이트 식히기
```

## 3. 성능 기준

올바르게 구현하면 PPO 는 대략 다음을 이룬다. 공개 구현들이 흔히 보고하는 기준이며 이 쪽에서 잰 수가 아니므로, 하이퍼파라미터와 시드에 따라 크게 달라질 수 있다.

- **CartPole-v1**: 10만 스텝 안에 풂(리워드 약 500)
- **LunarLander-v2**: 약 50만 스텝에 풂(리워드 약 200)
- **아타리(Breakout)**: 약 1000만 프레임에 400점 이상

## 4. 흔히 빠지는 구현 함정

1. **미니배치마다 어드밴티지를 정규화하지 않기**: 그래디언트 크기가 배치마다 달라 학습이 불안정해질 수 있다
2. **로그 확률을 잘못 계산**: 연속 액션에서는 액션 차원에 걸쳐 로그 확률을 더해야 한다
3. **옛 로그 확률을 분리(detach)하기를 잊기**: 옛 로그 확률에 그래디언트가 붙으면 안 된다
4. **자동 리셋을 빠뜨리기**: 둘레는 끝날 때 자동으로 리셋되어야 한다
5. **에피소드 경계에서 GAE를 잘못 다루기**: done 플래그로 가려야 한다
6. **러닝레이트를 어닐링하지 않기**: 어닐링하지 않으면 마지막 성능이 나빠진다

**연습문제 1.** <span class="diff hard" title="어려움"></span>
이 절에서 다룬 방법의 폴리시 경사를 유도하라. 어느 항이 추정해야 하는 것이고 어느 항이 정확히 계산할 수 있는 것인지 분명히 밝혀라.

</div>

??? success "풀이"
    폴리시 경사는 $\nabla_\theta J(\theta) = \mathbb{E}_{\tau \sim \pi_\theta}[\sum_t \nabla_\theta \log \pi_\theta(a_t | s_t) \cdot \hat{A}_t]$ 형태이며, 여기서 $\hat{A}_t$ 는 어드밴티지 추정값이고, 이 쪽에서는 GAE 다. 로그 확률 그래디언트 $\nabla_\theta \log \pi_\theta$ 는 자동 미분으로 정확히 계산할 수 있다. 어드밴티지 $\hat{A}_t$ 는 샘플링한 궤적에서 추정해야 하므로 분산이 들어온다. 기댓값은 미니배치에 걸친 평균으로 추정한다. PPO 는 같은 롤아웃을 여러 에폭 쓰므로, 첫 미니배치 뒤로는 데이터를 모은 폴리시와 지금 폴리시가 달라진다. 그 차이를 비 $r = \exp(\log\pi_\theta - \log\pi_\text{old})$ 로 보정하는데, 이때 옛 로그 확률은 롤아웃 때 저장한 상수라 그래디언트가 흐르지 않는다(4절의 함정 3). $\square$

**연습문제 2.** <span class="diff med" title="중간"></span>
1절의 밸류 함수 자르기에서 $L_V$ 가 자른 항을 고르는 것은 언제인가? $V_\text{옛}=1$, $\epsilon=0.2$, $V_\text{타깃}=2$ 일 때 $V_\theta$ 가 1.1 과 1.5 인 두 경우의 $L_V$ 와 $V_\theta$ 에 대한 그래디언트를 구하라.

</div>

??? success "풀이"
    $V_\text{자름}$ 은 $V_\theta$ 를 $[V_\text{옛}-\epsilon, V_\text{옛}+\epsilon]$ 으로 자른 값이다. $\max$ 는 두 제곱 오차 가운데 큰 쪽을 고르므로, 자른 값이 타깃에서 더 멀 때 자른 항이 골라지고 그때 그래디언트는 0 이다. $V_\theta = 1.1$ 은 범위 $[0.8, 1.2]$ 안이라 두 항이 같아 $L_V = 0.81$ 이고 그래디언트는 $2(1.1-2) = -1.8$ 이다. $V_\theta = 1.5$ 이면 $V_\text{자름} = 1.2$ 라 $(1.5-2)^2 = 0.25$ 와 $(1.2-2)^2 = 0.64$ 가운데 큰 0.64 가 골라지고, 그 항은 $V_\theta$ 에 의존하지 않아 그래디언트가 0 이다. 곧 값 예측이 타깃 쪽으로 $\epsilon$ 넘게 움직이면 더는 끌어당기지 않는다. 황 외(2022)는 이 장치가 성능을 뚜렷이 높이지 않았고 오히려 해칠 수 있다고 보고해, 1절에서 「선택 사항」으로 둔 것이다. $\square$

**연습문제 3.** <span class="diff med" title="중간"></span>
`total_timesteps` 가 100만, 환경 8개, `n_steps` 가 128, 미니배치 4개, 에폭 4번이라 하자. 2절의 루프에서 전체 갱신(롤아웃) 횟수, 롤아웃 하나의 배치 크기와 미니배치 크기, 전체 그래디언트 스텝 수를 구하라. 러닝레이트를 0 까지 선형 어닐링한다면 $k$ 번째 갱신(1부터)의 러닝레이트는 처음 값 $\eta_0$ 의 몇 배인가?

</div>

??? success "풀이"
    배치 크기는 $8\times128 = 1{,}024$ 이고, 전체 갱신 횟수는 $\lfloor 10^6/1{,}024\rfloor = 976$ 번이다. 미니배치 크기는 $1{,}024/4 = 256$ 이며, 갱신마다 에폭 4번 × 미니배치 4개 = 16 번의 그래디언트 스텝을 밟으므로 모두 $976\times16 = 15{,}616$ 스텝이다. 선형 어닐링은 흔히 $\eta_k = \eta_0\,\big(1 - (k-1)/K\big)$ 로 쓰며, $K = 976$ 이면 첫 갱신에서 $\eta_0$, 마지막 갱신에서 $\eta_0/976$ 이 되어 0 에 가까워진다. 같은 롤아웃을 16 번 나누어 쓰므로, 에폭을 늘리면 샘플 효율은 오르지만 폴리시가 롤아웃을 모은 폴리시에서 멀어져 비가 크게 벗어나기 쉽다. $\square$

**연습문제 4.** <span class="diff med" title="중간"></span>
1절의 리워드 정규화는 리워드를 표준편차로 나누기만 하고 평균은 빼지 않는다. CartPole 처럼 살아 있는 매 스텝 리워드 1 을 주는 환경에서 평균까지 빼면 어떤 일이 생기는지 설명하라. 또 왜 리워드 자체가 아니라 할인된 리턴의 표준편차로 나누는가?

</div>

??? success "풀이"
    CartPole 의 리워드는 늘 1 이라 평균을 빼면 모든 리워드가 0 이 되어 버티는 것에 대한 보상이 사라지고, 추정한 평균이 1 보다 조금이라도 크게 잡히면 리워드가 음수가 된다. 리워드가 음수면 에피소드를 빨리 끝낼수록 리턴이 커지므로, 「오래 버티라」는 과제가 「빨리 쓰러지라」는 과제로 뒤집힐 수 있다. 양수 상수로 나누는 것은 리턴을 같은 비율로 줄일 뿐 최적 폴리시를 바꾸지 않는다. 할인된 리턴의 표준편차로 나누는 것은 학습 신호의 크기를 정하는 것이 리워드 하나가 아니라 크리틱이 맞혀야 하는 리턴이기 때문이다. 리턴의 크기를 1 근처로 맞추면 값 로스의 크기가 환경과 상관없이 비슷해져, 값 로스 계수 $c_v$ 와 러닝레이트를 환경마다 다시 고르지 않아도 된다. $\square$

## 정리하며

올바른 PPO 구현은 핵심인 잘라 낸 목표 말고도 많은 세부 사항을 꼼꼼히 살펴야 한다. 벡터 둘레, GAE, 적절한 정규화, 러닝레이트 스케줄의 결합이 강건하고 효율적인 학습 시스템을 만든다.
