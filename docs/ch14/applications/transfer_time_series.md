# 시계열 데이터를 위한 전이 학습

시계열 전이 학습은 과거 데이터에서 학습한 표현을 새 기간·대상·과제에 활용한다. 시간 해상도·단위·결측·예측 시점과 분포 변화를 함께 맞춰야 한다. 시계열이 모두 비정상이거나 이미지에서는 분포 이동이 없다는 뜻은 아니다.

## 1. 핵심 개념

- **시간 의존**: 인접·계절 표본과 겹치는 윈도는 독립 표본이 아닐 수 있다.
- **분포 변화**: 기간·개체·관측 체계별로 입력과 정답 관계가 달라질 수 있다.
- **관측 범위**: 예측 시점까지 실제로 이용 가능한 자료를 명시한다.
- **전이 범위**: 전처리·피처·계수·출력 헤드 중 무엇을 재사용하는지 정한다.
- **평가**: 시간 분할·예측 지평·라벨 지연과 중복을 관리한다.

## 2. 시계열을 위한 전이 학습 구조

### LSTM과 GRU 전이

순환 구조가 시간 피처의 전이를 가능케 한다.

$$(h_t,c_t)=\operatorname{LSTM}(x_t,(h_{t-1},c_{t-1});\theta)$$

**전이 방법**: 긴 과거 시퀀스로 사전 학습한 뒤 목표 과제에 미세 조정한다

**좋은 점**:

- 시간 무늬를 잡아낸다
- 길이가 제각각인 시퀀스을 다룬다
- 차례를 따르는 성질이 시계열과 들어맞는다

**나쁜 점**:

- 시퀀스이 길면 학습이 흔들린다
- 경사 소실 문제
- 병렬 계산이 제한된다

### 트랜스포머 기반 전이

트랜스포머는 정답 문맥을 쓰는 학습에서 위치별 계산을 병렬화할 수 있다. 예측 과제의 마스크와 위치·시간 간격 정보를 정의해야 하며 순환 모델보다 항상 빠르거나 그래디언트가 안정적인 것은 아니다.

$$H=\operatorname{Attention}(XW_Q,XW_K,XW_V;M)$$

**전이 방법**: 자기 지도 목표로 사전 학습한 뒤 아래쪽 과제에 미세 조정한다

**좋은 점**:

- 허용된 위치를 병렬로 결합할 수 있다.
- 전역 문맥을 직접 참조할 수 있지만 마스크·예측 시점 제약을 지켜야 한다.
- 최적화 안정성·장기 예측 품질은 구조 이름만으로 보장되지 않는다.

**나쁜 점**:

- 사전 학습 데이터가 많이 필요하다
- 위치 인코딩의 설계 선택이 매우 중요하다
- 사전 학습 분포에 과적합될 수 있다

### 컨볼루션 전이

1차원 컨볼루션은 국소 시간 관계를 처리한다. 다음은 각 시점에서 현재·과거만 읽는 인과 형태다. 양쪽 패딩을 쓰는 코드와 동일한 식은 아니다. 관측이 끝난 과거 윈도 전체를 인코딩하는 일과 매 위치의 인과 예측도 구분한다.

$$y_t=\sum_{i=0}^{K-1}W_i x_{t-i}$$

**전이 방법**: 신호 처리 과제로 사전 학습한 뒤 금융 예측에 맞춘다

**좋은 점**:

- 효율적인 계산
- 위계적 피처 학습
- 자연스러운 시간 국소성

**나쁜 점**:

- 받는 영역이 좁다
- 먼 거리 의존을 다루기 어렵다

## 3. 분야에 맞춘 전이 방법

### 시계열을 위한 사전 학습 과제

!!! tip "사전 학습 목표"
    목표 변수를 쓰지 않고도 분야에 관련된 무늬를 잡아내는 사전 학습 과제를 설계하라.

**자기 회귀 예측**: 과거에서 앞으로의 값을 맞힌다.

$$\mathcal{L} = \sum_{t} \|x_{t+h} - \hat{x}_{t+h}(\mathbf{x}_{1:t})\|^2$$

**가린 예측**: 시간 단계를 무작위로 가리고 이웃에서 맞힌다.

$$\mathcal{L} = \sum_{i \in M} \|x_i - \hat{x}_i\|^2$$

**대조 학습**: 어떤 두 시간 윈도를 양성으로 둘지 과제에 맞게 정한다. 가까운 시간이나 이동한 입력이 반드시 같은 의미·예측 정답을 갖는 것은 아니다. 아래 후보 분모에는 양성도 포함해야 한다.

$$\mathcal{L} = -\log \frac{\exp(s(x_t, x_{t+\tau})/T)}{\sum_j \exp(s(x_t, x_j)/T)}$$

**추세-계절 분해**: 추세 성분과 계절 성분을 가른다.

### 시장 국면 전이

퀀트 금융에서 전이 학습은 시장 국면을 살펴야 한다.

$$P_{\text{source}} = \text{Bull Market Regime}$$

$$P_{\text{target}} = \text{Sideways Regime}$$

국면마다 변동성과 자기 상관과 상관 구조가 다르다.

**국면을 고려한 미세 조정**:

- 국면 정의에 당시 이용 가능한 관측만 사용한다.
- 러닝레이트·전이 범위는 시간 검증에서 선택한다.
- 거리·국면 이름만으로 적응 기법의 성공이나 정답 관계 보존을 보장하지 않는다.

## 4. 비정상성과 전이 학습

### 어려움: 옮겨 가는 분포

시계열에서는 과거·미래 기간의 분포가 달라질 수 있다. 이미지·텍스트에서도 분포 이동은 생길 수 있으므로 한 분야만의 고유한 현상으로 단정하지 않는다.

$$P_{\text{source}}(x_t, x_{t+1}, \ldots) \neq P_{\text{target}}(x_t, x_{t+1}, \ldots)$$

주식 시장의 관계는 다음에 따라 바뀐다.

- 시장 구조의 변화
- 규제의 변화
- 기술의 발전
- 거시 경제 여건

### 맞추어 가는 방법

**이어지는 학습**: 최근 데이터로 이따금 다시 학습한다.

$$\theta_t=\theta_{t-1}-\alpha\nabla_\theta\mathcal L(\text{사용 가능한 최근 학습 자료})$$

**일부 되돌리기**: 앞쪽 표현은 지키면서 뒤쪽 레이어를 다시 초기화한다.

$$\theta^{\text{new}}_{\text{late}} = \text{random init}$$

$$\theta^{\text{new}}_{\text{early}} = \theta_{\text{pretrain}}^{\text{early}}$$

**적응 정규화**: 기준 계수에서 벗어나는 크기에 패널티를 줄 수 있다. 다음 제곱 L2 예는 한 선택이며, 강도의 시간 변화를 자동 최적화하는 일반 법칙은 아니다.

$$\mathcal{L} = \mathcal{L}_{\text{task}} + \lambda(t) \|\theta-\theta_{\text{init}}\|_2^2$$

lambda(t)는 검증한 일정으로 정한다. 시간이 지날수록 항상 줄이는 것이 최적이라는 보장도 없고 기준에 가까우면 기존 성능이 반드시 보존되는 것도 아니다.

## 5. 실용적인 고려

### 피처 만들기와 정규화

!!! warning "정규화의 중요성"
    정규화의 통계는 학습 기간 또는 당시 이용 가능한 과거 구간에서만 추정한다. 예측 대상 미래까지 포함한 표본별 평균·표준편차는 누수다. 사전 학습과 새 데이터의 단위·역변환 규칙을 함께 맞춘다.

**표준화의 선택지**:

- 고정 표준화: 학습 기간에서 추정한 통계를 이후에 적용한다.
- 롤링 표준화: 각 예측 시점 이전 자료만 사용한다.
- 표본별 정규화: 관측 입력 윈도 안에서만 계산하고 미래 정답 정보를 사용하지 않는다.

### 시간 맞추기

소스와 목표 사이의 시간을 맞추어야 한다.

| 측면 | 맞추는 방법 |
|--------|-------------------|
| **샘플링 빈도** | 공통 빈도로 다시 표집한다 |
| **거래 시간** | 시장 시간의 차이를 살핀다 |
| **시간대** | 공통 시간 기준으로 바꾼다 |
| **휴일** | 거래소 휴장을 한결같이 다룬다 |

### 룩백 기간 고르기

적절한 룩백 길이는 샘플링 빈도·관측 지연·예측 지평과 과제에 따라 다르다. 자기상관 감소 시간만으로 결정하는 일반 함수는 없고 아래 식은 정량적인 선택 규칙으로 사용할 수 없다.

	ext{룩백 길이는 과거 자료만 쓰는 시간 검증에서 선택한다.}

**비교 조건**: 단계 수를 일·분·틱 등 실제 시간으로 환산하고 중복 윈도의 라벨 구간이 평가 분할에 섞이지 않는지 확인한다.

고정된 50~500단계나 60~250일을 모든 데이터의 권장 길이로 제시하지 않는다. 후보 길이별 오차·지연·표본 수와 과적합을 검증한다.

## 6. 실험으로 본 성능

이 페이지에는 실제 시계열을 사전 학습·미세 조정하고 기준 모델과 비교한 실험이 없다. MSE 5~15% 감소나 표본 수별 20~30% 개선 같은 출처 없는 수치를 일반 효과로 제시하지 않는다.

같은 시간 분할·예측 지평·변수·학습 예산에서 무작위 초기화, 동결 피처와 미세 조정을 비교한다. 여러 시작 시점과 변동을 보고하며 미래 구간을 반복 튜닝에 사용한 결과는 독립 최종 평가와 구분한다.

## 7. 금융 시계열의 고유한 어려움

**국면 전환**: 상승장에서 학습한 모델이 폭락 때 무너진다

**낮은 신호 대 잡음비**: 시장의 잡음이 정보의 전이를 막는다

**비정상 피처**: 상관과 변동성이 끊임없이 바뀐다

**미래 참조 바이어스**: 추론 때 쓸 수 없는 앞날의 정보

---

## 8. 평가·운영 조건

학습·검증·테스트를 시간 순서와 실제 관측 가능 시점으로 나눈다. 윈도·정답 지평이 경계를 넘으면 적절한 간격을 두고 전처리 통계·피처 선택·모델 선택을 학습·검증 구간 안에 제한한다.

재학습 주기나 앙상블은 분기마다 자동으로 좋다는 규칙이 아니다. 실제 변화·라벨 지연·운영 비용을 반영해 검증한다. 금융 과제의 예측 오차와 거래 성과·비용은 서로 다른 평가다.

## 9. 연구의 방향

- 이론에 바탕한 시계열 전이 학습
- 적응적 전이를 위한 자동 국면 알아채기
- 자산과 시간 틀을 넘나드는 다중 과제 학습
- 새 시장에 빠르게 맞추기 위한 메타 학습

<div class="drillbox" markdown>

**연습문제 3.** <span class="diff hard" title="어려움"></span>
아래 TSEncoder의 축·리셉티브 필드·인과성과 추가 학습 구성 요소를 설명하라.

</div>

??? success "연습문제 3 풀이"
    nn을 torch.nn으로 가져와야 하며 입력은 (B,input_dim,L), 출력은 (B,hidden_dim)이다. 커널 3 두 개의 위치별 리셉티브 필드는 5이고 전체 평균은 관측 윈도 전체를 집계한다. padding=1은 각 중간 위치에서 미래 이웃도 읽지만 윈도 전체가 예측 시점 이전에 관측됐다면 그 자체가 미래 누수는 아니다. 각 시점 예측에는 인과 컨볼루션이 필요하다. 전이에는 사전 학습 목표·출력 헤드·웨이트 저장과 갱신 범위를 별도로 연결해야 한다.

    ```python
    class TSEncoder(nn.Module):
        def __init__(self, input_dim, hidden_dim):
            super().__init__()
            self.conv = nn.Sequential(
                nn.Conv1d(input_dim, hidden_dim, 3, padding=1), nn.ReLU(),
                nn.Conv1d(hidden_dim, hidden_dim, 3, padding=1), nn.ReLU(),
            )
            self.pool = nn.AdaptiveAvgPool1d(1)
        def forward(self, x):  # x: (B, C, T)
            return self.pool(self.conv(x)).squeeze(-1)
    ```

## 정리하며

시계열의 시간축·관측 가능성·정규화·라벨 지평을 전이 범위와 함께 정한다. 표현 재사용은 하나의 가설이며 출처 없는 성능 배율·고정 룩백·재학습 주기로 성공을 보장하지 않는다. 과거만 쓰는 독립 시간 평가가 필요하다.
