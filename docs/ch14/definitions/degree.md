# 차수

꼭짓점의 차수는 그 꼭짓점에 닿는 변의 개수를 세며, 그래프에서 가장 단순하면서도 가장 많은 것을 알려 주는 국소 잣대 가운데 하나이다. 차수 분포는 망이 정규인지, 중심 마디가 짜임을 좌우하는지, 어떤 알고리즘 지름길을 쓸 수 있는지를 드러낸다. 방향 그래프에서는 차수를 들어오는 것과 나가는 것으로 갈라 망을 흐르는 정보나 밑천의 흐름을 드러낸다.

---

## 1. 무방향 그래프의 차수

무방향 그래프 $G = (V, E)$에서 꼭짓점 $v$의 **차수** $\deg(v)$은 $v$에 닿는 변의 개수이다. $v$의 제 고리는 $\deg(v)$에 2을 보탠다(변의 양끝이 모두 $v$이다).

$$
\deg(v) = |\{e \in E : v \in e\}|
$$

$\deg(v) = 0$인 꼭짓점을 **외톨이 꼭짓점**이라 하고, $\deg(v) = 1$인 꼭짓점을 **잎**(또는 매달린 꼭짓점)이라 한다.

!!! example "차수 셈하기"
    꼭짓점 $\{a, b, c, d\}$과 변 $\{(a,b), (a,c), (a,d), (b,c)\}$의 그래프를 생각하자. 그러면 $\deg(a) = 3$, $\deg(b) = 2$, $\deg(c) = 2$, $\deg(d) = 1$이다. 꼭짓점 $d$은 잎이다.

---

## 2. 방향 그래프의 차수

방향 그래프 $G = (V, E)$에서 변 $(u, v)$마다 $u$에서 $v$으로 가는 방향이 있다. 그래서 꼭짓점마다 차수 잣대가 둘로 갈린다.

$v$의 **들어오는 차수** $\deg^-(v)$은 $v$으로 들어오는 변의 개수를 센다:

$$
\deg^-(v) = |\{(u, v) \in E : u \in V\}|
$$

$v$의 **나가는 차수** $\deg^+(v)$은 $v$에서 나가는 변의 개수를 센다:

$$
\deg^+(v) = |\{(v, w) \in E : w \in V\}|
$$

방향 그래프에서 $v$의 전체 차수는 $\deg(v) = \deg^-(v) + \deg^+(v)$이다.

!!! example "들어오는 차수와 나가는 차수"
    변이 $\{(a,b), (a,c), (b,c), (c,a)\}$인 방향 그래프에서 꼭짓점 $a$은 $\deg^+(a) = 2$($b$과 $c$으로 가는 변)이고 $\deg^-(a) = 1$($c$에서 오는 변)이다. 꼭짓점 $c$은 $\deg^+(c) = 1$이고 $\deg^-(c) = 2$이다.

---

## 3. 변 개수와의 관계

모든 꼭짓점 차수의 합은 변의 개수와 곧바로 이어진다. 무방향 그래프에서 변마다 양끝 꼭짓점의 차수에 꼭 1씩 보태므로 [악수 보조정리](handshaking.md)가 나온다:

$$
\sum_{v \in V} \deg(v) = 2|E|
$$

방향 그래프에서 방향 변마다 한 꼭짓점의 나가는 차수에 1, 다른 꼭짓점의 들어오는 차수에 1을 보탠다:

$$
\sum_{v \in V} \deg^-(v) = \sum_{v \in V} \deg^+(v) = |E|
$$

---

## 4. 차수 열

그래프의 **차수 열**은 꼭짓점 차수를 늘어나지 않는 차례로 정렬한 목록이다. 차수 열이 다른 두 그래프는 같은 꼴일 수 없으므로 차수 열은 기본적인 그래프 불변량이다.

!!! example "차수 열 보기"
    꼭짓점 $\{1, 2, 3, 4\}$과 변 $\{(1,2), (2,3), (3,4)\}$의 길 그래프 $P_4$의 차수 열은 $(2, 2, 1, 1)$이다.

음이 아닌 정수의 늘어나지 않는 열이 모두 단순 그래프의 차수 열로 이루어지지는 않는다. **에르되시-갈라이 정리**가 필요충분조건을 준다. 곧 늘어나지 않는 열 $d_1 \geq d_2 \geq \cdots \geq d_n$이 그래프로 이루어질 때 그리고 그때만, 합 $\sum d_i$이 짝수이고 $k \in \{1, \ldots, n\}$마다 다음이 성립한다:

$$
\sum_{i=1}^{k} d_i \leq k(k-1) + \sum_{i=k+1}^{n} \min(d_i, k)
$$

---

## 5. 정규 그래프

꼭짓점마다 차수가 꼭 $k$이면 그 그래프는 **$k$-정규**이다. 특별한 경우로 다음이 있다:

| 정규성 | 이름 | 보기 |
|---|---|---|
| 0-정규 | 빈 그래프 | 외톨이 꼭짓점 $n$개 |
| 1-정규 | 완전 짝짓기 | 변이 겹치지 않는 짝 |
| 2-정규 | 겹치지 않는 고리 | 모든 꼭짓점을 덮는 고리의 합집합 |
| 3-정규 | 세제곱 그래프 | 피터슨 그래프 |
| $(n-1)$-정규 | 완전 그래프 | $K_n$ |

꼭짓점 $n$개의 $k$-정규 그래프에서 악수 보조정리는 $|E| = kn/2$을 주므로 $kn$이 짝수여야 한다.

## 6. 차수 셈하기

```python
"""
무방향 그래프와 방향 그래프의 차수 셈하기.

이웃 목록 표현에서 꼭짓점 차수를 셈하는 법을 보이며,
차수 열과 정규성 살피기도 함께 다룬다.
"""

# === 무방향 차수 ===

def compute_degrees_undirected(adj, n):
    """무방향 그래프에서 꼭짓점마다 차수를 셈한다."""
    degrees = [0] * n
    for u in range(n):
        degrees[u] = len(adj[u])
    return degrees

# === 방향 차수 ===

def compute_degrees_directed(adj, n):
    """방향 그래프의 들어오는 차수와 나가는 차수를 셈한다."""
    in_deg = [0] * n
    out_deg = [0] * n
    for u in range(n):
        out_deg[u] = len(adj[u])
        for v in adj[u]:
            in_deg[v] += 1
    return in_deg, out_deg

# === 차수 열 ===

def degree_sequence(adj, n):
    """늘어나지 않는 차례로 차수 열을 되돌린다."""
    degrees = compute_degrees_undirected(adj, n)
    return sorted(degrees, reverse=True)

# === 정규성 살피기 ===

def is_k_regular(adj, n):
    """그래프가 k-정규인지 살핀다. k이나 -1을 되돌린다."""
    degrees = compute_degrees_undirected(adj, n)
    if len(set(degrees)) == 1:
        return degrees[0]
    return -1

# === 메인 ===

if __name__ == "__main__":
    # 무방향 그래프: 매달린 꼭짓점이 있는 세모
    adj_undirected = [[1, 2], [0, 2, 3], [0, 1], [1]]
    degrees = compute_degrees_undirected(adj_undirected, 4)
    print(f"Degrees: {degrees}")
    print(f"Degree sequence: {degree_sequence(adj_undirected, 4)}")
    print(f"Sum of degrees: {sum(degrees)}, 2*|E| = {2 * 4}")

    # 방향 그래프
    adj_directed = [[1, 2], [2], [0], []]
    in_d, out_d = compute_degrees_directed(adj_directed, 4)
    print(f"\nDirected in-degrees:  {in_d}")
    print(f"Directed out-degrees: {out_d}")

    # 정규 그래프: 꼭짓점 4개의 고리
    adj_cycle = [[1, 3], [0, 2], [1, 3], [2, 0]]
    k = is_k_regular(adj_cycle, 4)
    print(f"\nCycle C4 is {k}-regular")
```

**출력:**
```
Degrees: [2, 3, 2, 1]
Degree sequence: [3, 2, 2, 1]
Sum of degrees: 8, 2*|E| = 8
Directed in-degrees:  [1, 1, 2, 0]
Directed out-degrees: [2, 1, 1, 0]
Cycle C4 is 2-regular
```

## 연습문제

**연습문제 1.**
그래프 $G$의 차수 열이 $(5, 3, 3, 3, 2, 2)$이다. 그런 그래프가 있는가? 있다면 하나 그려라. 없다면 왜 그런지 설명하여라.

??? success "연습문제 1 풀이"
    차수의 합은 $5 + 3 + 3 + 3 + 2 + 2 = 18$으로 짝수이므로 악수 보조정리가 만족된다. 에르되시-갈라이 조건을 확인하자. $k = 1$일 때 $5 \leq 1(0) + \min(3,1) + \min(3,1) + \min(3,1) + \min(2,1) + \min(2,1) = 5$이다. 이는 (등호로) 성립한다. 남은 $k$ 값도 모두 통과한다. 한 가지 실현: 꼭짓점에 $0, \ldots, 5$의 이름을 붙이고 $0$을 $\{1,2,3,4,5\}$에, $1$을 $\{2,3\}$에, $4$을 $\{5\}$에 잇는다. 그러면 차수가 $(5, 3, 3, 3, 2, 2)$이 된다. $\square$

---

**연습문제 2.**
꼭짓점이 적어도 둘인 그래프에는 차수가 같은 꼭짓점 둘이 있음을 증명하여라.

??? success "연습문제 2 풀이"
    꼭짓점 $n$개의 그래프에서 차수마다 $\{0, 1, \ldots, n-1\}$에 들어 값이 $n$가지 있을 수 있다. 그러나 차수 0과 $n-1$은 함께 있을 수 없다. 차수가 $n-1$인 꼭짓점은 나머지 모두에 이웃하므로 외톨이 꼭짓점이 있을 수 없다. 그러므로 꼭짓점 $n$개에 서로 다른 차수 값이 많아야 $n - 1$가지이다. 비둘기집 원리에 따라 적어도 두 꼭짓점이 같은 차수를 갖는다. $\square$

---

**연습문제 3.**
선수 $n$명의 토너먼트는 방향 완전 그래프이다. 나가는 차수의 합이 $\binom{n}{2}$임을 증명하여라.

??? success "연습문제 3 풀이"
    토너먼트에는 서로 다른 꼭짓점 짝마다 방향 변이 꼭 하나 있다. 변의 총 개수는 $\binom{n}{2}$이다. 방향 변마다 꼭 한 꼭짓점의 나가는 차수에 1을 보태므로 $\sum_{v} \deg^+(v) = |E| = \binom{n}{2}$이다. $\square$

---

**연습문제 4.**
방향 그래프의 이웃 목록이 주어졌을 때 샘(들어오는 차수 0)이면서 웅덩이(나가는 차수 0)인 꼭짓점을 모두 되돌리는 함수를 적어라. 어떤 그래프에 그런 꼭짓점이 있는가?

??? success "연습문제 4 풀이"
    들어오는 차수와 나가는 차수가 모두 0인 꼭짓점은 들어오는 변도 나가는 변도 없는 외톨이 꼭짓점이다. 이 함수는 들어오는 차수와 나가는 차수를 셈한 뒤 둘 다 0인 꼭짓점을 되돌린다:

    ```python
    def isolated_vertices(adj, n):
        in_deg = [0] * n
        for u in range(n):
            for v in adj[u]:
                in_deg[v] += 1
        return [v for v in range(n) if in_deg[v] == 0 and len(adj[v]) == 0]
    ```

    그런 꼭짓점은 그래프의 나머지와 온통 끊겨 있다. $\square$

**연습 5.**
$k \geq 1$인 $k$-정규 이분 그래프에 완전 짝짓기가 있음(곧 $|L| = |R|$임)을 증명하여라. 힌트: 조각마다 변을 세어라.

??? success "연습 5의 풀이"
    이분 나눔을 $(L, R)$이라 하자. $L$의 꼭짓점마다 차수가 $k$이므로 변의 총 개수는 $k|L|$이다. $R$의 꼭짓점도 차수가 $k$이므로 총 개수는 $k|R|$이기도 하다. 그러므로 $k|L| = k|R|$이고 $k \geq 1$이므로 $|L| = |R|$이다. 완전 짝짓기가 있음은 홀의 정리에서 따라 나온다. 곧 아무 $S \subseteq L$에 대해 $S$에서 나온 변이 $R$에 변의 끝점 $k|S|$개를 보태는데, ($R$의 꼭짓점마다 차수가 많아야 $k$이므로) 이는 $R$의 서로 다른 꼭짓점 적어도 $|S|$개에 닿아야 한다. 따라서 $|N(S)| \geq |S|$이고 홀의 조건이 만족된다. $\square$
