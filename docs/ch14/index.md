# 15장: 전이 학습

전이 학습은 사전 학습한 표현·웨이트를 새 데이터와 과제에 재사용한다. 데이터가 적을 때 유용한 출발점이 될 수 있지만 새 모델보다 항상 좋거나 도메인 차이를 자동으로 해결하지는 않는다. 갱신 범위·입력 전처리·모델 선택과 실제 목표 평가를 함께 살펴본다.

## 1. 피처 추출과 미세 조정

계수 동결, 실행 모드와 정규화 버퍼를 구분한다. 새로 동결을 해제한 계수도 옵티마이저·러닝레이트 스케줄에 실제로 연결되어야 한다.

- [기본 전이 학습](transfer_learning/basic_transfer_learning.md): ResNet 분류 헤드 교체와 동결의 범위
- [미세 조정](transfer_learning/fine_tuning.md): 전체·일부 갱신, 레이어별 러닝레이트와 망각 완화
- [사용자 데이터셋](transfer_learning/custom_dataset_transfer.md): ImageFolder, 클래스 대응과 불균형 평가
- [고급 기법](transfer_learning/advanced_techniques.md): AMP·경사 누적·스케줄·TTA의 실제 연결

## 2. 도메인 적응

입력 피처 분포를 맞추는 일과 목표의 정답 관계를 보존하는 일은 다르다. 분포 거리가 작아도 좋은 예측이나 성공적인 전이를 보장하지는 않는다.

- [MMD](domain_adaptation/mmd.md): 커널 평균 거리, 표본 추정과 정렬의 한계

## 3. 시계열 전이

새 기간·대상에 표현을 재사용할 때 시간 해상도·단위·라벨 지연과 관측 가능 시점을 일치시킨다. 미래 자료가 정규화·윈도·모델 선택에 섞이지 않게 한다.

- [시계열 전이 학습](applications/transfer_time_series.md): 예측·복원 목표와 시간 분할 평가

## 정리하며

사전 학습 웨이트를 읽는 것, 계수를 동결하는 것과 고정 피처 평가를 구분한다. 독립 검증·테스트에서 새 모델과 비교하고, 불균형·도메인 이동·시간 의존에 맞는 지표로 음의 전이도 확인한다.
