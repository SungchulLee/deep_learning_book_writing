# 해석 방법 분류

---

## 1. 개요

설명 방법의 분야는 넓고 빠르게 자란다. 분류를 또렷이 해 두면 상황마다 알맞은 도구를 고르기 쉽다. 이 절은 서로 독립인 세 축으로 방법을 나눈다. 범위(국소 대 전역), 모델 접근 수준(모델 무관 대 모델 특화), 설명 유형(피처 기반, 예시 기반, 개념 기반)이다.

---

## 2. 범위에 따른 분류

### 국소 해석

국소(local) 방법은 개별 예측을 해석한다. 주어진 입력 $\mathbf{x}$에 대해 "모델은 왜 $f(\mathbf{x}) = \hat{y}$라고 예측했는가?"에 답한다.

*보기*: "이 대출 신청은 부채 대 소득 비율이 0.45를 넘고 신청자의 신용 이력이 2년에 못 미쳐 거절되었습니다."

국소 방법은 다음 형태의 설명을 내놓는다.

$$
f(\mathbf{x}) \approx g(\mathbf{x}) = \phi_0 + \sum_{i=1}^{d} \phi_i(\mathbf{x})
$$

여기서 $\phi_i(\mathbf{x})$는 이 입력에서 피처 $i$에 매긴 기여도다.

**대표적인 국소 방법**: LIME, SHAP 값, Grad-CAM, Integrated Gradients, Saliency Map, 반사실적 설명.

### 전역 해석

전역(global) 방법은 모델이 전체적으로 어떻게 동작하는지 해석한다. "모델이 입력 공간 전체에서 어떤 패턴을 배웠는가?"에 답한다.

*보기*: "이 신용 모델은 주로 상환 이력(중요도 35%), 신용 사용률(25%), 신용 이력의 길이(20%)에 기댄다."

전역 방법은 국소 설명을 집계하거나 모델의 구조를 직접 분석한다. 예를 들어 피처 $j$의 전역 중요도를 국소 기여도 절댓값의 평균으로 잡는다.

$$
I_j = \mathbb{E}_{\mathbf{x}}[|\phi_j(\mathbf{x})|]
$$

**대표적인 전역 방법**: 순열 중요도, 집계한 SHAP, TCAV, 개념 병목 모델, 부분 의존도 그림(PDP).

### 준국소 방법

국소와 전역 사이에서 입력 공간의 한 영역에 대해 모델의 행동을 해석하는 방법도 있다. 집단별 설명과 규칙 추출이 여기에 든다.

---

## 3. 모델 접근 수준에 따른 분류

### 모델에 무관한 방법

모델에 무관한(model-agnostic) 방법은 모델을 블랙박스로 보고 입력과 출력의 관계만 쓴다. 어떤 구조에도 작동한다.

| 방법 | 방식 | 복잡도 |
|--------|-----------|------------|
| LIME | 국소 대리 모델 적합 | 표본마다 $O(N \cdot d)$ |
| 커널 SHAP | 연합(coalition)에 대한 가중 회귀 | 정확히는 $O(2^d)$, 실제로는 샘플링 |
| 순열 중요도 | 피처 값 뒤섞기 | $O(N \cdot d)$ |
| 부분 의존도 | 주변 효과 추정 | 격자점 $G$개에 $O(N \cdot G)$ |
| 반사실적 설명 | 최소 변화를 찾는 최적화 | 경우마다 다름 |

**장점**: 어디에나 쓸 수 있고, 구조를 가리지 않으며, 서로 다른 종류의 모델을 비교할 수 있다.

**한계**: 계산이 비싸고(모델을 여러 번 돌려야 한다), 구조 특유의 내부 정보를 놓칠 수 있으며, 샘플링이 불안정성을 끌어들일 수 있다.

### 모델에 맞춘 방법

모델에 맞춘(model-specific) 방법은 모델 내부 구조를 활용해 더 세밀하고 효율적인 설명을 낸다.

**미분 가능한 모델(뉴럴 네트워크)에는**:

| 방법 | 활용하는 것 | 적용 대상 |
|--------|----------|-------------|
| 바닐라 그래디언트 | 역전파 | 미분 가능한 모든 모델 |
| Grad-CAM | 피처 맵의 그래디언트 | 공간 피처 맵을 지닌 CNN |
| Integrated Gradients | 그래디언트의 경로 적분 | 미분 가능한 모든 모델 |
| SmoothGrad | 잡음으로 평활화한 그래디언트 | 미분 가능한 모든 모델 |
| LRP | 레이어별 관련성 분해 | 뉴럴 네트워크 |
| DeepLIFT | 기준 입력 대비 활성화 차이 | 뉴럴 네트워크 |

**어텐션 기반 모델(트랜스포머)에는**:

| 방법 | 활용하는 것 | 적용 대상 |
|--------|----------|-------------|
| 어텐션 시각화 | 원시 어텐션 웨이트 | 트랜스포머 |
| 어텐션 롤아웃 | 레이어를 따라 누적한 어텐션 | 다층 트랜스포머 |
| 어텐션 흐름 | 그래디언트로 가중한 어텐션 | 트랜스포머 |
| 프로빙 분류기 | 잠재 표현 | 모든 인코더 |

**트리 기반 모델에는**:

| 방법 | 활용하는 것 | 적용 대상 |
|--------|----------|-------------|
| Tree SHAP | 트리 구조 | 결정 트리, 앙상블 |
| 피처 중요도(지니/정보 이득) | 분할 기준 | 트리 앙상블 |
| 결정 경로 | 트리를 지나는 경로 | 단일 트리 |

## 4. 설명 유형에 따른 분류

### 피처 기여도 분석

피처 기여도 분석은 입력 피처마다 중요도 점수를 매긴다. "피처마다 이 예측에 얼마나 기여했는가?"에 답한다.

$$
f(\mathbf{x}) = \phi_0 + \sum_{i=1}^{d} \phi_i(\mathbf{x})
$$

이 가법 분해가 SHAP, Integrated Gradients, LRP, DeepLIFT를 하나로 묶는 틀이다. 방법 사이의 핵심 차이는 기여도 $\phi_i$를 *어떻게* 계산하느냐에 있다.

| 방법 | 기여도 계산 방식 | 완전성 |
|--------|----------------------|-------------|
| 바닐라 그래디언트 | 국소 민감도 $\partial f / \partial x_i$ | 아니오 |
| 그래디언트 × 입력 | 민감도 × 값 $x_i \cdot \partial f / \partial x_i$ | 아니오 |
| Integrated Gradients | 베이스라인에서 입력까지의 경로 적분 | 예 |
| SHAP | 연합에 대한 한계 기여 | 예 |
| LRP | 관련성 역전파 | 예 |
| DeepLIFT | 기준 입력과의 차이 | 예 |

### 예시 기반 설명

예시 기반 방법은 비슷하거나 영향이 큰 트레인 데이터를 들어 예측을 해석한다.

**프로토타입 기반 설명**: "이 입력은 프로토타입 $p_c$와 가장 비슷하므로 클래스 $c$로 분류한다."

**영향력 있는 데이터**: "이 예측에는 트레인 샘플 $\{x_1, x_3, x_{42}\}$가 가장 큰 영향을 미쳤다."

**반사실적 설명**: "부채 대 소득 비율을 0.45에서 0.35로 낮추면 예측이 '거절'에서 '승인'으로 바뀐다."

### 개념 기반 설명

개념 기반 방법은 원시 피처가 아니라 사람이 이해할 수 있는 개념으로 해석한다.

**개념 활성화 벡터(CAV)**: 활성화 공간에서 사람의 개념(예를 들어 "줄무늬", "털", "높은 변동성")에 대응하는 방향을 배운다.

**CAV를 이용한 검정(TCAV)**: 모델의 예측이 어떤 개념에 얼마나 민감한지 정량화한다. 클래스 $c$의 입력 가운데 개념 방향 $v_l^k$로 움직였을 때 점수가 오르는 입력의 비율이다.

$$
\text{TCAV}_{c,k,l} = \frac{|\{x \in X_c : \nabla h_l(x) \cdot v_l^k > 0\}|}{|X_c|}
$$

**개념 병목 모델**: 네트워크가 먼저 사람이 해석할 수 있는 개념을 예측하게 하고, 그 개념으로 최종 예측을 하게 한다.

## 5. 통합 관점

달라 보이는 방법 여럿이 하나의 틀로 이어진다. 룬드베리와 리(2017)는 여러 방법이 가법 피처 기여도 분석의 특수한 경우임을 보였다.

$$
g(z') = \phi_0 + \sum_{i=1}^{M} \phi_i z'_i
$$

여기서 $z' \in \{0, 1\}^M$는 입력을 단순화한 이진 표현(피처가 있으면 1, 없으면 0)이고 $\phi_i$는 피처 기여도다. 로스 함수, 가중 커널, 정칙화 항을 달리 고르면 LIME, SHAP을 비롯한 여러 방법이 나온다.

| 방법 | 커널 $\pi_{x'}(z')$ | 로스 $\mathcal{L}$ | 정칙화 $\Omega$ |
|--------|----------------------|---------------------|------------------------|
| LIME | $\exp(-D(x, z)^2 / \sigma^2)$ | 제곱 오차 | $L_1$이나 피처의 수 |
| SHAP | $\frac{M-1}{\binom{M}{\lvert z' \rvert}\lvert z' \rvert(M-\lvert z' \rvert)}$ | 제곱 오차 | 없음(단일 해) |
| Integrated Gradients | — | — | 경로 적분 |

## 6. 방법 선택을 위한 결정 트리

```
시작
├── 특정 예측 하나를 설명해야 하는가?
│   ├── 예 → 국소 방법
│   │   ├── 모델이 미분 가능한가?
│   │   │   ├── 예 → 그래디언트 기반(빠름)이나 SHAP(엄밀함)
│   │   │   └── 아니오 → LIME이나 커널 SHAP
│   │   ├── 이론적 보장이 필요한가?
│   │   │   ├── 예 → SHAP이나 Integrated Gradients
│   │   │   └── 아니오 → Grad-CAM(CNN)이나 바닐라 그래디언트(빠름)
│   │   └── 규제가 요구하는가?
│   │       ├── 예 → SHAP(성질이 잘 문서화되어 있음)
│   │       └── 아니오 → 적절한 아무 방법
│   └── 아니오 → 전역 방법
│       ├── 피처 중요도 순위를 매기는가?
│       │   ├── 예 → 순열 중요도나 SHAP 값의 집계
│       │   └── 아니오 → 부분 의존성이나 개념 방법
│       └── 개념 수준으로 이해해야 하는가?
│           ├── 예 → TCAV, 개념 병목 모델
│           └── 아니오 → 전역 대리 모델이나 규칙 추출
└── 모델 구조는?
    ├── CNN → Grad-CAM, 피처 시각화
    ├── 트랜스포머 → 어텐션 분석, 프로빙
    ├── 트리 앙상블 → Tree SHAP
    └── 아무거나 → LIME, 커널 SHAP
```

**연습문제 1.** <span class="diff med" title="중간"></span>
이 절에서 다룬 설명 방법을, XOR 입력을 분류하는 ReLU 활성화의 두 레이어 뉴럴 네트워크에 적용하라. 입력 $x = [1, 1]$에 대한 설명을 계산하여라.

</div>

??? success "풀이"
    웨이트가 $W_1, b_1, W_2, b_2$인 트레인된 XOR 네트워크에서 출력은 $f(x) = W_2 \cdot \text{ReLU}(W_1 x + b_1) + b_2$이다. 설명 방법은 입력 피처마다 기여도를 내놓는다. $x = [1, 1]$(클래스 0)이면 두 피처 모두 음수 쪽 분류에 기여한다. 기여도 값은 방법마다 다르다. 그래디언트 기반 방법은 $\partial f / \partial x_i$을 계산하고, 섭동 기반 방법은 피처를 가렸을 때 출력이 얼마나 바뀌는지 잰다. XOR 문제는 결정 경계가 선형이 아니므로 선형 설명 방법이 틀릴 수 있음을 보여 준다. $\square$

<div class="drillbox" markdown>

**연습문제 2.** <span class="diff hard" title="어려움"></span>
이 절의 설명 방법이 완전성 공리를 만족하는지, 곧 어떤 베이스라인 $x_0$에 대해 모든 피처 기여도의 합이 $f(x) - f(x_0)$과 같은지 증명하거나 반례를 들어라.

</div>

??? success "풀이"
    완전성 공리(섀플리 값 이론에서는 효율성이라고도 한다)는 기여도의 합이 입력에서의 모델 출력과 베이스라인에서의 출력의 차이와 같다는 것이다. 이 방법이 완전성을 만족하는지는 그 구성에 달렸다. 그래디언트 방법은 완전성을 만족하지 못한다(그래디언트는 한 점의 국소적인 양이고 경로를 따라 적분한 것이 아니다). Integrated Gradients는 구성 자체로 완전성을 만족한다(경로를 따라 미적분의 기본정리를 쓴다). SHAP 값은 섀플리 공리로 효율성을 만족한다. 완전성을 어기는 방법은 기여도를 너무 크거나 작게 매길 수 있어, 기여도 전체를 전역 설명으로 믿기 어렵게 만든다. $\square$

<div class="drillbox" markdown>

**연습문제 3.** <span class="diff med" title="중간"></span>
이 방법이 내놓는 설명이 얼마나 믿을 만한지 평가하는 실험을 설계하라. 방법이 중요하다고 짚은 피처가 실제로 모델에 중요한지를 삽입 곡선과 삭제 곡선으로 재어라.

</div>

??? success "풀이"
    절차는 이렇다. (1) 시험 이미지마다 피처 기여도를 계산한다. (2) 삭제: 기여도가 큰 차례로 피처를 하나씩 가리며 모델의 확신도가 떨어지는 모습을 기록한다. 믿을 만한 설명이면 확신도가 빠르게 떨어진다. (3) 삽입: 빈 베이스라인에서 시작해 기여도가 큰 차례로 피처를 하나씩 드러내며 확신도가 오르는 모습을 기록한다. 믿을 만한 설명이면 확신도가 빠르게 오른다. (4) 두 곡선 아래 넓이를 계산한다. (5) 무작위 순서(베이스라인)와 다른 방법과 비교한다. 믿을 만한 방법이면 삭제 곡선의 넓이가 작고 삽입 곡선의 넓이가 커야 한다. 통계적으로 믿을 만하려면 시험 표본 1000개 넘게 되풀이한다. $\square$

**연습문제 4.** <span class="diff med" title="중간"></span>
이 설명 방법을 신용 부도를 예측하는 금융 모델에 어떻게 적용할 수 있는지 논하라. 설명이 채워야 할 규제 요건은 무엇인가?

</div>

    신용 모델에는 규제(ECOA, GDPR 22조)가 불리한 결정마다 그 사람에게 맞춘 설명을 요구한다. 방법은 다음을 내놓아야 한다. (1) 거절에 가장 크게 기여한 요인(불리한 처분 사유). (2) 일관된 설명(비슷한 신청자는 비슷한 설명을 받는다). (3) 실행 가능한 설명(신청자가 무엇을 바꾸어야 하는지 안다). 이 절의 설명 방법으로 피처 중요도를 짚을 수 있으나, 강건성(입력이 조금 바뀌었다고 설명이 확 달라지면 안 된다)과 충실성(중요한 피처를 없애면 예측이 바뀌어야 한다)을 평가해야 한다. 보호 속성은 대리 차별이 드러나지 않도록 조심히 다루어야 한다. $\square$

## 정리하며

설명 방법의 분류를 알아야 알맞은 도구를 고를 수 있다. 세 핵심 축, 곧 범위, 모델 접근 수준, 설명 유형이 빠르게 늘어나는 방법들을 헤쳐 갈 틀을 준다. 실제로는 서로 다른 유형의 방법을 함께 써야 모델의 행동을 가장 폭넓게 이해할 수 있다.
