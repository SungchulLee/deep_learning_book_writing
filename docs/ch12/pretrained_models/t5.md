# T5: 텍스트에서 텍스트로 옮기는 전이 트랜스포머

T5(Text-to-Text Transfer Transformer)는 분류·번역·요약 등을 텍스트 입력에서 텍스트 출력을 예측하는 형식으로 표현한다. 인코더·디코더와 생성 손실을 여러 과제에 공유할 수 있지만, 새 과제의 프롬프트만 적으면 자동으로 잘 수행한다는 뜻은 아니다.

## 1. 텍스트에서 텍스트로 옮기는 틀

T5는 다양한 텍스트 과제의 목표를 출력 문자열로 표현한다. 분류는 레이블 문자열, 추출은 답 문자열, 번역·요약은 목표 텍스트를 생성한다. 실제 체크포인트가 어떤 과제와 접두사로 학습되었는지도 확인한다.

| 과제 | 입력 | 출력 |
|------|-------|--------|
| 번역 | `translate English to German: That is good.` | `Das ist gut.` |
| 요약 | `summarize: <article>` | `<summary>` |
| 분류 | `sentiment: This movie is great!` | `positive` |
| 질문 답변 | `question: Who wrote Harry Potter? context: ...` | `J.K. Rowling` |

이 하나로 모은 꼴이 다음을 가능케 한다.

- 같은 인코더·디코더 틀을 여러 과제에 사용할 수 있다.
- 과제별 데이터를 섞거나 사전 학습 뒤 미세 조정할 수 있다.
- 출력 문자열의 형식·평가 기준과 학습 비중은 과제마다 정해야 한다.

---

## 2. 구조

T5는 원래의 인코더-디코더 트랜스포머 구조를 쓴다.

$$
\text{T5} = \text{Encoder} + \text{Decoder}
$$

### 핵심 설계 선택

| 요소 | 원래 T5의 대표 설정 | 확인할 변형 |
|---|---|---|
| 구조 | 인코더·디코더 | 디코더 전용과 문맥 접근이 다름 |
| 위치 | 버킷 상대 위치 편향 | 절대 위치 표가 아님 |
| 정규화 | Pre-LN, 평균을 빼지 않는 RMS 기반 방식 | 일반 nn.LayerNorm과 다름 |
| 피드포워드 | ReLU | v1.1은 GEGLU |
| 임베딩 | 인코더·디코더 입력 임베딩 공유 | 출력 투영 공유 여부는 버전에 따라 확인 |

### 모델의 크기

| 모델 | 인코더/디코더 층 | $d_{\text{model}}$ | 매개변수 |
|-------|------------------------|---------|------------|
| T5-Small | 6/6 | 512 | 6000만 |
| T5-Base | 12/12 | 768 | 2억 2000만 |
| T5-Large | 24/24 | 1024 | 7억 7000만 |
| T5-3B | 24/24 | 1024 | 30억 |
| T5-11B | 24/24 | 1024 | 110억 |

## 3. 사전 학습: 구간 마스킹

원래 T5는 구간을 마스킹한 입력에서 제거된 토큰을 복원하는 span corruption 목표를 사용한다.

1. 원문의 약 15%를 평균 길이 3 정도의 마스킹 구간으로 나눈다.
2. 각 구간을 서로 다른 센티널 토큰 <extra_id_0>, <extra_id_1> 등으로 대체한다.
3. 센티널과 제거된 구간들을 순서대로 이어 붙인 목표문을 자기 회귀로 예측한다.

**예:**

```
Original: "Thank you for inviting me to your party last week."
Input: "Thank you <extra_id_0> to your party <extra_id_1> week."
Target: "<extra_id_0> for inviting me <extra_id_1> last"
```

입력에서는 여러 토큰 구간을 센티널 하나로 줄이고 출력에서는 제거된 토큰과 센티널을 생성한다. 전체 원문을 출력하는 복원 방식보다 목표 길이를 줄일 수 있지만 BERT보다 언제나 연산·표본 효율이 좋다는 보장은 아니다.

### 사전 학습 목표 비교

| 목표 | 문맥 | 손실 대상 |
|---|---|---|
| BERT MLM | 손상 입력의 양방향 문맥 | 선택된 위치의 원래 토큰 |
| 인과 LM | 과거 입력 | 각 유효 위치의 다음 토큰 |
| T5 span corruption | 손상 원문과 앞서 출력한 목표 토큰 | 제거된 구간·센티널·종료 토큰 |

인코더는 손상 원문을 양방향으로 읽고 디코더는 목표의 앞부분과 원문 메모리를 조건으로 다음 토큰을 생성한다. 토큰별 MLM과 순서대로 목표를 조건에 추가하는 방식이 다르다.

### 여러 과제 학습

원래 T5는 C4의 복원 목표와 지도 과제를 섞는 설정을 실험했다. 과제 비율은 데이터 크기와 샘플링 규칙으로 정하며 특정 혼합이 모든 다운스트림 과제에 도움이 된다는 뜻은 아니다.

$$\mathcal{L} = \sum_{\text{task}} w_{\text{task}} \cdot \mathcal{L}_{\text{task}}$$

Flan-T5는 지시와 예시를 포함하는 여러 과제의 후속 학습으로 T5 계열을 확장했다. 과제 수만으로 새 분야의 성능을 보장할 수 없고 데이터 구성·중복·평가 조건을 함께 확인해야 한다.

## 4. PyTorch 구현

**원래 T5와의 차이:** 이 코드는 일반 nn.LayerNorm으로 평균을 빼고 편향도 학습한다. T5의 RMS 기반 정규화와 다르다. 인코더·디코더 입력 임베딩은 공유하지만 lm_head는 별도의 가중치다. feed_forward_proj 설정은 실제 FFN 선택에 사용되지 않고 항상 ReLU다. 사전 학습 가중치와 원래 초기화·출력 스케일 설정도 재현하지 않는다.

**목표 정렬:** forward는 labels를 자동 시프트하지 않는다. main은 decoder_input_ids와 labels를 같은 값으로 두어 현재 토큰을 그대로 예측하는 구성이며 정상적인 다음 토큰 복원 학습 예제가 아니다. 실제로는 디코더 입력을 시작 토큰과 앞선 목표로 구성하고 labels는 다음 목표 토큰으로 맞춰야 한다. attention_mask는 원문 마스크가고 목표 PAD 어텐션·손실은 별도로 처리해야 한다.

**미완성 캐시:** 교차 어텐션이 과거 K·V에 동일한 원문 K·V를 매번 다시 이어 붙인다. 셀프 어텐션의 상대 위치 쿼리 오프셋과 인과 마스크도 캐시 전체 길이에 맞춰 구성하지 않는다. use_cache 인수가 있다는 이유만으로 올바른 점진 생성이 가능하다고 해석하지 않는다. 위치 버킷은 max_distance보다 먼 거리를 합치는 규칙이지 처리 가능한 입력 길이의 하드 한계가 아니다.

출력은 무작위 모델과 입력의 모양·손실 예시이며 학습 성능 결과가 아니다. 유한한 -1e9 가산 마스크는 전부 가린 행이나 저정밀 자료형에서 별도 검토가 필요하다.

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
import math
from typing import Optional, Dict, Tuple, List

class T5Config:
    """T5 모형 설정."""
    
    def __init__(
        self,
        vocab_size: int = 32128,
        d_model: int = 512,
        d_kv: int = 64,
        d_ff: int = 2048,
        num_layers: int = 6,
        num_decoder_layers: int = None,
        num_heads: int = 8,
        relative_attention_num_buckets: int = 32,
        relative_attention_max_distance: int = 128,
        dropout_rate: float = 0.1,
        layer_norm_epsilon: float = 1e-6,
        feed_forward_proj: str = "relu"
    ):
        self.vocab_size = vocab_size
        self.d_model = d_model
        self.d_kv = d_kv
        self.d_ff = d_ff
        self.num_layers = num_layers
        self.num_decoder_layers = num_decoder_layers or num_layers
        self.num_heads = num_heads
        self.relative_attention_num_buckets = relative_attention_num_buckets
        self.relative_attention_max_distance = relative_attention_max_distance
        self.dropout_rate = dropout_rate
        self.layer_norm_epsilon = layer_norm_epsilon
        self.feed_forward_proj = feed_forward_proj

class T5RelativePositionBias(nn.Module):
    """
    T5 방식의 상대 자리 편향.
    
    효율을 위해 양동이에 담은 상대 자리를 쓴다.
    """
    
    def __init__(
        self,
        num_heads: int,
        num_buckets: int = 32,
        max_distance: int = 128,
        is_decoder: bool = False
    ):
        super().__init__()
        
        self.num_heads = num_heads
        self.num_buckets = num_buckets
        self.max_distance = max_distance
        self.is_decoder = is_decoder
        
        self.relative_attention_bias = nn.Embedding(num_buckets, num_heads)
    
    @staticmethod
    def _relative_position_bucket(
        relative_position: torch.Tensor,
        bidirectional: bool = True,
        num_buckets: int = 32,
        max_distance: int = 128
    ) -> torch.Tensor:
        """
        상대 자리 양동이를 셈한다.
        
        먼 자리일수록 양동이 간격이 로그로 벌어진다.
        """
        ret = 0
        n = -relative_position
        
        if bidirectional:
            num_buckets //= 2
            ret += (n < 0).to(torch.long) * num_buckets
            n = torch.abs(n)
        else:
            n = torch.max(n, torch.zeros_like(n))
        
        # 양동이의 절반은 정확한 자리를 위한 것이다
        max_exact = num_buckets // 2
        is_small = n < max_exact
        
        # 나머지 절반은 로그로 커지는 칸을 위한 것이다
        val_if_large = max_exact + (
            torch.log(n.float() / max_exact) /
            math.log(max_distance / max_exact) *
            (num_buckets - max_exact)
        ).to(torch.long)
        
        val_if_large = torch.min(
            val_if_large,
            torch.full_like(val_if_large, num_buckets - 1)
        )
        
        ret += torch.where(is_small, n, val_if_large)
        return ret
    
    def forward(self, query_length: int, key_length: int) -> torch.Tensor:
        """
        상대 자리 편향을 셈한다.
        
        돌려주는 값: [1, num_heads, query_length, key_length]
        """
        device = self.relative_attention_bias.weight.device
        
        # 상대 자리
        context_position = torch.arange(query_length, device=device)[:, None]
        memory_position = torch.arange(key_length, device=device)[None, :]
        relative_position = memory_position - context_position
        
        # 자리를 양동이에 담는다
        relative_position_bucket = self._relative_position_bucket(
            relative_position,
            bidirectional=not self.is_decoder,
            num_buckets=self.num_buckets,
            max_distance=self.max_distance
        )
        
        # 편향 값을 얻는다
        values = self.relative_attention_bias(relative_position_bucket)
        values = values.permute([2, 0, 1]).unsqueeze(0)
        
        return values

class T5Attention(nn.Module):
    """상대 자리 편향을 갖춘 T5 다중 머리 주의."""
    
    def __init__(
        self,
        config: T5Config,
        is_decoder: bool = False,
        has_relative_attention_bias: bool = False
    ):
        super().__init__()
        
        self.is_decoder = is_decoder
        self.has_relative_attention_bias = has_relative_attention_bias
        
        self.d_model = config.d_model
        self.d_kv = config.d_kv
        self.num_heads = config.num_heads
        self.inner_dim = self.num_heads * self.d_kv
        
        # 사영
        self.q = nn.Linear(config.d_model, self.inner_dim, bias=False)
        self.k = nn.Linear(config.d_model, self.inner_dim, bias=False)
        self.v = nn.Linear(config.d_model, self.inner_dim, bias=False)
        self.o = nn.Linear(self.inner_dim, config.d_model, bias=False)
        
        # 상대 자리 편향
        if has_relative_attention_bias:
            self.relative_attention_bias = T5RelativePositionBias(
                num_heads=config.num_heads,
                num_buckets=config.relative_attention_num_buckets,
                max_distance=config.relative_attention_max_distance,
                is_decoder=is_decoder
            )
        
        self.dropout = nn.Dropout(config.dropout_rate)
    
    def forward(
        self,
        hidden_states: torch.Tensor,
        key_value_states: Optional[torch.Tensor] = None,
        position_bias: Optional[torch.Tensor] = None,
        attention_mask: Optional[torch.Tensor] = None,
        past_key_value: Optional[Tuple[torch.Tensor]] = None,
        use_cache: bool = False
    ) -> Tuple[torch.Tensor, Optional[torch.Tensor], Optional[Tuple[torch.Tensor]]]:
        """
        앞먹임.
        
        인수:
            hidden_states: [batch, seq_len, d_model]
            key_value_states: 교차 주의에서 쓰는 인코더의 숨은 상태
            position_bias: 미리 셈해 둔 자리 편향
            attention_mask: 주의 가림
            past_key_value: 점진 디코딩을 위해 담아 둔 KV
            use_cache: 고친 캐시를 돌려줄지 여부
        """
        batch_size, seq_len = hidden_states.shape[:2]
        
        # 자기 주의 또는 교차 주의
        is_cross_attention = key_value_states is not None
        
        # Q를 셈한다
        query_states = self.q(hidden_states)
        query_states = query_states.view(batch_size, -1, self.num_heads, self.d_kv).transpose(1, 2)
        
        # K, V를 셈한다 (교차 주의에서는 인코더에서)
        if is_cross_attention:
            key_states = self.k(key_value_states)
            value_states = self.v(key_value_states)
        else:
            key_states = self.k(hidden_states)
            value_states = self.v(hidden_states)
        
        key_states = key_states.view(batch_size, -1, self.num_heads, self.d_kv).transpose(1, 2)
        value_states = value_states.view(batch_size, -1, self.num_heads, self.d_kv).transpose(1, 2)
        
        # 캐싱을 다룬다
        if past_key_value is not None:
            key_states = torch.cat([past_key_value[0], key_states], dim=2)
            value_states = torch.cat([past_key_value[1], value_states], dim=2)
        
        present_key_value = (key_states, value_states) if use_cache else None
        
        # 주의 점수
        scores = torch.matmul(query_states, key_states.transpose(-2, -1))
        
        # 자리 편향을 더한다
        if position_bias is None and self.has_relative_attention_bias:
            position_bias = self.relative_attention_bias(
                query_length=seq_len,
                key_length=key_states.size(2)
            )
        
        if position_bias is not None:
            scores += position_bias
        
        # 주의 가림을 적용한다
        if attention_mask is not None:
            scores += attention_mask
        
        # 소프트맥스와 드롭아웃
        attn_weights = F.softmax(scores.float(), dim=-1).type_as(scores)
        attn_weights = self.dropout(attn_weights)
        
        # 값에 적용한다
        attn_output = torch.matmul(attn_weights, value_states)
        attn_output = attn_output.transpose(1, 2).contiguous()
        attn_output = attn_output.view(batch_size, -1, self.inner_dim)
        attn_output = self.o(attn_output)
        
        return attn_output, position_bias, present_key_value

class T5LayerFF(nn.Module):
    """T5 순전파 층."""
    
    def __init__(self, config: T5Config):
        super().__init__()
        
        self.DenseReluDense = nn.Sequential(
            nn.Linear(config.d_model, config.d_ff, bias=False),
            nn.ReLU(),
            nn.Dropout(config.dropout_rate),
            nn.Linear(config.d_ff, config.d_model, bias=False)
        )
        self.layer_norm = nn.LayerNorm(config.d_model, eps=config.layer_norm_epsilon)
        self.dropout = nn.Dropout(config.dropout_rate)
    
    def forward(self, hidden_states: torch.Tensor) -> torch.Tensor:
        """앞 정규화 순전파 신경망."""
        normed = self.layer_norm(hidden_states)
        ff_output = self.DenseReluDense(normed)
        return hidden_states + self.dropout(ff_output)

class T5EncoderBlock(nn.Module):
    """T5 인코더 블록."""
    
    def __init__(self, config: T5Config, has_relative_attention_bias: bool = False):
        super().__init__()
        
        self.layer_norm = nn.LayerNorm(config.d_model, eps=config.layer_norm_epsilon)
        self.self_attention = T5Attention(
            config,
            is_decoder=False,
            has_relative_attention_bias=has_relative_attention_bias
        )
        self.feed_forward = T5LayerFF(config)
        self.dropout = nn.Dropout(config.dropout_rate)
    
    def forward(
        self,
        hidden_states: torch.Tensor,
        attention_mask: Optional[torch.Tensor] = None,
        position_bias: Optional[torch.Tensor] = None
    ) -> Tuple[torch.Tensor, Optional[torch.Tensor]]:
        """앞먹임."""
        # 자기 주의
        normed = self.layer_norm(hidden_states)
        attn_output, position_bias, _ = self.self_attention(
            normed,
            position_bias=position_bias,
            attention_mask=attention_mask
        )
        hidden_states = hidden_states + self.dropout(attn_output)
        
        # 순전파 신경망
        hidden_states = self.feed_forward(hidden_states)
        
        return hidden_states, position_bias

class T5DecoderBlock(nn.Module):
    """자기 주의와 교차 주의를 갖춘 T5 디코더 블록."""
    
    def __init__(self, config: T5Config, has_relative_attention_bias: bool = False):
        super().__init__()
        
        self.layer_norm = nn.LayerNorm(config.d_model, eps=config.layer_norm_epsilon)
        
        # 가린 자기 주의
        self.self_attention = T5Attention(
            config,
            is_decoder=True,
            has_relative_attention_bias=has_relative_attention_bias
        )
        
        # 교차 주의
        self.cross_attention_layer_norm = nn.LayerNorm(
            config.d_model, eps=config.layer_norm_epsilon
        )
        self.cross_attention = T5Attention(config, is_decoder=True)
        
        # 순전파 신경망
        self.feed_forward = T5LayerFF(config)
        self.dropout = nn.Dropout(config.dropout_rate)
    
    def forward(
        self,
        hidden_states: torch.Tensor,
        encoder_hidden_states: torch.Tensor,
        attention_mask: Optional[torch.Tensor] = None,
        encoder_attention_mask: Optional[torch.Tensor] = None,
        position_bias: Optional[torch.Tensor] = None,
        encoder_decoder_position_bias: Optional[torch.Tensor] = None,
        past_key_value: Optional[Tuple] = None,
        use_cache: bool = False
    ) -> Tuple:
        """앞먹임."""
        self_attn_past_key_value = past_key_value[:2] if past_key_value else None
        cross_attn_past_key_value = past_key_value[2:] if past_key_value else None
        
        # 자기 주의
        normed = self.layer_norm(hidden_states)
        attn_output, position_bias, present_key_value = self.self_attention(
            normed,
            position_bias=position_bias,
            attention_mask=attention_mask,
            past_key_value=self_attn_past_key_value,
            use_cache=use_cache
        )
        hidden_states = hidden_states + self.dropout(attn_output)
        
        # 교차 주의
        normed = self.cross_attention_layer_norm(hidden_states)
        cross_attn_output, _, cross_present = self.cross_attention(
            normed,
            key_value_states=encoder_hidden_states,
            attention_mask=encoder_attention_mask,
            past_key_value=cross_attn_past_key_value,
            use_cache=use_cache
        )
        hidden_states = hidden_states + self.dropout(cross_attn_output)
        
        # 순전파 신경망
        hidden_states = self.feed_forward(hidden_states)
        
        present = present_key_value + cross_present if use_cache else None
        
        return hidden_states, position_bias, present

class T5Model(nn.Module):
    """온전한 T5 인코더-디코더 모형."""
    
    def __init__(self, config: T5Config):
        super().__init__()
        self.config = config
        
        # 함께 쓰는 임베딩
        self.shared = nn.Embedding(config.vocab_size, config.d_model)
        
        # 인코더
        self.encoder_embed_dropout = nn.Dropout(config.dropout_rate)
        self.encoder_blocks = nn.ModuleList([
            T5EncoderBlock(config, has_relative_attention_bias=(i == 0))
            for i in range(config.num_layers)
        ])
        self.encoder_final_layer_norm = nn.LayerNorm(
            config.d_model, eps=config.layer_norm_epsilon
        )
        
        # 디코더
        self.decoder_embed_dropout = nn.Dropout(config.dropout_rate)
        self.decoder_blocks = nn.ModuleList([
            T5DecoderBlock(config, has_relative_attention_bias=(i == 0))
            for i in range(config.num_decoder_layers)
        ])
        self.decoder_final_layer_norm = nn.LayerNorm(
            config.d_model, eps=config.layer_norm_epsilon
        )
        
        # 언어 모형 머리
        self.lm_head = nn.Linear(config.d_model, config.vocab_size, bias=False)
    
    def encode(
        self,
        input_ids: torch.Tensor,
        attention_mask: Optional[torch.Tensor] = None
    ) -> torch.Tensor:
        """입력 수열을 인코딩한다."""
        hidden_states = self.shared(input_ids)
        hidden_states = self.encoder_embed_dropout(hidden_states)
        
        # 주의 가림을 바꾼다
        if attention_mask is not None:
            extended_mask = (1.0 - attention_mask.unsqueeze(1).unsqueeze(2)) * -1e9
        else:
            extended_mask = None
        
        position_bias = None
        for block in self.encoder_blocks:
            hidden_states, position_bias = block(
                hidden_states,
                attention_mask=extended_mask,
                position_bias=position_bias
            )
        
        hidden_states = self.encoder_final_layer_norm(hidden_states)
        return hidden_states
    
    def decode(
        self,
        decoder_input_ids: torch.Tensor,
        encoder_hidden_states: torch.Tensor,
        encoder_attention_mask: Optional[torch.Tensor] = None,
        past_key_values: Optional[List] = None,
        use_cache: bool = False
    ) -> Tuple[torch.Tensor, Optional[List]]:
        """출력 수열을 디코딩한다."""
        hidden_states = self.shared(decoder_input_ids)
        hidden_states = self.decoder_embed_dropout(hidden_states)
        
        # 디코더를 위한 인과 가림
        seq_len = decoder_input_ids.size(1)
        causal_mask = torch.triu(
            torch.ones(seq_len, seq_len, device=decoder_input_ids.device),
            diagonal=1
        ).bool()
        causal_mask = causal_mask.unsqueeze(0).unsqueeze(0) * -1e9
        
        # 인코더 주의 가림
        if encoder_attention_mask is not None:
            encoder_extended_mask = (
                1.0 - encoder_attention_mask.unsqueeze(1).unsqueeze(2)
            ) * -1e9
        else:
            encoder_extended_mask = None
        
        position_bias = None
        presents = [] if use_cache else None
        
        for i, block in enumerate(self.decoder_blocks):
            past = past_key_values[i] if past_key_values else None
            
            hidden_states, position_bias, present = block(
                hidden_states,
                encoder_hidden_states,
                attention_mask=causal_mask,
                encoder_attention_mask=encoder_extended_mask,
                position_bias=position_bias,
                past_key_value=past,
                use_cache=use_cache
            )
            
            if use_cache:
                presents.append(present)
        
        hidden_states = self.decoder_final_layer_norm(hidden_states)
        return hidden_states, presents
    
    def forward(
        self,
        input_ids: torch.Tensor,
        decoder_input_ids: torch.Tensor,
        attention_mask: Optional[torch.Tensor] = None,
        labels: Optional[torch.Tensor] = None
    ) -> Dict[str, torch.Tensor]:
        """앞먹임."""
        # 부호화
        encoder_hidden_states = self.encode(input_ids, attention_mask)
        
        # 디코딩
        decoder_hidden_states, _ = self.decode(
            decoder_input_ids,
            encoder_hidden_states,
            encoder_attention_mask=attention_mask
        )
        
        # 언어 모형 머리
        logits = self.lm_head(decoder_hidden_states)
        
        # 손실을 계산한다
        loss = None
        if labels is not None:
            loss = F.cross_entropy(
                logits.view(-1, logits.size(-1)),
                labels.view(-1),
                ignore_index=-100
            )
        
        return {'loss': loss, 'logits': logits}

# 사용 예
```

## 6. T5의 변형

| 변형 | 대표 변화 | 구분할 점 |
|---|---|---|
| T5 v1.1 | GEGLU, 사전 학습 드롭아웃 생략, 입력 임베딩·출력 분류 가중치 비공유 | 인코더와 디코더의 입력 임베딩까지 분리한다는 뜻은 아님 |
| mT5 | 다국어 mC4 사전 학습 | 지원 언어별 성능은 별도 평가 |
| Flan-T5 | 지시 미세 조정 | 모든 공개 모델보다 우수하다는 보편적인 순위가 아님 |
| UL2 | 여러 복원·접두 목적의 혼합 | 과제 모드·데이터와 계산 예산을 확인 |
| LongT5 | 국소·transient global 어텐션 | 긴 길이를 지원하는 구현과 품질을 함께 평가 |

### T5가 남긴 것

T5 연구는 구조·복원 목표·데이터·학습 규모를 비교했다. 각 결론은 논문의 실험 범위에서 읽어야 하며 한 요소만의 보편적인 우열로 바꾸어서는 안 된다.

구간 마스킹은 목표 길이를 줄일 수 있지만 모델 계수 자체를 자동으로 줄이지 않는다. 모델을 두 배 키우고 데이터를 반으로 줄이면 항상 좋아진다는 규칙도 없다. 구조·계수·토큰 수·학습 계산을 구분해 비교한다.

## 7. 사전 학습 목표 비교

아래 함수들은 각각 다른 학습 목표를 설명하는 조각이며 하나의 완성된 사전 학습 시스템은 아니다. 손실 집계의 유효 토큰·정답 정렬을 먼저 정한다.

create_mlm_data는 input_ids를 제자리 변경하고 특수 토큰·PAD를 예측 대상에서 제외하지 않는다. 새 난수·확률 텐서는 CPU에 생성되어 GPU 입력과 장치가 맞지 않을 수 있다. 유효 위치가 하나도 선택되지 않은 배치의 평균 손실도 처리해야 한다.

create_span_corruption_data는 pass로 끝나 None을 반환하는 미구현 함수다. 아래 ELECTRA는 생성기에 손상되지 않은 원본을 그대로 넘기며 생성기 MLM 손실도 구현하지 않아 정상적인 ELECTRA 사전 학습이 아니다. ul2_objective는 정의되지 않은 span_corruption·prefix_lm을 호출하는 개념 조각이다.

### 인과 언어 모델링 (CLM)

GPT, LLaMA를 비롯한 디코더 전용 모델이 쓴다.

$$
\mathcal{L}_{\text{CLM}} = -\sum_{t=1}^{T} \log P(x_t | x_1, \ldots, x_{t-1})
$$

**성질:**

- 한 방향 (왼쪽에서 오른쪽)
- 생성에 자연스럽다
- 학습 설정이 간단하다

```python
import torch
import torch.nn.functional as F

def causal_lm_loss(logits, labels):
    """
    인과 언어 모형화 손실.
    
    인수:
        logits: [batch, seq_len, vocab_size]
        labels: [batch, seq_len]
    """
    # 다음 토큰 맞히기를 위해 민다
    shift_logits = logits[..., :-1, :].contiguous()
    shift_labels = labels[..., 1:].contiguous()
    
    return F.cross_entropy(
        shift_logits.view(-1, shift_logits.size(-1)),
        shift_labels.view(-1),
        ignore_index=-100
    )
```

### 마스크 언어 모델링 (MLM)

BERT, RoBERTa를 비롯한 인코더 전용 모델이 쓴다.

$$
\mathcal{L}_{\text{MLM}} = -\sum_{i \in \mathcal{M}} \log P_\theta(x_i\mid\widetilde{\mathbf{x}})
$$

**입력 손상 방식 (BERT):**

- 토큰의 15%를 고른다
- 80%는 [MASK]으로 바꾼다
- 10%는 무작위 토큰으로 바꾼다
- 10%는 그대로 둔다

```python
import torch
import torch.nn as nn

def create_mlm_data(input_ids, vocab_size, mask_token_id, mask_prob=0.15):
    """가린 언어 모형 학습 데이터를 만든다."""
    labels = input_ids.clone()
    
    # 가림막 만들기
    probability_matrix = torch.full(input_ids.shape, mask_prob)
    masked_indices = torch.bernoulli(probability_matrix).bool()
    
    # 특별 토큰은 가리지 않는다
    labels[~masked_indices] = -100
    
    # 80%는 [MASK]
    indices_replaced = torch.bernoulli(torch.full(input_ids.shape, 0.8)).bool() & masked_indices
    input_ids[indices_replaced] = mask_token_id
    
    # 10%는 무작위
    indices_random = torch.bernoulli(torch.full(input_ids.shape, 0.5)).bool() & masked_indices & ~indices_replaced
    random_words = torch.randint(vocab_size, input_ids.shape)
    input_ids[indices_random] = random_words[indices_random]
    
    # 10%는 그대로
    return input_ids, labels
```

### 접두 언어 모델링

양방향 접두와 인과 이어 가기를 아우른다.

$$
\mathcal{L} = -\sum_{t > L_{\text{prefix}}} \log P(x_t | x_1, \ldots, x_{t-1})
$$

UL2와 일부 인코더-디코더 모델이 쓴다.

### 바뀐 토큰 찾기 (ELECTRA)

바뀐 토큰을 찾아내는 판별기를 학습시킨다.

$$
\mathcal{L} = -\sum_{t=1}^{T} \left[ y_t \log D(x_t) + (1-y_t) \log(1 - D(x_t)) \right]
$$

여기서는 실제 입력의 원래 토큰과 다른 토큰이면 $y_t=1$이고 D는 교체 여부의 확률이다. 생성기가 샘플링했어도 우연히 원래 ID와 같으면 교체 라벨은 0이다. 생성기의 MLM 손실과 판별기 손실을 함께 구성하는 것은 별도 단계다.

```python
class ELECTRA(nn.Module):
    def __init__(self, generator, discriminator):
        super().__init__()
        self.generator = generator  # 작은 가린 언어 모형
        self.discriminator = discriminator  # 주 모형
    
    def forward(self, input_ids, masked_indices):
        # 생성기가 가린 토큰을 맞힌다
        gen_logits = self.generator(input_ids)
        
        # 바꿔 넣을 것을 뽑는다
        with torch.no_grad():
            gen_probs = F.softmax(gen_logits, dim=-1)
            sampled = torch.multinomial(gen_probs.view(-1, gen_probs.size(-1)), 1)
            sampled = sampled.view(input_ids.shape)
        
        # 가린 자리를 바꾼다
        corrupted = input_ids.clone()
        corrupted[masked_indices] = sampled[masked_indices]
        
        # 판별기가 어느 것이 바뀌었는지 맞힌다
        disc_logits = self.discriminator(corrupted)
        labels = (corrupted != input_ids).float()
        
        return disc_logits, labels
```

### 비교

| 목표 | 대표 구성 | 예측 대상 |
|---|---|---|
| 인과 LM | 인과 디코더 | 다음 토큰 |

    T5의 원문 토큰은 양방향으로 읽고 목표는 원문 메모리와 앞선 목표에 조건부로 생성한다. 디코더 전용은 프롬프트·목표를 한 시퀀스에서 인과적으로 처리한다. 뒤 위치는 프롬프트 전체를 읽을 수 있으며 어느 구조가 항상 더 잘 확장되거나 우수한지는 같은 예산에서 비교해야 한다.

---

<div class="drillbox" markdown>

**연습문제 3.** <span class="diff med" title="중간"></span>
span corruption과 BERT MLM의 입력·목표 차이를 설명하라.

</div>

??? success "연습문제 3 풀이"
    T5는 원문의 여러 구간을 센티널로 대체하고 제거된 구간들을 센티널과 함께 목표문으로 생성한다. BERT는 손상 입력의 선택 위치에서 원래 토큰을 각각 예측한다. T5는 짧은 목표를 구성할 수 있지만 모든 조건에서 BERT보다 효율적이거나 성능이 좋다는 뜻은 아니다.

**연습문제 4.** <span class="diff med" title="중간"></span>
T5의 비교 연구에서 구조와 학습 규모의 효과를 해석할 때 무엇을 통제해야 하는가?

</div>

??? success "연습문제 4 풀이"
    학습 토큰·배치·갱신 수·모델 크기·계산량과 데이터 구성을 확인한다. 계수 수가 같아도 구조별 연산 비용과 목표 길이가 다르다. 논문의 설정별 결과를 모든 지도 과제나 새로운 데이터의 보편 법칙으로 확장하지 않는다.

## 정리하며

T5는 다양한 과제를 텍스트 생성 형식으로 표현하고 구간 마스킹 사전 학습을 활용한다. 원래 모델·v1.1·다른 변형을 구분하며, 이 예제의 일반 LayerNorm·목표 정렬·미완성 캐시와 학습 데이터 함수의 한계를 함께 확인한다.
