# 24장: 대규모 언어 모델
이 장은 대규모 언어 모델을 두루 다룬다. 곧 그 기초, 구조, 스케일링 법칙, 프롬프트 재주, 찾아 붙여 생성, 스스로 움직이는 체계, 파라미터 효율적 파인튜닝, 추론 최적화, 결 맞추기 방법을 살펴본다. 절마다 수학의 엄밀함과 실전 짜기 길잡이를 아우른다.

---

## 1. 대규모 언어 모델의 기초

사전 학습 목표에서 평가와 대화 인공지능까지, 대규모 언어 모델을 떠받치는 핵심 개념.

- 대규모 언어 모델 개요 — 대규모 언어 모델의 정의, 할 수 있는 것, 한계
- 뿌리와 발전 — n-그램에서 요즘 대규모 언어 모델 갈래까지의 흐름
- 디코더 구조 — 인과 셀프 어텐션을 쓰는 디코더만의 트랜스포머
- 다음 토막 어림하기 — 자기회귀 말 나타내기 목표와 풀기 전략
- [사전 학습 목표](llm_foundations/pretraining_objectives.md) — 인과 말 나타내기와 가린 말 나타내기, 잡음 없애기 목표, UL2 같은 요즘 전략
- 토막내기와 규모 — BPE, WordPiece, SentencePiece와 단어 곳간 크기의 트레이드오프
- 큰 규모의 학습 데이터 — 데이터 고르기, 거르기, 겹침 없애기, 오염 위험
- [평가 지표](llm_foundations/evaluation_metrics.md) — 대규모 언어 모델의 내재 평가, 일별 평가, 사람의 평가
- 대화 인공지능 — 규칙 기초 대화 로봇에서 대규모 언어 모델 도우미까지의 여러 차례 대화 체계
- [어려움과 한계](llm_foundations/challenges.md) — 맥락 다스리기, 사실의 믿음성, 편향, 윤리에 맞는 펼치기
- 앞으로의 방향 — 구조의 효율, 따짐, 여러 갈래 아우르기, 스스로 움직이는 몸짓
- 학습 문제 — 대화 인공지능 체계를 세우고 값매김하는 손수 하기 학습

## 3. 규모 키우기

대규모 언어 모델의 성능과 계산에 가장 알맞은 학습을 다스리는 실증 스케일링 법칙.

- 친칠라 규모 키우기 — 친칠라 손실의 매개변수 나타내기와 어림

## 4. 프롬프트

프롬프트를 꾸며 대규모 언어 모델에서 바라는 몸짓을 이끌어 내는 재주.

- [프롬프트 개요](prompting/prompting_overview.md) — 파인튜닝에서 프롬프트로의 틀 바뀜
- 프롬프트 빚기 — 잘 듣는 프롬프트의 핵심 원리와 구조 무늬
- 영 발 프롬프트 — 보기 없이 일을 해내기
- 몇 발 프롬프트 — 보기를 고르고 늘어놓아 맥락 안에서 학습하기
- [Chain-of-Thought(CoT)](prompting/chain_of_thought.md) — 성능을 낫게 하는 한 걸음씩 따지기
- 스스로 한결같기 — 여러 따짐 길에 대한 다수결
- 생각의 나무 — 따짐 전략을 가지 쳐 살펴보기
- 프롬프트 최적화 — 띄엄띄엄한 프롬프트와 이어진 프롬프트를 저절로 찾기

---

## 5. 찾아 붙여 생성

대규모 언어 모델의 내놓음을 바깥 앎에 뿌리내리게 하는 찾아 붙여 생성.

- 찾아 붙여 생성 개요 — 구조, 왜 하는가, 언제 파인튜닝을 앞서는가
- [밀집 검색(Dense Retrieval)](rag/dense_retrieval.md) — 두 인코더 구조와 맞대어 학습
- 벡터 데이터베이스 — 닮음 찾기를 위한 FAISS와 벡터 데이터베이스 기술
- 텍스트 덩이 짓기 — 금융 텍스트의 덩이 짓기 전략과 트레이드오프
- 찾개-읽개 구조 — 막무가내, 되풀이, 알맞게 맞추는 변종을 담은 온전한 물길
- 다시 매기기 — 엇갈린 인코더로 다시 매기는 두 단계 찾기
- 찾아 붙여 생성 평가 — 찾기와 생성의 좋음을 재는 잣대

## 6. 에이전트

계획, 연장 쓰기, 여럿이 어울리기를 갖춘 대규모 언어 모델 기초 스스로 움직이는 체계.

- 에이전트 개요 — 계획, 기억, 연장 쓰기를 갖춘 대규모 언어 모델 에이전트 구조
- 연장 쓰기 — 연장의 틀을 정하고 실행 얼거리 세우기
- 함수 부르기 — API 수준의 구조 있는 함수 부르기 구조
- [ReAct](agents/react.md) — 생각-행동-살핌 되풀이로 따지고 움직이기
- 계획 — 일 쪼개기와 계획하고 실행하는 구조
- 여럿이 움직이는 체계 — 감독, 토론, 조립선 무늬
- [사례 분석](agents/case_studies.md) — 여러 업계의 실제 대화 인공지능 펼치기
- 대규모 언어 모델 쓰임새 — 여러 분야에서의 ChatGPT 실전 쓰임새

## 7. 효율적인 대규모 언어 모델

익힐 매개변수를 아주 적게 쓰고 대규모 언어 모델을 맞추는 파인튜닝 방법.

- 효율 개요 — 파라미터 효율적 파인튜닝이 왜 필요한가와 방법의 갈래
- [LoRA](efficient_llm/lora.md) — 저랭크 적응의 수학 기초와 짜기
- QLoRA — 일반 하드웨어에서 파인튜닝을 가능하게 하는 양자화된 LoRA
- [어댑터 층](efficient_llm/adapters.md) — 이어진, 나란한, AdapterFusion 병목 단원
- [Prefix Tuning](efficient_llm/prefix_tuning.md) — 무게를 고치지 않고 모델을 맞추는 부드러운 앞가지
- 프롬프트 다듬기 — 일에 맞추려 이어진 부드러운 프롬프트를 최적화
- BitFit — 매개변수를 가장 적게 고치는 편향만 파인튜닝
- [매개변수 아끼는 파인튜닝 비교](efficient_llm/peft_comparison.md) — LoRA, QLoRA, 어댑터, 앞가지 다듬기 비교하여 살피기

## 8. 추론

처리량, 늦음, 기억 공간 효율을 위해 대규모 언어 모델 내놓기 다듬기.

- 추론 개요 — 기억 공간 대역폭 병목, 미리 채우기와 풀기 단계
- [KV 캐시](inference/kv_cache.md) — 키-값 텐서를 갈무리해 겹치는 계산 없애기
- [FlashAttention](inference/flash_attention.md) — 들고남을 헤아리는 정확한 어텐션, 기억 공간 O(N)
- [양자화](inference/quantization.md) — 펼치기를 위한 무게와 활성화의 양자화
- [Speculative Decoding](inference/speculative_decoding.md) — 작은 모델로 밑그림을 그리고 확인해 빠르게 하기
- 쪽 나눈 어텐션 — KV 캐시를 다스리는 가상 기억 공간 생각(vLLM)
- 이어지는 배치 짓기 — 처리량을 낫게 하는 바퀴 단위 일정 짜기
- 모델 나눠 담기 — 모델 무게를 여러 기기에 흩뿌리기
- 텐서 나란히 하기 — 선형 층과 어텐션 층의 칸 나란히 하기와 줄 나란히 하기
- 물길 나란히 하기 — 층별 흩뿌리기와 물길 거품 살피기
- [모델 압축](inference/model_compression_overview.md) — 펼치기를 위한 가지치기, 양자화, 지식 증류

## 9. 결 맞추기

사람 피드백 강화학습과 그 대안으로 대규모 언어 모델의 몸짓을 사람의 뜻에 맞추기.

- 결 맞추기 개요 — 왜 필요한가와 세 단계 물길
- 사람 피드백 강화학습 — 세 단계 물길
- 갚음 나타내기 — 브래들리-테리 뜻 모델과 갚음 구조
- 대규모 언어 모델을 위한 PPO — 언어 모델 학습에 맞춘 가까운 정책 최적화
- DPO — 드러난 갚음 모델 없이 뜻을 곧바로 최적화
- 헌법 인공지능 — 헌법 원리로 스스로 살피며 결 맞추기
- [학습 파이프라인](alignment/training_pipeline.md) — 사전 학습과 결 맞추기 단계, 그리고 최적화 전략
