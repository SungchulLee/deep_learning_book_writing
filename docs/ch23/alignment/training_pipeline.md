# 사전 학습과 선호 기반 후속 학습

언어 모델의 사전 학습과 후속 학습은 목적·자료·평가가 다르다. 이 절은 CLM, 지도 파인튜닝(SFT), 보상 모델과 PPO 기반 RLHF, DPO의 관계를 설명한다. 모든 모델이 같은 순서와 알고리즘을 사용하는 것은 아니며 특정 제품의 비공개 학습 과정을 재현하는 문서도 아니다.

## 1. 사전 학습의 목표와 자료

인과 언어 모델링은 이전 토큰에 조건을 건 다음 토큰 로그우도를 최대화한다. 최소화하는 손실로 쓰면 부호를 바꾸어야 한다.

$$\mathcal L_{\mathrm{CLM}}(\theta)=-\sum_t\log p_\theta(x_t\mid x_{<t}).$$

입력 문맥의 인과성·경계·목표 이동·padding 제외를 맞춘다. BERT식 마스킹 복원과 같은 우도는 아니며, 사전 학습만으로 지시 준수·사실성·안전성이 완성되지는 않는다. 반대로 기반 모델은 어떤 지시도 전혀 따르지 못한다고 단정할 수도 없다.

웹·책·코드·문서 등의 혼합은 모델·자료의 권리와 목적에 따라 다르다. 공개되지 않은 모델에 특정 출처가 가장 큰 비중이라고 추정하지 않는다. 중복·평가 오염·민감 정보·언어별 분포를 검토하고 필터링으로 바뀐 분포도 평가한다.

AdamW·학습률 스케줄·혼합 정밀도·분산 학습은 흔한 구성 선택이지만 세부 설정을 모든 모델의 규칙으로 제시하지 않는다. FP16에서 쓰는 loss scaling이 BF16에도 항상 필수인 것은 아니다. [스케일링 법칙](../scaling/scaling_overview.md)은 특정 조건의 손실·계산 배분을 다루며 고정 달러 비용을 제공하지 않는다.

## 2. 지도 파인튜닝

SFT는 (프롬프트 x, 바람직한 응답 y) 자료로 응답 토큰을 예측한다.

$$\mathcal L_{\mathrm{SFT}}=-\mathbb E_{(x,y)}\sum_{\ell=1}^{|y|}\log\pi_\theta(y_\ell\mid x,y_{<\ell}).$$

이 식은 프롬프트를 조건으로 주고 응답에만 손실을 적용하는 설정이다. 실제 입력 템플릿·역할·EOS·손실 마스크를 맞추어야 한다. 시범은 사람이 작성하거나 다른 절차로 생성·검토할 수 있다. 품질·다양성·중복·분할을 확인하고 학습률·epoch는 검증으로 선택한다.

SFT가 형식만, 선호 학습이 품질과 안전만을 담당한다는 엄격한 분업은 없다. 두 단계 모두 자료와 목적에 따라 여러 행동을 바꾸며 망각·과적합·분포 밖 실패를 평가해야 한다.

## 3. 보상 모델과 사람 선호

[InstructGPT 연구](https://arxiv.org/abs/2203.02155)의 한 흐름은 사람 시범의 SFT 뒤 응답 비교로 보상 모델을 학습하고 이를 최적화하는 것이다. 같은 x에 대한 선호 응답 y_w와 비선호 y_l의 점수 차이를 Bradley–Terry 손실로 학습할 수 있다.

$$\mathcal L_{\mathrm{RM}}=-\mathbb E\log\sigma[R_\phi(x,y_w)-R_\phi(x,y_l)].$$

R은 학습한 스칼라 점수이며 검증된 사실 확률이나 모든 사람이 공유하는 절대 효용이 아니다. 주석 기준·평가자 차이·동점·자료 편향과 정책 출력의 분포 이동에 영향을 받는다. 같은 prompt의 여러 비교는 서로 독립이 아닐 수 있어 자료 분할과 집계도 고려한다.

스칼라에 여러 품질을 결합할 수는 있지만 가치 간 상충과 집단별 차이를 가릴 수 있다. 비교가 절대 점수보다 항상 더 일관된다는 보편적 규칙도 없다. 실제 주석 일치와 오류를 확인해야 한다.

## 4. PPO 기반 RLHF

학습한 보상과 기준 정책에서의 이탈 벌점을 함께 고려하는 목적의 예는 다음과 같다.

$$\max_\theta\ \mathbb E_{x,y\sim\pi_\theta}R_\phi(x,y)
-\beta\,\mathbb E_x D_{\mathrm{KL}}[\pi_\theta(\cdot\mid x)\|\pi_{\mathrm{ref}}(\cdot\mid x)].$$

β>0은 보상과 이탈 제한의 균형을 조절한다. KL 벌점은 분포 이동을 억제할 수 있지만 보상 모델의 허점을 이용하는 reward hacking을 완전히 막지는 못한다.

[PPO](https://arxiv.org/abs/1707.06347)는 이전 정책 대비 행동 확률 비율 r_t와 추정 advantage를 사용한 clipped surrogate를 최대화한다.

$$\mathbb E_t\min\{r_t\hat A_t,\operatorname{clip}(r_t,1-\epsilon,1+\epsilon)\hat A_t\}.$$

토큰 선택이 행동이고 프롬프트와 이전 생성이 상태다. 이 clipped 목적과 별도의 기준 정책 KL은 역할이 다르다. clipping이 모든 정책 변화나 전체 KL의 상한을 강제로 보장하는 것도 아니다.

정책·기준·보상·가치 기능을 사용할 수 있지만 항상 독립된 같은 크기 네 모델이 동시에 같은 방식으로 학습되는 것은 아니다. 공유·동결·분산·offload·batch에 따라 메모리가 달라져 SFT의 정확히 네 배라고 단정할 수 없다.

## 5. DPO와 AI 피드백

[DPO](https://arxiv.org/abs/2305.18290)는 기준 정책과의 응답 로그확률 비율을 선호 손실에 사용한다.

$$\mathcal L_{\mathrm{DPO}}=-\mathbb E\log\sigma\left[\beta\log\frac{\pi_\theta(y_w\mid x)}{\pi_{\mathrm{ref}}(y_w\mid x)}-\beta\log\frac{\pi_\theta(y_l\mid x)}{\pi_{\mathrm{ref}}(y_l\mid x)}\right].$$

기본적인 오프라인 DPO는 별도 보상 모델·가치 모델과 PPO의 온라인 rollout 루프를 요구하지 않는다. ‘보상 모델을 먼저 학습한 뒤 DPO로 강화학습한다’는 단일 절차로 설명하지 않는다. 구현은 단순해질 수 있지만 항상 더 안정적·저렴하거나 정확하다는 보장은 없고 선호 자료·기준·길이·분포 영향을 받는다.

[Constitutional AI](https://arxiv.org/abs/2212.08073)는 원칙에 따른 비평·수정으로 SFT 자료를 구성하는 단계와 AI 선호로 보상 모델·강화학습을 수행하는 단계를 연구했다. 수정 응답의 SFT 자체를 RLAIF라고 부르지는 않는다. 원칙을 정하고 평가하는 사람의 판단과 오류·편향 검토도 여전히 필요하다.

## 6. 후속 평가와 운영

사람 선호 점수 향상과 실제 사실성·공정성·안전·업무 성공은 따로 평가한다. 독립 프롬프트, 여러 집단·언어, 과잉 거절·누락·출처·불확실성과 분포 이동을 살핀다. 보상이나 하나의 평가자를 최적화한 결과만으로 모든 목표가 달성됐다고 선언하지 않는다.

자료 수준의 보완·학습 목적·후처리·접근 권한과 모니터링은 서로 다른 역할이다. [편향과 공정성](../../ch41/index.md)의 기준과 상충도 함께 고려한다. 이 페이지는 개념 설명이며 사전 학습·RLHF·DPO를 실행하거나 제품 내부 구조를 확인한 결과가 아니다.

??? success "연습문제 1 풀이"

    CLM은 이전 문맥에서 다음 토큰을 예측한다. SFT는 바람직한 응답 예시에 조건부 우도를 학습하고, 보상 모델은 응답 비교의 선호 점수 차이를 학습한다. 셋의 자료·손실·평가가 다르며 사전 학습이 모든 지시를 못 따르거나 SFT가 형식만 가르친다고 단정할 수 없다.

**연습문제 2.** <span class="diff med" title="중간"></span>

??? success "연습문제 2 풀이"

    KL은 기준 정책에서 지나치게 벗어나는 행동에 벌점을 주고 clipping은 이전 정책 대비 비율에 따른 대리 목적의 이득을 제한한다. clipping은 전체 KL의 엄격한 상한이 아니며 두 장치 모두 보상 오류·reward hacking을 완전히 제거하지 못한다.

**연습문제 3.** <span class="diff easy" title="쉬움"></span>

??? success "연습문제 3 풀이"

??? success "연습문제 4 풀이"

## 정리하며

사전 학습·SFT·보상 학습·PPO·DPO는 서로 다른 목적과 계산을 가진다. 공개 연구의 절차를 비공개 제품 전체에 투영하지 않고, 손실 개선과 실제 행동·사실성·공정성의 평가를 구분한다.
