# 금융 구조의 모델 보안

머신러닝 모델을 참 금융 구조에 내놓으면 추론 하나하나의 강건성을 넘어서는 지킴 문제가 생긴다. 이 마디는 모델 훔치기와 데이터에 독 타기에서 든든히 내놓는 버릇에 이르기까지, 머신러닝 금융 구조의 끝에서 끝까지의 지킴을 다룬다.

---

## 1. 위협의 터

### 모델 빼내기

API을 쓸 수 있는 겨루는 이는 물음과 되받음의 짝으로 대신 쓸 모델을 익혀 모델을 **훔칠** 수 있다.

$$
f_{\text{surrogate}} \approx f_{\text{target}} \quad \text{via} \quad \{(\mathbf{x}_i, f_{\text{target}}(\mathbf{x}_i))\}_{i=1}^N
$$

**금융에 미침**: 제 것인 거래 신호, 미쁨 점수 모델, 위험 모델은 큰 앎의 재산이다. 빼내기는 모델 훔치기와 그에 이어지는 화이트박스 적대적 공격을 함께 이룬다.

**방어**:

- 물음 잦기 마디 짓기와 튀는 것 알아내기
- 출력 흔들기(추론에 눈금 맞춘 잡음 더하기)
- 물무늬 넣기(모델의 피처에 짚어낼 수 있는 무늬 박기)

### 데이터에 독 타기

학습 데이터에 힘을 미칠 수 있는 겨루는 이는 모델의 성능을 떨어뜨리거나 타깃 있는 뒷문을 만드는 **독 탄 보기**를 끼워 넣을 수 있다.

$$
\mathcal{D}_{\text{poisoned}} = \mathcal{D}_{\text{clean}} \cup \{(\mathbf{x}_{\text{poison}}, y_{\text{target}})\}
$$

**금융에서의 보기**:

- 모델 학습에 쓰는 지난 값 데이터를 흔들기
- 옳다고 레이블 붙인 속임 거래를 학습 꾸러미에 끼워 넣기
- 다른 데이터 밑동(별그림, 누리 긁기)을 망가뜨리기

#### 피처 부딪힘으로 하는 타깃 있는 독 타기

데이터에 독 타기 가운데 특히 음흉한 것이 **맑은 레이블 독 타기**이다. 치는 이가 레이블을 하나도 바꿀 필요가 없다. 그 대신 피처 공간에서 타깃과 부딪히는 독 탄 학습 보기를 지어낸다.

$$
\mathbf{x}_{\text{poison}} = \arg\min_{\mathbf{x}} \| f(\mathbf{x}) - f(\mathbf{x}_{\text{target}}) \|_2^2 + \beta \| \mathbf{x} - \mathbf{x}_{\text{base}} \|_2^2
$$

여기서 $f(\cdot)$은 배운 피처를 뽑아내고, $\mathbf{x}_{\text{target}}$은 치는 이가 시험 때 틀리게 갈리길 바라는 보기이며, $\mathbf{x}_{\text{base}}$은 치는 이가 고른 클래스의 옳은 보기다. 첫째 항은 타깃과 피처 공간에서 부딪히게 하고, 둘째 항은 독 탄 것이 옳은 밑 보기와 눈으로 비슷하게 남게 한다(그래서 레이블이 맞아 보인다).

모델이 이 독 탄 보기로 익히면 타깃의 피처를 독 탄 것의 클래스와 이어 붙이는 피처를 배운다. 그러면 레이블을 하나도 망가뜨리지 않고도 시험 때 타깃이 틀리게 갈린다.

**계량 금융에 걸리는 까닭**: 금융 머신러닝의 학습 데이터는 흔히 바깥 업체, 다른 데이터 대는 곳, 긁어 온 데서 온다. 겨루는 이는 옳은 데이터와 통계로 들어맞아 성능 살핌을 다 지나면서도, 모델의 결정 경계를 은근히 밀어 어떤 증권이나 시장 상황을 틀리게 가르게 하는 지어낸 시장 데이터 점을 만들 수 있다.

#### 데이터에 독 타기를 막기

| 방어 | 구조 | 트레이드오프 |
|---------|-----------|-----------|
| 데이터 씻기 | 학습 앞서 피처 공간의 튀는 값을 없앤다 | 드물지만 옳은 일까지 버릴 수 있다 |
| 미침 함수 | 어떤 추론에 크게 미치는 학습 점을 짚어낸다 | 데이터가 크면 계산이 비싸다 |
| 스펙트럼 자국 | 피처의 공분산을 스펙트럼으로 살펴 독 탄 보기를 짚어낸다 | 독이 어느 만큼 몰려 있어야 한다 |
| 차이 사사로움 | 익히는 동안 잡음을 더해 점 하나의 미침을 제약된이다 | 모델의 정확도가 떨어진다 |
| 앙상블의 뜻 정확도 | 데이터를 나눠 학습된 모델들의 추론을 견준다 | 계산 비용이 는다 |

### 뒷문 공격

**뒷문**은 있으면 타깃대로 틀리게 가르게 만드는 숨은 방아쇠 피처가다.

$$
f(\mathbf{x} + \text{trigger}) = y_{\text{target}} \quad \forall \mathbf{x}
$$

맑은 입력에서는 $f(\mathbf{x}) = y_{\text{correct}}$이다.

**금융의 위험**: 뒷문이 심긴 미쁨 모델은 어떤 피처 무늬가 든 속임 신청을 받아 줄 수 있다.

## 2. 든든히 내놓는 버릇

### 여러 켜 방어 구조

```
들임 따지기 → 결 지켜보기 → 모형 모둠 → 날임 따지기 → 판단
       ↓                  ↓                   ↓                ↓
   튀는 것            분포 옮겨감        어긋남           자리와
   알아내기            알림              알아내기        한결같음
```

### 입력 따지기

```python
import torch
from typing import Dict, Optional

class InputValidator:
    """
    미루어 보기 앞서 모형 들임을 따진다.
    
    밖 분포 들임, 맞섬의 확률, 자료 됨됨이의 탈을
    살핀다.
    """
    
    def __init__(
        self,
        feature_means: torch.Tensor,
        feature_stds: torch.Tensor,
        feature_mins: torch.Tensor,
        feature_maxs: torch.Tensor,
        z_threshold: float = 5.0
    ):
        self.means = feature_means
        self.stds = feature_stds
        self.mins = feature_mins
        self.maxs = feature_maxs
        self.z_threshold = z_threshold
    
    def validate(self, x: torch.Tensor) -> Dict[str, torch.Tensor]:
        """
        들임을 따지고 됨됨이 표시를 돌려준다.
        """
        # z 점수 살피기: 아주 튀는 값에 표시한다
        z_scores = (x - self.means) / (self.stds + 1e-8)
        extreme = (z_scores.abs() > self.z_threshold).any(dim=1)
        
        # 자리 살피기: 익힘 자리 밖의 값에 표시한다
        below = (x < self.mins).any(dim=1)
        above = (x > self.maxs).any(dim=1)
        out_of_range = below | above
        
        # 빠진 값 살피기
        has_nan = torch.isnan(x).any(dim=1)
        
        return {
            'valid': ~(extreme | out_of_range | has_nan),
            'extreme_values': extreme,
            'out_of_range': out_of_range,
            'has_missing': has_nan,
            'max_z_score': z_scores.abs().max(dim=1)[0]
        }
```

### 모델 지켜보기

맞서는 액션이나 모델이 떨어지는 확률을 끊임없이 지켜본다.

| 신호 | 뜻하는 바 | 할 일 |
|--------|-----------|--------|
| 추론 분포 옮겨감 | 데이터 옮겨감이나 흔들기 | 알리고 살핀다 |
| 여느 것과 다른 물음 피처 | 모델 빼내기 시도 | 잦기를 마디 짓고 막는다 |
| 갑작스러운 정확도 떨어짐 | 독 타기나 분포 옮겨감 | 대비 모델로 물러난다 |
| 피처 중요도 바뀜 | 뜻 옮겨감이나 공격 | 따지며 다시 학습된이다 |
| 앙상블 어긋남이 치솟음 | 분포 외 입력 | 사람이 살피도록 표시한다 |

### 규정에서 헤아릴 것

금융 머신러닝 모델에는 남다른 규정 요건이 있다.

- **모델 위험 다루기(SR 11-7)**: 모델을 따지고 적고 지켜봐야 한다
- **풀이할 수 있어야 함**: 맞섬의 강건성을 적고 시험해야 한다
- **고르게 빌려주기 법**: 강건성을 따질 때 지켜야 할 성능을 헤아려야 한다
- **데이터 다스리기**: 학습 데이터의 온전함을 지키고 되짚어 볼 수 있어야 한다

## 3. 두루 갖춘 지킴 살핌표

머신러닝 모델을 참 금융 구조에 내놓을 때 살필 것들이다.

- [ ] 맞섬의 강건성 따지기(오토어택이나 그 밭에 맞는 것)
- [ ] 입력 따지기와 튀는 것 알아내기
- [ ] 모델 빼내기 방어(잦기 마디 짓기, 출력 흔들기)
- [ ] 데이터에 독 타기 버티기(학습 데이터 따지기)
- [ ] 뒷문 알아내기(뉴럴 클렌즈 따위)
- [ ] 앙상블 어긋남 지켜보기
- [ ] 분포 옮겨감 알아내기
- [ ] 물러설 구조(규칙 기초의 대비)
- [ ] 모델의 모든 판단에 대한 되짚음 자취
- [ ] 붉은 편 겨루기를 꾸준히 하기

## 연습문제

<div class="drillbox" markdown>

**연습문제 1.** <span class="diff med" title="중간"></span>
선형 분류기 $f(x) = w^T x + b$에서 예측한 클래스를 바꾸는 데 드는 가장 작은 $\ell_\infty$ 섭동을 계산하여라. 이것이 뉴럴 넷트웍의 강건성과 어떻게 이어지는지 밝혀라.

</div>

??? success "연습문제 1 풀이"
    선형 분류기에서 $\ell_\infty$ 노름으로 잰 결정 경계까지의 거리는 $\frac{|w^T x + b|}{\|w\|_1}$이다. 가장 작은 섭동은 $\delta^* = \frac{|w^T x + b|}{\|w\|_1} \cdot \text{sign}(w)$이다. 뉴럴 넷트웍에서는 그 자리의 선형 어림 $f(x + \delta) \approx f(x) + \nabla_x f \cdot \delta$이 FGSM(그래디언트의 부호를 쓴다)이 왜 잘 듣는지를 밝혀 준다. 차원이 높은 모델이 무른 까닭은 $\|w\|_1$은 차원과 함께 커지는데 $|w^T x + b|$은 꼭 그렇지 않아 강건성의 여유가 줄어들기 때문이다. $\square$

---

<div class="drillbox" markdown>

**연습문제 2.** <span class="diff med" title="중간"></span>
이 마디에서 다룬 공격나 방어를 CIFAR-10의 ResNet-18 모델에 짜 넣어라. $\epsilon = 8/255$의 PGD-20 공격 아래에서 클린 정확도와 강건 정확도를 알려라.

</div>

??? success "연습문제 2 풀이"
    여느 ResNet-18은 클린 정확도가 $\sim$93%이지만 PGD-20($\epsilon = 8/255$, 스텝 크기 $2/255$) 아래의 강건 정확도는 $\sim$0%이다. 이 마디의 방법을 걸면 피처와는 재주에 따라 다르다. 적대적 학습은 클린 정확도 $\sim$83%에 강건 정확도 $\sim$50%이고, 인증 가능한 방어는 더 낮지만 증명할 수 있는 테두리를 준다. 정확도와 강건성의 트레이드오프는 기초부터 있는 것이라, 강건성을 높이면 클린 정확도가 흔히 5~15% 든다. 아무렇게나 하는 시드 3개의 평균과 표준편차로 알려라. $\square$

<div class="drillbox" markdown>

**연습문제 3.** <span class="diff hard" title="어려움"></span>
섭동 공 안에서 클래스별 데이터의 밑자리가 서로 겹친다고 볼 때, 모델이 담는 힘을 키우지 않고서는 어떤 방어도 맑은 데이터의 높은 정확도와 $\ell_\infty$ 섭동에 대한 높은 강건성을 함께 이룰 수 없음을 증명하여라.

</div>

??? success "연습문제 3 풀이"
    두 클래스의 밑자리가 거리 $\epsilon$ 안에서 겹치면(곧 $\|x_1 - x_2\|_\infty \leq 2\epsilon$인 $x_1 \in \text{클래스 1}, x_2 \in \text{클래스 2}$이 있으면), $x_1$과 $x_2$ 둘 다에서 강건한 분류기는 적어도 하나를 틀리게 가를 수밖에 없다(섭동 공이 겹치기 때문이다). 이것이 정확도와 강건성의 기초 트레이드오프다. 겹치는 밑자리의 몫이 피할 수 없는 정확도 로스를 정한다. 여느 그림 분포에서는 $\epsilon = 8/255$에서 겹침이 꽤 있어, 살펴본 10~15%의 정확도 떨어짐을 밝혀 준다. 모델이 담는 힘을 키우면(더 너른 네트워크) 얽힌 강건한 결정 경계를 더 잘 그려 트레이드오프를 얼마쯤 눅일 수 있다. $\square$

<div class="drillbox" markdown>

**연습문제 4.** <span class="diff med" title="중간"></span>
금융 머신러닝 구조(속임수 알아내기나 거래 신호 만들기 따위)에서 맞섬의 강건성이 어떻게 드러나는지 다루어라. 위협 모델이 보기 다룸과 어떻게 다른가?

</div>

??? success "연습문제 4 풀이"
    금융에서 겨루는 이는 알아내는 구조에 맞추어 스스로 움직이는 꾀 많은 무리(속임수꾼, 저자 흔드는 이)다. 보기 다룸과 다른 핵심은 이렇다. (1) 흔들 수 있는 밭이 돈으로 될 만한 것에 옭매인다(속임수꾼이 제 거래 자취를 통째로 바꿀 수는 없다). (2) 공격이 잇따르며 맞추어 간다(겨루는 이가 구조의 되받음을 보고 손본다). (3) 헛 정확도와 놓침의 값이 서로 어긋난다(옳은 거래를 막는 것과 속임수를 놓치는 것). (4) $\ell_p$ 노름은 뜻이 없고 밭에 맞는 섭동 모델이 있어야 한다. 방어는 맞추어 오는 겨루는 이에게도 든든해야 하므로, 알아내는 잣대가 알려지면 비껴갈 수 있는 알아내기 기초의 길은 많이 걸러진다. $\square$

## 정리하며

금융 구조의 모델 보안에는 추론 하나하나의 강건성을 넘어 통틀어 보는 길이 있어야 한다. 입력 따지기, 강건한 모델, 출력 지켜보기, 조직의 절차를 아우른 여러 켜 방어가 참 금융 머신러닝의 갖가지 위협에 가장 미더운 지킴을 준다.
