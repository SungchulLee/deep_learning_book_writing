# 금융 시스템의 모델 보안

머신러닝 모델을 실제 금융 시스템에 배포하면 예측 하나하나의 강건성을 넘어서는 보안 문제가 생긴다. 이 절은 모델 탈취와 데이터 포이즈닝에서 강건한 배포 관행에 이르기까지, 금융 머신러닝 시스템의 전 과정에 걸친 보안을 다룬다.

---

## 1. 위협 지형

### 모델 추출

API를 쓸 수 있는 적대자는 질의와 응답의 짝으로 대리 모델을 학습해 모델을 **훔칠** 수 있다.

$$
f_{\text{surrogate}} \approx f_{\text{target}} \quad \text{via} \quad \{(\mathbf{x}_i, f_{\text{target}}(\mathbf{x}_i))\}_{i=1}^N
$$

**금융에 미치는 영향**: 독자적인 거래 신호, 신용 평가 모델, 위험 모델은 귀중한 지식 재산이다. 모델 추출은 그 자체로 모델 탈취이면서, 훔친 대리 모델로 화이트박스 적대적 공격을 준비할 수 있게 해 준다.

**방어**:

- 질의 빈도 제한과 이상 질의 탐지
- 출력 섭동(예측에 보정된 잡음 더하기)
- 워터마킹(모델의 동작에 나중에 확인할 수 있는 표식 심기)

### 데이터 포이즈닝

학습 데이터에 영향을 줄 수 있는 적대자는 모델의 성능을 떨어뜨리거나 표적 백도어를 만드는 **포이즈닝된 샘플**을 끼워 넣을 수 있다.

$$
\mathcal{D}_{\text{poisoned}} = \mathcal{D}_{\text{clean}} \cup \{(\mathbf{x}_{\text{poison}}, y_{\text{target}})\}
$$

**금융에서의 보기**:

- 모델 학습에 쓰는 과거 가격 데이터를 조작하기
- 정상으로 레이블된 사기 거래를 학습 꾸러미에 끼워 넣기
- 대체 데이터 원천(위성 사진, 웹 스크래핑)을 오염시키기

#### 피처 충돌을 이용한 표적 포이즈닝

데이터 포이즈닝 가운데 특히 교묘한 것이 **클린 레이블 포이즈닝**이다. 공격자가 레이블을 하나도 바꿀 필요가 없다. 그 대신 피처 공간에서 타깃과 충돌하는(겹치는) 포이즈닝된 학습 샘플을 만든다.

$$
\mathbf{x}_{\text{poison}} = \arg\min_{\mathbf{x}} \| f(\mathbf{x}) - f(\mathbf{x}_{\text{target}}) \|_2^2 + \beta \| \mathbf{x} - \mathbf{x}_{\text{base}} \|_2^2
$$

여기서 $f(\cdot)$는 학습된 피처 추출기이고, $\mathbf{x}_{\text{target}}$은 공격자가 테스트 때 오분류되기를 바라는 샘플이며, $\mathbf{x}_{\text{base}}$는 공격자가 고른 클래스의 정상 샘플이다. 첫째 항은 피처 공간에서 타깃과 겹치게 하고, 둘째 항은 포이즈닝된 샘플이 정상 베이스 샘플과 눈으로 보기에 비슷하게 남게 한다(그래서 레이블이 맞아 보인다).

모델이 이 포이즈닝된 샘플로 학습하면 타깃의 피처를 포이즈닝된 샘플의 클래스와 연결하도록 배운다. 그러면 레이블을 하나도 건드리지 않고도 테스트 때 타깃이 오분류된다.

**계량 금융과 관련된 까닭**: 금융 머신러닝의 학습 데이터는 흔히 외부 업체, 대체 데이터 제공처, 스크래핑한 원천에서 온다. 적대자는 정상 데이터와 통계적으로 들어맞아 품질 점검을 모두 통과하면서도, 모델의 결정 경계를 미묘하게 밀어 특정 증권이나 시장 상황을 오분류하게 하는 가짜 시장 데이터 점을 만들 수 있다.

#### 데이터 포이즈닝 방어

| 방어 | 원리 | 트레이드오프 |
|---------|-----------|-----------|
| 데이터 정제 | 학습 전에 피처 공간의 이상값을 없앤다 | 드물지만 정상인 사건까지 버릴 수 있다 |
| 영향 함수 | 특정 예측에 크게 영향을 주는 학습 점을 찾아낸다 | 데이터가 크면 계산이 비싸다 |
| 스펙트럼 시그니처 | 피처 공분산의 스펙트럼을 분석해 포이즈닝된 샘플을 찾아낸다 | 포이즈닝 샘플이 어느 정도 이상 있어야 한다 |
| 차분 프라이버시 | 학습하는 동안 잡음을 더해 점 하나의 영향을 제한한다 | 모델의 정확도가 떨어진다 |
| 앙상블 합의 | 데이터를 나눠 학습한 모델들의 예측을 비교한다 | 계산 비용이 는다 |

### 백도어 공격

**백도어**는 트리거가 있으면 모델이 타깃 클래스로 오분류하게 만드는 숨은 패턴이다.

$$
f(\mathbf{x} + \text{trigger}) = y_{\text{target}} \quad \forall \mathbf{x}
$$

클린 입력에서는 $f(\mathbf{x}) = y_{\text{correct}}$이다.

**금융의 위험**: 백도어가 심긴 신용 평가 모델은 특정 피처 패턴이 든 사기 신청을 승인해 줄 수 있다.

## 2. 강건한 배포 관행

### 다층 방어 구조

입력 검증, 피처 분포 모니터링, 모델 앙상블, 출력 검증을 차례로 거친 뒤에 판단을 내린다. 단계마다 이상값 탐지, 분포 이동 경보, 앙상블 불일치 탐지, 범위·일관성 점검을 한다.

```
들임 평가 → 결 지켜보기 → 모형 모둠 → 날임 평가 → 판단
       ↓                  ↓                   ↓                ↓
   튀는 것            분포 옮겨감        어긋남           자리와
   탐지            알림              탐지        한결같음
```

### 입력 평가

```python
import torch
from typing import Dict, Optional

class InputValidator:
    """
    미루어 보기 앞서 모형 들임을 따진다.
    
    밖 분포 들임, 적대적 확률, 자료 됨됨이의 탈을
    살핀다.
    """
    
    def __init__(
        self,
        feature_means: torch.Tensor,
        feature_stds: torch.Tensor,
        feature_mins: torch.Tensor,
        feature_maxs: torch.Tensor,
        z_threshold: float = 5.0
    ):
        self.means = feature_means
        self.stds = feature_stds
        self.mins = feature_mins
        self.maxs = feature_maxs
        self.z_threshold = z_threshold
    
    def validate(self, x: torch.Tensor) -> Dict[str, torch.Tensor]:
        """
        들임을 평가하고 됨됨이 표시를 돌려준다.
        """
        # z 점수 살피기: 아주 튀는 값에 표시한다
        z_scores = (x - self.means) / (self.stds + 1e-8)
        extreme = (z_scores.abs() > self.z_threshold).any(dim=1)
        
        # 자리 살피기: 익힘 자리 밖의 값에 표시한다
        below = (x < self.mins).any(dim=1)
        above = (x > self.maxs).any(dim=1)
        out_of_range = below | above
        
        # 빠진 값 살피기
        has_nan = torch.isnan(x).any(dim=1)
        
        return {
            'valid': ~(extreme | out_of_range | has_nan),
            'extreme_values': extreme,
            'out_of_range': out_of_range,
            'has_missing': has_nan,
            'max_z_score': z_scores.abs().max(dim=1)[0]
        }
```

### 모델 모니터링

적대적 행동이나 모델 성능 저하의 징후를 끊임없이 지켜본다.

| 신호 | 뜻하는 바 | 조치 |
|--------|-----------|--------|
| 예측 분포 이동 | 데이터 드리프트나 조작 | 경보를 내고 조사한다 |
| 비정상적인 질의 패턴 | 모델 추출 시도 | 빈도를 제한하고 차단한다 |
| 갑작스러운 정확도 하락 | 포이즈닝이나 분포 이동 | 대비 모델로 전환한다 |
| 피처 중요도 변화 | 개념 드리프트나 공격 | 평가하고 다시 학습한다 |
| 앙상블 불일치 급증 | 분포 외 입력 | 사람이 검토하도록 표시한다 |

### 규제상 고려 사항

금융 머신러닝 모델에는 고유한 규제 요건이 있다.

- **모델 위험 관리(SR 11-7)**: 모델을 검증하고 문서화하고 모니터링해야 한다
- **설명 가능성과 문서화**: 모델의 판단 근거와 적대적 강건성을 문서화하고 시험해야 한다
- **공정 대출법**: 강건성을 높이는 조치가 집단 간 공정성을 해치지 않는지 따져야 한다
- **데이터 거버넌스**: 학습 데이터의 무결성을 지키고 출처를 추적할 수 있어야 한다

## 3. 종합 보안 체크리스트

머신러닝 모델을 실제 금융 시스템에 배포할 때 확인할 것들이다.

- [ ] 적대적 강건성 평가(AutoAttack이나 도메인에 맞는 공격)
- [ ] 입력 검증과 이상값 탐지
- [ ] 모델 추출 방어(호출 빈도 제한, 출력 섭동)
- [ ] 데이터 포이즈닝 대비(학습 데이터 검증)
- [ ] 백도어 탐지(뉴럴 클렌즈 등)
- [ ] 앙상블 불일치 모니터링
- [ ] 분포 이동 탐지
- [ ] 대비 체계(규칙 기반 백업)
- [ ] 모델의 모든 판단에 대한 감사 추적 기록
- [ ] 정기적인 레드팀 훈련

## 연습문제

<div class="drillbox" markdown>

**연습문제 1.** <span class="diff med" title="중간"></span>
선형 분류기 $f(x) = w^T x + b$에서 예측한 클래스를 바꾸는 데 드는 가장 작은 $\ell_\infty$ 섭동을 계산하여라. 이것이 뉴럴 네트워크의 강건성과 어떻게 이어지는지 설명하여라.

</div>

??? success "풀이"
    선형 분류기에서 $\ell_\infty$ 노름으로 잰 결정 경계까지의 거리는 $\frac{|w^T x + b|}{\|w\|_1}$이다. 가장 작은 섭동은 $\delta^* = \frac{|w^T x + b|}{\|w\|_1} \cdot \text{sign}(w)$이다. 뉴럴 네트워크에서는 국소 선형 근사 $f(x + \delta) \approx f(x) + \nabla_x f \cdot \delta$이 FGSM(그래디언트의 부호를 쓴다)이 왜 잘 통하는지를 설명해 준다. 차원이 높은 모델이 취약한 까닭은 $\|w\|_1$은 차원과 함께 커지는데 $|w^T x + b|$은 꼭 그렇지 않아 강건성의 여유가 줄어들기 때문이다. $\square$

**연습문제 2.** <span class="diff med" title="중간"></span>
이 절에서 다룬 공격이나 방어를 CIFAR-10의 ResNet-18 모델에 구현하여라. $\epsilon = 8/255$의 PGD-20 공격 아래에서 클린 정확도와 강건 정확도를 보고하여라.

</div>

??? success "풀이"
    일반 ResNet-18은 클린 정확도가 $\sim$93%이지만 PGD-20($\epsilon = 8/255$, 스텝 크기 $2/255$) 아래의 강건 정확도는 $\sim$0%이다. 이 절의 방법을 적용한 결과는 기법에 따라 다르다. 적대적 학습은 클린 정확도 $\sim$83%에 강건 정확도 $\sim$50%이고, 인증 가능한 방어는 더 낮지만 증명할 수 있는 바운드를 준다. 정확도와 강건성의 트레이드오프는 근본적인 것이라, 강건성을 높이면 클린 정확도가 흔히 5~15% 떨어진다. 무작위 시드 3개의 평균과 표준편차로 보고하여라. $\square$

**연습문제 3.** <span class="diff hard" title="어려움"></span>
섭동 공 안에서 클래스별 데이터의 서포트가 서로 겹친다고 볼 때, 모델이 용량을 키우지 않고서는 어떤 방어도 클린 데이터의 높은 정확도와 $\ell_\infty$ 섭동에 대한 높은 강건성을 함께 이룰 수 없음을 증명하여라.

</div>

??? success "풀이"
    두 클래스의 서포트가 거리 $\epsilon$ 안에서 겹치면(곧 $\|x_1 - x_2\|_\infty \leq 2\epsilon$인 $x_1 \in \text{클래스 1}, x_2 \in \text{클래스 2}$이 있으면), $x_1$과 $x_2$ 둘 다에서 강건한 분류기는 적어도 하나를 틀리게 가를 수밖에 없다(섭동 공이 겹치기 때문이다). 이것이 정확도와 강건성의 근본적인 트레이드오프다. 겹치는 서포트의 비중이 피할 수 없는 정확도 손실을 정한다. 자연 이미지 분포에서는 $\epsilon = 8/255$에서 겹침이 꽤 있어, 관찰되는 10~15%의 정확도 하락을 설명해 준다. 모델 용량을 키우면(더 넓은 네트워크) 복잡한 강건 결정 경계를 더 잘 그려 트레이드오프를 어느 정도 완화할 수 있다. $\square$

<div class="drillbox" markdown>

**연습문제 4.** <span class="diff med" title="중간"></span>
금융 머신러닝 시스템(사기 탐지나 거래 신호 생성 등)에서 적대적 강건성이 어떻게 드러나는지 논하여라. 위협 모델이 비전과 어떻게 다른가?

</div>

??? success "풀이"
    금융에서 적대자는 탐지 시스템에 맞추어 전략을 바꾸는 교묘한 집단(사기꾼, 시장 조작자)이다. 비전과 다른 핵심은 이렇다. (1) 섭동할 수 있는 피처가 경제적으로 그럴듯한 범위로 제약된다(사기꾼이 자기 거래 이력을 통째로 바꿀 수는 없다). (2) 공격이 순차적이고 적응적이다(적대자가 시스템의 응답을 보고 고친다). (3) 거짓 양성과 거짓 음성의 비용이 비대칭이다(정상 거래를 막는 것과 사기를 놓치는 것). (4) $\ell_p$ 노름은 의미가 없고 도메인에 맞는 섭동 모델이 있어야 한다. 방어는 적응형 적대자에게도 강건해야 하므로, 탐지 기준이 알려지면 회피할 수 있는 탐지 기반 방법은 쓸모가 크게 줄어든다. $\square$

## 정리하며

금융 시스템의 모델 보안에는 예측 하나하나의 강건성을 넘어 시스템 전체를 보는 시각이 필요하다. 입력 검증, 강건한 모델, 출력 모니터링, 조직의 절차를 아우른 다층 방어가 실제 금융 머신러닝이 마주하는 갖가지 위협에 가장 믿을 만한 보안을 준다.
