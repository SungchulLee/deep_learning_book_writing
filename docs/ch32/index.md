# 33장: 신경 상미분방정식

신경 ODE는 은닉상태의 시간 미분 h′=fθ(t,h)를 신경망으로 정의하고, 수치 적분한 상태를 모델 출력으로 사용한다. 연속시간 표현과 유한 정밀도의 계산을 함께 이해해야 하며, 적분 구간·솔버·허용 오차·미분 방식도 모델 동작에 영향을 준다.

## 1. 기초와 최소 예제

[상미분방정식 기초](neural_ode_foundations/fundamentals.md)는 초기값 문제의 해 조건, 고전 벡터장과 수치 적분에서 시작한다. ResNet과의 연결, torchdiffeq 인터페이스, 분류기·정규화 예제와 adjoint의 가정을 다룬다. 코드의 직접 역전파와 adjoint를 구분하고 실제로 호출하는 데모 범위도 확인한다.

[간단한 신경 ODE](neural_ode_foundations/50_neural_ode.md)는 공유 벡터장을 오일러로 반복하는 최소 분류 구조다. 적응형 방법이나 adjoint를 사용하지 않으며, 미사용 method 옵션과 부동소수점 누적의 끝점 문제를 설명한다. 벡터장 깊이와 적분 스텝 수는 다른 개념이다.

## 2. 솔버와 계산 정확도

[수치 솔버](neural_ode_foundations/numerical_solvers.md)는 오일러·RK 방법의 국소·전역 오차, 안정 영역과 적응형 제어를 비교한다. 출력 요청 시점 수와 내부 스텝·함수 평가 횟수(NFE)를 구분한다.

[솔버 선택과 검증](evaluation/solver_selection.md)에서는 강성·상태 스케일·미분 지원을 확인하고 실제 시간·메모리를 비교하는 절차를 세운다. 같은 가중치의 수치 오차 실험과 솔버별 재학습 성능 실험은 서로 다른 비교다. 특정 허용 오차나 솔버가 모든 작업에서 최적이라고 가정하지 않는다.

## 3. 불규칙 관측과 잠재 동역학

[Latent ODE](advanced/latent_odes.md)는 초기 잠재분포, ODE 흐름과 관측 디코더를 결합한다. 불규칙 시각에서 상태를 구할 수 있지만 결측 마스크와 관측 시각의 정보성은 여전히 모델링해야 한다. 보간·평활화와 미래 예측의 정보 범위, 초기 불확실성과 새 과정 잡음을 구분한다.

## 4. 금리 곡선의 동역학

[기간구조 동역학](finance_applications/term_structure.md)은 만기별 금리 곡선을 저차원 요인으로 표현하는 개념을 다룬다. 달력 시간과 잔존 만기, 금리와 선도금리를 구분하며, 과거 예측용 ODE와 위험중립 무차익 SDE가 요구하는 조건이 다름을 설명한다. 실제 가격 산정이나 검증된 금융 성능을 제시하는 예제는 아니다.

## 정리하며

신경 ODE는 모든 잔차망의 자동적인 무한 깊이 극한이나 무조건 가역적인 수치 모델을 뜻하지 않는다. 벡터장의 해 조건과 수치 근사, gradient 경로를 맞추어 읽는다. 연속시간의 장점은 필요한 작업의 정확도·비용·정보 범위를 검증하면서 활용한다.
