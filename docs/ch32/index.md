# 33장: 신경 상미분방정식

여느 신경망은 붙박인 띄엄띄엄한 층의 차례로 데이터를 바꾼다. **신경 상미분방정식**(Neural ODE)은 이 띄엄띄엄한 차례를 이어진 때의 움직임 계로 바꾼다. 신경망의 은닉 상태가 신경망으로 매개변수화한 상미분 방정식에 따라 바뀐다. 이 이어진 깊이 관점은 남은 이음 신경망을 끝없는 깊이로 넓히고, 상미분 방정식 솔버의 허용 오차로 계산을 맞추어 갈 수 있게 하며, **딸림 방법**으로 기억을 아끼는 학습을 준다.

핵심 생각은 단순하다. 남은 이음 신경망은 $\mathbf{h}_{t+1} = \mathbf{h}_t + f(\mathbf{h}_t, \theta)$을 계산한다. 아주 얇은 층이 끝없이 많은 끝에서 이는 다음이 된다

$$
\frac{d\mathbf{h}(t)}{dt} = f\!\bigl(\mathbf{h}(t), t, \theta\bigr)
$$

내놓기는 수치 솔버로 이 상미분 방정식을 때 $t_0$에서 $t_1$까지 적분해 얻고, 기울기는 중간 깨움을 담아 두지 않고 뒤로 도는 상미분 방정식(딸림 방정식)을 풀어 계산한다.

이 장은 수학 기초, 이어진 고르게 맞추는 흐름, 신경 확률 미분 방정식과 숨은 상미분 방정식을 아우르는 나아간 넓힘, 따지는 방법, 계량 금융에서의 쓰임새를 다룬다.

- 단원 차례 -- 처음의 상미분 방정식 기초에서 나아간 쓰임새까지 모든 학습 단원의 온전한 살펴보기
- 딸림 민감도 방법 -- 깨움을 모두 담아 두는 대신 뒤로 도는 상미분 방정식을 풀어 기억을 아끼는 기울기 계산
- [수치 솔버](neural_ode_foundations/numerical_solvers.md) -- 오일러, 룽게-쿠타, 맞추어 가는 솔버와 그 정확도·비용·기억의 트레이드오프
- 앞 민감도와 딸림 민감도 -- 상미분 방정식 풀이를 거친 기울기 계산에서 앞 민감도와 딸림 방법 비교
- 계산 비용 살피기 -- 비용 구조, 함수 매김 횟수, 실제로 펼칠 때 살필 것 이해하기

## 4. 평가

- 정확도와 빠르기의 트레이드오프 -- 솔버 허용 오차, 함수 매김 횟수, 풀이 정확도 사이의 근본 트레이드오프
- 띄엄띄엄한 모델과 비교 -- 정확도, 효율, 쓸 수 있음에서 신경 상미분방정식이 남은 이음 신경망 및 순환 신경망과 어떻게 견주어지는가
- 비교 시험 -- 계산, 수치, 실제 따지기 차원에 걸친 표준 비교 시험 방식
- [솔버 선택 가이드](evaluation/solver_selection.md) -- 쓰임새 마당과 정확도 요구에 따라 상미분 방정식 솔버를 고르는 실제 안내
