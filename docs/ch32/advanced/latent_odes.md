# 불규칙 시계열을 위한 Latent ODE

관측 간격이 달라도 잠재상태의 시간 진화를 연속적으로 정의할 수 있다. Latent ODE는 초기 잠재상태의 확률분포, 결정적 ODE와 관측모형을 결합한다. [Rubanova 등의 연구](https://arxiv.org/abs/1907.03907)는 불규칙 관측을 처리하는 ODE-RNN 인코더와 이러한 잠재 생성모델을 연결한다.

## 1. 생성모델과 추론모델

```
Observations → RNN Encoder → z₀ ~ q(z₀|x) → ODE Solver → z(t) → Decoder → x̂(t)
```

생성은 z₀∼p(z₀)를 뽑고 z′=fθ(t,z)를 적분한 뒤, 요청 시각 tᵢ마다 **디코더의 관측분포** pψ(xᵢ|z(tᵢ))에서 값을 얻는 순서다. 솔버는 잠재상태를 구하고 디코더가 관측 공간으로 옮긴다. 두 역할을 구분한다.

추론 인코더는 관측값·시간·마스크를 받아 qφ(z₀|관측)을 만든다. 예를 들어 관측을 역시간 순서로 처리하는 RNN 또는 ODE-RNN을 사용할 수 있다. 인코더를 역방향으로 계산하는 것과 생성 ODE의 시간 방향, 생성모델 자체의 가역성은 서로 다른 개념이다.

## 2. 불규칙 시각과 결측 좌표

관측 사이의 Δt가 달라도 ODE를 해당 구간에서 적분할 수 있다. 규칙적인 격자로 먼저 보간하지 않아도 된다는 장점이 있지만, 빠진 좌표의 마스크·관측 잡음과 로스 집계는 여전히 정의해야 한다. 모든 결측 문제가 자동으로 해결되는 것은 아니다.

RNN도 시간 간격·마스크를 입력하거나 별도의 시간 감쇠를 사용해 불규칙 관측을 처리할 수 있다. 따라서 RNN은 반드시 고정 간격 데이터만 받는다는 비교는 부정확하다. ODE의 차이는 관측 사이의 잠재 진화를 명시하는 데 있다.

관측 시각 자체가 상태와 관련된 경우에는 관측된 값의 우도만으로 표본 선택을 설명하기 어렵다. 원 연구는 관측 시각의 확률을 Poisson 과정 등으로 모델링하는 확장도 다룬다. 이것은 기본 Latent ODE 목적에 저절로 포함되는 기능은 아니다.

## 3. ELBO로 학습하기

관측 시각 집합 I에서 z(tᵢ)가 z₀로부터 결정된다고 하자. 관측모형이 z₀가 주어졌을 때 인수분해되면 다음 생성모델을 얻는다.

$$p(x_{I},z_0)=p(z_0)\prod_{i\in I}p_\psi(x_i\mid z(t_i;z_0))$$

qφ(z₀|x_I)를 곱하고 나눈 뒤 Jensen 부등식을 적용하면 다음 ELBO를 최대화한다.

$$\log p(x_I)\geq
\mathbb E_{q_\phi}\sum_{i\in I}\log p_\psi(x_i\mid z(t_i;z_0))
-D_{\mathrm{KL}}(q_\phi(z_0\mid x_I)\|p(z_0))$$

결측 좌표는 관측모형과 마스크에 맞추어 포함한다. 초기 상태를 적분하는 결정적 경로에 독립적인 잡음 잠재변수를 매 시각 도입한 것은 아니므로, 시각마다 별도의 latent KL을 더하지 않는다. 연속 흐름이 있다는 이유로 관측 디코더의 변수변환 Jacobian을 ELBO에 무조건 더하는 것도 아니다.

초기 잠재 불확실성과 관측 잡음으로 다양한 경로·관측을 만들 수 있다. 그러나 z₀가 주어지면 잠재경로는 결정적이다. 이후에 새로 발생하는 과정 잡음·점프를 표현하려면 SDE나 점프·사건 구조 같은 다른 가정이 필요하다.

## 4. ODE-RNN의 역할

ODE-RNN은 이전 관측 뒤 상태를 다음 관측 직전까지 ODE로 이동시키고, 관측을 받으면 이산 갱신한다.

$$h_i^-=\operatorname{ODESolve}(h_{i-1}^+,t_{i-1},t_i),
\qquad h_i^+=\operatorname{RNNCell}(h_i^-,x_i,\text{mask}_i)$$

이를 직접 예측 상태로 사용하거나 초기 잠재분포를 추론하는 인코더로 사용할 수 있다. ODE-RNN과 Latent ODE가 항상 같은 모델이거나 한쪽이 언제나 더 빠른 것은 아니다. 은닉 갱신·관측 수와 솔버 호출 비용이 함께 든다.

## 5. 보간·평활화·예측의 정보 범위

전체 관측을 인코더에 넣고 중간 시점을 재구성하는 것은 보간·평활화다. 미래 예측에서는 기준 시각 이전에 도착한 관측만 q에 넣어야 한다. 미래 데이터를 이용한 역방향 인코더의 재구성 점수를 인과적 예측 성능으로 보고하지 않는다.

어떤 시점에서든 솔버를 호출할 수 있다는 것은 학습하지 않은 먼 미래에서도 예측이 정확하다는 뜻이 아니다. 외삽, 희소 구간과 긴 간격의 불확실성을 따로 평가한다. 시간·변수 스케일과 결측 패턴도 학습·테스트에서 확인한다.

## 6. 비용과 표현상의 한계

비용은 인코더의 관측 처리, NFE×벡터장 비용, 요청 시각별 디코더·우도 계산과 역전파의 합이다. 관측 수가 늘어도 비용이 완전히 일정하지 않으며 성긴 데이터라고 항상 RNN보다 빠르지도 않다. 시간 범위, 강성, 허용 오차와 출력 수·모델 폭을 함께 기록한다.

직접 미분과 adjoint는 다른 메모리·오차 특성을 갖는다. adjoint 비용을 항상 순방향의 두 배로, 전체 저장량을 상태 차원만으로 정할 수 없다. 고정 차원에서 정확하고 유일한 ODE 흐름은 존재 구간에서 연속 역을 갖지만, 관측 디코더와 수치 근사는 이 성질을 전체 관측 모델에 보장하지 않는다.

이 페이지는 개념·확률모형을 설명하며 학습 구현이나 성능 실험을 제공하지 않는다. 불규칙 거래·센서 관측에 적용할 때도 관측 시간의 의미와 예측 정보 범위를 먼저 정해야 한다.

**연습문제 1.** <span class="diff hard" title="어려움"></span>
결정적 잠재 ODE의 ELBO에서 초기 상태 KL이 나타나는 이유를 유도하라.

</div>

??? success "연습문제 1 풀이"

    log∫q(z₀|x)[p(z₀)∏ᵢp(xᵢ|z(tᵢ;z₀))/q(z₀|x)]dz₀에 Jensen 부등식을 적용한다. 기대 관측 로그우도에서 KL(q(z₀|x)||p(z₀))를 뺀 식을 얻는다. 생성 경로는 같은 f와 초기값으로 결정되어 별도 시점별 확률 전이 KL을 넣지 않는다. 다른 drift를 가진 경로분포나 SDE의 KL을 이 식에 그대로 대체할 수는 없다.

## 정리하며

Latent ODE는 초기 잠재분포·연속 동역학·관측분포를 결합해 불규칙 시각을 다룬다. 마스크와 관측 시각의 정보성, 보간과 예측의 차이를 명시한다. 초기 상태 불확실성·과정 잡음과 솔버 호출·관측 처리의 비용을 구분한다.
