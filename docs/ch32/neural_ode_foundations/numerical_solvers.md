# 신경 ODE의 수치 솔버

벡터장 z′=fθ(t,z)를 정해도 컴퓨터가 반환하는 것은 수치 적분의 근사다. 솔버·스텝·오차 허용치는 출력과 학습 기울기, 시간·메모리 비용에 영향을 준다. 이 페이지는 방법의 차수와 안정성, 적응형 제어를 구분해 선택 기준을 세운다.

## 1. 고정 스텝 방법

전진 오일러는 zₙ₊₁=zₙ+h f(tₙ,zₙ)다. 충분한 매끄러움과 유한 구간의 안정성 아래 한 스텝 오차는 O(h²), 전역 오차는 O(h)다. “1차”는 보통 전역 수렴 차수를 뜻한다.

명시적 중점법은 시작 기울기로 중간 상태를 만든 뒤 그곳의 기울기를 사용한다. 고전 RK4는 네 단계의 기울기를 (1,2,2,1)/6로 결합한다. 중점법의 전역 차수는 2, RK4는 4다. 각 방법의 오차 상수와 안정 영역도 다르므로 같은 호출 수나 같은 스텝에서 항상 우열이 고정되지는 않는다.

| 방법 | 전역 차수 | 기본 한 스텝의 벡터장 호출 |
|---|---|---|
| 전진 오일러 | 1 | 1회 |
| 명시적 중점 | 2 | 2회 |
| RK4 | 4 | 4회 |
| Adams–Bashforth | 차수에 따라 다름 | 과거 값 재사용, 시작 구간은 별도 |

torchdiffeq의 rk4는 3/8 규칙을 사용해 [기초 페이지](fundamentals.md)의 고전 RK4와 내부 계수가 다르다. 둘 다 매끄러운 문제에서 4차이며 실제 사용 구현을 구분한다.

## 2. 적응형 Dormand–Prince

Dormand–Prince 5(4)는 서로 다른 차수의 근사 차이로 한 스텝 오차를 추정한다. rtol·atol에 따라 크기를 정규화한 오차 err를 계산하고, 개념적으로 다음과 같이 스텝을 조절한다.

$$h_{\mathrm{new}}\approx h\,c\,\mathrm{err}^{-1/5}$$

c는 안전 계수다. 실제 구현은 최대·최소 증감률과 수락·거절 규칙 등을 포함한다. 원소별 척도는 보통 atol+rtol·상태 크기 형태이며 이를 norm으로 집계한다. 허용 오차는 **국소 오차 추정의 제어값**이지 모든 출력 원소의 최종 전역 오차를 보장하는 값이 아니다.

```python
from torchdiffeq import odeint

z_T = odeint(dynamics_fn, z_0, t_span, method='dopri5',
             atol=1e-5, rtol=1e-5)
```

이 예시는 dynamics_fn(t,z), z_0와 단조로운 평가 시각 t_span이 먼저 정의되어 있어야 한다. 변수 이름 z_T와 달리 반환값은 요청한 **모든 시점의 상태**이며 마지막 상태는 마지막 시간 축 원소다. 내부 적분 시점과 출력 요청 시점은 같을 필요가 없다.

## 3. NFE와 배치 비용

NFE는 벡터장 평가 횟수다. 고정 스텝에서는 방법별 호출 수와 스텝 수가 직접 연결되지만, 적응형에서는 초기 스텝 추정과 거절된 스텝도 비용에 들어간다. Dormand–Prince는 단계 재사용을 하므로 “언제나 스텝당 정확히 6회”라는 숫자만으로 전체 비용을 계산하지 않는다.

표준 배치 odeint 호출은 배치 텐서 전체를 하나의 상태로 다루며 **공유된 적응 스텝**을 사용한다. 배치의 각 표본이 독립적으로 다른 스텝을 골라 동시에 끝내는 인터페이스로 설명하지 않는다. 어려운 표본의 스케일·오차가 전체 배치 비용에 영향을 줄 수 있다.

같은 NFE라도 해상도·모델·배치 크기·정밀도에 따라 시간이 다르다. 순방향과 역방향 NFE를 따로 기록하고 벽시계 시간·최대 메모리도 함께 비교한다. 출력 시점을 늘린 것과 내부 스텝을 늘린 것도 구분한다.

## 4. 안정성과 강성

시험방정식 y′=λy에서 오일러 증폭 인자는 R(hλ)=1+hλ다. 복소 평면에서 |1+hλ|≤1은 경계까지의 절대안정 영역이고, 음의 실수 λ에 대해 수치 해가 감쇠하려면 0<h<2/|λ|를 사용한다.

강성 문제는 관심 구간의 변화보다 훨씬 빠르게 감쇠하는 모드 때문에 명시적 방법의 안정 스텝이 지나치게 작아지는 경우를 포함한다. Lipschitz 상수가 크다는 사실만으로 언제나 강성이라고 할 수는 없다. 적응형 명시적 솔버도 안정 영역의 제약을 피하지 못한다.

후진 오일러는 R(z)=1/(1−z)로 왼쪽 반평면에서 A-stable하다. 하지만 **모든 암시적 방법이 A-stable한 것은 아니다**. 차수와 해법에 따라 안정 영역이 다르며 매 스텝의 선형·비선형 풀이 비용도 필요하다. implicit_adams라는 이름만 보고 모든 강성 문제에 적합한 BDF·Radau와 동일시하지 않는다.

## 5. 학습에서의 선택 기준

고정 스텝은 계산 예산을 예측하기 쉽고 동일한 내부 격자로 반복할 수 있다. 적응형은 구간별 오차 추정으로 불필요한 스텝을 줄일 수 있지만 입력·파라미터에 따라 비용과 수치 결과가 달라진다. 고정 스텝의 rtol만 바꾸어 정확도가 조절된다고 기대하지 않고 step_size를 명시한다.

직접 역전파는 실제 솔버의 수치 계산 그래프를 사용한다. 연속 adjoint는 별도 역방향 민감도 문제를 적분한다. 적응형이라는 이유로 미분이 불가능한 것은 아니며, adjoint가 모든 문제에서 더 정확하거나 빠르다는 보장도 없다. 두 방식은 유한 허용 오차에서 기울기가 달라질 수 있다.

[공식 torchdiffeq 문서](https://github.com/rtqichen/torchdiffeq)의 사용법과 버전을 확인하고, 같은 학습 가중치에서 스텝·허용 오차를 바꾸었을 때 출력과 gradient가 얼마나 안정적인지 점검한다. 최종 선택은 요구 정확도와 실제 시간·메모리의 균형으로 판단한다.

## 연습문제

<div class="drillbox" markdown>

**연습문제 1.** <span class="diff hard" title="어려움"></span>
y′=−y, y(0)=1에서 오일러·호인·고전 RK4의 t=1 근사식을 적고 수렴 차수를 설명하라. h=1/N으로 둔다.

</div>

??? success "연습문제 1 풀이"

    오일러는 (1−h)^N, 호인은 (1−h+h²/2)^N, RK4는 (1−h+h²/2−h³/6+h⁴/24)^N이다. e⁻¹과 비교하면 매끄러운 문제의 작은 h 영역에서 오차가 각각 O(h), O(h²), O(h⁴)다. h=0.1의 오일러 오차는 |0.9¹⁰−e⁻¹|≈0.01920이며 0.052가 아니다. 스텝을 반으로 했을 때 오차 비가 점근적으로 2·4·16에 가까워지는 것이 차수 확인의 의미다.



---

<div class="drillbox" markdown>

**연습문제 2.** <span class="diff hard" title="어려움"></span>
전진·후진 오일러의 안정 영역을 비교하고 적응형 명시적 방법이 강성을 자동 해결하는지 설명하라.

</div>

??? success "연습문제 2 풀이"

    전진은 |1+z|≤1인 중심 −1·반지름1 원판이고, 후진은 |1/(1−z)|≤1로 왼쪽 반평면을 포함한다. 적응형 명시적 방법은 오차에 맞추어 스텝을 줄일 수 있어도 안정 영역 밖에서 큰 스텝을 안전하게 쓸 수는 없다. 암시적 방법도 종류·차수와 내부 풀이 비용을 따로 확인해야 한다.



---

<div class="drillbox" markdown>

**연습문제 3.** <span class="diff med" title="중간"></span>
한 스텝 오차 O(h^(p+1))에서 전역 오차 O(h^p)를 얻는 조건과 부등식을 제시하라.

</div>

??? success "연습문제 3 풀이"

    고정 구간 [0,T]에서 정확한 초기값과 Lipschitz 안정성, 균일한 국소 오차 상수를 가정한다. ||eₙ₊₁||≤(1+hL)||eₙ||+Ch^(p+1)을 반복하면 L>0에서 ||e_N||≤(C/L)h^p(e^(LT)−1)이다. L=0은 합을 직접 계산해 CTh^p를 얻는다. T가 h에 따라 무한히 커지거나 해가 충분히 매끄럽지 않으면 같은 결론을 자동 적용할 수 없다.



---

<div class="drillbox" markdown>

**연습문제 4.** <span class="diff med" title="중간"></span>
배치 적응형 솔버의 출력 시점 수와 내부 NFE, 역전파 방식을 구분하라.

</div>

??? success "연습문제 4 풀이"

    출력 시점 수는 반환 텐서의 시간 축 길이이고 내부 스텝·NFE와 같지 않다. 표준 배치 호출은 배치 전체 상태의 공유 적응 스텝을 사용한다. 직접 역전파와 연속 adjoint는 별도 선택이며 각각의 순방향·역방향 NFE와 실제 메모리를 측정해야 한다. 허용 오차 감소가 최종 작업 정확도를 단조 개선한다고 보장할 수 없다.



## 정리하며

솔버 차수는 매끄러움·안정성 조건 아래 전역 오차가 줄어드는 비율이다. 적응형의 국소 오차 제어와 강성의 안정 제약을 구분하고, 실제 시간·메모리와 순·역방향 NFE를 함께 평가한다. 배치의 공유 스텝과 요청 출력 시점도 명확히 해석한다.
