# 뉴럴 ODE의 솔버 선택과 검증

솔버 선택은 모델의 예측 오차와 수치 오차를 구분하는 작업이다. 같은 벡터장도 내부 스텝·허용 오차에 따라 다른 수치 출력을 만들고, 학습에서는 gradient 계산법까지 영향을 준다. 검증되지 않은 고정 속도표 대신 작업별로 정확도·실제 비용·gradient 안정성을 비교하는 절차를 세운다.

## 1. 방법 분류와 오차 차수

명시적·암시적은 새 상태를 얻는 방정식의 형태, 고정·적응 스텝은 내부 시간 간격의 선택 방식이다. 이 둘은 독립된 분류다. 다단계 방법은 과거 여러 상태·미분값을 재사용한다.

충분히 매끄럽고 안정적인 유한 구간에서 전역 p차 방법의 한 스텝 오차는 보통 O(h^(p+1))다. 따라서 오일러는 국소 O(h²)·전역 O(h), RK4는 국소 O(h⁵)·전역 O(h⁴)다. 전역 오차는 국소 오차를 시간에 단순히 곱한 값이 아니라 전파·증폭한 합이다.

예를 들어 ||eₙ₊₁||≤(1+hL)||eₙ||+Ch^(p+1)에서 고정 T의 오차는 O(h^p)를 얻지만, 상수에는 e^(LT) 같은 민감도가 들어갈 수 있다. 차수만으로 큰 스텝·장기 구간의 정확도를 보장하지 않는다.

## 2. 솔버와 라이브러리를 구분하기

| 구성 | 확인할 피처 |
|---|---|
| 고정 오일러·RK4 | 내부 step_size와 안정 영역, 실제 호출 수 |
| 적응형 명시적 RK | 국소 오차 추정, 거절 스텝과 강성의 안정 제약 |
| Radau·BDF 등 | Jacobian·비선형 풀이 비용과 해당 구현의 미분 지원 |
| Adams 계열 | 시작 방법, 과거 값 재사용과 차수별 안정성 |

[SciPy 문서](https://docs.scipy.org/doc/scipy/reference/generated/scipy.integrate.solve_ivp.html)의 DOP853은 8차 명시적 방법이며 dense output에 7차 보간을 사용한다. 이를 단순한 8/7 embedded pair로 설명하지 않는다. 또한 SciPy의 DOP853, torchdiffeq의 dopri5·dopri8은 이름·계수·인터페이스를 구분해야 한다.

[SUNDIALS CVODE](https://sundials.readthedocs.io/en/latest/cvode/Introduction_link.html)는 비강성용 Adams와 강성용 BDF 계열을 제공하지만, 두 계열 사이를 자동으로 바꾸는 LSODA와 같은 설명을 붙이지 않는다. 차수 범위도 각각 다르다. 암시적 RK 전체가 s단계에서 모두 2s−1차인 것도 아니다. 예를 들어 Gauss와 Radau 계열은 서로 다른 차수·안정 특성을 갖는다.

과학 계산 솔버를 호출할 수 있다는 것과 PyTorch 파라미터·GPU에 대해 원하는 방식으로 미분할 수 있다는 것은 별개다. 사용하는 래퍼·민감도 구현과 버전을 확인해야 한다.

## 3. 보존된 선택 트리의 한계

```
시작: 뉴럴 상미분 방정식 문제

1. h의 차원은?
   - Low (<100): Use adaptive solver (DOP853)
   - 높음(1000 이상): 은근한 방법을 쓰거나 뻣뻣함을 살핀다

2. 뻣뻣함 비 λ_max/λ_min을 어림하는가?
   - Stiff (ratio > 100): Use implicit method or CVODE
   - Non-stiff: Use explicit method (RK4 or DOP853)

3. 빠르기와 정확도 가운데 무엇이 먼저인가?
   - 빠르기가 결정적: 붙박이 걸음과 헐거운 허용 오차의 RK4
   - 정확도가 결정적: 맞추어 가는 걸음의 DOP853
   - Both: DOP853 (adaptive step balances both)

4. 익히기에 미분할 수 있어야 하는가?
   - Yes: Use adjoint-compatible solver (most solvers OK)
   - 뒷먹임의 안정을 보장한다
```

위 블록은 기존 문서의 안내 예시로 보존하지만 검증된 자동 선택 규칙은 아니다. 상태 차원이 100 또는 1,000이라는 이유만으로 강성을 판정하지 않는다. 고유값 비율 100도 복소 고유값·비정규성·시간 구간·빠른 모드의 역할을 모두 설명하는 보편 임계값은 아니다.

고정 RK4의 정확도는 스텝 크기로 조절하며 “헐거운 허용 오차”만 설정해서 바뀌는 것이 아니다. adjoint와 호환되는 솔버를 골랐다고 역방향 안정성이 보장되는 것도 아니다.

## 4. 보존된 기본값 예시 읽기

```
Use: DOP853 (Dormand-Prince 8th order adaptive)
허용 오차: 1e-6에서 1e-4
까닭: 정확도와 빠르기의 균형이 좋고 여러 액션을 다룬다
```

```
Use: RK4 with fixed step h = 0.01
Tolerance: N/A (fixed step)
까닭: 빠르고 웃돈이 적으며 매끄러운 계에 넉넉하다
```

```
Use: CVODE or implicit RK (Radau)
허용 오차: 1e-6
Reason: Handles stiffness; standard choice in scientific computing
```

```
쓰기: 딸림 상미분 방정식 + DOP853
Tolerance: 1e-4 to 1e-3 (loosen for faster training)
되짚을 자리: 10~20걸음마다
```

이 네 블록은 기존 설정 예시이지 모든 작업의 권장값이나 측정 결과가 아니다. 특히 적응형 명시적 방법은 강성이 사라지지 않는 한 작은 안정 스텝을 계속 요구할 수 있다. 단지 정확도가 높다는 이유로 DOP853을 모든 뉴럴 ODE의 기본값으로 고정하지 않는다.

허용 오차의 절대항은 상태 단위와, 상대항은 크기와 연결된다. 예측 로스의 10%를 허용 오차로 쓰는 규칙은 단위·오차 전파가 맞지 않을 수 있다. 분류·회귀라는 작업 이름만으로 1e−3 또는 1e−6이 충분하다고 단정하지 않고 실제 상태 스케일과 출력·gradient 민감도를 확인한다.

## 5. 직접 미분·adjoint·checkpoint

최종 로스 L=ℓ(h(T))에서 열벡터 adjoint a는 a′=−(∂f/∂h)ᵀa를 만족한다. 초기값이 θ와 독립이면 파라미터 gradient는 **+∫₀ᵀ(∂f/∂θ)ᵀa dt**다. 역방향 적분 구간으로 쓰면 방향에 맞는 부호를 사용해야 한다.

직접 역전파는 수치 연산의 그래프를 저장한다. 연속 adjoint는 역문제를 풀고, checkpoint 방식은 저장한 상태에서 일부 구간을 재계산한다. 저장량 O(√N)이나 특정 배수의 속도·메모리 개선은 특정 저장 계획과 N·상태 크기 조건 아래의 분석이며 모든 구현의 고정 특성이 아니다.

역방향에서 감쇠한 상태를 재구성하는 문제는 불안정할 수 있다. adjoint의 조건수가 언제나 cond(J_f)²라는 보편 공식은 없다. 작은 문제에서 방향 도함수·유한 차분과 비교하고, 직접 미분·허용 오차·checkpoint 선택에 따른 gradient 차이를 확인한다. 유한 차분 자체도 반올림·차분 크기·솔버 오차에 영향을 받는다.

## 6. 수치 오차와 작업 성능을 분리한 비교

먼저 **같은 학습 웨이트**를 고정하고 솔버·스텝·허용 오차만 바꾸어 출력의 수렴, NFE·거절 횟수·실제 시간·메모리를 본다. 작은 검증 문제의 해석해 또는 더 엄격한 참조해를 사용할 수 있지만 후자도 근사다.

그다음 솔버를 바꾸어 **각각 재학습한 모델**을 비교한다. 이는 수치 오차뿐 아니라 학습 경로의 차이도 포함하므로 앞의 실험과 분리한다. 구조·초기화·학습 예산·데이터 분할을 맞추고 반복 변동을 보고한다.

시계열은 시간 순서의 검증·테스트를 사용하고 허용 오차·솔버 선택에 테스트 구간을 사용하지 않는다. 정확도와 비용의 Pareto 경계를 비교해 사용 목적에 맞는 구성을 고른다. 낮은 NFE만으로 항상 빠르다고 단정하지 않는다. 암시적 방법에는 Jacobian·선형계 풀이 비용도 있기 때문이다.

## 7. 실패 상태의 점검

과도한 NFE, 최소 스텝 도달이나 NaN이 생기면 상태·시간 스케일, 벡터장 매끄러움과 성장, 강성, discontinuity 처리와 gradient 방식을 점검한다. 허용 오차를 더 작게 만드는 것이 언제나 해결책은 아니다. 알려진 점프 시각이나 사건을 일반 매끄러운 구간처럼 통과시키지 않는다.

이 페이지에는 솔버별 성능을 측정한 실험이 없다. 근거 없는 금융 예측 시간·MSE 표나 보편적인 최적 솔버 순위 대신 위 비교 절차를 사용한다.

**연습문제 1.** <span class="diff med" title="중간"></span>
y′=−1000y+3000−2000e⁻ᵗ, y(0)=0의 해와 전진 오일러의 안정 스텝을 구하라. 적응형 명시적 방법이 곧 큰 스텝을 쓸 수 있는가?

</div>

??? success "연습문제 1 풀이"

    특수해 3−(2000/999)e⁻ᵗ와 초기 과도항 −(997/999)e⁻¹⁰⁰⁰ᵗ를 합한다. 빠른 모드 λ=−1000 때문에 오일러의 감쇠 안정 스텝은 0<h<0.002다. RK4도 음의 실축 안정 경계 약 −2.785에 의해 h≈0.002785보다 작아야 한다. 적응형 명시적 방법도 안정 영역의 제약이 남으므로 과도항 이후 전체를 50~100회 호출로 푼다고 미리 단정할 수 없다.

**연습문제 2.** <span class="diff hard" title="어려움"></span>
두 단계 명시적 RK의 2차 조건을 적고 중점·호인 방법을 구하라.

</div>

??? success "연습문제 2 풀이"

    k₁=f(t,y), k₂=f(t+c₂h,y+a₂₁hk₁), y′=y+h(b₁k₁+b₂k₂)에서 b₁+b₂=1, b₂c₂=1/2, b₂a₂₁=1/2가 필요하다. 따라서 a₂₁=c₂≠0이고 b₂=1/(2c₂)다. 중점법은 c₂=1/2,b₁=0,b₂=1이고 호인은 c₂=1,b₁=b₂=1/2다. 충분한 매끄러움과 안정성 아래 전역2차를 얻는다.

**연습문제 3.** <span class="diff med" title="중간"></span>
적응형 솔버가 모든 뉴럴 ODE에 필수인가? 허용 오차를 작업 로스의 10%로 정해도 되는가?

</div>

??? success "연습문제 3 풀이"

    필수는 아니다. 고정 스텝도 적절한 간격·검증과 함께 사용할 수 있다. 적응형은 오차 추정으로 스텝을 조절하지만 강성을 자동 해결하지는 않는다. 상태 단위의 atol·상대 rtol과 작업 로스는 단위·집계가 달라 단순 비율 규칙은 일반적으로 근거가 없다. 출력과 gradient의 민감도를 검증해야 한다.

**연습문제 4.** <span class="diff hard" title="어려움"></span>
같은 웨이트의 수치 비교와 각 솔버로 재학습한 비교를 어떻게 설계할 것인가?

</div>

??? success "연습문제 4 풀이"

    첫 비교는 데이터·웨이트를 고정해 스텝·허용 오차만 바꾸고 참조 출력과의 차이, gradient 차이·NFE·시간·메모리를 잰다. 두 번째는 같은 구조·초기화·예산에서 각각 학습하고 독립 테스트 성능과 반복 변동을 평가한다. 시계열은 시간 순서를 유지하고 설정은 검증 구간에서 고른다. 두 실험의 차이를 합쳐 특정 솔버의 보편 성능으로 주장하지 않는다.



## 정리하며

솔버 선택에는 정확도 차수뿐 아니라 강성·상태 스케일·미분 구현과 비용이 함께 필요하다. 보존된 설정 예시를 보편 규칙으로 사용하지 않고, 고정 웨이트의 수치 실험과 재학습의 작업 성능 실험을 분리해 평가한다.
