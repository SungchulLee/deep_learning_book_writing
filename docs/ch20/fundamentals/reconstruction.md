# 풀이 다시 세우기

동적 짜기 알고리즘은 흔히 가장 좋은 풀이의 **값**을 셈한다. 곧 가장 적은 값, 가장 큰 이익, 가장 긴 부분 차례의 길이이다. 그러나 대개의 쓰임새는 풀이 자체를 바란다. 곧 어디를 잘랐는지, 어떤 물건을 골랐는지, 어떤 글자를 맞춰 놓았는지이다. 다 채운 동적 짜기 표에서 풀이를 다시 세우는 것은 되돌이 관계식 짜기를 채워 주는 바탕 솜씨이다.

## 다시 세우기 문제

동적 짜기 표를 다 채우면 칸마다 딸린 아래 문제의 가장 좋은 값이 들어 있다. 다시 세우는 일은 표를 거슬러 좇아 그 가장 좋은 값에 이른 결정의 차례를 되찾는 것이다.

이를 해내는 여느 방식이 둘 있다:

1. **동적 짜기 표를 되짚어 가기**. 마지막 답이 든 칸에서 시작해 어떤 고름이 그 값을 낳았는지 살피고 그 길을 거슬러 따라간다.
2. **결정 가리개를 또렷이 담아 두기**. 앞으로 나아가며 칸마다 한 고름을 따로 둔 표에 적고, 나중에 그 가리개를 따라가 풀이를 되찾는다.

두 방식 모두 칸마다 $O(1)$ 일감만 더하므로 다시 세우기가 전체 시간 복잡도를 바꾸지 않는다.

## 방식 1: 표를 되짚어 가기

글줄 $X = x_1 x_2 \cdots x_m$과 $Y = y_1 y_2 \cdots y_n$의 최장 공통 부분 차례 문제를 보자. 되돌이 관계식은 다음과 같다

$$
c[i][j] = \begin{cases} 0 & \text{if } i = 0 \text{ or } j = 0 \\ c[i-1][j-1] + 1 & \text{if } x_i = y_j \\ \max(c[i-1][j],\; c[i][j-1]) & \text{if } x_i \neq y_j \end{cases}
$$

표를 채운 뒤 $c[m][n]$에서 시작해 거슬러 좇는다:

- $x_i = y_j$이면 글자 $x_i$이 최장 공통 부분 차례에 든다. $c[i-1][j-1]$으로 옮긴다.
- $c[i-1][j] \ge c[i][j-1]$이면 $c[i-1][j]$으로 옮긴다.
- 아니면 $c[i][j-1]$으로 옮긴다.

$i = 0$이나 $j = 0$이 될 때까지 이어 간다. 모은 글자를 (거꾸로 된 차례로) 이으면 최장 공통 부분 차례가 된다.

```python
"""
동적 짜기 표를 되짚어 최장 공통 부분 차례를
다시 세운다.
"""


# ===================================================================
# 다시 세우기를 곁들인 최장 공통 부분 차례
# ===================================================================
def lcs_with_reconstruction(x: str, y: str) -> str:
    """최장 공통 부분 차례의 길이를 셈하고 부분 차례를 다시 세운다."""
    m, n = len(x), len(y)
    c = [[0] * (n + 1) for _ in range(m + 1)]

    # 동적 짜기 표를 채운다
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if x[i - 1] == y[j - 1]:
                c[i][j] = c[i - 1][j - 1] + 1
            else:
                c[i][j] = max(c[i - 1][j], c[i][j - 1])

    # 되짚어 최장 공통 부분 차례를 다시 세운다
    result = []
    i, j = m, n
    while i > 0 and j > 0:
        if x[i - 1] == y[j - 1]:
            result.append(x[i - 1])
            i -= 1
            j -= 1
        elif c[i - 1][j] >= c[i][j - 1]:
            i -= 1
        else:
            j -= 1

    return "".join(reversed(result))


# ===================================================================
# 메인
# ===================================================================
if __name__ == "__main__":
    x = "ABCBDAB"
    y = "BDCAB"
    lcs = lcs_with_reconstruction(x, y)
    print(f"X = {x}")
    print(f"Y = {y}")
    print(f"LCS = {lcs} (length {len(lcs)})")
```

**출력:**
```
X = ABCBDAB
Y = BDCAB
LCS = BCAB (length 4)
```

## 방식 2: 결정 가리개

되짚으며 결정을 다시 끌어내는 대신 앞으로 나아갈 때 담아 둔다. 칸마다 되돌이 관계식의 어느 갈래를 탔는지 적는다.

되돌이 관계식이 다음과 같은 막대 자르기 문제에서

$$
r[n] = \max_{1 \le i \le n} \bigl(p_i + r[n - i]\bigr)
$$

최댓값을 주는 첫 자르기 길이 $i$을 적어 두는 딸림 배열 $s[n]$을 둔다:

```python
"""
풀이를 다시 세우려 결정 가리개를 곁들인 막대 자르기.
"""


# ===================================================================
# 다시 세우기를 곁들인 막대 자르기
# ===================================================================
def rod_cutting(prices: list[int], n: int) -> tuple[int, list[int]]:
    """최대 벌이와 자른 길이의 목록을 돌려준다."""
    r = [0] * (n + 1)
    s = [0] * (n + 1)

    for j in range(1, n + 1):
        best = -1
        for i in range(1, j + 1):
            if prices[i - 1] + r[j - i] > best:
                best = prices[i - 1] + r[j - i]
                s[j] = i
        r[j] = best

    # 자르기를 다시 세운다
    cuts = []
    remaining = n
    while remaining > 0:
        cuts.append(s[remaining])
        remaining -= s[remaining]

    return r[n], cuts


# ===================================================================
# 메인
# ===================================================================
if __name__ == "__main__":
    prices = [1, 5, 8, 9, 10, 17, 17, 20, 24, 30]
    n = 7
    revenue, cuts = rod_cutting(prices, n)
    print(f"Rod length: {n}")
    print(f"Maximum revenue: {revenue}")
    print(f"Cuts: {cuts}")
```

**출력:**
```
Rod length: 7
Maximum revenue: 18
Cuts: [1, 6]
```

가리개 배열 $s$이 걸음마다의 결정을 담고 있어, 다시 세우기는 적어 둔 고름을 따라가는 단순한 되풀이가 된다.

## 두루 쓰는 다시 세우기 결

어떤 문제든 다시 세우기는 다음의 한결같은 결을 따른다:

1. 마지막 답이 든 칸에서 **시작한다**(예컨대 $dp[n]$, $dp[m][n]$, $dp[0][n-1]$).
2. 되돌이 관계식을 다시 따져 보거나 담아 둔 결정을 보아, 그 칸의 값을 낳은 고름을 **가려낸다**.
3. 그 고름을 **적는다**(담은 물건, 낸 자르기, 맞춘 글자).
4. 그 고름이 가리키는 아래 문제 칸으로 **옮긴다**.
5. 바탕 경우에 이를 때까지 **되풀이한다**.

결과는 거꾸로 된 차례의 결정 차례(마지막 상태에서 바탕 경우까지)이며, 이를 뒤집으면 앞으로 가는 차례의 풀이를 얻는다.

!!! tip "가리개를 담을 때와 되짚을 때"
    결정 가리개를 담으면 칸마다 $O(1)$ 공간이 더 들지만 다시 세우기가 아주 쉬워진다. 가리개 없이 되짚으면 기억 공간을 아끼지만 걸음마다 되돌이 관계식을 다시 따져야 한다. 되돌이 관계식이 여러 고름에 걸친 $\min$이나 $\max$을 쓰는 문제(행렬 사슬 곱하기 같은)에서는 흔히 가리개를 담는 쪽이 편하다.

## 연습문제

**연습문제 1.**
풀이 다시 세우기의 상태, 옮아감, 바탕 경우를 가려내어라.

??? success "연습문제 1 풀이"
    **상태**는 아래 문제를 적는 데 필요한 앎을 담는다. **옮아감**(되돌이 관계식)은 어떤 상태의 가장 좋은 값을 더 작은 상태로 나타낸다. **바탕 경우**는 곧바로 풀 수 있는 가장 작은 아래 문제의 값을 준다. 이 셋이 함께 동적 짜기 풀이를 온전히 정한다. $\square$

---

**연습문제 2.**
풀이 다시 세우기의 위에서 아래로(적어 두기) 짜기와 아래에서 위로(표 채우기) 짜기를 견주어라. 어느 쪽이 나으며 왜 그런가?

??? success "연습문제 2 풀이"
    **위에서 아래로**: 곳간을 곁들인 되돌이. 정말 필요한 아래 문제만 셈한다(게으른 값매김). 되돌이 관계식에서 옮겨 적기 쉽다. 되돌이 깊이 문제가 생길 수 있다. **아래에서 위로**: 되풀이로 기댐 차례에 따라 표를 채운다. 필요 없는 것까지 모든 아래 문제를 셈한다. 되돌이 군더더기가 없다. 공간을 줄이기 쉽다. 이 문제에서는 아래 문제가 모두 필요하면 아래에서 위로가 흔히 낫고, 닿지 않는 아래 문제가 많으면 위에서 아래로가 낫다. $\square$

---

**연습문제 3.**
풀이 다시 세우기의 시간 복잡도와 공간 복잡도는 무엇인가? 공간을 더 줄일 수 있는가?

??? success "연습문제 3 풀이"
    시간 복잡도는 상태의 수에 상태마다의 옮아감 값을 곱한 것으로 정해진다. 공간은 담아 두는 상태의 수와 같다. 옮아감이 앞선 상태 가운데 한정된 몇 개에만 기대면(예컨대 2차원 표의 바로 앞 가로줄) 그 상태만 기억 공간에 두어 공간을 줄일 수 있으며, 흔히 $O(n^2)$에서 $O(n)$으로 줄어든다. $\square$

**연습문제 4.**
풀이 다시 세우기의 알고리즘을 네가 고른 작은 보기에 대해 좇아라. 동적 짜기 표의 값을 보여라.

??? success "연습문제 4 풀이"
    작은 들임(예컨대 $n = 5$이나 짧은 글줄/배열)을 골라라. 동적 짜기 표를 한 걸음씩 채우면서 각 칸이 앞서 셈한 칸에서 어떻게 나오는지 보여라. 마지막 답을 막무가내로 다 세어 본 것과 견주어 확인하라. 이렇게 좇아 보면 되돌이 관계식이 옳음을 확인하고 알고리즘에 대한 직관이 선다. $\square$
