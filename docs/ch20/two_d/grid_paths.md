# 격자 길

격자 길 문제는 2차원 동적 짜기로 들어가는 자연스러운 길이다. 크기 $m \times n$인 격자가 주어질 때 오른쪽이나 아래로만 움직여 왼쪽 위 구석에서 오른쪽 아래 구석까지 가는 길을 세거나 가장 좋게 하는 것이 일이다. 2차원 표 짜임 덕분에 되돌이 관계식과 그 기댐이 눈에 잘 들어오고, 문제를 장애물, 값, 다른 제약이 있는 경우로 쉽게 넓힐 수 있다.

## 문제: 길 세기

$m \times n$ 격자가 주어질 때 칸마다 오른쪽이나 아래로만 움직여 자리 $(0, 0)$에서 자리 $(m-1, n-1)$까지 가는 서로 다른 길의 수를 세어라.

**보기:** $3 \times 3$ 격자에는 서로 다른 길이 6개 있다.

## 점화식

$dp[i][j]$을 $(0, 0)$에서 $(i, j)$까지 가는 서로 다른 길의 수라 하자. 칸 $(i, j)$에는 $(i-1, j)$에서(아래로 움직여) 또는 $(i, j-1)$에서(오른쪽으로 움직여) 닿을 수 있으므로

$$
dp[i][j] = dp[i-1][j] + dp[i][j-1] \quad \text{for } i \ge 1, \; j \ge 1
$$

바탕 경우는 다음과 같다

$$
dp[i][0] = 1 \;\text{for all } i, \quad dp[0][j] = 1 \;\text{for all } j
$$

첫 가로줄(모두 오른쪽)이나 첫 세로줄(모두 아래)의 어느 칸에든 닿는 길이 꼭 하나뿐이기 때문이다.

## 조합으로 푸는 풀이

$(0,0)$에서 $(m-1, n-1)$까지의 길은 아래로 $m - 1$번, 오른쪽으로 $n - 1$번 움직이는 것을 어떤 차례로 늘어놓은 것이다. 서로 다른 차례의 수는 다음과 같다

$$
\binom{m + n - 2}{m - 1} = \frac{(m + n - 2)!}{(m - 1)!(n - 1)!}
$$

동적 짜기 방식과 조합 공식은 같은 답을 주지만 동적 짜기는 장애물이나 들쭉날쭉한 값이 있는 격자로 넓힐 수 있다.

## 표 채우기

```python
"""
격자 길: 동적 짜기로 2차원 격자의 길을 세고 가장 좋게 한다.
"""


# ===================================================================
# 서로 다른 길 세기
# ===================================================================
def unique_paths(m: int, n: int) -> int:
    """m x n 격자에서 서로 다른 길을 센다. 시간: O(mn), 공간: O(mn)."""
    dp = [[1] * n for _ in range(m)]

    for i in range(1, m):
        for j in range(1, n):
            dp[i][j] = dp[i - 1][j] + dp[i][j - 1]

    return dp[m - 1][n - 1]
```

## 장애물이 있는 격자

어떤 칸이 막혀 있으면 장애물 칸에 $dp[i][j] = 0$으로 둔다:

$$
dp[i][j] = \begin{cases} 0 & \text{if cell } (i,j) \text{ is an obstacle} \\ dp[i-1][j] + dp[i][j-1] & \text{otherwise} \end{cases}
$$

```python
# ===================================================================
# 장애물이 있을 때 길 세기
# ===================================================================
def unique_paths_with_obstacles(grid: list[list[int]]) -> int:
    """1이 장애물인 격자에서 길을 센다. 시간: O(mn), 공간: O(mn)."""
    m, n = len(grid), len(grid[0])
    if grid[0][0] == 1 or grid[m - 1][n - 1] == 1:
        return 0

    dp = [[0] * n for _ in range(m)]
    dp[0][0] = 1

    for i in range(m):
        for j in range(n):
            if grid[i][j] == 1:
                dp[i][j] = 0
            else:
                if i > 0:
                    dp[i][j] += dp[i - 1][j]
                if j > 0:
                    dp[i][j] += dp[i][j - 1]

    return dp[m - 1][n - 1]
```

## 값이 가장 적은 길

칸마다 값이 딸려 있을 때 $(0, 0)$에서 $(m-1, n-1)$까지 전체 값이 가장 적은 길을 찾는다:

$$
dp[i][j] = \text{cost}[i][j] + \min\bigl(dp[i-1][j],\; dp[i][j-1]\bigr)
$$

$dp[0][0] = \text{cost}[0][0]$이다.

```python
# ===================================================================
# 값이 가장 적은 길
# ===================================================================
def min_cost_path(cost: list[list[int]]) -> int:
    """왼쪽 위에서 오른쪽 아래까지의 가장 적은 값. 시간: O(mn), 공간: O(mn)."""
    m, n = len(cost), len(cost[0])
    dp = [[0] * n for _ in range(m)]
    dp[0][0] = cost[0][0]

    for i in range(1, m):
        dp[i][0] = dp[i - 1][0] + cost[i][0]
    for j in range(1, n):
        dp[0][j] = dp[0][j - 1] + cost[0][j]

    for i in range(1, m):
        for j in range(1, n):
            dp[i][j] = cost[i][j] + min(dp[i - 1][j], dp[i][j - 1])

    return dp[m - 1][n - 1]
```

## 공간 줄이기

가로줄마다 지금과 앞선 가로줄에만 기대므로 공간이 $O(mn)$에서 $O(n)$으로 준다:

```python
# ===================================================================
# 공간을 줄인 서로 다른 길 세기
# ===================================================================
def unique_paths_optimized(m: int, n: int) -> int:
    """O(n) 공간으로 서로 다른 길을 센다."""
    dp = [1] * n
    for _ in range(1, m):
        for j in range(1, n):
            dp[j] += dp[j - 1]
    return dp[n - 1]
```

## 복잡도

| 변형 | 시간 | 공간 | 줄인 공간 |
|---------|------|-------|-----------------|
| 길 세기 | $O(mn)$ | $O(mn)$ | $O(n)$ |
| 장애물 곁들임 | $O(mn)$ | $O(mn)$ | $O(n)$ |
| 가장 적은 값 | $O(mn)$ | $O(mn)$ | $O(n)$ |

```python
# ===================================================================
# 메인
# ===================================================================
if __name__ == "__main__":
    # 서로 다른 길
    for m, n in [(3, 3), (3, 7), (7, 3)]:
        print(f"unique_paths({m},{n}) = {unique_paths(m, n)}")

    # 장애물 곁들임
    grid = [[0, 0, 0], [0, 1, 0], [0, 0, 0]]
    print(f"paths with obstacle = {unique_paths_with_obstacles(grid)}")

    # 가장 적은 값
    cost = [[1, 3, 1], [1, 5, 1], [4, 2, 1]]
    print(f"min cost path = {min_cost_path(cost)}")
```

**출력:**
```
unique_paths(3,3) = 6
unique_paths(3,7) = 28
unique_paths(7,3) = 28
paths with obstacle = 2
min cost path = 7
```

## 연습문제

**연습문제 1.**
격자 길의 상태, 옮아감, 바탕 경우를 가려내어라.

??? success "연습문제 1 풀이"
    **상태**는 아래 문제를 적는 데 필요한 앎을 담는다. **옮아감**(되돌이 관계식)은 어떤 상태의 가장 좋은 값을 더 작은 상태로 나타낸다. **바탕 경우**는 곧바로 풀 수 있는 가장 작은 아래 문제의 값을 준다. 이 셋이 함께 동적 짜기 풀이를 온전히 정한다. $\square$

---

**연습문제 2.**
격자 길의 위에서 아래로(적어 두기) 짜기와 아래에서 위로(표 채우기) 짜기를 견주어라. 어느 쪽이 나으며 왜 그런가?

??? success "연습문제 2 풀이"
    **위에서 아래로**: 곳간을 곁들인 되돌이. 정말 필요한 아래 문제만 셈한다(게으른 값매김). 되돌이 관계식에서 옮겨 적기 쉽다. 되돌이 깊이 문제가 생길 수 있다. **아래에서 위로**: 되풀이로 기댐 차례에 따라 표를 채운다. 필요 없는 것까지 모든 아래 문제를 셈한다. 되돌이 군더더기가 없다. 공간을 줄이기 쉽다. 이 문제에서는 아래 문제가 모두 필요하면 아래에서 위로가 흔히 낫고, 닿지 않는 아래 문제가 많으면 위에서 아래로가 낫다. $\square$

---

**연습문제 3.**
격자 길의 시간 복잡도와 공간 복잡도는 무엇인가? 공간을 더 줄일 수 있는가?

??? success "연습문제 3 풀이"
    시간 복잡도는 상태의 수에 상태마다의 옮아감 값을 곱한 것으로 정해진다. 공간은 담아 두는 상태의 수와 같다. 옮아감이 앞선 상태 가운데 한정된 몇 개에만 기대면(예컨대 2차원 표의 바로 앞 가로줄) 그 상태만 기억 공간에 두어 공간을 줄일 수 있으며, 흔히 $O(n^2)$에서 $O(n)$으로 줄어든다. $\square$

**연습문제 4.**
격자 길의 알고리즘을 네가 고른 작은 보기에 대해 좇아라. 동적 짜기 표의 값을 보여라.

??? success "연습문제 4 풀이"
    작은 들임(예컨대 $n = 5$이나 짧은 글줄/배열)을 골라라. 동적 짜기 표를 한 걸음씩 채우면서 각 칸이 앞서 셈한 칸에서 어떻게 나오는지 보여라. 마지막 답을 막무가내로 다 세어 본 것과 견주어 확인하라. 이렇게 좇아 보면 되돌이 관계식이 옳음을 확인하고 알고리즘에 대한 직관이 선다. $\square$
