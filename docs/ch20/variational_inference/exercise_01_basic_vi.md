## 2. 논의

### 가우스 평균: 해석적 기준해

첫 과제는 알려진 관측 분산 σ²와 정규 사전 θ∼N(μ₀,σ₀²)를 사용한다. 사후 분산 v=(σ₀⁻²+nσ⁻²)⁻¹, 사후 평균 m=v(μ₀σ₀⁻²+σ⁻²∑ᵢxᵢ)다. q=N(m_q,s²)는 정확한 사후를 포함하므로 최적 ELBO에서 근사 차이는 0이다. 추론 코드가 없는 기존 출력만으로 최적화나 수렴이 검증된 것은 아니다.

### 선형 회귀: 사전과 절편

코드 문자열의 회귀 모델은 w∼N(0,λ⁻¹I)와 τ∼Gamma(a₀,b₀)를 **독립**으로 둔다. 이는 w|τ의 분산을 τ에 반비례하게 두는 정규–감마 사전과 다르다. 두 완전조건부분포는 다루기 쉽지만 결합 사후가 표준 정규–감마의 해석적 형태가 된다고 단정하면 안 된다.

평균장 q(w)=N(m,V), q(τ)=Gamma(a,b)와 shape–rate 정의 아래에서 CAVI는 다음과 같다.

$$V=(\lambda I+E[\tau]X^\top X)^{-1},\qquad m=E[\tau]VX^\top y,$$

$$a=a_0+n/2,\qquad b=b_0+\tfrac12\left[\|y-Xm\|^2+\operatorname{tr}(X^\top XV)\right].$$

생성 데이터에는 절편 −1이 있지만 X에는 두 피처만 있다. 절편을 추정하려면 1의 열을 추가하고 해당 계수의 사전도 정의해야 한다. 정확한 기준 비교는 알려진 τ의 켤레 해, 정당한 수치 적분 또는 검증한 다른 추론 등 실제 모델과 일치하는 방법으로 구성한다.

### 베이즈 혼합과 모델 비교

세 번째 과제의 q(μₖ,τₖ)는 성분 내부의 의존성을 유지하는 정규–감마 블록이다. 이를 q(μₖ)q(τₖ)로 분리하면 다른 평균장 분포족이 된다. 배정의 로그 밀도에는 E[τₖ(x−μₖ)²] 등 결합 적률을 올바르게 사용한다. K별 ELBO는 각기 다른 근사 차이와 최적화 오차를 가지므로 증거의 정확한 순위가 아니다. 최대 우도 GMM의 점 추정과 베이즈 분포 추정도 같은 결과를 요구하는 비교가 아니다.

### 확률적 추론과 자연경사

N개 관측 중 균등하게 뽑은 크기 M의 미니배치에서는 관측 로그 우도 합을 N/M배하고 사전·엔트로피 항은 한 번 포함한다. 이 비율은 전체 데이터 합 목적의 불편 추정을 위한 것이며, 데이터 평균 목적을 쓰면 정규화도 일관되게 바꿔야 한다.

가우스 근사의 평균만 움직이고 공분산 S를 고정하면 평균 블록의 자연경사는 S∇_mL다. 공분산까지 함께 학습하는 전체 자연경사를 이 식 하나로 대체할 수는 없다. 비켤레 로지스틱 회귀에는 기대 우도와 경사를 근사할 방법이 필요하고, 확률적 갱신은 매번 ELBO를 높인다고 보장되지 않는다.

프로빗 회귀도 원래 표현에서 정규 사전과 베르누이 우도가 직접 켤레가 아니지만, 잠재 가우스 변수를 도입하면 조건부 켤레 구조를 활용하는 다른 CAVI를 구성할 수 있다. ‘비켤레이므로 어떤 CAVI도 불가능하다’는 코드 문자열의 문장은 이 범위로 보완해서 읽는다. 과제에 포함된 경로와 출력·그림은 실행하거나 재생성하지 않았다.

<div class="drillbox" markdown>

**연습문제 4.** <span class="diff hard" title="어려움"></span>
아래 기존 테스트 골격이 변분 추론의 검증으로 충분한지 비판하고 적합한 확인 항목을 제시하라.

</div>

??? success "연습문제 4 풀이"

    기존 골격은 공백이 든 식별자와 정의되지 않은 뉴럴 넷트웍 형태를 사용해 실행 가능한 VI 테스트가 아니다. 요청에 따라 코드는 유지했다. 가우스 기준해와 변분 평균·분산 비교, 양의 분산, 책임도 합 1, 정확한 좌표 갱신에서의 올바른 ELBO 비감소성, 몬테카를로 경사의 고정 파라메터 반복 오차 등을 모델에 맞게 확인해야 한다. 확률적 최적화의 매회 단조성을 일반적인 통과 기준으로 삼지 않는다.

    ```python
    def test_variational inference():
        model = Variational Inference(...)
        # 보통의 입력
        assert model(normal_input).shape == expected_shape
        # 원소가 하나인 배치
        assert model(single_input).shape == (1, ...)
        # 큰 값 (넘침을 확인한다)
        out = model(torch.ones(...) * 1000)
        assert torch.isfinite(out).all()
        # 경사의 흐름
        out = model(normal_input)
        out.sum().backward()
        for p in model.parameters():
            assert p.grad is not None
    ```


## 정리하며

이 과제 모음은 완성된 추론 구현이 아닌 출발점이다. 정확한 기준해가 있는 모델, 조건부 켤레성과 결합 사후의 차이, 블록 의존성, 미니배치 목적의 배율을 구분해서 유도한다. 기존의 일반 뉴럴 넷트웍 테스트 골격은 VI 검증으로 사용할 수 없다.
