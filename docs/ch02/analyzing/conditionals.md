# 조건문

알고리즘이 분기점, 즉 `if`, `if-else`, 또는 다중 분기 조건문에 도달하면 수행하는
연산의 횟수가 어느 분기가 실행되느냐에 따라 달라진다. 입력이 다르면 다른 분기가
실행되므로, 최선의 경우, 최악의 경우, 평균적인 경우 실행 시간의 구분이 구체적으로
드러나는 곳이 바로 조건문 분석이다.

## 분석 규칙

조건 검사에 $T_{\text{cond}}$ 시간이, `if` 분기에 $T_{\text{if}}$ 시간이,
`else` 분기에 $T_{\text{else}}$ 시간이 걸리는 `if-else` 문을 생각하자.

**최악의 경우 규칙.** 더 비싼 분기를 택한다.

$$
T_{\text{worst}} = T_{\text{cond}} + \max(T_{\text{if}},\; T_{\text{else}})
$$

**최선의 경우 규칙.** 더 싼 분기를 택한다.

$$
T_{\text{best}} = T_{\text{cond}} + \min(T_{\text{if}},\; T_{\text{else}})
$$

**평균적인 경우 규칙.** 각 분기에 그 확률로 가중치를 준다. 조건이 참일 확률을
$p$라 하면

$$
T_{\text{avg}} = T_{\text{cond}} + p \cdot T_{\text{if}} + (1 - p) \cdot T_{\text{else}}
$$

!!! tip "두 분기의 비용이 같을 때"

    두 분기가 점근적으로 같은 시간이 걸리면 조건문은 경우에 따라 달라지는 동작을
    들여오지 않는다. 예를 들어 $T_{\text{if}} = \Theta(n)$이고
    $T_{\text{else}} = \Theta(n)$이면 어느 분기가 실행되든 전체 비용은
    $\Theta(n)$이다.

## 단순한 if 문

`else` 분기가 없는 `if` 문은 $T_{\text{else}} = 0$인 특수한 경우이다.

```
if condition:
    body
```

- **최악의 경우:** $T_{\text{cond}} + T_{\text{body}}$(조건이 참)
- **최선의 경우:** $T_{\text{cond}}$(조건이 거짓이어서 몸체를 건너뜀)

??? example "최댓값 찾기"

    ```
    FindMax(A, n):
        max_val = A[0]              # O(1)
        for i = 1 to n - 1:        # O(n)번 반복
            if A[i] > max_val:      #   O(1) 비교
                max_val = A[i]      #   O(1) 대입
        return max_val              # O(1)
    ```

    4번 줄의 `if` 문은 $n - 1$번 수행된다. **최악의 경우**(배열이 오름차순)에는
    매 반복마다 대입이 수행되며 각각 $O(1)$이 든다. **최선의 경우**(첫 원소가
    최댓값)에는 대입이 한 번도 수행되지 않는다. 어느 쪽이든 반복문은 $n - 1$번
    돌므로 전체는 $\Theta(n)$이다.

## 다중 분기 조건문

분기가 $k$개인 `if-elseif-else` 사슬에 대해 최악의 경우 규칙은 다음과 같이
일반화된다.

$$
T_{\text{worst}} = T_{\text{cond}_1} + T_{\text{cond}_2} + \cdots + T_{\text{cond}_k} + \max_{1 \leq j \leq k} T_{\text{branch}_j}
$$

조건 검사는 하나가 성공할 때까지 차례로 평가된다는 점에 유의하라.
최악의 경우 마지막 분기에 도달하기까지 모든 조건을 평가할 수도 있다.

??? example "수 분류하기"

    ```
    Classify(x):
        if x > 0:                   # O(1)
            result = "positive"     # O(1)
        else if x < 0:              # O(1)
            result = "negative"     # O(1)
        else:
            result = "zero"         # O(1)
        return result               # O(1)
    ```

    모든 분기가 $\Theta(1)$ 시간이고 조건은 많아야 두 개가 검사된다. 이 구문
    전체는 $\Theta(1)$에 실행된다.

## 반복문 안의 조건문

조건문이 반복문 안에 나타나면 분석은 각 분기가 전체 반복에 걸쳐 얼마나 자주
실행되는지에 달려 있다. 이 상호작용이 반복문이 $O(n)$에 도는지 $O(n^2)$에 도는지를
결정하는 경우가 많다.

??? example "비용이 변하는 분기를 가진 조건문"

    ```
    Process(A, n):
        for i = 0 to n - 1:
            if A[i] == 0:
                Scan(A, n)          # O(n)
            else:
                A[i] = A[i] + 1     # O(1)
    ```

    - **최선의 경우:** `A`에 0이 없다. 매 반복이 $O(1)$이므로
      $T_{\text{best}}(n) = \Theta(n)$이다.
    - **최악의 경우:** 모든 원소가 0이다. $n$번의 반복이 각각 비용 $O(n)$의
      `Scan`을 호출하므로 $T_{\text{worst}}(n) = \Theta(n^2)$이다.
    - **평균적인 경우:** 각 원소가 확률 $p$로 0이면 `Scan` 호출의 기댓값은
      $pn$이므로
      $T_{\text{avg}}(n) = n \cdot [p \cdot O(n) + (1 - p) \cdot O(1)] = O(pn^2 + n)$이다.

## 흔한 함정: 조건의 비용을 무시하는 것

조건 자체를 평가하는 비용이 무시할 수 없는 경우가 있다. 조건에 함수 호출이나
자료구조 전체에 대한 비교가 들어 있으면 반드시 분석에 포함해야 한다.

!!! warning "조건이 공짜라고 가정하지 말 것"

    ```
    if IsSorted(A, n):      # 검사에 O(n)
        return A             # O(1)
    else:
        Sort(A, n)           # O(n log n)
    ```

    최악의 경우 비용은 그냥 $O(n \log n)$이 아니라 $O(n) + O(n \log n) = O(n \log n)$이다.
    분기가 실행되기도 전에 조건 검사가 $O(n)$을 기여한다.

## 연습문제

**연습문제 1.**
조건문에서 다룬 분석 기법을 너비 $d$인 층 $L$개로 이루어진 신경망의 순전파에 적용하라.

??? success "연습문제 1 풀이"
    각 층은 행렬 곱($O(d^2)$)과 활성화($O(d)$)를 수행한다. 이 절의 기법을 사용하여 층당 비용을 $L$개 층에 걸쳐 결합하면 전체 순전파 복잡도를 얻는다.

---

**연습문제 2.**
조건문의 분석 방법을 적용하여 작은 예제($n = 6$)를 따라가 보라. 정확한 연산 횟수를 세어라.

??? success "연습문제 2 풀이"
    $n = 6$에 대해 알고리즘이 수행하는 각 연산을 열거한다. 곱셈, 덧셈, 비교, 대입을 각각 따로 센다. 이를 합해 총합을 구한 뒤 빅오 표기법으로 표현한다.

---

**연습문제 3.**
조건문의 분석을 사용하여 학습 루프의 어느 단계(순전파, 역전파, 최적화기 갱신)가 전체 실행 시간을 지배하는지 판단하라.

??? success "연습문제 3 풀이"
    각 단계에 분석을 따로 적용한다. 순전파 $O(BPL)$, 역전파 $O(BPL)$, 최적화기 갱신 $O(P)$. 복잡도가 가장 큰 단계가 지배한다. 배치 크기가 크고 층이 많으면 순전파와 역전파(각각 $O(BPL)$)가 최적화기 갱신($O(P)$)을 지배한다.

---

**연습문제 4.**
조건문의 분석 기법이 논의된 알고리즘에 대해 꽉 조인 경계(상계와 하계가 일치)를 준다는 것을 증명하라.

??? success "연습문제 4 풀이"
    최악의 경우를 분석하여 상계를 보인다. 알고리즘이 최대 횟수의 연산을 수행하도록 강제하는 입력을 구성하여 하계를 보인다. 두 경계가 일치하면 분석이 꽉 조인 것이다($\Theta$ 표기법). $\square$
