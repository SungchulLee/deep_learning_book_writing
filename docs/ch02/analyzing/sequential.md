# 순차 합성

대부분의 알고리즘은 여러 단계를 차례로 수행한다. 자료구조를 초기화하고, 입력을 처리하고,
출력을 만들어 낸다. 전체 실행 시간을 분석하려면 연속된 코드 블록의 비용을 결합하는
규칙이 필요하다. 순차 합성이 그 규칙을 제공하며, 점근 표기법과 맞물려 어느 단계가
전체 비용을 지배하는지 드러낸다.

## 합 규칙

알고리즘이 실행 시간 $T_1(n)$과 $T_2(n)$인 두 단계로 이루어져 있으면 전체 실행
시간은 그 합이다.

$$
T(n) = T_1(n) + T_2(n)
$$

이는 $k$개의 순차 단계로 자연스럽게 확장된다.

$$
T(n) = T_1(n) + T_2(n) + \cdots + T_k(n) = \sum_{i=1}^{k} T_i(n)
$$

합 규칙은 실행 시간의 정의에서 곧바로 따라 나온다. 각 단계가 정확히 한 번씩 수행되므로
전체 연산 횟수는 각 단계의 연산 횟수의 합이다.

??? example "연속된 두 반복문"

    ```
    Process(A, n):
        // 1단계: 최댓값 찾기
        max_val = A[0]
        for i = 1 to n - 1:
            if A[i] > max_val:
                max_val = A[i]

        // 2단계: 최댓값과 같은 원소 세기
        count = 0
        for i = 0 to n - 1:
            if A[i] == max_val:
                count = count + 1

        return count
    ```

    1단계는 $T_1(n) = \Theta(n)$에 실행된다. 2단계는 $T_2(n) = \Theta(n)$에 실행된다.
    합 규칙에 의해 $T(n) = \Theta(n) + \Theta(n) = \Theta(n)$이다.

## 최댓값 규칙

점근적 표현을 결합할 때 합은 가장 큰 항이 지배한다.
음이 아닌 함수 $f$와 $g$에 대해

$$
O(f(n)) + O(g(n)) = O(\max(f(n), g(n)))
$$

더 정확히 말하면, $T_1(n) = O(f(n))$이고 $T_2(n) = O(g(n))$이며 충분히 큰 모든
$n$에 대해 $f(n) \leq g(n)$이면 다음이 성립한다.

$$
T(n) = T_1(n) + T_2(n) = O(g(n))
$$

$f(n) + g(n) \leq 2g(n) = O(g(n))$이기 때문이다.

!!! tip "지배항이 이긴다"

    순차 단계들의 점근적 비용이 서로 다르면 가장 비싼 단계만이 중요하다.
    $\Theta(n^2)$ 단계 뒤에 $\Theta(n)$ 단계가 오면 전체는 $\Theta(n^2)$이다.
    점근적 의미에서 선형 단계는 "공짜"이다.

## 최댓값 규칙 적용하기

세 개의 순차 국면을 가진 알고리즘을 생각해 보자.

```
Algorithm(A, n):
    Phase1(A, n)        # O(n)
    Phase2(A, n)        # O(n^2)
    Phase3(A, n)        # O(n log n)
```

합 규칙과 최댓값 규칙에 의해

$$
T(n) = O(n) + O(n^2) + O(n \log n) = O(n^2)
$$

이차 국면이 지배한다.

??? example "정렬한 뒤 탐색하기"

    데이터를 정렬한 뒤 탐색을 여러 번 수행하는 것은 흔한 알고리즘 패턴이다.

    ```
    SortAndSearch(A, n, targets, m):
        Sort(A, n)                          # O(n log n)
        for i = 0 to m - 1:                 # m번 반복
            BinarySearch(A, n, targets[i])  # 각각 O(log n)
    ```

    1국면의 비용은 $O(n \log n)$이다. 2국면의 비용은 $O(m \log n)$이다. 합계는

    $$
    T(n, m) = O(n \log n) + O(m \log n) = O((n + m) \log n)
    $$

    $m = O(n)$이면 이는 $O(n \log n)$으로 간단해진다. $m \leq n$이므로 정렬이
    지배한다.

## 상수가 중요한 경우

최댓값 규칙은 상수 인자가 억제되는 점근적 분석에 적용된다. 실제로는 상수 인자가 큰
$O(n)$ 단계 두 개가 상수 인자가 작은 $O(n \log n)$ 단계 하나보다 느릴 수 있다.
현실적인 입력 크기에서 그렇다는 뜻이다. 순차 합성은 증가 속도를 알려줄 뿐 정확한
시간을 알려주지는 않는다.

??? example "실무에서의 상수"

    ```
    SlowLinear(A, n):       # 100n번 연산
    FastNlogN(A, n):        # 2n log n번 연산
    ```

    점근적으로는 `SlowLinear`가 더 빠르다($O(n)$ 대 $O(n \log n)$). 그러나
    $n < 2^{50}$에서는 상수가 작은 $n \log n$ 알고리즘이 실제로 더 빨리 끝난다.
    $\log_2 n < 50$일 때 $2n \log_2 n < 100n$이기 때문이다.

## 다른 규칙과의 합성

순차 합성은 반복문 규칙, 조건문 규칙과 결합된다.

| 구문 | 규칙 |
|---|---|
| `S1; S2`(나열) | $T_1(n) + T_2(n)$ |
| `for` 반복문 | 반복 횟수 $\times$ 몸체 비용 |
| `if-else` | 조건 $+$ 분기들의 최댓값 |
| 중첩 구문 | 안쪽에서 바깥쪽으로 규칙 적용 |

알고리즘의 전체 비용은 이 규칙들을 합성하여 만들어진다. 가장 안쪽 구문에서 시작해
바깥으로 나오면서, 같은 중첩 수준에 연속된 블록이 나타날 때마다 순차 합성을 적용한다.

!!! warning "실행 순서는 비용이 아니라 정확성에 중요하다"

    합 규칙 $T_1(n) + T_2(n)$은 어느 단계가 먼저 실행되든 같은 총합을 준다.
    그러나 순서를 바꾸면 알고리즘의 정확성이 달라질 수 있다. 합 규칙은 *비용* 에
    관한 서술이지 *의미* 에 관한 서술이 아니다.

## 연습문제

**연습문제 1.**
순차 합성에서 다룬 분석 기법을 너비 $d$인 층 $L$개로 이루어진 신경망의 순전파에 적용하라.

??? success "연습문제 1 풀이"
    각 층은 행렬 곱($O(d^2)$)과 활성화($O(d)$)를 수행한다. 이 절의 기법을 사용하여 층당 비용을 $L$개 층에 걸쳐 결합하면 전체 순전파 복잡도를 얻는다.

---

**연습문제 2.**
순차 합성의 분석 방법을 적용하여 작은 예제($n = 6$)를 따라가 보라. 정확한 연산 횟수를 세어라.

??? success "연습문제 2 풀이"
    $n = 6$에 대해 알고리즘이 수행하는 각 연산을 열거한다. 곱셈, 덧셈, 비교, 대입을 각각 따로 센다. 이를 합해 총합을 구한 뒤 빅오 표기법으로 표현한다.

---

**연습문제 3.**
순차 합성의 분석을 사용하여 학습 루프의 어느 단계(순전파, 역전파, 최적화기 갱신)가 전체 실행 시간을 지배하는지 판단하라.

??? success "연습문제 3 풀이"
    각 단계에 분석을 따로 적용한다. 순전파 $O(BPL)$, 역전파 $O(BPL)$, 최적화기 갱신 $O(P)$. 복잡도가 가장 큰 단계가 지배한다. 배치 크기가 크고 층이 많으면 순전파와 역전파(각각 $O(BPL)$)가 최적화기 갱신($O(P)$)을 지배한다.

---

**연습문제 4.**
순차 합성의 분석 기법이 논의된 알고리즘에 대해 꽉 조인 경계(상계와 하계가 일치)를 준다는 것을 증명하라.

??? success "연습문제 4 풀이"
    최악의 경우를 분석하여 상계를 보인다. 알고리즘이 최대 횟수의 연산을 수행하도록 강제하는 입력을 구성하여 하계를 보인다. 두 경계가 일치하면 분석이 꽉 조인 것이다($\Theta$ 표기법). $\square$
