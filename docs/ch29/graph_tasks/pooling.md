# Graph Pooling

Node-level GNN layers produce per-node embeddings, but many tasks---molecular
property prediction, graph classification, social network analysis---require a
single fixed-size representation for the entire graph.  Graph pooling bridges
this gap by aggregating node embeddings into a graph-level vector.

## Flat (Global) Pooling

The simplest approach applies a permutation-invariant aggregation function
over all node embeddings $\{\mathbf{h}_v : v \in V\}$.

### Sum, Mean, and Max Pooling

$$
\mathbf{h}_G^{\text{sum}} = \sum_{v \in V} \mathbf{h}_v, \quad
\mathbf{h}_G^{\text{mean}} = \frac{1}{|V|} \sum_{v \in V} \mathbf{h}_v, \quad
\mathbf{h}_G^{\text{max}} = \max_{v \in V} \mathbf{h}_v
$$

Each variant preserves different information:

| Method | Preserves | Loses |
|---|---|---|
| Sum | Graph size, total signal | Per-node detail |
| Mean | Average distribution | Graph size |
| Max | Extreme features | Frequency information |

!!! tip "Multi-Pool Strategy"
    Concatenating multiple pooling outputs captures complementary information:
    $\mathbf{h}_G = [\mathbf{h}_G^{\text{sum}} \| \mathbf{h}_G^{\text{mean}} \| \mathbf{h}_G^{\text{max}}]$.

### Attention Pooling

Assign a learned importance score to each node before aggregation:

$$
\mathbf{h}_G = \sum_{v \in V} \alpha_v \, \mathbf{h}_v
$$

where the attention weights are

$$
\alpha_v = \frac{\exp\!\bigl(f(\mathbf{h}_v)\bigr)}{\sum_{u \in V} \exp\!\bigl(f(\mathbf{h}_u)\bigr)}
$$

and $f$ is a learnable scoring function (typically a small MLP).  This allows
the model to focus on the most informative nodes.

## Hierarchical Pooling

Flat pooling compresses all nodes in one step, discarding graph structure.
Hierarchical methods coarsen the graph progressively, preserving multi-scale
structural information.

### DiffPool

DiffPool learns a soft assignment matrix $S^{(l)} \in \mathbb{R}^{n_l \times n_{l+1}}$
at each layer, mapping $n_l$ nodes to $n_{l+1}$ cluster nodes:

$$
X^{(l+1)} = S^{(l)\top} Z^{(l)}, \quad A^{(l+1)} = S^{(l)\top} A^{(l)} S^{(l)}
$$

where $Z^{(l)}$ is the GNN embedding at layer $l$ and $A^{(l)}$ is the
adjacency matrix.  The assignment matrix is generated by a separate GNN:

$$
S^{(l)} = \text{softmax}\!\bigl(\text{GNN}_{\text{pool}}(A^{(l)}, X^{(l)})\bigr)
$$

DiffPool is fully differentiable but requires specifying the number of
clusters at each level and has $O(n^2)$ memory cost due to the dense
assignment matrix.

### SAGPool (Self-Attention Graph Pooling)

SAGPool selects a subset of the most important nodes using a learned score:

$$
\mathbf{s} = \text{GNN}(A, X) \in \mathbb{R}^n
$$

The top-$k$ nodes by score are retained:

$$
\text{idx} = \text{top-}k(\mathbf{s}, \lceil k \cdot n \rceil), \quad
X' = X_{\text{idx}} \odot \sigma(\mathbf{s}_{\text{idx}})
$$

where $\odot$ denotes element-wise multiplication with the gated scores.
The adjacency matrix is also subsampled to match the retained nodes.

SAGPool is more memory-efficient than DiffPool since it avoids dense
assignment matrices.

### TopKPool

TopKPool is a simpler variant: it computes a scalar projection score per
node and keeps the top-$k$ fraction.  The score vector is

$$
\mathbf{s} = \frac{X \mathbf{p}}{\|\mathbf{p}\|}
$$

where $\mathbf{p}$ is a learnable projection vector.

## Implementation

```python
"""
Graph pooling operations for GNNs.

Demonstrates sum, mean, attention, and top-k pooling.
"""

import torch
import torch.nn as nn
import torch.nn.functional as F


# === Flat Pooling ===
def global_sum_pool(x: torch.Tensor, batch: torch.Tensor) -> torch.Tensor:
    """Sum pooling over nodes, grouped by batch index."""
    num_graphs = batch.max().item() + 1
    out = torch.zeros(num_graphs, x.size(1), device=x.device)
    out.scatter_add_(0, batch.unsqueeze(1).expand_as(x), x)
    return out


def global_mean_pool(x: torch.Tensor, batch: torch.Tensor) -> torch.Tensor:
    """Mean pooling over nodes, grouped by batch index."""
    sums = global_sum_pool(x, batch)
    counts = torch.zeros(sums.size(0), device=x.device)
    counts.scatter_add_(0, batch, torch.ones_like(batch, dtype=torch.float))
    return sums / counts.unsqueeze(1).clamp(min=1)


# === Attention Pooling ===
class AttentionPool(nn.Module):
    """Attention-weighted global pooling."""

    def __init__(self, in_dim: int, hidden_dim: int = 64):
        super().__init__()
        self.score_fn = nn.Sequential(
            nn.Linear(in_dim, hidden_dim),
            nn.Tanh(),
            nn.Linear(hidden_dim, 1),
        )

    def forward(self, x: torch.Tensor, batch: torch.Tensor) -> torch.Tensor:
        scores = self.score_fn(x)
        # Softmax per graph
        max_scores = torch.zeros(batch.max() + 1, 1, device=x.device)
        max_scores.scatter_reduce_(0, batch.unsqueeze(1), scores, reduce="amax")
        scores = scores - max_scores[batch]
        exp_scores = scores.exp()
        sum_exp = torch.zeros(batch.max() + 1, 1, device=x.device)
        sum_exp.scatter_add_(0, batch.unsqueeze(1), exp_scores)
        alpha = exp_scores / sum_exp[batch].clamp(min=1e-8)
        weighted = x * alpha
        return global_sum_pool(weighted, batch)


# === Example ===
if __name__ == "__main__":
    torch.manual_seed(42)
    # Two graphs batched: graph 0 has 3 nodes, graph 1 has 2 nodes
    x = torch.randn(5, 8)
    batch = torch.tensor([0, 0, 0, 1, 1])

    print("Sum pool shape:", global_sum_pool(x, batch).shape)    # [2, 8]
    print("Mean pool shape:", global_mean_pool(x, batch).shape)  # [2, 8]

    attn_pool = AttentionPool(in_dim=8)
    print("Attn pool shape:", attn_pool(x, batch).shape)         # [2, 8]
```

## Choosing a Pooling Method

| Method | Complexity | Structure preserved | Best for |
|---|---|---|---|
| Sum/Mean/Max | $O(n)$ | None | Small graphs, baselines |
| Attention | $O(n)$ | Learned importance | Variable-size graphs |
| DiffPool | $O(n^2)$ | Hierarchical clusters | Dense, structured graphs |
| SAGPool | $O(n)$ | Node selection | Large graphs, efficiency |
