# 38장: 밸류 기반 방법

밸류 기반 심층 강화학습은 표로 된 Q 함수를 뉴럴 네트워크로 바꾸어 차원이 높은 상태 공간의 둘레에서도 배울 수 있게 한다. 이 장은 DQN과 그 여러 개선, 오프폴리시 데이터를 위한 다단계 트레인 보정, 연속 액션으로의 넓힘, 고정된 데이터셋에서 배우는 오프라인 강화학습 방법, 평가의 가장 좋은 방식을 다룬다. 주문 실행, 시장 조성, 이산 액션 기반 거래 전략 같은 금융 응용을 곳곳에서 펼친다.

---

## 1. 차례

### 38.1 DQN

- DQN의 기초 -- 표로 된 Q 학습에서 시간차 로스를 쓰는 뉴럴 네트워크 함수 근사로
- 경험 리플레이 -- 리플레이 버퍼에 전이를 담고 뽑아 시간 상관을 끊고 데이터 효율을 높이기
- 타깃 네트워크 -- 온라인 네트워크를 가끔씩만 갱신하는 타깃 네트워크에서 떼어 놓아 트레인을 안정시키기
- DQN 구현 -- Q 학습, 경험 리플레이, 타깃 네트워크를 아우른 온전한 DQN 알고리즘과 의사 코드
- [DQN의 하이퍼파라미터](dqn/hyperparameters.md) -- 러닝레이트, 할인율, 버퍼 크기, 탐험 스케줄을 튜닝하는 법을 두루 안내

### 38.2 DQN 개선

- Double DQN -- 액션 선택과 평가를 떼어 놓아 Q 값 과대추정 다루기
- Dueling DQN -- 트레인을 효율적으로 하려 Q 값을 상태 값과 어드밴티지로 분해하기
- 우선순위 경험 리플레이 -- 중요도 샘플링 보정과 함께 시간차 오차의 크기에 비례해 전이 샘플링
- Noisy Networks -- 네트워크 웨이트의 파라미터 잡음으로 하는 상태에 의존하는 학습 기반 탐험
- 분포적 강화학습 -- 기댓값 대신 C51 범주형 원자로 리턴의 전체 분포 나타내기
- [Rainbow](improvements/rainbow.md) -- 서로 충돌하지 않는 DQN 개선 여섯 가지를 성능 좋은 에이전트 하나로 아우르기

### 38.3 다단계 트레인

- [n-step 리턴](multi_step/n_step_returns.md) -- 편향과 분산을 맞바꾸며 부트스트래핑 전에 실제 리워드를 여럿 써서 신용 할당을 낫게 하기
- Retrace(람다) -- 잘라 낸 중요도 샘플링 비율로 여러 스텝 타깃을 안전하게 오프폴리시 보정
- V-Trace -- 잘라 낸 중요도 웨이트로 분산 액터-러너 구조의 폴리시 지연 보정

### 38.4 연속 액션 공간

- [정규화 어드밴티지 함수(NAF)](continuous/naf.md) -- 연속 액션 DQN에서 argmax를 해석적으로 계산하게 하는 이차 형태 Q 함수 분해
- QT-Opt -- 어떤 Q 네트워크 구조에서도 액션을 추정으로 최적화하는 교차 엔트로피 방법

### 38.5 오프라인 강화학습

- 오프라인 강화학습의 기초 -- 둘레와 주고받지 않고 고정된 데이터셋에서 트레인하기, 분포 이동 문제, 일반 DQN이 실패하는 까닭
- [보수적 Q 학습(CQL)](offline/cql.md) -- 분포 밖 액션의 참값의 하한을 주는 비관적 Q 값 추정
- 배치 제약 Q 학습(BCQ) -- 오프라인 데이터셋에 있는 것과 닮은 액션만 고르도록 폴리시를 제약하기
- [암묵적 Q 학습(IQL)](offline/iql.md) -- 익스펙타일 회귀로 분포 밖 액션 질의를 아예 피하기

### 38.6 평가

- 트레인 곡선 -- 에피소드마다의 리턴과 진단 지표를 지켜보고 건강한 트레인과 그렇지 않은 트레인을 가려내기
- 벤치마크 -- 고전 제어와 아타리에서 연속 제어 벤치마크 모음에 이르는 표준 강화학습 평가 둘레
- 통계적 검정 -- 믿을 만한 알고리즘 비교를 위한 웰치 t 검정, 만-휘트니 U, 신뢰 구간

### 38.7 금융 응용

- 주문 실행 -- 시장 충격 비용을 가장 작게 하려 DQN으로 큰 포지션을 최적으로 처분하기
- [시장 조성](finance/market_making.md) -- DQN으로 재고 위험을 다루며 최적 호가 전략 트레인하기
- [이산 액션 기반 거래](finance/discrete_trading.md) -- 기술 피처와 거래 비용 벌점을 쓰는 DQN으로 매수/매도/보유 결정하기
