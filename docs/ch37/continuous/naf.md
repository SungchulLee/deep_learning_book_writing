# 33.4.1 정규화 어드밴티지 함수(NAF)

---

## 1. 연속 액션의 어려움

일반 DQN은 액션을 고르려면 $\arg\max_a Q(s, a)$ 가 필요한데, 이산 액션에서는 (모두 늘어놓으면 되니) 쉽지만 연속 액션 공간에서는 다룰 수 없다. **정규화 어드밴티지 함수(NAF)**(Gu et al., 2016)는 Q를 액션의 이차 함수로 적어 argmax를 해석적으로 계산할 수 있게 하여 이를 푼다.

---

## 2. NAF 분해

NAF는 Q를 상태 가치와 이차 형태 어드밴티지로 분해한다:

$$Q(s, a) = V(s) + A(s, a)$$

여기서 어드밴티지는 음정부호 이차식이다:

$$A(s, a) = -\frac{1}{2}(a - \mu(s))^T P(s) (a - \mu(s))$$

여기서:

- $V(s)$: 상태 밸류 함수(스칼라)
- $\mu(s)$: 상태 $s$의 최적 액션(액션 공간과 차원이 같은 벡터)
- $P(s) = L(s) L(s)^T$: 상태에 의존하는 양정부호 행렬
- $L(s)$: 대각이 양인 아래쪽 삼각 행렬(네트워크 출력에서)

---

## 3. 핵심 성질

1. **닫힌 형태 argmax**: $A(s, a) \leq 0$이고 $a = \mu(s)$에서 같으므로:

   $$\arg\max_a Q(s, a) = \mu(s)$$

   최적화가 필요 없다. 네트워크가 최적 액션을 곧바로 내놓는다.

2. **닫힌 형태 최대**: $\max_a Q(s, a) = V(s)$

3. **탐험**: 트레인하는 동안 $\mu(s)$에 가우스 잡음을 더한다:

   $$a = \mu(s) + \mathcal{N}(0, \sigma^2 I)$$

---

## 4. 구조

```
들임: 상태 s
  → 함께 쓰는 숨은 켜
  → Three output heads:
      V(s):  Linear → scalar
      μ(s):  Linear → action_dim (optimal action)
      L(s):  Linear → action_dim * (action_dim + 1) / 2
             → 아래 세모꼴로 형태 바꾸기
             → 양의 정부호를 다지려 exp(대각선)
  → P = L @ L^T
  → A(s,a) = -0.5 * (a-μ)^T P (a-μ)
  → Q(s,a) = V + A
```

---

## 5. 트레인

NAF는 경험 리플레이와 타깃 네트워크를 쓰는 DQN 트레인 루프를 그대로 쓴다:

$$\mathcal{L}(\theta) = \mathbb{E}\left[\left(r + \gamma V_{\theta^-}(s') - Q_\theta(s, a)\right)^2\right]$$

유의: $\max_a Q(s', a) = V(s')$이므로 타깃이 $r + \gamma V_{\theta^-}(s')$ 로 단순해진다.

---

## 6. 한계

- **단봉성**: 이차 형태는 상태마다 최적 액션이 하나라고 가정한다. 봉우리가 여럿인 액션 분포를 나타내지 못한다
- **표현력의 한계**: 이차 형태 어드밴티지는 복잡한 액션 값 지형을 담지 못할 수 있다
- **확장성**: 행렬 $P$ 가 액션 차원 $d$ 에 따라 $O(d^2)$ 으로 커진다
- **최근의 대안**: 연속 제어에서 DDPG, TD3, SAC이 NAF를 거의 대신했다

---

## 7. 금융과의 관계

NAF는 다음과 같은 연속적인 포트폴리오 배분에 쓸모 있다:

- 액션 = 포트폴리오 웨이트(연속)
- 이차 형태가 포트폴리오 최적화의 평균-분산 구조를 자연스럽게 담는다
- 양정부호 행렬 $P$ 를 상태에 의존하는 위험 벌점으로 해석할 수 있다

## 연습문제

<div class="drillbox" markdown>

**연습문제 1.** <span class="diff med" title="중간"></span>
$P(s) = L(s)L(s)^T$ 이고 $L(s)$ 가 대각 성분이 양수인 아래쪽 삼각 행렬이면 $P(s)$ 가 양정부호임을 보이고, 이로부터 「3. 핵심 성질」의 $\arg\max_a Q(s, a) = \mu(s)$ 와 $\max_a Q(s, a) = V(s)$ 를 이끌어라. 대각 성분에 `exp` 를 씌우지 않고 그대로 쓰면 무엇이 깨지는가?

</div>

??? success "풀이"
    $x \ne 0$ 이면 $x^T P x = x^T L L^T x = \|L^T x\|^2 \ge 0$ 이다. 대각이 모두 양수인 삼각 행렬은 행렬식이 대각의 곱이라 0 이 아니므로 $L^T$ 는 가역이고, $x \ne 0$ 이면 $L^T x \ne 0$ 이다. 따라서 $x^T P x > 0$ 이다. 그러면 $A(s, a) = -\tfrac12(a - \mu)^T P (a - \mu) \le 0$ 이고 등호는 $a = \mu(s)$ 에서만 성립한다. $V(s)$ 는 $a$ 와 무관하므로 $Q = V + A$ 는 $a = \mu(s)$ 에서 최대 $V(s)$ 를 갖는다. 대각을 그대로 쓰면 대각 성분이 0 이 될 수 있어 $P$ 가 양반정부호로 떨어지고, 그러면 어떤 방향으로는 $A$ 가 평평해져 최댓값이 한 점으로 정해지지 않는다. 대각의 부호는 $LL^T$ 에서 상쇄되므로 음수 자체는 문제가 아니지만, 0 을 지나는 순간이 문제다. `exp` 는 대각을 늘 양수로 묶어 이것을 막는다. $\square$

<div class="drillbox" markdown>

**연습문제 2.** <span class="diff hard" title="어려움"></span>
CartPole-v1 은 액션이 이산(2개)이라 NAF 를 쓸 까닭이 없다. 액션이 1차원 연속($[-2, 2]$)인 Pendulum-v1 에서 NAF 를 구현하라. $d = 1$ 일 때 $L$, $P$, $A$ 가 각각 무엇이 되는지 먼저 적고, 시드 여러 개로 트레인 곡선을 그려라.

</div>

??? success "풀이"
    $d = 1$ 이면 $L$ 의 출력은 $d(d+1)/2 = 1$ 개뿐이다. 네트워크가 낸 값 $\ell(s)$ 에 `exp` 를 씌워 $L = e^{\ell}$, $P = e^{2\ell}$ 이고 $A(s, a) = -\tfrac12 e^{2\ell(s)}(a - \mu(s))^2$ 이다. 곧 네트워크는 상태마다 스칼라 셋 $V$, $\mu$, $\ell$ 을 내는 셈이고, $Q$ 는 $a$ 에 대한 아래로 볼록한 포물선이다. $\mu$ 는 `tanh` 를 씌운 뒤 2 를 곱해 액션 범위 안에 둔다. 트레인은 「5. 트레인」의 로스 그대로이고, 탐험은 $\mu(s)$ 에 가우스 잡음을 더한 뒤 범위로 자른다. Gu 등처럼 타깃 네트워크를 소프트 업데이트($\tau \approx 0.001$~$0.005$)로 따라가게 하는 것이 흔하다. Pendulum 은 리워드가 늘 0 이하이고 에피소드가 200 스텝이므로, 에피소드 리턴이 처음의 큰 음수에서 0 쪽으로 올라오는지를 본다. 시드에 따라 곡선이 크게 흩어지므로 평균과 흩어짐을 함께 그리고, 수치는 직접 잰 값을 적어 둔다. $\square$

---

<div class="drillbox" markdown>

**연습문제 3.** <span class="diff med" title="중간"></span>
액션이 $d$ 차원일 때 NAF 네트워크의 출력 개수를 세고, 같은 액션 공간을 차원마다 $k$ 칸으로 나눠 일반 DQN 으로 푸는 경우와 견주어라. 자산 50 개의 포트폴리오 웨이트를 액션으로 삼는 금융 응용에서는 어느 쪽이 현실적인가?

</div>

??? success "풀이"
    NAF 의 출력은 $V$ 1 개, $\mu$ $d$ 개, $L$ 의 아래쪽 삼각 성분 $d(d+1)/2$ 개로 모두 $1 + d + d(d+1)/2$ 개이고, $A$ 를 계산하는 데 샘플마다 $O(d^2)$ 의 행렬–벡터 곱이 든다. 이산화한 DQN 은 액션 조합마다 출력이 하나라 $k^d$ 개가 필요하다. $d = 50$ 이면 NAF 는 $1 + 50 + 1{,}275 = 1{,}326$ 개로 충분하지만, $k = 3$ 으로 거칠게 나눠도 DQN 은 $3^{50} \approx 7 \times 10^{23}$ 개라 불가능하다. 그러니 이 규모에서는 NAF 쪽만 현실적이다. 다만 NAF 의 $O(d^2)$ 도 $d$ 가 수백을 넘으면 부담이 되고, 이차 형태라는 가정(「6. 한계」의 단봉성)이 맞는지가 더 큰 문제일 수 있다. $\square$

<div class="drillbox" markdown>

**연습문제 4.** <span class="diff med" title="중간"></span>
리워드 신호가 성기고(거래를 마칠 때만 실현되고) 지연되는 금융 거래 응용에 이 방법을 어떻게 맞출지 논하라.

</div>

??? success "풀이"
    성긴 리워드는 신용 할당을 어렵게 한다. 에이전트는 여러 스텝 전의 액션을 마지막에 생긴 이익이나 손실에 연결해야 한다. 해결책: (1) 최적 폴리시를 보존하면서 더 촘촘한 피드백을 주는 중간 신호(미실현 손익, 위험 지표)로 리워드 셰이핑, (2) 성긴 리워드를 더 효율적으로 뒤로 전파하는 멀티스텝 리턴, (3) 지난 경험에 실제로 이룬 결과로 새 레이블을 붙이는 사후 경험 리플레이(hindsight experience replay). NAF 자체는 신용 할당을 돕지 않는다. 타깃 $r + \gamma V_{\theta^-}(s')$ 이 한 스텝 타깃이므로 (2)의 멀티스텝 리턴을 따로 붙여야 한다. 대신 「7. 금융과의 관계」처럼 $P(s)$ 를 위험 벌점으로 읽을 수 있어, 어드밴티지의 형태가 평균–분산 구조와 맞아떨어지는 문제라면 적은 데이터로도 안정적으로 배울 여지가 있다. $\square$
