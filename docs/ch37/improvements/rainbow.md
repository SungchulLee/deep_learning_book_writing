# Rainbow

**Rainbow**(Hessel et al., 2018)는 서로 충돌하지 않는 DQN 개선 여섯 가지를 하나로 아우른 에이전트다:

1. **Double DQN** — 과대추정 바이어스를 줄인다
2. **듀얼링 구조** — 값과 어드밴티지를 나눈다
3. **우선순위 경험 리플레이** — 정보가 많은 전이에 집중한다
4. **여러 스텝 리턴**(n-step) — 리워드를 여러 스텝 뒤로 한 번에 전파해 신용 할당이 빨라진다
5. **분포적 강화학습**(C51) — 리턴의 전체 분포를 나타낸다
6. **Noisy Networks** — 학습 기반 탐험(ε 그리디를 대신한다)

---

## 1. 구조

Rainbow는 **NoisyLinear** 레이어를 가진 **듀얼링** 네트워크를 써서 리턴에 대한 **범주형 분포**(C51)를 내놓는다:

```
들임: 상태
  → 함께 쓰는 확률 켜
  → 값 클래스와 이점 클래스로 가름
  → 클래스마다 NoisyLinear 켜를 씀
  → Value stream: (n_atoms,) — distribution of V(s)
  → Advantage stream: (action_dim × n_atoms) — distribution of A(s, a)
  → Combine: Z(s, a) = V(s) + A(s, a) - mean(A)  [distributional]
  → 알갱이 위의 소프트맥스
```

---

## 2. 학습 알고리즘

```
For each training step:
  1. Sample prioritized batch from replay buffer (PER)
  2. Compute n-step distributional targets (C51 + n-step)
  3. 타깃의 액션 고르기에 겹 DQN을 씀
  4. Compute distributional cross-entropy loss with IS weights (PER)
  5. 로스를 바탕으로 우선순위를 고침
  6. No ε-greedy needed (NoisyNets handle exploration)
```

---

## 3. n-step 타깃 아우르기

Rainbow는 C51과 함께 n-step 리턴을 쓴다:

$$R^{(n)}_t = \sum_{k=0}^{n-1} \gamma^k r_{t+k}$$

$$y_t = R^{(n)}_t + \gamma^n Z_{\theta^-}(s_{t+n}, a^*)$$

여기서 $a^*$ 는 온라인 네트워크가 고른 액션(Double DQN)이고, 분포 $Z$ 의 원자를 $R^{(n)}_t + \gamma^n z_j$ 로 옮긴 뒤 C51 처럼 고정된 원자 위로 투영한다. 이를 위해 리플레이 버퍼는 연속된 전이 $n$개를 묶어 $n$-step 리턴을 미리 계산해 두어야 하고, 그 사이에 에피소드가 끝나면 거기서 합을 끊고 부트스트랩하지 않는다.

---

## 4. 어블레이션 결과

Hessel 등(2018)이 포괄적인 어블레이션 실험을 했다. 구성 요소를 하나씩 뺐을 때:

| 뺀 구성 요소 | 중앙값 점수 하락 |
|-------------------|------------------|
| 우선순위 경험 리플레이 | 가장 크게 떨어짐 |
| 여러 스텝 리턴 | 크게 떨어짐 |
| 분포(C51) | 중간 정도 떨어짐 |
| Noisy Networks | 중간 정도 떨어짐 |
| 듀얼링 | 조금 떨어짐 |
| Double DQN | 조금 떨어짐 |

**핵심 발견**: 우선순위 경험 리플레이와 여러 스텝 리턴이 Rainbow의 성능에 가장 크게 기여했다.

---

## 5. 실용적인 고려

### 하이퍼파라미터

| 파라미터 | Rainbow 값 |
|-----------|--------------|
| n-step | 3 |
| 원자(C51) | 51 |
| $V_\text{min}, V_\text{max}$ | -10, 10 |
| 우선순위 경험 리플레이 $\alpha$ | 0.5 |
| 우선순위 경험 리플레이 $\beta$ | 0.4 → 1.0 |
| Noisy Networks $\sigma_0$ | 0.5 |
| 러닝레이트 | 6.25 × 10⁻⁵ |
| 배치 크기 | 32 |
| 타깃 갱신 빈도 | 8000 |

### 계산 비용

Rainbow는 다음 때문에 학습 스텝마다 DQN의 2배쯤 계산이 든다:

- 분포 출력(액션마다 출력이 1개가 아니라 원자 51개)
- 우선순위 경험 리플레이의 합 트리 연산
- NoisyLinear의 순전파

그래도 샘플 효율이 좋아져 흔히 그 이상을 메운다.

---

## 6. 간단히 한 Rainbow

실제 쓰임새에서는 영향이 가장 큰 구성 요소 셋을 아우른 간단한 버전으로도 흔히 충분하다:

- **우선순위 경험 리플레이** + **여러 스텝 리턴** + **Double DQN**

이는 구현이 훨씬 단순하면서도 Rainbow가 얻는 것의 80%쯤을 담는다.

## 연습문제

<div class="drillbox" markdown>

**연습문제 1.** <span class="diff med" title="중간"></span>
여섯 구성 요소는 원래 스칼라 Q 값을 전제로 만들어졌다. Rainbow 가 C51 의 분포 출력과 함께 쓰려면 (가) Double DQN 의 액션 선택, (나) 우선순위 경험 리플레이의 우선순위, (다) 듀얼링의 결합을 각각 어떻게 바꿔야 하는지 설명하라.

</div>

??? success "풀이"
    (가) 분포에는 $\arg\max$ 를 바로 쓸 수 없으므로, 온라인 네트워크가 내는 분포의 평균 $\sum_j z_j p_j(s', a)$ 로 $a^*$ 를 고르고, 그 $a^*$ 에 대한 분포는 타깃 네트워크에서 가져온다. (나) 스칼라 TD 오차 $|\delta|$ 가 없으므로, 투영한 타깃 분포와 온라인 분포 사이의 교차 엔트로피(KL 발산과 상수 차이) 로스를 우선순위로 쓴다. Hessel 등은 이것이 TD 오차의 절댓값보다 노이즈에 덜 흔들린다고 보았다. (다) 값 스트림은 원자 수만큼, 어드밴티지 스트림은 액션 수 × 원자 수만큼 로짓을 내고, 원자마다 $V + A - \text{mean}_a A$ 로 합친 뒤 원자 축으로 소프트맥스를 해 액션마다 확률 분포를 만든다. 로짓 수준에서 합치므로 결과는 늘 올바른 확률 분포다. $\square$

---

<div class="drillbox" markdown>

**연습문제 2.** <span class="diff hard" title="어려움"></span>
$n = 3$, $\gamma = 0.99$ 이고 세 스텝 동안 리워드가 모두 1 인 전이에서 $R^{(3)}_t$ 와 원자 $z_j$ 가 옮겨 가는 자리 $R^{(3)}_t + \gamma^3 z_j$ 를 구하라. 두 번째 스텝에서 에피소드가 끝났다면 타깃은 어떻게 되는가? $n$ 을 크게 할 때의 이득과 대가도 적어라.

</div>

??? success "풀이"
    $R^{(3)}_t = 1 + 0.99 + 0.99^2 = 2.9701$ 이고 $\gamma^3 = 0.970299$ 이므로 원자 $z_j$ 는 $2.9701 + 0.970299\,z_j$ 로 옮겨 간 뒤 고정된 원자 위로 투영된다. 두 번째 스텝($t+1$)에서 끝났다면 합은 $r_t + \gamma r_{t+1} = 1.99$ 에서 끊기고, 그 뒤는 부트스트랩하지 않으므로 타깃 분포는 1.99 한 점에 몰린 분포를 투영한 것이다. $n$ 을 키우면 실제 리워드가 더 많이 들어가 부트스트랩의 바이어스가 줄고 리워드가 빨리 전파된다. 하지만 그 $n$ 스텝의 행동은 지금 폴리시가 아니라 버퍼에 저장된 옛 폴리시의 것이라, 오프폴리시 보정 없이 쓰면 바이어스가 생기고 리턴의 분산도 커진다. Rainbow 가 $n = 3$ 처럼 작은 값을 쓰는 까닭이다. $\square$

<div class="drillbox" markdown>

**연습문제 3.** <span class="diff med" title="중간"></span>
기본 DQN에 비해 이 방법이 더하는 계산·메모리 오버헤드를 분석하라. 금융 응용에서 그 트레이드오프가 값을 하는가?

</div>

??? success "풀이"
    구성 요소마다 오버헤드가 다르다. Double DQN 은 다음 상태에 대한 순전파를 한 번 더 하고, 듀얼링은 스트림 하나만큼 파라메터를 더 두며, C51 은 출력이 액션마다 원자 51 개로 늘고 투영 계산이 붙는다. 우선순위 경험 리플레이는 합 트리 메모리와 $O(\log N)$ 의 뽑기·갱신 비용을, NoisyLinear 는 레이어마다 $\sigma$ 파라메터와 노이즈 생성 비용을 더한다. 데이터가 비싸고 실수가 값비싼 금융 응용에서는 샘플 효율과 안정성이 좋아지므로 오버헤드가 값을 한다. 금융 상태 공간은 흔히 차원이 중간 정도이므로(피처 10~100개) 스텝마다 늘어나는 비용이 더 나은 결정의 가치에 견주면 크지 않다. $\square$

<div class="drillbox" markdown>

**연습문제 4.** <span class="diff med" title="중간"></span>
리워드 신호가 성기고(거래를 마칠 때만 실현되고) 지연되는 금융 거래 응용에 이 방법을 어떻게 맞출지 논하라.

</div>

??? success "풀이"
    성긴 리워드는 신용 할당을 어렵게 한다. 에이전트는 여러 스텝 전의 액션을 마지막에 생긴 이익이나 손실에 연결해야 한다. 해결책: (1) 최적 폴리시를 보존하면서 더 촘촘한 피드백을 주는 중간 신호(미실현 손익, 위험 지표)로 리워드 셰이핑, (2) 성긴 리워드를 더 효율적으로 뒤로 전파하는 멀티스텝 리턴, (3) 지난 경험에 실제로 이룬 결과로 새 레이블을 붙이는 사후 경험 리플레이(hindsight experience replay). Rainbow 안에서는 n-step 리턴이 (2)를 이미 맡고, 우선순위 경험 리플레이가 드물게 나오는 리워드 전이를 자주 다시 뽑아 준다. 거래 손익처럼 리턴의 꼬리가 두꺼운 문제에서는 C51 의 분포 출력이 위험을 따로 볼 수 있게 해 주지만, 지지 구간 $[V_\min, V_\max]$ 를 손익 규모에 맞게 다시 잡아야 한다. $\square$
