# 33.2.6 Rainbow

**Rainbow**(Hessel et al., 2018)는 DQN의 서로 충돌하지 않는 개선 여섯 가지를 하나로 아우른 에이전트다:

1. **Double DQN** — 과대추정 바이어스를 줄인다
2. **듀얼링 구조** — 값과 어드밴티지를 나눈다
3. **우선순위 경험 리플레이** — 정보가 많은 전이에 집중한다
4. **여러 스텝 리턴**(n-step) — 신용 할당이 낫다
5. **분포 강화학습**(C51) — 리턴의 전체 분포를 나타낸다
6. **Noisy Networks** — 학습 기반 탐험(ε 그리디를 대신한다)

---

## 1. 구조

Rainbow는 **NoisyLinear** 레이어를 가진 **듀얼링** 네트워크를 써서 리턴에 대한 **범주형 분포**(C51)를 내놓는다:

```
들임: 상태
  → 함께 쓰는 확률 켜
  → 값 클래스와 이점 클래스로 가름
  → 클래스마다 NoisyLinear 켜를 씀
  → Value stream: (n_atoms,) — distribution of V(s)
  → Advantage stream: (action_dim × n_atoms) — distribution of A(s, a)
  → Combine: Z(s, a) = V(s) + A(s, a) - mean(A)  [distributional]
  → 알갱이 위의 소프트맥스
```

---

## 2. 학습 알고리즘

```
For each training step:
  1. Sample prioritized batch from replay buffer (PER)
  2. Compute n-step distributional targets (C51 + n-step)
  3. 타깃의 액션 고르기에 겹 DQN을 씀
  4. Compute distributional cross-entropy loss with IS weights (PER)
  5. 로스를 바탕으로 우선순위를 고침
  6. No ε-greedy needed (NoisyNets handle exploration)
```

---

## 3. n-step 타깃 아우르기

Rainbow는 C51과 함께 n-step 리턴을 쓴다:

$$R^{(n)}_t = \sum_{k=0}^{n-1} \gamma^k r_{t+k}$$

$$y_t = R^{(n)}_t + \gamma^n Z_{\theta^-}(s_{t+n}, a^*)$$

이는 연속된 전이 $n$개를 담고 잘라 낸 리턴을 계산해야 한다.

---

## 4. 어블레이션 결과

Hessel 등(2018)이 포괄적인 어블레이션 실험을 했다. 구성 요소를 하나씩 뺐을 때:

| 뺀 구성 요소 | 중앙값 점수 하락 |
|-------------------|------------------|
| 우선순위 경험 리플레이 | 가장 크게 떨어짐 |
| 여러 스텝 리턴 | 크게 떨어짐 |
| 분포(C51) | 중간 정도 떨어짐 |
| Noisy Networks | 중간 정도 떨어짐 |
| 듀얼링 | 조금 떨어짐 |
| Double DQN | 조금 떨어짐 |

**핵심 발견**: 우선순위 경험 리플레이와 여러 스텝 리턴이 Rainbow의 성능에 가장 크게 기여했다.

---

## 5. 실용적인 고려

### 하이퍼파라미터

| 파라미터 | Rainbow 값 |
|-----------|--------------|
| n-step | 3 |
| 원자(C51) | 51 |
| $V_\text{min}, V_\text{max}$ | -10, 10 |
| 우선순위 경험 리플레이 $\alpha$ | 0.5 |
| 우선순위 경험 리플레이 $\beta$ | 0.4 → 1.0 |
| Noisy Networks $\sigma_0$ | 0.5 |
| 러닝레이트 | 6.25 × 10⁻⁵ |
| 배치 크기 | 32 |
| 타깃 갱신 빈도 | 8000 |

### 계산 비용

Rainbow는 다음 때문에 학습 스텝마다 DQN의 2배쯤 계산이 든다:

- 분포 출력(원자 51개 × 액션 수 대 1 × 액션 수)
- 우선순위 경험 리플레이의 합 트리 연산
- NoisyLinear의 순전파

그래도 샘플 효율이 좋아져 흔히 그 이상을 메운다.

---

## 6. 간단히 한 Rainbow

실제 쓰임새에서는 영향이 가장 큰 구성 요소 셋을 아우른 간단한 버전으로도 흔히 충분하다:

- **우선순위 경험 리플레이** + **여러 스텝 리턴** + **Double DQN**

이는 구현이 훨씬 단순하면서도 Rainbow가 얻는 것의 80%쯤을 담는다.

## 연습문제

<div class="drillbox" markdown>

**연습문제 1.** <span class="diff med" title="중간"></span>
Q 값 근사에 뉴럴 네트워크를 쓰는 어려움을 이 방법이 어떻게 다루는지 설명하라. 이 방법이 없으면 어떤 불안정이 생기는가?

</div>

??? success "풀이"
    뉴럴 네트워크로 Q 값을 근사하면 순차 데이터의 상관과 움직이는 타깃 문제(타깃이 현재 파라미터에 의존한다) 때문에 불안정하다. 이 방법은 특정 구조나 알고리즘 선택으로 이 문제를 다룬다. 이것이 없으면 그래디언트 갱신이 계속 바뀌는 타깃을 좇아 학습이 발산하고 파국적인 과대추정이나 진동이 생긴다. 이 방법은 상관을 끊거나 일정 기간 타깃을 고정해 학습을 안정시킨다. $\square$

---

<div class="drillbox" markdown>

**연습문제 2.** <span class="diff hard" title="어려움"></span>
CartPole-v1 둘레에서 이 방법을 구현하라. 둘레를 푸는 데(100 에피소드 평균 리워드 > 475) 필요한 에피소드 수를 보고하고 학습 곡선을 그려라.

</div>

??? success "풀이"
    은닉 유닛 64개의 2레이어 MLP, 러닝레이트 $3 \times 10^{-4}$의 Adam, 이 절의 기법을 쓰면 에이전트가 보통 200~500 에피소드에 CartPole을 푼다. 학습 곡선은 처음의 무작위 수준 성능(리워드 $\approx 20$), 빠르게 좋아지는 구간, 최적에 가까운 성능으로의 수렴을 보인다. 핵심 구현 세부: 리플레이 버퍼 크기 10000, 배치 크기 64, 100스텝마다 타깃 네트워크 갱신, 300 에피소드에 걸쳐 1.0에서 0.01로 선형 감소하는 $\epsilon$-그리디. $\square$

<div class="drillbox" markdown>

**연습문제 3.** <span class="diff med" title="중간"></span>
기본 DQN에 비해 이 방법이 더하는 계산·메모리 오버헤드를 분석하라. 금융 응용에서 그 트레이드오프가 값을 하는가?

</div>

??? success "풀이"
    오버헤드는 방법마다 다르지만 보통 순전파를 더 하거나(Double DQN은 2배), 네트워크 파라미터를 더 두거나(듀얼링 구조), 메모리를 더 쓴다(우선순위 경험 리플레이). 데이터가 비싸고 실수가 값비싼 금융 응용에서는 샘플 효율과 안정성이 좋아지므로 오버헤드가 값을 한다. 금융 상태 공간은 흔히 차원이 중간 정도이므로(피처 10~100개) 스텝마다 늘어나는 비용이 더 나은 결정의 가치에 견주면 크지 않다. $\square$

---

<div class="drillbox" markdown>

**연습문제 4.** <span class="diff med" title="중간"></span>
리워드 신호가 성기고(거래를 마칠 때만 실현되고) 지연되는 금융 거래 응용에 이 방법을 어떻게 맞출지 논하라.

</div>

??? success "풀이"
    성긴 리워드는 신용 할당을 어렵게 한다. 에이전트는 여러 스텝 전의 액션을 마지막에 생긴 이익이나 손실에 연결해야 한다. 해결책: (1) 최적 폴리시를 보존하면서 더 촘촘한 피드백을 주는 중간 신호(미실현 손익, 위험 지표)로 리워드 셰이핑, (2) 성긴 리워드를 더 효율적으로 뒤로 전파하는 멀티스텝 리턴, (3) 지난 경험에 실제로 이룬 결과로 새 레이블을 붙이는 사후 경험 리플레이(hindsight experience replay). 이 절의 방법은 드문 리워드 신호에서 배우는 안정성을 높여 기여한다. $\square$
