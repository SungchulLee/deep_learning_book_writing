# 33.2.6 Rainbow

**무지개**(Hessel et al., 2018)는 DQN의 서로 어긋나지 않는 좋게 하기 여섯을 하나로 아우른 에이전트다:

1. **Double DQN** — 지나친 어림 편향을 줄인다
2. **맞겨루기 구조** — 값과 이점 갈래를 나눈다
3. **앞섬 경험 리플레이** — 앎이 많은 옮김에 집중한다
4. **여러 걸음 리턴**(n-step) — 공 돌리기가 낫다
5. **분포 강화학습**(C51) — 리턴의 온 분포를 나타낸다
6. **Noisy Networks** — 배우는 살펴보기(ε 욕심쟁이를 대신한다)

---

## 1. 구조

무지개는 **NoisyLinear** 층을 가진 **맞겨루기** 네트워크를 써서 리턴에 대한 **갈래 분포**(C51)를 내놓는다:

```
들임: 상태
  → 함께 쓰는 낌새 켜
  → 값 갈래와 이점 갈래로 가름
  → 갈래마다 NoisyLinear 켜를 씀
  → Value stream: (n_atoms,) — distribution of V(s)
  → Advantage stream: (action_dim × n_atoms) — distribution of A(s, a)
  → Combine: Z(s, a) = V(s) + A(s, a) - mean(A)  [distributional]
  → 알갱이 위의 소프트맥스
```

---

## 2. 학습 알고리즘

```
For each training step:
  1. Sample prioritized batch from replay buffer (PER)
  2. Compute n-step distributional targets (C51 + n-step)
  3. 과녁의 움직임 고르기에 겹 DQN을 씀
  4. Compute distributional cross-entropy loss with IS weights (PER)
  5. 손실을 바탕으로 우선순위를 고침
  6. No ε-greedy needed (NoisyNets handle exploration)
```

---

## 3. n-step 과녁 아우르기

무지개는 C51과 함께 n-step 리턴을 쓴다:

$$R^{(n)}_t = \sum_{k=0}^{n-1} \gamma^k r_{t+k}$$

$$y_t = R^{(n)}_t + \gamma^n Z_{\theta^-}(s_{t+n}, a^*)$$

이는 잇단 옮김 $n$개를 담고 잘라 낸 리턴을 셈해야 한다.

---

## 4. 떼어 보기 결과

Hessel 등(2018)이 두루 떼어 보기를 했다. 조각을 하나씩 뺐을 때:

| 뺀 조각 | 가운뎃값 점수 떨어짐 |
|-------------------|------------------|
| 우선순위 경험 리플레이 | 가장 크게 떨어짐 |
| 여러 걸음 리턴 | 크게 떨어짐 |
| 분포(C51) | 웬만큼 떨어짐 |
| Noisy Networks | 웬만큼 떨어짐 |
| 맞겨루기 | 조금 떨어짐 |
| Double DQN | 조금 떨어짐 |

**핵심 발견**: 우선순위 경험 리플레이와 여러 걸음 리턴이 무지개의 성능에 가장 크게 이바지했다.

---

## 5. 실용적인 고려

### 하이퍼파라미터

| 잡 | 무지개 값 |
|-----------|--------------|
| n-step | 3 |
| 원자(C51) | 51 |
| $V_\text{min}, V_\text{max}$ | -10, 10 |
| 우선순위 경험 리플레이 $\alpha$ | 0.5 |
| 우선순위 경험 리플레이 $\beta$ | 0.4 → 1.0 |
| Noisy Networks $\sigma_0$ | 0.5 |
| 학습률 | 6.25 × 10⁻⁵ |
| 배치 크기 | 32 |
| 과녁 고침 잦음 | 8000 |

### 계산 비용

무지개는 다음 때문에 학습 걸음마다 DQN의 2배쯤 계산이 든다:

- 분포 내놓기(원자 51개 × 행동 대 1 × 행동)
- 우선순위 경험 리플레이의 합 나무 연산
- NoisyLinear의 앞으로 가기

그래도 표본 효율이 좋아져 흔히 그 이상을 메운다.

---

## 6. 간단히 한 무지개

실제 쓰임새에서는 영향이 가장 큰 조각 셋을 아우른 간단한 판으로 흔히 넉넉하다:

- **우선순위 경험 리플레이** + **여러 걸음 리턴** + **Double DQN**

이는 짜기가 훨씬 단순하면서도 무지개가 얻는 것의 80%쯤을 담는다.

## 연습문제

<div class="drillbox" markdown>

**연습문제 1.** <span class="diff med" title="중간"></span>
Q 값 어림에 신경망을 쓰는 어려움을 이 방법이 어떻게 다루는지 밝혀라. 이 길이 없으면 어떤 불안정이 생기는가?

</div>

??? success "연습문제 1 풀이"
    신경망 Q 값 어림은 차례 데이터의 얽힘과 움직이는 과녁 문제(과녁이 지금 잡에 매인다) 때문에 불안정하다. 이 방법은 특정 구조나 알고리즘 공정성으로 이 말썽을 다룬다. 이것이 없으면 기울기 고침이 한결같지 않은 과녁을 좇아 학습이 발산하고 재앙 같은 지나친 어림이나 흔들림이 생긴다. 이 길은 얽힘을 끊거나 얼마 동안 과녁을 붙박아 학습을 안정시킨다. $\square$

---

<div class="drillbox" markdown>

**연습문제 2.** <span class="diff hard" title="어려움"></span>
CartPole-v1 둘레에서 이 방법을 짜라. 둘레를 푸는 데(100판 평균 보상 > 475) 필요한 판수를 알리고 학습 굽은 줄을 그려라.

</div>

??? success "연습문제 2 풀이"
    숨은 낱덩이 64개의 2층 여러 층 신경망, 학습률 $3 \times 10^{-4}$의 Adam, 이 마디의 재주를 쓰면 에이전트가 보통 200~500판에 CartPole을 푼다. 학습 굽은 줄은 처음의 아무 성능(보상 $\approx 20$), 빠르게 좋아지는 마당, 거의 가장 좋은 성능으로의 수렴을 보인다. 핵심 짜기 세부: 되돌려 보기 버퍼 크기 10000, 배치 크기 64, 100걸음마다 타깃 네트워크 고침, 300판에 걸쳐 1.0에서 0.01로 선형으로 스러지는 $\epsilon$ 욕심쟁이. $\square$

---

<div class="drillbox" markdown>

**연습문제 3.** <span class="diff med" title="중간"></span>
맨 DQN에 비교하여 이 방법이 더하는 계산과 기억 덧짐을 살펴라. 금융 응용에서 그 트레이드오프가 값을 하는가?

</div>

??? success "연습문제 3 풀이"
    덧짐은 방법마다 다르지만 보통 앞으로 가기를 더 하거나(Double DQN은 2배), 네트워크 잡을 더 두거나(맞겨루기 갈래), 기억을 더 쓴다(우선순위 경험 리플레이). 데이터가 비싸고 실수가 값비싼 금융 응용에서는 표본 효율과 안정이 좋아지므로 덧짐이 값을 한다. 금융 상태 자리는 흔히 차원이 웬만하므로(특징 10~100개) 걸음마다 늘어나는 비용이 더 나은 결정의 값어치에 견주면 크지 않다. $\square$

---

<div class="drillbox" markdown>

**연습문제 4.** <span class="diff med" title="중간"></span>
보상 신호가 성기고(거래를 마칠 때만 실현되고) 늦는 금융 거래 쓰임새에 이 방법을 어떻게 맞출지 다루어라.

</div>

??? success "연습문제 4 풀이"
    성긴 보상은 공 돌리기를 어렵게 한다. 에이전트는 여러 걸음 전의 행동을 끝내 생긴 이익이나 손실에 이어야 한다. 맞추는 길: (1) 가장 좋은 정책을 지키면서 더 빽빽한 피드백을 주는 중간 신호(실현되지 않은 손익, 위험 잣대)로 보상 다듬기, (2) 성긴 보상을 더 효율 좋게 뒤로 퍼뜨리는 여러 걸음 리턴, (3) 지난 겪음에 이룬 결과로 새 레이블을 붙이는 뒤늦은 경험 리플레이. 이 마디의 방법은 드문 보상 신호에서 배우는 안정을 높여 이바지한다. $\square$
